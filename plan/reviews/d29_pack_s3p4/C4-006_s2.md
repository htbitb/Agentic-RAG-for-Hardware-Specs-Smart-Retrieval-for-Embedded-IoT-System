### Clock Configuration: SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz (STM32G474)

To run the STM32G474 at its maximum frequency of 170 MHz using HSI16 (16 MHz) as the PLL input, several hardware requirements specified in the Reference Manual [STM32G474_RM0440 p.98, p.267, p.279] and the Datasheet [STM32G474_Datasheet p.123] must be met:

1. **Voltage Scaling (Range 1 Boost Mode):**
   - The device powers on in Range 1 normal mode (maximum frequency 150 MHz [STM32G474_Datasheet p.123]).
   - To operate up to 170 MHz, Range 1 Boost mode must be activated by clearing the `R1MODE` bit in `PWR_CR5` (`PWR->CR5 &= ~PWR_CR5_R1MODE;`) [STM32G474_RM0440 p.267].
   - The PWR clock gate (`RCC_APB1ENR1_PWREN`) must be enabled first.

2. **Flash Read Latency (Wait States):**
   - According to RM0440 Table 9 (Category 3 devices) [STM32G474_RM0440 p.98], in Range 1 Boost mode with $136\text{ MHz} < HCLK \le 170\text{ MHz}$, the flash read access latency must be set to **4 wait states** (`LATENCY = 4WS`).
   - The wait states must be increased and verified before switching to the higher frequency [STM32G474_RM0440 p.99].

3. **PLL Multipliers & Dividers:**
   - Input clock: $\text{HSI16} = 16\text{ MHz}$ (`PLLSRC = 0b10`).
   - Division factor $M$: set to 4 (`PLLM = 3`, i.e., $4 - 1$), resulting in $f_{\text{VCO\_IN}} = 16 / 4 = 4\text{ MHz}$ (valid range: $2.66\text{ MHz}$ to $16\text{ MHz}$ [STM32G474_Datasheet p.123]).
   - Multiplication factor $N$: set to 85 (`PLLN = 85`), resulting in $f_{\text{VCO\_OUT}} = 4 \times 85 = 340\text{ MHz}$ (valid range in Range 1: $96\text{ MHz}$ to $344\text{ MHz}$ [STM32G474_Datasheet p.123]).
   - Division factor $R$: set to 2 (`PLLR = 0`, i.e., $2/2 - 1$), giving $f_{\text{PLL\_R}} = 340 / 2 = 170\text{ MHz}$ (up to $170\text{ MHz}$ in boost mode [STM32G474_Datasheet p.123]).
   - Enable PLL "R" clock output (`PLLREN = 1`).

4. **Safe Clock Transition for $HCLK > 80\text{ MHz}$:**
   - Per RM0440 section 7.2.7 (*System clock selection*) [STM32G474_RM0440 p.279], when switching from HSI16 to a PLL frequency higher than $80\text{ MHz}$, the AHB prescaler should first be configured to divide the frequency by 2 (`HPRE = div2`), the clock switch to PLL performed, a delay of at least $1\ \mu\text{s}$ observed, and then the AHB prescaler returned to division by 1.

```c
#include "stm32g4xx.h"

/**
 * @brief  Configures the system clock to 170 MHz using the PLL fed by HSI16.
 *         SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz.
 */
void SystemClock_Config(void)
{
    /* 1. Enable PWR peripheral clock to access power control registers */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* 2. Switch to Range 1 Boost Mode (required for SYSCLK > 150 MHz)
     *    R1MODE bit in PWR_CR5: 0 = Boost mode, 1 = Normal mode [STM32G474_RM0440 p.267]
     */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 3. Configure Flash read access latency:
     *    In Range 1 Boost mode with HCLK = 170 MHz, 4 wait states (4WS) are required
     *    [STM32G474_RM0440 p.98].
     */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY_Msk) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY_Msk) != FLASH_ACR_LATENCY_4WS) {
        /* Wait until the new latency is taken into account */
    }

    /* 4. Configure PLL:
     *    - Source: HSI16 (16 MHz) -> PLLSRC = 0b10
     *    - PLLM = 4 (value 3)    -> VCO_IN = 16 MHz / 4 = 4 MHz [STM32G474_Datasheet p.123]
     *    - PLLN = 85             -> VCO_OUT = 4 MHz * 85 = 340 MHz [STM32G474_Datasheet p.123]
     *    - PLLR = 2 (value 0)    -> PLLCLK = 340 MHz / 2 = 170 MHz [STM32G474_Datasheet p.123]
     *    - PLLREN = 1            -> Enable PLL "R" output
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_1 |
                   (3U << RCC_PLLCFGR_PLLM_Pos) |
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   (0U << RCC_PLLCFGR_PLLR_Pos) |
                   RCC_PLLCFGR_PLLREN;

    /* 5. Enable the Main PLL and busy-wait until PLLRDY is set */
    RCC->CR |= RCC_CR_PLLON;
    while ((RCC->CR & RCC_CR_PLLRDY) == 0U) {
        /* Busy-wait for PLL lock */
    }

    /* 6. Intermediate AHB prescaler:
     *    Stepping through HCLK/2 when switching from HSI16 to PLL > 80 MHz
     *    [STM32G474_RM0440 p.279].
     */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE_Msk) | RCC_CFGR_HPRE_3; /* AHB div 2 (85 MHz) */

    /* 7. Switch SYSCLK to PLL (SW = 0b11) and wait for SWS to confirm PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW_Msk) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS_Msk) != RCC_CFGR_SWS_PLL) {
        /* Busy-wait for system clock switch to PLL */
    }

    /* 8. Short delay (>= 1 us) before switching AHB to full speed [STM32G474_RM0440 p.279] */
    for (volatile uint32_t i = 0; i < 50; i++) {
        __NOP();
    }

    /* 9. Set AHB prescaler to 1: HCLK = SYSCLK = 170 MHz.
     *    APB1 and APB2 prescalers remain at /1 (reset default 0b000).
     */
    RCC->CFGR &= ~RCC_CFGR_HPRE_Msk;
}
```

### Technical Analysis: Range 1 Normal Mode vs. 170 MHz SYSCLK

Operating at a system clock of 170 MHz with the internal voltage regulator configured in Range 1 normal mode (`PWR_CR5.R1MODE = 1`) is outside the specified operating limits of the STM32G474:

1. **Hardware Operating Limits:**
   - As documented in RM0440 Section 6.1.5 (Table 38 *Range 1 boost mode configuration*) [STM32G474_RM0440 p.232]:
     - **Range 1 Normal mode (`R1MODE = 1`)**: Maximum system clock frequency is **SYSCLK ≤ 150 MHz**.
     - **Range 1 Boost mode (`R1MODE = 0`)**: Maximum system clock frequency is **SYSCLK ≤ 170 MHz**.
   - Datasheet Table 17 (*General operating conditions*) [STM32G474_Datasheet p.84] similarly defines the maximum frequency of 170 MHz exclusively under Range 1 Boost mode.
   - Operating at 170 MHz with `R1MODE = 1` violates dynamic voltage scaling limits, creating timing hazards and potential instability.

2. **Resolution Options:**
   - **Option 1 (Maintain 170 MHz):** Keep `PWR_CR5.R1MODE = 0` (Range 1 Boost mode). This is the only valid configuration that supports SYSCLK = 170 MHz.
   - **Option 2 (Use Range 1 Normal Mode):** Lower the system frequency to the maximum permitted frequency in normal mode, which is **SYSCLK = HCLK = PCLK1 = PCLK2 = 150 MHz**.

### Implementation for Option 2: 150 MHz in Range 1 Normal Mode (`PWR_CR5.R1MODE = 1`)

To achieve the maximum possible frequency in Range 1 Normal Mode:
- **PLL Configuration:**
  - Input: $\text{HSI16} = 16000000\text{ Hz}$
  - Division factor $M = 4$ (`PLLM = 3`) $\rightarrow 16000000\text{ Hz} / 4 = 4000000\text{ Hz}$ (VCO input)
  - Multiplication factor $N = 75$ (`PLLN = 75`) $\rightarrow 4000000\text{ Hz} \times 75 = 300000000\text{ Hz}$ (VCO output)
  - Division factor $R = 2$ (`PLLR = 0`) $\rightarrow 300000000\text{ Hz} / 2 = 150000000\text{ Hz}$ (PLL "R" output)
- **Flash Latency:**
  - Category 3 devices in Range 1 normal mode for $120\text{ MHz} < HCLK \le 150\text{ MHz}$ require 4 wait states (`FLASH_ACR_LATENCY_4WS`) [STM32G474_RM0440 p.98].

```c
#include "stm32g4xx.h"

/**
 * @brief  Configures the system clock to 150 MHz in Range 1 Normal Mode (PWR_CR5.R1MODE = 1).
 *         SYSCLK = HCLK = PCLK1 = PCLK2 = 150 MHz.
 */
void SystemClock_Config_150MHz(void)
{
    /* 1. Enable PWR peripheral clock */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* 2. Configure Range 1 Normal Mode (R1MODE = 1) [STM32G474_RM0440 p.232] */
    PWR->CR5 |= PWR_CR5_R1MODE;

    /* 3. Configure Flash read access latency:
     *    Table 9 specifies 4 wait states (4WS) for Range 1 normal mode at 150 MHz [STM32G474_RM0440 p.98].
     */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY_Msk) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY_Msk) != FLASH_ACR_LATENCY_4WS) {
        /* Wait until latency update takes effect */
    }

    /* 4. Configure PLL:
     *    Source = HSI16 (16 MHz)
     *    VCO_IN  = 16 MHz / 4 = 4 MHz
     *    VCO_OUT = 4 MHz * 75 = 300 MHz
     *    PLLCLK  = 300 MHz / 2 = 150 MHz
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_1 |
                   (3U << RCC_PLLCFGR_PLLM_Pos) |
                   (75U << RCC_PLLCFGR_PLLN_Pos) |
                   (0U << RCC_PLLCFGR_PLLR_Pos) |
                   RCC_PLLCFGR_PLLREN;

    /* 5. Enable PLL and busy-wait for lock */
    RCC->CR |= RCC_CR_PLLON;
    while ((RCC->CR & RCC_CR_PLLRDY) == 0U) {
        /* Wait for PLL ready */
    }

    /* 6. Intermediate AHB prescaler:
     *    Divide HCLK by 2 when switching from HSI16 to PLL > 80 MHz [STM32G474_RM0440 p.233].
     */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE_Msk) | RCC_CFGR_HPRE_3;

    /* 7. Switch SYSCLK source to PLL and wait for status flag */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW_Msk) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS_Msk) != RCC_CFGR_SWS_PLL) {
        /* Wait for switch */
    }

    /* 8. Short delay (>= 1 us) before full speed [STM32G474_RM0440 p.233] */
    for (volatile uint32_t i = 0; i < 50; i++) {
        __NOP();
    }

    /* 9. Return AHB prescaler to 1: SYSCLK = HCLK = PCLK1 = PCLK2 = 150 MHz */
    RCC->CFGR &= ~RCC_CFGR_HPRE_Msk;
}
```

### Complete Initialisation Program: Clock Tree & TIM1 PWM on PA8

Below is the complete standalone bare-metal C program for the STM32G474 configured in Range 1 Boost mode (operating at $\text{SYSCLK} = \text{HCLK} = \text{PCLK1} = \text{PCLK2} = 170\text{ MHz}$ via HSI16 and PLL) and outputting a 20 kHz PWM signal with 25% duty cycle on pin PA8 (TIM1 Channel 1).

```c
#include "stm32g4xx.h"

int main(void)
{
    /* =========================================================================
     * 1. CLOCK CONFIGURATION: 170 MHz (HSI16 + PLL in Range 1 Boost Mode)
     * ========================================================================= */

    /* Enable PWR peripheral clock */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* Switch internal regulator to Range 1 Boost mode (R1MODE = 0)
     * [STM32G474_RM0440 p.232, p.267] (required for SYSCLK > 150 MHz).
     */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* Configure Flash latency: 4 wait states (4WS) for 170 MHz in Range 1 Boost mode
     * [STM32G474_RM0440 p.98].
     */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY_Msk) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY_Msk) != FLASH_ACR_LATENCY_4WS) {
        /* Wait for Flash latency confirmation */
    }

    /* Configure Main PLL:
     * - Source: HSI16 (16 MHz)
     * - PLLM = 4 (PLLM bits = 3): VCO_IN = 16 MHz / 4 = 4 MHz [STM32G474_Datasheet p.123]
     * - PLLN = 85 (PLLN bits = 85): VCO_OUT = 4 MHz * 85 = 340 MHz [STM32G474_Datasheet p.123]
     * - PLLR = 2 (PLLR bits = 0): PLLCLK = 340 MHz / 2 = 170 MHz [STM32G474_Datasheet p.123]
     * - Enable PLL "R" clock output (PLLREN = 1)
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_1 |
                   (3U << RCC_PLLCFGR_PLLM_Pos) |
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   (0U << RCC_PLLCFGR_PLLR_Pos) |
                   RCC_PLLCFGR_PLLREN;

    /* Turn on PLL and busy-wait for lock */
    RCC->CR |= RCC_CR_PLLON;
    while ((RCC->CR & RCC_CR_PLLRDY) == 0U) {
        /* Wait until PLL is locked */
    }

    /* Intermediate AHB prescaler (/2) when switching to PLL > 80 MHz [STM32G474_RM0440 p.233] */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE_Msk) | RCC_CFGR_HPRE_3;

    /* Switch SYSCLK source to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW_Msk) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS_Msk) != RCC_CFGR_SWS_PLL) {
        /* Wait until PLL is selected as system clock source */
    }

    /* Wait at least 1 us before switching AHB prescaler to full speed [STM32G474_RM0440 p.233] */
    for (volatile uint32_t i = 0; i < 50; i++) {
        __NOP();
    }

    /* Return AHB prescaler to /1 -> HCLK = PCLK1 = PCLK2 = SYSCLK = 170 MHz */
    RCC->CFGR &= ~RCC_CFGR_HPRE_Msk;

    /* =========================================================================
     * 2. GPIO CONFIGURATION: PA8 -> TIM1_CH1 (Alternate Function 6)
     * ========================================================================= */

    /* Enable GPIOA peripheral clock */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;

    /* Set PA8 mode to Alternate Function (MODER8 = 10b) */
    GPIOA->MODER = (GPIOA->MODER & ~GPIO_MODER_MODE8_Msk) | (2U << GPIO_MODER_MODE8_Pos);

    /* Output type push-pull (OTYPER8 = 0) */
    GPIOA->OTYPER &= ~GPIO_OTYPER_OT8;

    /* High-speed output (OSPEEDR8 = 11b) */
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED8_Pos);

    /* No pull-up, no pull-down (PUPDR8 = 00b) */
    GPIOA->PUPDR &= ~GPIO_PUPDR_PUPD8_Msk;

    /* Connect PA8 to AF6 (TIM1_CH1) via AFR[1] (AFRH) [STM32G474_Datasheet p.73] */
    GPIOA->AFR[1] = (GPIOA->AFR[1] & ~(0xFU << GPIO_AFRH_AFSEL8_Pos)) | (6U << GPIO_AFRH_AFSEL8_Pos);

    /* =========================================================================
     * 3. TIM1 CONFIGURATION: 20 kHz PWM, 25 % Duty Cycle (Edge-aligned Mode 1)
     * ========================================================================= */

    /* Enable TIM1 peripheral clock */
    RCC->APB2ENR |= RCC_APB2ENR_TIM1EN;

    /* Timer clock = APB2 timer clock = 170 MHz
     * Target frequency = 20 kHz:
     *   ARR + 1 = 170,000,000 / ( (PSC + 1) * 20,000 )
     * With PSC = 0: ARR + 1 = 8500  =>  ARR = 8499
     * Target duty cycle = 25 %:
     *   CCR1 = 25 % * (ARR + 1) = 0.25 * 8500 = 2125
     */
    TIM1->PSC = 0;
    TIM1->ARR = 8499;
    TIM1->CCR1 = 2125;

    /* Configure PWM mode 1 on Channel 1:
     * - CC1S = 00 (Channel 1 configured as output)
     * - OC1M = 0110b (PWM mode 1: active while CNT < CCR1, inactive otherwise)
     * - OC1PE = 1 (Preload enable for CCR1)
     */
    TIM1->CCMR1 = (TIM1->CCMR1 & ~(TIM_CCMR1_OC1M_Msk | TIM_CCMR1_CC1S_Msk)) |
                  (6U << TIM_CCMR1_OC1M_Pos) |
                  TIM_CCMR1_OC1PE;

    /* Channel 1 output enable (CC1E = 1), active-high polarity (CC1P = 0) */
    TIM1->CCER |= TIM_CCER_CC1E;

    /* Enable ARR preload */
    TIM1->CR1 |= TIM_CR1_ARPE;

    /* Main Output Enable (MOE = 1) - required for advanced-control timers (TIM1/TIM8/TIM20)
     * [STM32G474_RM0440 p.1270]
     */
    TIM1->BDTR |= TIM_BDTR_MOE;

    /* Generate an update event to load preloaded registers (PSC, ARR, CCR1) */
    TIM1->EGR = TIM_EGR_UG;

    /* Start TIM1 counter (CEN = 1) */
    TIM1->CR1 |= TIM_CR1_CEN;

    /* Main loop */
    while (1) {
    }
}
```

### Technical Explanation

1. **Operating Mode & Clock Tree:**
   - Because 170 MHz is the absolute maximum clock frequency of the STM32G474 and exceeds the 150 MHz limit of Range 1 normal mode [STM32G474_RM0440 p.232], the internal regulator is configured in **Range 1 Boost mode** (`PWR->CR5 &= ~PWR_CR5_R1MODE`) [STM32G474_RM0440 p.267].
   - The PLL is driven by the 16 MHz internal oscillator (HSI16) with $M = 4$, $N = 85$, and $R = 2$, generating $f_{\text{VCO}} = 340\text{ MHz}$ and $f_{\text{PLL\_R}} = 170\text{ MHz}$ [STM32G474_Datasheet p.123].
   - Flash access latency is configured to 4 wait states (`FLASH_ACR_LATENCY_4WS`) before switching clocks [STM32G474_RM0440 p.98].
   - An intermediate division of AHB by 2 is used during the switch to comply with RM0440 clock-switching guidelines for frequencies above 80 MHz [STM32G474_RM0440 p.233].

2. **Pin Multiplexing:**
   - Pin PA8 is configured in Alternate Function push-pull mode (`MODER[17:16] = 10b`, `OTYPER[8] = 0`).
   - In `GPIOA->AFR[1]` (AFRH), bits `[3:0]` are set to `6` to map PA8 to `TIM1_CH1` [STM32G474_Datasheet p.73].

3. **PWM Generation:**
   - With an APB2 prescaler of 1, the TIM1 kernel clock equals $170\text{ MHz}$.
   - A prescaler of `PSC = 0` provides maximum timing resolution (13.05 bits, 8500 discrete steps).
   - $\text{ARR} = 8499$ sets the period:
     $$f_{\text{PWM}} = \frac{170\text{ MHz}}{(0 + 1) \times (8499 + 1)} = 20{,}000\text{ Hz}$$
   - $\text{CCR1} = 2125$ sets the active-high pulse width:
     $$\text{Duty Cycle} = \frac{2125}{8500} = 25.00\%$$
   - `TIM1->BDTR |= TIM_BDTR_MOE` sets the Main Output Enable bit, enabling the physical output pad on advanced-control timers [STM32G474_RM0440 p.1270]. Register preloading and the update event (`UG`) ensure glitch-free timer startup.
