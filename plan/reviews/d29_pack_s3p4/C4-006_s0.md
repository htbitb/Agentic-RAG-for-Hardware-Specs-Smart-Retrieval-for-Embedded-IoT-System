### STM32G474 Clock Configuration to 170 MHz (HSI16 PLL)

To configure the STM32G474 to run at **SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz** from the 16 MHz internal HSI16 oscillator, the following configuration steps and hardware requirements from RM0440 must be satisfied:

1. **Power Controller & Range 1 Boost Mode**:
   - The STM32G474 core voltage regulator powers up in Range 1 normal mode (SYSCLK ≤ 150 MHz).
   - Reaching 170 MHz requires entering **Range 1 Boost Mode** by clearing the `R1MODE` bit (bit 8) in the `PWR_CR5` register [STM32G474_RM0440 p.232].
   - Before modifying `PWR_CR5`, clock gating to the Power interface must be enabled by setting `PWREN` in `RCC->APB1ENR1`.
   - RM0440 specifies that when switching to a frequency > 150 MHz in Boost mode, the AHB prescaler (`HPRE`) should first divide the clock by 2 (`HPRE = DIV2`) before switching, followed by a wait of at least 1 µs, after which `HPRE` is restored to 1 (`DIV1`) [STM32G474_RM0440 p.233].

2. **Flash Memory Latency**:
   - According to RM0440 Table 9 (*Number of wait states according to CPU clock (HCLK) frequency* [STM32G474_RM0440 p.98]), in VCORE Range 1 Boost mode at HCLK ≤ 170 MHz (above 136 MHz), the Flash read access latency must be set to **4 wait states** (`LATENCY = 4`, `FLASH_ACR_LATENCY_4WS`).
   - The code polls `FLASH->ACR` to ensure the new latency value is committed before switching to the higher clock frequency.

3. **PLL Calculation**:
   - **Input source**: HSI16 ($f_{\text{IN}} = 16\text{ MHz}$, selected via `RCC_PLLCFGR_PLLSRC_1`).
   - **Prescaler M**: $M = 4$ (register value `3U << RCC_PLLCFGR_PLLM_Pos`), yielding $f_{\text{VCO\_IN}} = 16\text{ MHz} / 4 = 4\text{ MHz}$.
   - **Multiplier N**: $N = 85$ (register value `85U << RCC_PLLCFGR_PLLN_Pos`), yielding $f_{\text{VCO}} = 4\text{ MHz} \times 85 = 340\text{ MHz}$.
   - **Output Divider R**: $R = 2$ (register value `0U << RCC_PLLCFGR_PLLR_Pos`), yielding $f_{\text{PLL\_R}} = 340\text{ MHz} / 2 = 170\text{ MHz}$.
   - **PLL Output Enable**: Set `RCC_PLLCFGR_PLLREN` to enable the main PLL "R" clock output.

4. **PLL Enable and Clock Switch**:
   - Turn on the PLL with `RCC->CR |= RCC_CR_PLLON` and poll `RCC_CR_PLLRDY` until locked.
   - Switch SYSCLK source to PLL by setting `SW = 0b11` (`RCC_CFGR_SW_PLL`) and poll `SWS` in `RCC->CFGR` until `RCC_CFGR_SWS_PLL` is indicated.
   - Finally, restore `HPRE` to 1 (`RCC_CFGR_HPRE_DIV1`) to achieve the target 170 MHz HCLK and bus clocks.

### Bare-Metal C Code (`stm32g4xx.h`)

```c
#include "stm32g4xx.h"

/**
 * @brief Configure SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz using HSI16 and PLL.
 */
void clock_init(void)
{
    /* 1. Enable Power interface clock in RCC */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* 2. Set AHB prescaler to DIV2 before transitioning to Range 1 Boost mode */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    /* 3. Enable Range 1 Boost mode: clear R1MODE bit in PWR_CR5 */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 4. Configure Flash memory access latency to 4 wait states (for 170 MHz in Boost mode) */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY) != FLASH_ACR_LATENCY_4WS) {
        /* Wait until Flash latency setting is acknowledged */
    }

    /* 5. Configure Main PLL:
     *    Source = HSI16 (16 MHz)
     *    PLLM   = 4  (field value 3: 16 MHz / 4 = 4 MHz)
     *    PLLN   = 85 (field value 85: 4 MHz * 85 = 340 MHz VCO)
     *    PLLR   = 2  (field value 0: 340 MHz / 2 = 170 MHz)
     *    PLLREN = 1  (enable PLL "R" clock output)
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_1 |
                   (3U << RCC_PLLCFGR_PLLM_Pos) |
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   (0U << RCC_PLLCFGR_PLLR_Pos) |
                   RCC_PLLCFGR_PLLREN;

    /* 6. Enable PLL and wait until it is ready */
    RCC->CR |= RCC_CR_PLLON;
    while ((RCC->CR & RCC_CR_PLLRDY) == 0) {
        /* Busy-wait for PLL lock */
    }

    /* 7. Switch system clock source to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
        /* Busy-wait for SYSCLK switch to PLL */
    }

    /* 8. Short stabilization delay (> 1 us), then restore AHB prescaler to DIV1 */
    for (volatile uint32_t i = 0; i < 50; i++) {
        __NOP();
    }
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;
    while ((RCC->CFGR & RCC_CFGR_HPRE) != RCC_CFGR_HPRE_DIV1) {
        /* Wait until AHB prescaler update takes effect */
    }
}
```

### Hardware Constraint: Range 1 Normal Mode vs. 170 MHz

On the **STM32G474**, operating at **170 MHz in Range 1 normal mode (`PWR_CR5.R1MODE = 1`) is prohibited by the hardware electrical specifications and reference manual**:

1. **Maximum Frequency Limits** (RM0440 Section 6.1.5, Table 38, p. 232–233; DS12288 Section 5.3.1, Table 17, p. 84):
   - **Range 1 Normal Mode (`PWR_CR5.R1MODE = 1`)**: The maximum allowable CPU / system clock frequency is **$f_{\text{HCLK}} \le 150\text{ MHz}$**.
   - **Range 1 Boost Mode (`PWR_CR5.R1MODE = 0`)**: The core voltage regulator is boosted specifically to support frequencies above 150 MHz up to **$170\text{ MHz}$**.
   - Operating at 170 MHz with `R1MODE = 1` violates dynamic voltage scaling limits (`CLOCK_LIMIT:SYSCLK`) and risks core instability or timing faults.

2. **Flash Wait States** (RM0440 Section 3.3.3, Table 9, p. 98):
   - In Range 1 normal mode, 4 wait states (`LATENCY = 4`) cover up to the maximum permitted frequency of $150\text{ MHz}$.

### Complete Bare-Metal C Program (`stm32g4xx.h`)

Below is the complete initialization program configuring the STM32G474 clock tree to **170 MHz** (Range 1 Boost mode, HSI16 PLL) and generating a **20 kHz, 25% duty cycle PWM signal on PA8** using **TIM1 Channel 1**:

```c
#include "stm32g4xx.h"

int main(void)
{
    /* =========================================================================
     * 1. CLOCK TREE CONFIGURATION: SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz
     * ========================================================================= */

    /* Enable Power interface clock */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* Divide HCLK by 2 temporarily before entering Boost mode (RM0440 Table 38) */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    /* Clear R1MODE in PWR_CR5 to enter Range 1 Boost mode (allows SYSCLK up to 170 MHz) */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* Set Flash memory latency to 4 wait states (RM0440 Table 9 for 170 MHz in Boost mode) */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY) != FLASH_ACR_LATENCY_4WS) {
        /* Wait for Flash latency confirmation */
    }

    /* Configure PLL:
     * Source = HSI16 (16 MHz)
     * PLLM   = 4  (field value 3: 16 MHz / 4 = 4 MHz VCO input)
     * PLLN   = 85 (field value 85: 4 MHz * 85 = 340 MHz VCO output)
     * PLLR   = 2  (field value 0: 340 MHz / 2 = 170 MHz SYSCLK)
     * PLLREN = 1  (enable Main PLL R output)
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_1 |
                   (3U << RCC_PLLCFGR_PLLM_Pos) |
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   (0U << RCC_PLLCFGR_PLLR_Pos) |
                   RCC_PLLCFGR_PLLREN;

    /* Enable PLL and wait until locked */
    RCC->CR |= RCC_CR_PLLON;
    while ((RCC->CR & RCC_CR_PLLRDY) == 0) {
        /* Busy-wait for PLL ready */
    }

    /* Switch SYSCLK source to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
        /* Busy-wait until PLL is system clock */
    }

    /* Wait > 1 us stabilization delay, then restore AHB prescaler to DIV1 */
    for (volatile uint32_t i = 0; i < 50; i++) {
        __NOP();
    }
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;
    while ((RCC->CFGR & RCC_CFGR_HPRE) != RCC_CFGR_HPRE_DIV1) {
        /* Wait until AHB prescaler update takes effect */
    }

    /* =========================================================================
     * 2. GPIO INITIALIZATION: PA8 -> TIM1_CH1 (Alternate Function 6)
     * ========================================================================= */

    /* Enable GPIOA peripheral clock */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;

    /* Configure PA8 mode to Alternate Function (10b) */
    GPIOA->MODER &= ~GPIO_MODER_MODE8_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE8_Pos);

    /* Assign AF6 (TIM1_CH1) to PA8 via AFRH (AFR[1]) */
    GPIOA->AFR[1] &= ~GPIO_AFRH_AFSEL8_Msk;
    GPIOA->AFR[1] |= (6U << GPIO_AFRH_AFSEL8_Pos);

    /* Configure output speed to Very High Speed */
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED8_Pos);

    /* =========================================================================
     * 3. TIM1 INITIALIZATION: 20 kHz, 25% Duty Cycle PWM on Channel 1
     * ========================================================================= */

    /* Enable TIM1 peripheral clock */
    RCC->APB2ENR |= RCC_APB2ENR_TIM1EN;

    /* Frequency calculations:
     * TIM1CLK = 170 MHz (APB2 prescaler = 1, timer multiplier = 1)
     * Target frequency = 20 kHz
     * Counter clock = 170 MHz / (PSC + 1) = 170 MHz (with PSC = 0)
     * ARR = (TIM1CLK / f_target) - 1 = (170,000,000 / 20,000) - 1 = 8499
     * Duty cycle = 25%
     * CCR1 = (ARR + 1) * 25% = 8500 * 0.25 = 2125
     */
    TIM1->PSC = 0;
    TIM1->ARR = 8499;
    TIM1->CCR1 = 2125;

    /* Channel 1 Output Compare Mode:
     * - OC1M = 0110b (PWM mode 1: active while CNT < CCR1, inactive otherwise)
     * - OC1PE = 1 (Preload register enabled for glitch-free updates)
     */
    TIM1->CCMR1 &= ~TIM_CCMR1_OC1M_Msk;
    TIM1->CCMR1 |= (6U << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE;

    /* Enable Channel 1 output on pin (CC1E = 1, CC1P = 0 for active-high) */
    TIM1->CCER |= TIM_CCER_CC1E;

    /* Advanced Timer Output Enable:
     * - MOE bit in BDTR must be set for outputs to be driven to pins.
     * - Dead-time register (DTG bits in BDTR) left at reset default 0 (no dead time).
     */
    TIM1->BDTR |= TIM_BDTR_MOE;

    /* Enable auto-reload preload (ARPE) and start counter (CEN) */
    TIM1->CR1 |= TIM_CR1_ARPE | TIM_CR1_CEN;

    /* Main loop */
    while (1) {
    }
}
```

### Technical Explanation

1. **Clock Configuration (170 MHz)**:
   - Operating at 170 MHz requires VCORE **Range 1 Boost Mode**, selected by clearing `PWR_CR5.R1MODE` [STM32G474_RM0440 p.233, p.267]. Following ST's recommended sequence (Table 38), HCLK is divided by 2 via `HPRE = DIV2` before the transition, and restored to `DIV1` after stabilizing for at least 1 µs [STM32G474_RM0440 p.233].
   - Flash read latency is configured to **4 wait states** (`FLASH_ACR_LATENCY_4WS`), matching the timing requirement for $136\text{ MHz} < f_{\text{HCLK}} \le 170\text{ MHz}$ [STM32G474_RM0440 p.98].
   - The PLL multiplies the 16 MHz HSI16 clock ($M = 4 \rightarrow 4\text{ MHz}$, $N = 85 \rightarrow 340\text{ MHz VCO}$, $R = 2 \rightarrow 170\text{ MHz}$).

2. **Pin Routing (`PA8` $\rightarrow$ `TIM1_CH1`)**:
   - PA8 pin multiplexing assigns **AF6** (`TIM1_CH1`) in `GPIOA->AFR[1]` (AFRH) [STM32G474_Datasheet p.73].
   - The pin mode is set to Alternate Function (`MODER = 10b`) with push-pull output and very high slew rate.

3. **Timer 1 Configuration**:
   - `TIM1CLK` runs at 170 MHz since APB2 prescaler is 1.
   - With prescaler `PSC = 0`, period `ARR = 8499` produces an exact carrier frequency:
     $$f_{\text{PWM}} = \frac{170\,000\,000}{(0 + 1) \times (8499 + 1)} = 20\,000\text{ Hz}\quad (0.00\%\text{ error})$$
   - Setting `CCR1 = 2125` yields an exact 25.0% duty cycle:
     $$\text{Duty} = \frac{2125}{8500} = 25.00\%$$
   - `OC1M = 6` configures PWM Mode 1 (active-high output while `CNT < CCR1`).
   - Because TIM1 is an advanced-control timer, `TIM1->BDTR |= TIM_BDTR_MOE` (**Main Output Enable**) is required to drive the output stage to the physical I/O pin. No dead time is injected (`DTG = 0`). The peripheral clock gate was also enabled via `RCC->APB2ENR` prior to register access [STM32G474_RM0440 p.285].
