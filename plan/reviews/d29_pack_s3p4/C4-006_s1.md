### Clock Configuration: 170 MHz from HSI16 on STM32G474

To run the STM32G474 at **170 MHz** (maximum system frequency) using the internal 16 MHz HSI16 oscillator:

1. **Power Interface & Range 1 Boost Mode**:
   - Enable the PWR peripheral clock (`RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN`).
   - In STM32G4 series devices, frequencies above 150 MHz require **Voltage Scaling Range 1 Boost Mode** [STM32G474_RM0440 p.233]. Clearing bit `R1MODE` (bit 8) in `PWR->CR5` puts the internal voltage regulator into Range 1 Boost Mode [STM32G474_RM0440 p.267].

2. **Flash Wait States**:
   - According to RM0440 Table 9 (category 3 devices, Range 1 Boost mode), running at $150 < f_{\text{HCLK}} \le 170\text{ MHz}$ requires **4 wait states** (`LATENCY = 4WS`) [STM32G474_RM0440 p.98].
   - We set `LATENCY = 4` in `FLASH->ACR` before switching SYSCLK, and also enable instruction cache (`ICEN`), data cache (`DCEN`), and prefetch buffer (`PRFTEN`) for optimal execution performance [STM32G474_RM0440 p.130].

3. **PLL Calculation**:
   - Clock input: $f_{\text{HSI16}} = 16\text{ MHz}$.
   - PLL input divider $M$: set to 4 (`PLLM[3:0] = 3`, divider is $M = \text{PLLM} + 1 = 4$).
     $$f_{\text{VCO\_IN}} = \frac{16\text{ MHz}}{4} = 4\text{ MHz} \quad (\text{allowed range: } 2.66\text{ to } 16\text{ MHz}\text{, Table 46 } \text{[STM32G474_Datasheet p.123]})$$
   - VCO multiplier $N$: set to 85 (`PLLN = 85`).
     $$f_{\text{VCO\_OUT}} = 4\text{ MHz} \times 85 = 340\text{ MHz} \quad (\text{allowed range in Range 1: } 96\text{ to } 344\text{ MHz}\text{, Table 46 } \text{[STM32G474_Datasheet p.123]})$$
   - Main system clock divider $R$: set to 2 (`PLLR[1:0] = 00`, divider is 2).
     $$f_{\text{PLL\_R}} = \frac{340\text{ MHz}}{2} = 170\text{ MHz} \quad (\text{maximum } 170\text{ MHz in Boost mode } \text{[STM32G474_Datasheet p.123]})$$
   - Enable the PLL R output by setting `PLLREN` in `RCC->PLLCFGR` [STM32G474_RM0440 p.291].

4. **Safe Clock Transition**:
   - When switching to a frequency higher than 80 MHz (and especially into boost mode above 150 MHz), ST RM0440 specifies dividing the AHB clock by 2 (`HPRE = DIV2`), switching SYSCLK to the PLL, waiting at least $1\ \mu\text{s}$, and then setting the AHB prescaler to 1 (`HPRE = DIV1`) [STM32G474_RM0440 p.233, p.279].
   - The APB1 and APB2 prescalers remain at 1 (`PPRE1 = 0`, `PPRE2 = 0`), giving:
     $$\text{SYSCLK} = \text{HCLK} = \text{PCLK1} = \text{PCLK2} = 170\text{ MHz}$$

### Bare-Metal C Code

```c
#include "stm32g4xx.h"

void clock_init_170mhz(void)
{
    /* 1. Enable the Power Interface clock */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* 2. Configure Flash latency: 4 wait states required for 170 MHz in Range 1 Boost mode.
     *    Also enable prefetch, instruction cache, and data cache. */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY)
               | FLASH_ACR_LATENCY_4WS
               | FLASH_ACR_PRFTEN
               | FLASH_ACR_ICEN
               | FLASH_ACR_DCEN;

    /* 3. Enable Range 1 Boost mode by clearing R1MODE in PWR_CR5 (RM0440 Section 6.1.5) */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 4. Configure PLL:
     *    Source: HSI16 (16 MHz)
     *    PLLM  : /4 (register value 3 => divider = 3 + 1 = 4) -> f_VCO_IN = 4 MHz
     *    PLLN  : *85                                         -> f_VCO_OUT = 340 MHz
     *    PLLR  : /2 (register value 0 => divider = 2)         -> f_PLL_R = 170 MHz
     *    Enable PLL R output (PLLREN)
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSI
                 | (3U  << RCC_PLLCFGR_PLLM_Pos)
                 | (85U << RCC_PLLCFGR_PLLN_Pos)
                 | (0U  << RCC_PLLCFGR_PLLR_Pos)
                 | RCC_PLLCFGR_PLLREN;

    /* 5. Enable Main PLL and wait until it is locked */
    RCC->CR |= RCC_CR_PLLON;
    while ((RCC->CR & RCC_CR_PLLRDY) == 0U) {
        /* Busy-wait until PLL is ready */
    }

    /* 6. As recommended by RM0440 Sections 6.1.5 & 7.2.7:
     *    Divide HCLK by 2 before switching to system clock > 80 MHz / 150 MHz */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    /* 7. Switch system clock to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;

    /* 8. Wait until PLL is used as the system clock source */
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
        /* Busy-wait until system clock switches to PLL */
    }

    /* 9. Wait >= 1 us before switching AHB prescaler to 1.
     *    At 85 MHz (HCLK = 170 MHz / 2), 85 cycles equal 1 us.
     *    A 50-iteration loop of NOPs guarantees at least 1 us of transition time. */
    for (__IO uint32_t i = 0; i < 50; i++) {
        __NOP();
    }

    /* 10. Reconfigure AHB prescaler to 1 (HCLK = 170 MHz, PCLK1 = 170 MHz, PCLK2 = 170 MHz) */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;
}
```

### Hardware Constraint & Conflict

According to the **STM32G474 Reference Manual (RM0440 Section 6.1.5, Table 38)** and the **STM32G474 Datasheet (Table 17 & Table 46)**:

- In **Range 1 normal mode** (`PWR_CR5.R1MODE = 1`), the maximum allowable system frequency is **150 MHz**:
  > *"If the system frequency is 26 MHz < SYSCLK ≤ 150 MHz: Select the Range 1 normal mode by setting R1MODE bit in the PWR_CR5 register."* [STM32G474_RM0440 p.233]  
  > *PLL output clock R in Range 1 normal mode: maximum 150 MHz* [STM32G474_Datasheet p.123].
- Operating at **170 MHz** strictly requires **Range 1 Boost mode** (`PWR_CR5.R1MODE = 0`). Operating at 170 MHz with `R1MODE = 1` violates the silicon operating conditions.

### Solutions

Depending on whether **saving power in Range 1 normal mode** or **reaching 170 MHz** is your primary priority:

#### Option A (Recommended for Range 1 Normal Mode): Run at 150 MHz
To remain in **Range 1 normal mode** (`PWR_CR5.R1MODE = 1`), configure the PLL for **150 MHz** (the maximum rating for this mode):
- $f_{\text{VCO\_IN}} = 16\text{ MHz} / 4 = 4\text{ MHz}$ ($M = 4$, `PLLM = 3`)
- $f_{\text{VCO\_OUT}} = 4\text{ MHz} \times 75 = 300000000\text{ Hz}$ ($N = 75$, `PLLN = 75`)
- $f_{\text{PLL\_R}} = 300000000\text{ Hz} / 2 = 150\text{ MHz}$ ($R = 2$, `PLLR = 0`)
- Flash Latency: **4 WS** for $120 < f_{\text{HCLK}} \le 150\text{ MHz}$ in Range 1 normal mode [STM32G474_RM0440 Table 9, p.98].

```c
#include "stm32g4xx.h"

/* Configures Range 1 Normal Mode at its maximum frequency: 150 MHz */
void clock_init_150mhz_range1_normal(void)
{
    /* 1. Enable Power Interface clock */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* 2. Select Range 1 normal mode (R1MODE = 1 in PWR_CR5) */
    PWR->CR5 |= PWR_CR5_R1MODE;

    /* 3. Flash latency: 4 wait states required for 150 MHz in Range 1 normal mode.
     *    Enable prefetch buffer, instruction cache, and data cache. */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY)
               | FLASH_ACR_LATENCY_4WS
               | FLASH_ACR_PRFTEN
               | FLASH_ACR_ICEN
               | FLASH_ACR_DCEN;

    /* 4. Configure PLL:
     *    Source: HSI16 (16 MHz)
     *    PLLM  : /4  (3 => /4)  -> f_VCO_IN  = 4 MHz
     *    PLLN  : *75            -> f_VCO_OUT = 300 MHz
     *    PLLR  : /2  (0 => /2)  -> f_PLL_R   = 150 MHz
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSI
                 | (3U  << RCC_PLLCFGR_PLLM_Pos)
                 | (75U << RCC_PLLCFGR_PLLN_Pos)
                 | (0U  << RCC_PLLCFGR_PLLR_Pos)
                 | RCC_PLLCFGR_PLLREN;

    /* 5. Enable Main PLL and wait until locked */
    RCC->CR |= RCC_CR_PLLON;
    while ((RCC->CR & RCC_CR_PLLRDY) == 0U) {
        /* Wait for PLL */
    }

    /* 6. Switch system clock to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;

    /* 7. Wait until PLL is used as SYSCLK */
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
        /* Wait for clock switch */
    }
}
```

### STM32G474 Firmware Initialisation: 170 MHz Clock & 20 kHz PWM (PA8)

#### Complete Bare-Metal C Program

```c
#include "stm32g4xx.h"

int main(void)
{
    /* =========================================================================
     * 1. CLOCK CONFIGURATION (SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz)
     * ========================================================================= */

    /* 1.1 Enable Power Interface clock */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* 1.2 Configure Flash memory access latency:
     *     According to RM0440 Table 9 [STM32G474_RM0440 p.98], 150 < HCLK <= 170 MHz
     *     in Range 1 Boost mode requires 4 wait states (LATENCY = 4WS).
     *     Also enable instruction cache (ICEN), data cache (DCEN), and prefetch (PRFTEN) [STM32G474_RM0440 p.130].
     */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY)
               | FLASH_ACR_LATENCY_4WS
               | FLASH_ACR_PRFTEN
               | FLASH_ACR_ICEN
               | FLASH_ACR_DCEN;

    /* 1.3 Enable Range 1 Boost mode:
     *     Operating at 170 MHz strictly requires Range 1 Boost mode.
     *     Clear bit R1MODE in PWR_CR5 (RM0440 Section 6.1.5 [STM32G474_RM0440 p.232], [STM32G474_RM0440 p.267]).
     */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 1.4 Configure Main PLL:
     *     Source: HSI16 (16 MHz)
     *     PLLM  : /4 (register value 3 => divider = 3 + 1 = 4) -> f_VCO_IN = 4 MHz
     *     PLLN  : *85                                         -> f_VCO_OUT = 340 MHz
     *     PLLR  : /2 (register value 0 => divider = 2)         -> f_PLL_R = 170 MHz
     *     Enable PLL R output (PLLREN).
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSI
                 | (3U  << RCC_PLLCFGR_PLLM_Pos)
                 | (85U << RCC_PLLCFGR_PLLN_Pos)
                 | (0U  << RCC_PLLCFGR_PLLR_Pos)
                 | RCC_PLLCFGR_PLLREN;

    /* 1.5 Enable Main PLL and wait until locked */
    RCC->CR |= RCC_CR_PLLON;
    while ((RCC->CR & RCC_CR_PLLRDY) == 0U) {
        /* Busy-wait until PLL is ready */
    }

    /* 1.6 RM0440 transition recommendation: divide AHB by 2 before switching SYSCLK [STM32G474_RM0440 p.232] */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    /* 1.7 Switch system clock to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;

    /* 1.8 Wait until PLL is selected as SYSCLK source */
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
        /* Busy-wait until system clock switches to PLL */
    }

    /* 1.9 Wait at least 1 us at 85 MHz before setting AHB prescaler to 1 */
    for (volatile uint32_t i = 0; i < 50; i++) {
        __NOP();
    }

    /* 1.10 Set AHB prescaler = 1 (HCLK = 170 MHz, PCLK1 = 170 MHz, PCLK2 = 170 MHz) */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;

    /* =========================================================================
     * 2. GPIO INITIALISATION (PA8 -> TIM1_CH1, AF6)
     * ========================================================================= */

    /* 2.1 Enable GPIOA and TIM1 peripheral clocks */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_TIM1EN;

    /* 2.2 Configure PA8:
     *     - Mode: Alternate Function mode (MODER[17:16] = 10b)
     *     - AF: AF6 (TIM1_CH1) in AFR[1] (AFRH) bits [3:0] [STM32G474_Datasheet p.73]
     *     - Output type: Push-pull (OTYPER bit 8 = 0)
     *     - Output speed: Very high speed (OSPEEDR[17:16] = 11b)
     *     - Pull-up / pull-down: No pull (PUPDR[17:16] = 00b)
     */
    GPIOA->MODER = (GPIOA->MODER & ~GPIO_MODER_MODE8_Msk) | (2U << GPIO_MODER_MODE8_Pos);
    GPIOA->AFR[1] = (GPIOA->AFR[1] & ~(0xFU << GPIO_AFRH_AFSEL8_Pos)) | (6U << GPIO_AFRH_AFSEL8_Pos);
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED8_Pos);
    GPIOA->OTYPER &= ~GPIO_OTYPER_OT8;
    GPIOA->PUPDR &= ~GPIO_PUPDR_PUPD8_Msk;

    /* =========================================================================
     * 3. TIM1 INITIALISATION (20 kHz, 25 % Duty Cycle, PWM Mode 1)
     * ========================================================================= */

    /* 3.1 Timing calculations:
     *     TIM1 kernel clock = 170 MHz (APB2 prescaler = 1 => TIM1CLK = PCLK2 = 170 MHz)
     *     Prescaler: PSC = 0 (counting at 170 MHz)
     *     Target PWM frequency = 20,000 Hz:
     *       ARR = (170,000,000 / 20,000) - 1 = 8500 - 1 = 8499
     *     Target duty cycle = 25 %:
     *       CCR1 = 8500 * 0.25 = 2125
     */
    TIM1->PSC = 0;
    TIM1->ARR = 8499;
    TIM1->CCR1 = 2125;

    /* 3.2 Output Compare 1 Configuration:
     *     - CC1S = 00 (Channel 1 configured as output) [STM32G474_RM0440 p.1251]
     *     - OC1M = 0110 (PWM mode 1: active while CNT < CCR1, inactive otherwise)
     *     - OC1PE = 1 (Output compare 1 preload enable)
     */
    TIM1->CCMR1 = (TIM1->CCMR1 & ~(TIM_CCMR1_OC1M_Msk | TIM_CCMR1_CC1S_Msk))
                | (TIM_CCMR1_OC1M_1 | TIM_CCMR1_OC1M_2)
                | TIM_CCMR1_OC1PE;

    /* 3.3 Channel 1 Output Polarity and Enable:
     *     - CC1P = 0 (Active high)
     *     - CC1E = 1 (Enable OC1 output)
     */
    TIM1->CCER = (TIM1->CCER & ~TIM_CCER_CC1P) | TIM_CCER_CC1E;

    /* 3.4 Enable Auto-reload preload (ARPE) */
    TIM1->CR1 |= TIM_CR1_ARPE;

    /* 3.5 Generate an update event to load preloaded registers into active registers */
    TIM1->EGR |= TIM_EGR_UG;

    /* 3.6 Advanced Timer Requirement:
     *     Set Main Output Enable (MOE) in TIM1_BDTR so outputs are driven [STM32G474_RM0440 p.1267].
     */
    TIM1->BDTR |= TIM_BDTR_MOE;

    /* 3.7 Enable TIM1 counter */
    TIM1->CR1 |= TIM_CR1_CEN;

    /* 4. Infinite loop */
    while (1) {
    }
}
```

#### Explanation

1. **Clock Configuration & Operating Mode**:
   - The device is configured to run at **170 MHz** from HSI16 ($16\text{ MHz} / 4 \times 85 / 2 = 170\text{ MHz}$).
   - **Range 1 Boost mode** is enabled (`PWR->CR5 &= ~PWR_CR5_R1MODE`) because the maximum permissible frequency in Range 1 normal mode is 150 MHz; operating at 170 MHz strictly requires Boost mode [STM32G474_RM0440 p.232].
   - **Flash Latency** is configured to 4 wait states (`FLASH_ACR_LATENCY_4WS`) with instruction/data caches and prefetch buffer enabled [STM32G474_RM0440 p.98, p.130].
   - The AHB prescaler is briefly set to `/2` during clock source switching per RM0440 section 6.1.5 recommendations before being restored to `/1` [STM32G474_RM0440 p.232].

2. **GPIO PA8 Pin Routing**:
   - PA8 is configured in Alternate Function mode (`MODER8 = 10b`) with AF6 selected in `AFR[1]` (`AFRH`), which routes the `TIM1_CH1` peripheral signal to PA8 [STM32G474_Datasheet p.73].
   - Output type is configured as push-pull with high-speed slew rate.

3. **TIM1 PWM Setup**:
   - Because the APB2 prescaler is 1, the timer kernel clock `TIM1CLK` is equal to `PCLK2 = 170 MHz`.
   - With prescaler `PSC = 0`, the timer counts every clock tick ($1 / 170\text{ MHz} \approx 5.88\text{ ns}$).
   - An auto-reload value of `ARR = 8499` produces an exact PWM period of $8500 / 170\text{ MHz} = 50\ \mu\text{s}$, giving exactly **20 kHz** with 0% error.
   - Setting compare register `CCR1 = 2125` gives an exact duty cycle of $2125 / 8500 = 25.000\ \%$.
   - Channel 1 is configured in **PWM mode 1** (`OC1M = 0110b`), active-high (`CC1P = 0`) [STM32G474_RM0440 p.1251].
   - Being an advanced-control timer, `TIM1` requires the **Main Output Enable** bit (`MOE` in `TIM1_BDTR`) to be set to connect the timer output to the GPIO pin [STM32G474_RM0440 p.1267]. Finally, `CEN` in `TIM1_CR1` starts the counter.
