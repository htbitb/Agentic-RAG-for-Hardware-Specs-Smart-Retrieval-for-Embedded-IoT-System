### Hardware Analysis & Important Notice Regarding Pins PA2 / PA3

In the STM32G474 alternate function mapping (DS12288 Table 13, RM0440):
- **PA2** and **PA3** do **not** support **USART1**. Instead:
  - **PA2**: `USART2_TX` (AF7), `LPUART1_TX` (AF12), `TIM2_CH3` (AF1), `TIM15_CH1` (AF9)...
  - **PA3**: `USART2_RX` (AF7), `LPUART1_RX` (AF12), `TIM2_CH4` (AF1), `TIM15_CH2` (AF9)...
- **USART1** is mapped to:
  - **TX**: **PA9** (AF7), **PB6** (AF7), **PC4** (AF7), **PE0** (AF7), **PG9** (AF7)
  - **RX**: **PA10** (AF7), **PB7** (AF7), **PC5** (AF7), **PE1** (AF7)

If your console truly needs to be **USART1**, the standard pins to use are **PA9 (TX)** and **PA10 (RX)** (or PB6/PB7, PC4/PC5).
If your hardware board has physical header connections on **PA2** and **PA3**, then either **USART2** (AF7) or **LPUART1** (AF12) must be used.

Below, the full bare-metal CMSIS configuration for **USART1** is provided using the standard pins **PA9 / PA10** (and alternative pin setups are noted). If you instead need **LPUART1** on PA2/PA3 to keep USART2 free for your RS-485 transceiver, that configuration is also detailed.

### USART1 Configuration Details (115200 baud, 8N1, 16x oversampling)

1. **Clock & Baud Rate Calculation**:
   - Initial state: SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz.
   - USART1 clock source defaults to `PCLK2` (170 MHz) via `RCC->CCIPR` (`USART1SEL = 00b`).
   - For oversampling by 16 (`OVER8 = 0` in `USART_CR1`):
     $$\text{USARTDIV} = \frac{f_{\text{CK}}}{\text{Baud Rate}} = \frac{170\,000\,000}{115\,200} \approx 1475.6944$$
   - Rounding to the nearest integer yields:
     $$\text{USART1->BRR} = 1476 \quad (\text{0x05C4})$$
   - Resulting baud rate: $170\,000\,000 / 1476 \approx 115176.15\text{ baud}$ (relative error: $-0.02\%$, well within UART $\pm 2\%$ tolerance).

2. **Register Programming Sequence**:
   - Enable `GPIOA` clock on `RCC->AHB2ENR` (`RCC_AHB2ENR_GPIOAEN`).
   - Enable `USART1` clock on `RCC->APB2ENR` (`RCC_APB2ENR_USART1EN`).
   - Configure GPIO pins for Alternate Function 7 (`AF7`):
     - Mode: Alternate function mode (`MODER = 10b`).
     - Output speed: Very High / High (`OSPEEDR = 11b`).
     - Pull-up on RX line (`PUPDR = 01b`) to prevent floating line when idle.
     - AFR selection: AF7 (`AFRH = 7`).
   - Set Baud Rate: write `USART1->BRR = 1476U` **before** enabling the USART (`UE = 1`).
   - Configure `USART1->CR1`:
     - 8 data bits: `M1=0, M0=0` (reset state).
     - Parity control disabled: `PCE=0` (reset state).
     - 1 stop bit: `STOP = 00b` in `USART1->CR2` (reset state).
     - Oversampling by 16: `OVER8=0` (reset state).
     - Enable transmitter (`TE`), receiver (`RE`), and USART enable (`UE`).

### Bare-Metal CMSIS C Code

```c
#include "stm32g4xx.h"

/**
 * @brief  Initialize USART1 at 115200 baud, 8N1, oversampling by 16.
 * @note   On STM32G474, USART1 TX and RX are mapped to PA9 and PA10 (AF7).
 *         Pins PA2 and PA3 do not have alternate function mappings for USART1.
 *         (PA2/PA3 map to USART2 via AF7 or LPUART1 via AF12).
 */
void usart1_console_init(void)
{
    /* 1. Enable peripheral clocks for GPIOA and USART1 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 
     * 2. Configure GPIO pins PA9 (TX) and PA10 (RX) for Alternate Function 7
     *    Reset state of MODER for PA9 and PA10 is 00 (Input) or reset value.
     */
    GPIOA->MODER &= ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

    /* Alternate Function 7 (AF7) on PA9 and PA10 (AFRH) */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= (7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos);

    /* High speed on TX pin */
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED9_Pos);

    /* Internal pull-up on RX pin to hold line high when idle */
    GPIOA->PUPDR &= ~GPIO_PUPDR_PUPD10_Msk;
    GPIOA->PUPDR |= (1U << GPIO_PUPDR_PUPD10_Pos);

    /* 
     * 3. Baud rate configuration:
     *    f_CK = PCLK2 = 170 MHz, OVER8 = 0 (oversampling by 16)
     *    USARTDIV = 170000000 / 115200 = 1475.694 -> 1476 (0x05C4)
     *    Written prior to enabling the USART per requirement.
     */
    USART1->BRR = 1476U;

    /* 
     * 4. Configure frame format and enable USART:
     *    - 8 data bits: M[1:0] = 00b (CR1 bit 28 = 0, bit 12 = 0)
     *    - Parity control disabled: PCE = 0 (CR1 bit 10 = 0)
     *    - 1 stop bit: STOP[1:0] = 00b in CR2 (CR2 bits 13:12 = 0)
     *    - Oversampling by 16: OVER8 = 0 (CR1 bit 15 = 0)
     *    - Enable Transmitter (TE), Receiver (RE), and USART (UE)
     */
    USART1->CR2 &= ~USART_CR2_STOP_Msk; /* 1 stop bit */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
```

### Alternative: If Your Board Routes Console to PA2 / PA3 via LPUART1

If PA2 and PA3 are wired on your PCB and you must avoid USART2 (reserved for RS-485), **LPUART1** is available on PA2 (TX, AF12) and PA3 (RX, AF12):

```c
void lpuart1_console_pa2_pa3_init(void)
{
    /* 1. Enable peripheral clocks */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR2 |= RCC_APB1ENR2_LPUART1EN;

    /* 2. Configure PA2 (TX) and PA3 (RX) for AF12 (LPUART1) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE2_Msk | GPIO_MODER_MODE3_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE2_Pos) | (2U << GPIO_MODER_MODE3_Pos);

    GPIOA->AFR[0] &= ~((0xFU << GPIO_AFRL_AFSEL2_Pos) | (0xFU << GPIO_AFRL_AFSEL3_Pos));
    GPIOA->AFR[0] |= (12U << GPIO_AFRL_AFSEL2_Pos) | (12U << GPIO_AFRL_AFSEL3_Pos);

    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED2_Pos);
    GPIOA->PUPDR |= (1U << GPIO_PUPDR_PUPD3_Pos);

    /* 
     * 3. LPUART Baud rate:
     *    LPUARTDIV = (256 * 170000000) / 115200 = 377244.44 -> 377244 (0x5C19C)
     */
    LPUART1->BRR = 377244U;

    /* 4. Enable Transmitter, Receiver, and LPUART */
    LPUART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
```

### Assistant answer 1

### Hardware & Calculation Analysis

1. **Pin Mapping (PA6)**:
   - On the STM32G474 (DS12288 Table 13, RM0440), pin **PA6** provides **`TIM3_CH1`** via Alternate Function **AF2**.

2. **Timer Clock & Prescaler Calculation**:
   - Initial clock tree: SYSCLK = HCLK = PCLK1 = 170000000 Hz (170 MHz).
   - Because APB1 prescaler = 1, the timer kernel clock is:
     $$f_{\text{TIM}} = f_{\text{PCLK1}} = 170000000\text{ Hz}$$
   - Target PWM frequency: $f_{\text{target}} = 1000\text{ Hz}$ (1 kHz).
   - Timer period formula for edge-aligned up-counting:
     $$f_{\text{PWM}} = \frac{f_{\text{TIM}}}{(\text{PSC} + 1) \cdot (\text{ARR} + 1)}$$
   - TIM3 is a 16-bit general-purpose timer (maximum $\text{ARR} = 65535$).
   - With prescaler $\text{PSC} = 3$ ($\text{PSC} + 1 = 4$), the counter frequency is $170000000\text{ Hz} / 4 = 42500000\text{ Hz}$.
   - The required auto-reload value is:
     $$\text{ARR} + 1 = \frac{42500000\text{ Hz}}{1000\text{ Hz}} = 42500 \implies \mathbf{\text{ARR} = 42499} \quad (0 \le 42499 \le 65535)$$
   - This provides an exact $1000\text{ Hz}$ frequency ($0.0\%$ frequency error) with 42500 discrete duty cycle steps.

3. **50% Duty Cycle**:
   - In PWM Mode 1 (up-counting), the output is active while $\text{CNT} < \text{CCR1}$.
   $$\text{Duty} = \frac{\text{CCR1}}{\text{ARR} + 1} = 0.50 \implies \mathbf{\text{CCR1} = 21250}$$
   - Calculation: $42500 \times 0.50 = 21250$.

4. **Channel Configuration**:
   - **Mode**: Output mode on Channel 1 (`CC1S = 00b` in `TIM3->CCMR1`).
   - **PWM Mode 1**: `OC1M[3:0] = 0110b` (`OC1M_1 | OC1M_2` in `TIM3->CCMR1`).
   - **Preload**: Preload enabled (`OC1PE = 1` in `TIM3->CCMR1`, and `ARPE = 1` in `TIM3->CR1`).
   - **Polarity**: Active-high (`CC1P = 0` in `TIM3->CCER`).
   - **Output Enable**: Output enabled on pin (`CC1E = 1` in `TIM3->CCER`).
   - TIM3 is a general-purpose timer, so no main output enable (`BDTR.MOE`) is required (that applies only to advanced timers TIM1/TIM8/TIM20).
   - An update event (`EGR_UG`) is generated to latch the prescaler and preload values into the active shadow registers before enabling the counter (`CR1_CEN`).

### Bare-Metal CMSIS C Code

```c
#include "stm32g4xx.h"

/**
 * @brief  Initialize TIM3 Channel 1 on PA6 for 1 kHz PWM at 50% duty cycle.
 * @note   Edge-aligned up-counting PWM Mode 1, active-high, no dead time.
 *         Timer clock = 170000000 Hz (PCLK1 prescaler = 1).
 */
void tim3_ch1_fan_pwm_init(void)
{
    /* 1. Enable peripheral clocks for GPIOA and TIM3 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM3EN;

    /* 
     * 2. Configure PA6 for Alternate Function 2 (TIM3_CH1):
     *    - MODER: Alternate Function mode (10b)
     *    - AFR[0]: AF2 (TIM3_CH1) on PA6
     *    - OSPEEDR: High/Very High speed (11b)
     *    - PUPDR: No pull-up/pull-down (00b, reset state)
     */
    GPIOA->MODER &= ~GPIO_MODER_MODE6_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE6_Pos);

    GPIOA->AFR[0] &= ~(0xFU << GPIO_AFRL_AFSEL6_Pos);
    GPIOA->AFR[0] |= (2U << GPIO_AFRL_AFSEL6_Pos);

    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED6_Pos);

    /*
     * 3. Set timing parameters for 1 kHz, 50% duty:
     *    - f_tim = 170000000 Hz
     *    - PSC = 3 (divide by 4 -> 170000000 / 4 = 42500000 Hz counter clock)
     *    - ARR = 42499 (42500 counts per period -> 42500000 / 42500 = 1000 Hz exact)
     *    - CCR1 = 21250 (50% duty: 42500 * 0.50 = 21250)
     */
    TIM3->PSC = 3U;
    TIM3->ARR = 42499U;
    TIM3->CCR1 = 21250U;

    /*
     * 4. Configure Channel 1 for PWM Mode 1 with preload enabled:
     *    - CC1S = 00b (Channel 1 configured as output)
     *    - OC1M[3:0] = 0110b (PWM Mode 1: active while CNT < CCR1)
     *    - OC1PE = 1 (Output compare 1 preload enable)
     */
    TIM3->CCMR1 &= ~(TIM_CCMR1_CC1S_Msk | TIM_CCMR1_OC1M_Msk);
    TIM3->CCMR1 |= (TIM_CCMR1_OC1M_1 | TIM_CCMR1_OC1M_2) | TIM_CCMR1_OC1PE;

    /*
     * 5. Configure output polarity and enable output:
     *    - CC1P = 0 (Active high output)
     *    - CC1E = 1 (Enable Channel 1 output to pin)
     */
    TIM3->CCER &= ~TIM_CCER_CC1P;
    TIM3->CCER |= TIM_CCER_CC1E;

    /* 6. Enable auto-reload preload (ARPE) and generate an update event to latch PSC & ARR */
    TIM3->CR1 |= TIM_CR1_ARPE;
    TIM3->EGR = TIM_EGR_UG;

    /* 7. Start the timer counter */
    TIM3->CR1 |= TIM_CR1_CEN;
}
```

     *       Pins PA2/PA3 map to USART2 (AF7) or LPUART1 (AF12).
     * ========================================================================= */

    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED9_Pos);

    GPIOA->PUPDR &= ~GPIO_PUPDR_PUPD10_Msk;
    GPIOA->PUPDR |= (1U << GPIO_PUPDR_PUPD10_Pos);

     * 3. USART1 Peripheral Configuration (115200 baud, 8N1, 16x oversampling)
     * ========================================================================= */

     * USARTDIV = 170000000 / 115200 = 1475.694 -> 1476 (0x05C4).
     * BRR is configured prior to enabling the peripheral.

    USART1->CR2 &= ~USART_CR2_STOP_Msk;

    /* 8 data bits (M[1:0] = 00b), no parity (PCE = 0), enable TE, RE, and UE */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;

     * 4. TIM3 Channel 1 GPIO Configuration (PA6 = TIM3_CH1)

    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED6_Pos);

    TIM3->CCMR1 &= ~(TIM_CCMR1_CC1S_Msk | TIM_CCMR1_OC1M_Msk);

    TIM3->CR1 |= TIM_CR1_CEN;

     * 6. Background Loop
     * ========================================================================= */
    while (1)
    {
    }

    return 0;

### Explanation

1. **Clocks (`RCC`)**:
   - `GPIOA` is gated via `RCC->AHB2ENR` bit 0.
   - `TIM3` is on APB1 (`RCC->APB1ENR1` bit 1).
   - `USART1` is on APB2 (`RCC->APB2ENR` bit 14).
   - All peripherals receive their clock before their registers or GPIOs are accessed.

2. **Console UART (`USART1`)**:
   - As identified in Message 1, STM32G474 routes USART1 to **PA9 (TX)** and **PA10 (RX)** using Alternate Function 7 (`AF7`).
   - Operating at 170 MHz $f_{\text{PCLK2}}$ with 16× oversampling, the divider is $170\,000\,000 / 115200 \approx 1475.69$. Setting `BRR = 1476` achieves 115176 baud ($-0.02\%$ error).
   - `BRR` is written first; `USART1->CR1` then enables the transmitter (`TE`), receiver (`RE`), and the peripheral (`UE`) with standard 8 data bits and no parity.

3. **Fan PWM (`TIM3_CH1`)**:
   - **PA6** is configured for Alternate Function 2 (`AF2`) to route `TIM3_CH1`.
   - With an APB1 prescaler of 1, TIM3 runs at the full 170 MHz. Prescaler `PSC = 3` divides the clock down to 42.5 MHz.
   - Setting auto-reload `ARR = 42499` yields a period of 42500 counts ($42.5\text{ MHz} / 42500 = 1000\text{ Hz}$ exact).
   - Setting `CCR1 = 21250` creates an exact 50.0% duty cycle in PWM Mode 1 (active while $\text{CNT} < \text{CCR1}$).
   - `TIM3->EGR = TIM_EGR_UG` transfers the prescaler and preload values immediately into the shadow registers before the counter is started with `TIM3->CR1 |= TIM_CR1_CEN`.
