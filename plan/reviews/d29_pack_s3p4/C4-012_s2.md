### Pinout Conflict & Hardware Analysis

In the STM32G474 pin multiplexing matrix (Datasheet DS12288, Table 13 *Alternate functions*, p. 73):
* **PA2** supports **USART2_TX** (AF7) and **LPUART1_TX** (AF12). It has **no alternate function for USART1**.
* **PA3** supports **USART2_RX** (AF7) and **LPUART1_RX** (AF12). It has **no alternate function for USART1**.

The valid pin mappings for **USART1** on STM32G474 are:
* **USART1_TX**: **PA9** (AF7), **PB6** (AF7), **PC4** (AF7), **PE0** (AF7), or **PG9** (AF7).
* **USART1_RX**: **PA10** (AF7), **PB7** (AF7), **PC5** (AF7), or **PE1** (AF7).

Because PA2 and PA3 physically cannot be connected to USART1, there are two common scenarios in board design:
1. **The console must use USART1:** It must be mapped to valid USART1 pins such as **PA9 (TX)** and **PA10 (RX)** (or PB6/PB7).
2. **The console pins are physically PA2 and PA3:** On many STM32 boards (such as the NUCLEO-G474RE Virtual COM Port), PA2 and PA3 are wired to the ST-LINK VCP using **USART2**, while the RS-485 bus would be placed on another USART/UART (such as USART1, USART3, or UART4).

Below is the bare-metal CMSIS configuration for **USART1** routed to **PA9 (TX)** and **PA10 (RX)**.

### Baud Rate Calculation

* **Clock Source**: With SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz and `RCC->CCIPR.USART1SEL = 00` (reset default, PCLK2), the USART1 kernel clock is $f_{CK} = 170\text{ MHz}$.
* **Oversampling**: 16 ($OVER8 = 0$).
* **Formula**:
  $$\text{USARTDIV} = \frac{f_{CK}}{\text{Baud}} = \frac{170\,000\,000}{115\,200} \approx 1475.694$$
* **BRR Register**: With oversampling by 16, $\text{BRR} = \text{round}(1475.694) = 1476$ (`0x05C4`).
* **Actual Baud Rate**:
  $$\frac{170\,000\,000}{1476} \approx 115176.15\text{ baud}\quad (\text{error } -0.021\%)$$

### Bare-Metal C Implementation

```c
#include "stm32g4xx.h"

void usart1_console_init(void)
{
    /* 1. Enable peripheral clocks in RCC:
     *    - GPIOA clock enabled on AHB2 (RCC_AHB2ENR_GPIOAEN)
     *    - USART1 clock enabled on APB2 (RCC_APB2ENR_USART1EN)
     */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PA9 (TX) and PA10 (RX) for Alternate Function 7 (USART1):
     *    - Set MODER to 0b10 (Alternate Function mode) for pins 9 and 10
     *    - Set AFRH (AFR[1]) to AF7 (0b0111) for pins 9 and 10
     *    - Set OSPEEDR to high speed for PA9 (TX)
     *    - Set PUPDR to pull-up for PA10 (RX) to prevent floating line idle noise
     */
    GPIOA->MODER &= ~((3U << GPIO_MODER_MODE9_Pos) | (3U << GPIO_MODER_MODE10_Pos));
    GPIOA->MODER |=  ((2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos));

    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |=  ((7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos));

    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED9_Pos);
    GPIOA->PUPDR   &= ~(3U << GPIO_PUPDR_PUPD10_Pos);
    GPIOA->PUPDR   |=  (1U << GPIO_PUPDR_PUPD10_Pos); /* Pull-up on RX */

    /* 3. Configure USART1:
     *    - Reset CR1, CR2, CR3 to default (disabled, 8 data bits: M[1:0]=00,
     *      no parity: PCE=0, 1 stop bit: STOP[1:0]=00, oversampling by 16: OVER8=0)
     */
    USART1->CR1 = 0U;
    USART1->CR2 = 0U;
    USART1->CR3 = 0U;

    /* 4. Write Baud Rate Register BEFORE enabling the USART:
     *    At 170 MHz kernel clock and 115200 baud (oversampling by 16):
     *    BRR = 170000000 / 115200 = 1476 (0x05C4)
     */
    USART1->BRR = 1476U;

    /* 5. Enable Transmitter and Receiver */
    USART1->CR1 |= (USART_CR1_TE | USART_CR1_RE);

    /* 6. Enable USART peripheral */
    USART1->CR1 |= USART_CR1_UE;
}
```

### Timer Calculations for 1 kHz PWM at 50% Duty Cycle

1. **Timer Kernel Clock**:
   * With $PCLK1 = 170\text{ MHz}$ and the APB1 prescaler set to 1, the timer clock is:
     $$f_{\text{TIM3\_CLK}} = 170\text{ MHz}$$
2. **Frequency & Resolution**:
   * Target frequency: $f = 1000\text{ Hz}$.
   * Formula:
     $$f_{\text{PWM}} = \frac{f_{\text{TIM3\_CLK}}}{(\text{PSC} + 1) \cdot (\text{ARR} + 1)}$$
   * Choosing $\text{PSC} = 3$ (divide by 4):
     $$\text{ARR} + 1 = \frac{170\,000\,000}{4 \cdot 1000} = 42\,500 \implies \text{ARR} = 42\,499$$
   * Since $\text{ARR} = 42\,499 \le 65\,535$, it fits into TIM3's 16-bit auto-reload register while providing over 15 bits of duty resolution (42,500 discrete steps).
3. **Duty Cycle**:
   * For edge-aligned up-counting PWM mode 1:
     $$\text{Duty} = \frac{\text{CCR1}}{\text{ARR} + 1} = 0.50 \implies \text{CCR1} = \frac{42\,500}{2} = 21\,250$$

### Bare-Metal C Implementation

```c
#include "stm32g4xx.h"

void tim3_ch1_pwm_init(void)
{
    /* 1. Enable peripheral clocks in RCC:
     *    - GPIOA on AHB2 (RCC_AHB2ENR_GPIOAEN)
     *    - TIM3 on APB1 (RCC_APB1ENR1_TIM3EN)
     */
    RCC->AHB2ENR  |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM3EN;

    /* 2. Configure PA6 for Alternate Function 2 (TIM3_CH1):
     *    - MODER6 = 0b10 (Alternate Function mode)
     *    - AFR[0] (AFRL) pin 6 = AF2 (0b0010)
     *    - OSPEEDR6 = 0b11 (High speed)
     */
    GPIOA->MODER &= ~(3U << GPIO_MODER_MODE6_Pos);
    GPIOA->MODER |=  (2U << GPIO_MODER_MODE6_Pos);

    GPIOA->AFR[0] &= ~(0xFU << GPIO_AFRL_AFSEL6_Pos);
    GPIOA->AFR[0] |=  (2U << GPIO_AFRL_AFSEL6_Pos);

    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED6_Pos);

    /* 3. Set PWM frequency to 1 kHz:
     *    f_PWM = 170 MHz / ((PSC + 1) * (ARR + 1))
     *    PSC = 3, ARR = 42499 -> 170,000,000 / (4 * 42500) = 1000 Hz
     */
    TIM3->PSC = 3U;
    TIM3->ARR = 42499U;

    /* 4. Set 50% duty cycle:
     *    CCR1 = 42500 / 2 = 21250
     */
    TIM3->CCR1 = 21250U;

    /* 5. Configure Channel 1 for PWM Mode 1:
     *    - CC1S = 00 (Channel configured as output)
     *    - OC1M[3:0] = 0110b (PWM Mode 1: channel active while CNT < CCR1)
     *    - OC1PE = 1 (Output compare 1 preload enable)
     */
    TIM3->CCMR1 &= ~TIM_CCMR1_OC1M;
    TIM3->CCMR1 |= (6U << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE;

    /* 6. Configure output polarity and enable output:
     *    - CC1P = 0 (Active high, default)
     *    - CC1E = 1 (Enable Channel 1 output on pin)
     */
    TIM3->CCER |= TIM_CCER_CC1E;

    /* 7. Enable Auto-Reload Preload (ARPE) and trigger an update event:
     *    UG loads prescaler and shadow registers immediately
     */
    TIM3->CR1 |= TIM_CR1_ARPE;
    TIM3->EGR  = TIM_EGR_UG;

    /* 8. Enable TIM3 counter */
    TIM3->CR1 |= TIM_CR1_CEN;
}
```

### Complete Initialisation Program

Here is the complete bare-metal C program initializing both the USART1 console and the 1 kHz, 50% duty cycle PWM on TIM3 Channel 1 according to CMSIS conventions and the initial 170 MHz clock tree.

```c
#include "stm32g4xx.h"

int main(void)
{
    /* -------------------------------------------------------------------------
     * 1. Enable peripheral clocks in RCC:
     *    - GPIOA on AHB2 (RCC_AHB2ENR_GPIOAEN)
     *    - USART1 on APB2 (RCC_APB2ENR_USART1EN)
     *    - TIM3 on APB1 (RCC_APB1ENR1_TIM3EN)
     * ------------------------------------------------------------------------- */
    RCC->AHB2ENR  |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR  |= RCC_APB2ENR_USART1EN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM3EN;

    /* -------------------------------------------------------------------------
     * 2. Configure GPIOA pins:
     *    - PA6:  AF2 (TIM3_CH1)
     *    - PA9:  AF7 (USART1_TX)  [PA2 does not support USART1; PA9 is standard USART1_TX]
     *    - PA10: AF7 (USART1_RX)  [PA3 does not support USART1; PA10 is standard USART1_RX]
     * ------------------------------------------------------------------------- */
    /* Set Alternate Function mode (0b10) for PA6, PA9, PA10 */
    GPIOA->MODER &= ~((3U << GPIO_MODER_MODE6_Pos)  |
                      (3U << GPIO_MODER_MODE9_Pos)  |
                      (3U << GPIO_MODER_MODE10_Pos));
    GPIOA->MODER |=  ((2U << GPIO_MODER_MODE6_Pos)  |
                      (2U << GPIO_MODER_MODE9_Pos)  |
                      (2U << GPIO_MODER_MODE10_Pos));

    /* AF2 on PA6 (AFR[0] / AFRL) */
    GPIOA->AFR[0] &= ~(0xFU << GPIO_AFRL_AFSEL6_Pos);
    GPIOA->AFR[0] |=  (2U << GPIO_AFRL_AFSEL6_Pos);

    /* AF7 on PA9 and PA10 (AFR[1] / AFRH) */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) |
                       (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |=  ((7U << GPIO_AFRH_AFSEL9_Pos) |
                       (7U << GPIO_AFRH_AFSEL10_Pos));

    /* Output speed: high speed for PWM (PA6) and UART TX (PA9) */
    GPIOA->OSPEEDR |= ((3U << GPIO_OSPEEDR_OSPEED6_Pos) |
                       (3U << GPIO_OSPEEDR_OSPEED9_Pos));

    /* Pull-up on USART1 RX (PA10) to avoid floating line noise */
    GPIOA->PUPDR &= ~(3U << GPIO_PUPDR_PUPD10_Pos);
    GPIOA->PUPDR |=  (1U << GPIO_PUPDR_PUPD10_Pos);

    /* -------------------------------------------------------------------------
     * 3. Configure USART1:
     *    - 8 data bits (M[1:0] = 00), no parity (PCE = 0), 1 stop bit (STOP[1:0] = 00)
     *    - Oversampling by 16 (OVER8 = 0)
     *    - Baud rate 115200 at 170 MHz:
     *      BRR = 170000000 / 115200 = 1476
     *      BRR is written BEFORE enabling the USART
     * ------------------------------------------------------------------------- */
    USART1->CR1 = 0U;
    USART1->CR2 = 0U;
    USART1->CR3 = 0U;
    USART1->BRR = 1476U;

    /* Enable Transmitter and Receiver */
    USART1->CR1 |= (USART_CR1_TE | USART_CR1_RE);

    /* Enable USART peripheral */
    USART1->CR1 |= USART_CR1_UE;

    /* -------------------------------------------------------------------------
     * 4. Configure TIM3 for 1 kHz, 50% duty cycle PWM on CH1 (PA6):
     *    - Timer clock: 170000000 Hz (APB1 prescaler is 1)
     *    - Target frequency: 1000 Hz
     *      f_PWM = 170000000 / ((PSC + 1) * (ARR + 1))
     *      PSC = 3, ARR = 42499 -> 170000000 / (4 * 42500) = 1000 Hz
     *    - Duty cycle 50%:
     *      CCR1 = (ARR + 1) / 2 = 42500 / 2 = 21250
     * ------------------------------------------------------------------------- */
    TIM3->PSC  = 3U;
    TIM3->ARR  = 42499U;
    TIM3->CCR1 = 21250U;

    /* Channel 1 PWM Mode 1 (OC1M = 0110b), enable preload (OC1PE = 1) */
    TIM3->CCMR1 &= ~TIM_CCMR1_OC1M;
    TIM3->CCMR1 |= (6U << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE;

    /* Enable Channel 1 output on pin, active-high polarity (CC1P = 0) */
    TIM3->CCER |= TIM_CCER_CC1E;

    /* Enable Auto-reload preload (ARPE) */
    TIM3->CR1 |= TIM_CR1_ARPE;

    /* Generate update event to load prescaler and ARR shadow registers */
    TIM3->EGR = TIM_EGR_UG;

    /* Start counter */
    TIM3->CR1 |= TIM_CR1_CEN;

    /* -------------------------------------------------------------------------
     * 5. Main Loop
     * ------------------------------------------------------------------------- */
    while (1)
    {
    }
}
```

### Explanation of the Implementation

1. **Pin Assignment & Multiplexer (AF) Details**:
   * **PA2 and PA3 Hardware Conflict**: In the STM32G474 alternate function table, PA2 and PA3 do not connect to USART1 (PA2 and PA3 map to USART2 and LPUART1). Because USART2 is dedicated to the RS-485 transceiver and the console must use USART1, the USART1 signals are mapped to their standard primary pins: **PA9 (TX, AF7)** and **PA10 (RX, AF7)**.
   * **PA6**: Configured as Alternate Function 2 (`AFRL[27:24] = 0b0010`) to connect to **TIM3_CH1**.
2. **USART1 Configuration**:
   * Initializing `CR1`, `CR2`, and `CR3` to 0 selects 8 data bits, no parity, 1 stop bit, and $16\times$ oversampling.
   * At 170000000 Hz kernel clock, the baud rate register value is calculated as $170000000 / 115200 = 1476$.
   * As required, `BRR` is written before setting `USART_CR1_UE`.
3. **TIM3 PWM Generation**:
   * With APB1 prescaler = 1, the TIM3 counter clock is 170000000 Hz.
   * $\text{PSC} = 3$ divides the clock by 4: $170000000 / 4 = 42500000\text{ Hz}$. An auto-reload value $\text{ARR} = 42499$ ($42500$ ticks) gives $42500000 / 42500 = 1000\text{ Hz}$.
   * $\text{CCR1} = 21250$ gives an exact 50.0% duty cycle ($21250 / 42500 = 0.50$).
   * Setting `OC1M = 0110b` selects edge-aligned PWM Mode 1 (output high while `CNT < CCR1`). `CC1E = 1` enables the output driver to PA6, and writing `TIM_EGR_UG` loads the shadow registers before starting the timer with `TIM_CR1_CEN`.
