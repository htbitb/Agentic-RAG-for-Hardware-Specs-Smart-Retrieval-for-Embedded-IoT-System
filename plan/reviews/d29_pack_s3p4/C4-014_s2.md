### USART1 Configuration (230400 Baud, 8N1, PC4/PC5)

Below is the bare-metal C code to configure USART1 according to your specifications.

```c
#include "stm32g4xx.h"

void usart1_init(void)
{
    /* 1. Enable peripheral clock for GPIOC (AHB2) and USART1 (APB2) */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOCEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PC4 (TX) and PC5 (RX) as Alternate Function (AF7) */
    /* Set MODER to 0b10 (Alternate Function mode) for pins 4 and 5 */
    GPIOC->MODER &= ~(GPIO_MODER_MODE4_Msk | GPIO_MODER_MODE5_Msk);
    GPIOC->MODER |= (2U << GPIO_MODER_MODE4_Pos) | (2U << GPIO_MODER_MODE5_Pos);

    /* Set AF7 (0x07) in AFR[0] (AFRL) for pins 4 and 5 */
    GPIOC->AFR[0] &= ~((0xFU << GPIO_AFRL_AFSEL4_Pos) | (0xFU << GPIO_AFRL_AFSEL5_Pos));
    GPIOC->AFR[0] |= (7U << GPIO_AFRL_AFSEL4_Pos) | (7U << GPIO_AFRL_AFSEL5_Pos);

    /* 3. Configure USART1:
     * - Disable USART1 first to allow configuration (UE = 0).
     * - Default word length is 8 data bits (M1=0, M0=0 in CR1).
     * - Default parity is None (PCE=0 in CR1).
     * - Default oversampling is by 16 (OVER8=0 in CR1).
     * - Default stop bits is 1 stop bit (STOP=00b in CR2).
     */
    USART1->CR1 = 0U;
    USART1->CR2 = 0U;
    USART1->CR3 = 0U;

    /* 4. Set baud rate to 230400 baud before enabling USART.
     * At reset, RCC_CCIPR USART1SEL = 00b (PCLK2 selected as kernel clock).
     * PCLK2 = 170 MHz.
     * With OVER8 = 0 (oversampling by 16):
     *   USARTDIV = f_CK / baud_rate = 170,000,000 / 230,400 ≈ 737.847
     * Rounding to the nearest integer gives USART_BRR = 738 (0x02E2).
     * Actual baud rate = 170,000,000 / 738 = 230,352.3 baud (-0.02% error).
     */
    USART1->BRR = 738U;

    /* 5. Enable transmitter (TE), receiver (RE), and the USART peripheral (UE) */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
```

### Explanation

1. **Clock Enabling**:
   - `GPIOC` is clocked via `RCC->AHB2ENR` (`RCC_AHB2ENR_GPIOCEN`).
   - `USART1` is clocked via `RCC->APB2ENR` (`RCC_APB2ENR_USART1EN`).
   - By default (`RCC->CCIPR` bits `USART1SEL = 00`), USART1 uses `PCLK` (PCLK2 = 170 MHz).

2. **Pin Multiplexing**:
   - On the STM32G474, `PC4` carries `USART1_TX` and `PC5` carries `USART1_RX` on Alternate Function 7 (`AF7`).
   - `MODER4` and `MODER5` are configured to `0b10` (Alternate function mode).
   - In `AFR[0]` (`AFRL`), bits `[19:16]` (`AFSEL4`) and `[23:20]` (`AFSEL5`) are set to `7`.

3. **Baud Rate Calculation**:
   - With `OVER8 = 0` (oversampling by 16), the baud rate divisor formula is:
     $$\text{USARTDIV} = \frac{f_\text{CK}}{\text{Baud Rate}} = \frac{170\,000\,000}{230\,400} \approx 737.847$$
   - Rounding to the nearest integer yields `738` (`0x02E2`), providing an accurate baud rate of $230\,352\text{ baud}$ (relative error $< 0.021\%$, well within UART tolerance).

4. **Sequence & Enable**:
   - As requested, `USART1->BRR` is configured while `UE = 0`.
   - Finally, `USART1->CR1` is programmed with `TE` (Transmitter Enable), `RE` (Receiver Enable), and `UE` (USART Enable) to activate the interface.
