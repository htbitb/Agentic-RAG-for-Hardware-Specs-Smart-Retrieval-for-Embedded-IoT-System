### Assistant answer 0

### Pin Mapping Conflict and Resolution

On the **STM32G474**, **PA2** and **PA3** do **not** carry alternate functions for `USART1` (they carry `USART2_TX` / `USART2_RX` on AF7 and `LPUART1_TX` / `LPUART1_RX` on AF12 [STM32G474_Datasheet p. 73]). 

In the STM32G474 pinout, the pins multiplexed to `USART1` via **AF7** are:
- **PA9** (`USART1_TX`) / **PA10** (`USART1_RX`) (default primary pair)
- **PB6** (`USART1_TX`) / **PB7** (`USART1_RX`)
- **PC4** (`USART1_TX`) / **PC5** (`USART1_RX`)

To fulfill the console requirement without conflicting with USART2, the standard pin mapping **PA9 (TX)** and **PA10 (RX)** was selected.

---

### Configuration & Baud Rate Calculation

1. **Clock Configuration**:
   - `SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz`.
   - By default in `RCC->CCIPR`, `USART1SEL[1:0] = 00b`, selecting `PCLK` (PCLK2 = 170 MHz) as the USART1 kernel clock source $f_{CK}$.
2. **Baud Rate Calculation (Oversampling by 16)**:
   $$\text{USARTDIV} = \frac{f_{CK}}{\text{Baud Rate}} = \frac{170\,000\,000}{115200} \approx 1475.694$$
   Rounding to the nearest integer yields:
   $$\text{BRR} = 1476 \quad (\text{0x05C4})$$
   Actual baud rate: $\frac{170\,000\,000}{1476} \approx 115\,176.15\text{ Baud}$ (relative error $\approx +0.02\%$).
3. **Sequence**:
   - Enable GPIOA clock (`RCC_AHB2ENR_GPIOAEN`) and USART1 clock (`RCC_APB2ENR_USART1EN`).
   - Configure PA9 and PA10 in Alternate Function mode (MODER = `10b`) with AF7 (`AFRH` = 7).
   - Ensure USART1 is disabled (`UE = 0`) during configuration.
   - Configure 8 data bits (`M1:M0 = 00b`), no parity (`PCE = 0`), 1 stop bit (`STOP[1:0] = 00b`), and oversampling by 16 (`OVER8 = 0`).
   - Write the baud rate value to `USART1->BRR`.
   - Enable transmitter (`TE = 1`), receiver (`RE = 1`), and USART1 (`UE = 1`).

### C Implementation

```c
#include "stm32g4xx.h"

void usart1_init(void)
{
    /* 1. Enable peripheral clocks for GPIOA and USART1 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PA9 (TX) and PA10 (RX) as Alternate Function AF7 (USART1) */
    /* Set MODER9 and MODER10 to Alternate Function mode (0b10) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

    /* Set AF7 for PA9 and PA10 in AFR[1] (AFRH) */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= (7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos);

    /* Configure high output speed for PA9 */
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED9_Pos);

    /* Enable pull-up on RX line (PA10) to prevent floating when idle */
    GPIOA->PUPDR &= ~GPIO_PUPDR_PUPD10_Msk;
    GPIOA->PUPDR |= (1U << GPIO_PUPDR_PUPD10_Pos);

    /* 3. Disable USART1 before writing configuration registers */
    USART1->CR1 = 0;

    /* 4. Configure frame format: 8 data bits, no parity (default in CR1: M=0, PCE=0)
     *    Set 1 stop bit: CR2 STOP[1:0] = 00b
     */
    USART1->CR2 &= ~USART_CR2_STOP_Msk;

    /* 5. Set baud rate: 115200 baud with f_CK = 170 MHz (over8 = 0)
     *    BRR = 170000000 / 115200 = 1475.69 -> 1476 (0x5C4)
     *    Requirement: BRR written before USART is enabled
     */
    USART1->BRR = (170000000U + (115200U / 2U)) / 115200U;

    /* 6. Enable Transmitter (TE), Receiver (RE), and USART1 (UE) */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
```

### Assistant answer 1

### Configuration & Timer Parameter Calculations

1. **Pin Mapping**:
   - On the **STM32G474**, pin **PA6** maps to **TIM3_CH1** via **AF2** [STM32G474_Datasheet p. 73].
   - Configure PA6 in alternate function mode (`MODER6 = 10b`), AF2 (`AFRL6 = 0010b`), push-pull output, high speed.

2. **Clock and Frequency Calculation**:
   - System clock: `HCLK = PCLK1 = 170 MHz`.
   - When the APB1 prescaler is 1, the timer kernel clock is equal to PCLK1:
     $$f_{\text{TIM3CLK}} = 170\,\text{MHz}$$
   - The PWM output frequency is:
     $$f_{\text{PWM}} = \frac{f_{\text{TIM3CLK}}}{(\text{PSC} + 1) \times (\text{ARR} + 1)} = 1000\,\text{Hz}$$
   - Choosing $\text{PSC} = 3$ (divide by 4):
     $$\text{ARR} + 1 = \frac{170\,000\,000}{4 \times 1000} = 42500 \implies \text{ARR} = 42499$$
   - Since TIM3 is a 16-bit counter, $\text{ARR} = 42499 \le 65535$, fitting within 16 bits.
   - For a **50 % duty cycle** in edge-aligned PWM Mode 1:
     $$\text{CCR1} = \frac{\text{ARR} + 1}{2} = \frac{42500}{2} = 21250$$
     This provides exact 1000.0 Hz frequency and 50.0 % duty cycle (0 % error).

3. **Timer Peripheral Configuration (TIM3)**:
   - Enable `TIM3` clock in `RCC->APB1ENR1` (`TIM3EN`).
   - In `TIM3->CCMR1`:
     - Channel 1 configured as output: `CC1S = 00b`.
     - Output Compare 1 mode set to **PWM mode 1**: `OC1M = 0110b` (output active while $\text{CNT} < \text{CCR1}$, inactive otherwise).
     - Enable preload register: `OC1PE = 1`.
   - In `TIM3->CCER`:
     - Active-high polarity: `CC1P = 0`.
     - Enable output: `CC1E = 1`.
   - In `TIM3->CR1`:
     - Enable auto-reload preload: `ARPE = 1`.
     - Note: As a general-purpose timer, TIM3 does not have a main output enable (`BDTR.MOE`) bit.
   - Generate an update event via `TIM3->EGR |= TIM_EGR_UG` to load preloaded registers into shadow registers.
   - Start counter: `TIM3->CR1 |= TIM_CR1_CEN`.

### C Implementation

```c
#include "stm32g4xx.h"

void tim3_ch1_pwm_init(void)
{
    /* 1. Enable peripheral clocks for GPIOA and TIM3 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM3EN;

    /* 2. Configure PA6 as Alternate Function AF2 (TIM3_CH1) */
    /* Set PA6 mode to Alternate Function (0b10) */
    GPIOA->MODER &= ~GPIO_MODER_MODE6_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE6_Pos);

    /* Set AF2 in AFR[0] (AFRL) for pin 6 */
    GPIOA->AFR[0] &= ~GPIO_AFRL_AFSEL6_Msk;
    GPIOA->AFR[0] |= (2U << GPIO_AFRL_AFSEL6_Pos);

    /* High output speed */
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED6_Pos);

    /* 3. Configure TIM3 timebase for 1 kHz PWM
     *    Timer clock = 170 MHz (PCLK1 = 170 MHz, APB1 prescaler = 1)
     *    f_PWM = 170 MHz / ((PSC + 1) * (ARR + 1)) = 1 kHz
     *    PSC = 3 (clock divided by 4: 42.5 MHz)
     *    ARR = 42499 (42500 ticks per period -> 1.000 kHz)
     *    CCR1 = 21250 (50.0 % duty cycle)
     */
    TIM3->PSC = 3;
    TIM3->ARR = 42499;
    TIM3->CCR1 = 21250;

    /* 4. Configure PWM Mode 1 on Channel 1:
     *    - CC1S = 00b (CC1 channel configured as output)
     *    - OC1M[3:0] = 0110b (PWM mode 1: active while CNT < CCR1)
     *    - OC1PE = 1 (Output compare 1 preload enable)
     */
    TIM3->CCMR1 &= ~(TIM_CCMR1_CC1S_Msk | TIM_CCMR1_OC1M_Msk);
    TIM3->CCMR1 |= (6U << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE;

    /* 5. Configure channel polarity and enable output:
     *    - CC1P = 0 (Active high)
     *    - CC1E = 1 (Enable output on PA6)
     */
    TIM3->CCER &= ~TIM_CCER_CC1P;
    TIM3->CCER |= TIM_CCER_CC1E;

    /* 6. Enable auto-reload preload (ARPE) and load registers */
    TIM3->CR1 |= TIM_CR1_ARPE;
    TIM3->EGR = TIM_EGR_UG;

    /* 7. Start the timer counter */
    TIM3->CR1 |= TIM_CR1_CEN;
}
```

### Complete Initialisation Program

Here is the complete bare-metal C initialisation program for the STM32G474 combining USART1 console communication and TIM3 Channel 1 PWM output into `main()`.

```c
#include "stm32g4xx.h"

int main(void)
{
    /* 1. Enable peripheral clocks:
     *    - AHB2: GPIOA (PA6 for PWM, PA9/PA10 for USART1)
     *    - APB1: TIM3 (PWM generator)
     *    - APB2: USART1 (Serial console)
     */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM3EN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure GPIOA Alternate Functions:
     *    - PA6:  AF2 (TIM3_CH1)
     *    - PA9:  AF7 (USART1_TX)
     *    - PA10: AF7 (USART1_RX)
     */
    /* Set MODER to Alternate Function mode (0b10) for pins 6, 9, 10 */
    GPIOA->MODER &= ~(GPIO_MODER_MODE6_Msk | GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE6_Pos) |
                    (2U << GPIO_MODER_MODE9_Pos) |
                    (2U << GPIO_MODER_MODE10_Pos);

    /* AFRL: pin 6 -> AF2 (TIM3_CH1) */
    GPIOA->AFR[0] &= ~GPIO_AFRL_AFSEL6_Msk;
    GPIOA->AFR[0] |= (2U << GPIO_AFRL_AFSEL6_Pos);

    /* AFRH: pin 9 -> AF7 (USART1_TX), pin 10 -> AF7 (USART1_RX) */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= (7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos);

    /* Configure High output speed for output pins (PA6, PA9) */
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED6_Pos) | (3U << GPIO_OSPEEDR_OSPEED9_Pos);

    /* Pull-up on RX pin (PA10) to avoid floating line when disconnected */
    GPIOA->PUPDR &= ~GPIO_PUPDR_PUPD10_Msk;
    GPIOA->PUPDR |= (1U << GPIO_PUPDR_PUPD10_Pos);

    /* 3. Configure USART1:
     *    - Oversampling by 16 (CR1.OVER8 = 0)
     *    - Frame format: 8 data bits (M=0), no parity (PCE=0), 1 stop bit (CR2.STOP=0)
     *    - Baud rate: 115200 at f_CK = 170 MHz
     *      BRR = round(170000000 / 115200) = 1476 (0x5C4) -> 115176 Baud (+0.02% error)
     *    - BRR is written while USART1 is disabled (CR1 = 0)
     *    - Enable Transmitter (TE), Receiver (RE), and USART1 peripheral (UE)
     */
    USART1->CR1 = 0;
    USART1->CR2 &= ~USART_CR2_STOP_Msk;
    USART1->BRR = (170000000U + (115200U / 2U)) / 115200U;
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;

    /* 4. Configure TIM3 for 1 kHz PWM, 50 % duty cycle on Channel 1 (PA6):
     *    - Timer clock = 170 MHz (PCLK1 = 170 MHz, APB1 prescaler = 1)
     *    - Prescaler PSC = 3 (counter clock = 170 MHz / (3 + 1) = 42.5 MHz)
     *    - Period ARR = 42499 (frequency = 170 MHz / ((3 + 1) * (42499 + 1)) = 1000 Hz)
     *    - Pulse CCR1 = 21250 (duty cycle = 21250 / 42500 = 50 %)
     */
    TIM3->PSC = 3;
    TIM3->ARR = 42499;
    TIM3->CCR1 = 21250;

    /* Channel 1 Output Compare Mode: PWM mode 1 (OC1M = 0110b), preload enable (OC1PE = 1) */
    TIM3->CCMR1 &= ~(TIM_CCMR1_CC1S_Msk | TIM_CCMR1_OC1M_Msk);
    TIM3->CCMR1 |= (6U << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE;

    /* Polarity: Active high (CC1P = 0), Enable channel output (CC1E = 1) */
    TIM3->CCER &= ~TIM_CCER_CC1P;
    TIM3->CCER |= TIM_CCER_CC1E;

    /* Auto-reload preload enable (ARPE = 1), generate update event to load registers */
    TIM3->CR1 |= TIM_CR1_ARPE;
    TIM3->EGR = TIM_EGR_UG;

    /* Start counter (CEN = 1) */
    TIM3->CR1 |= TIM_CR1_CEN;

    /* 5. Main loop */
    while (1)
    {
    }
}
```

### Short Explanation

1. **Peripheral Clock Enabling & GPIO Mapping**:
   - The peripherals are clocked via `RCC->AHB2ENR` (GPIOA), `RCC->APB1ENR1` (TIM3), and `RCC->APB2ENR` (USART1).
   - Alternate function multiplexing configures PA6 as `AF2` for `TIM3_CH1` [STM32G474_Datasheet p. 73], and PA9 / PA10 as `AF7` for `USART1_TX` / `USART1_RX` [STM32G474_Datasheet p. 73].
   - A pull-up is added to PA10 to maintain an idle high state on the UART RX line when not driven.

2. **USART1 Configuration**:
   - `USART1->CR1` is cleared first so that `USART1->BRR` is written before the peripheral is enabled.
   - At $f_{CK} = 170\,\text{MHz}$ with oversampling by 16, setting $\text{BRR} = 1476$ produces an actual baud rate of $170\,000\,000 / 1476 \approx 115\,176\,\text{Baud}$ (0.02% error).
   - Setting `USART_CR1_TE | USART_CR1_RE | USART_CR1_UE` in `USART1->CR1` enables both transmission and reception.

3. **TIM3 PWM Generation**:
   - TIM3 runs from the 170 MHz APB1 timer clock.
   - With $\text{PSC} = 3$ (divide by $3 + 1 = 4$), the counter frequency is $170\,\text{MHz} / 4 = 42.5\,\text{MHz}$.
   - Auto-reload value $\text{ARR} = 42499$ yields a period of $(42499 + 1) / 42.5\,\text{MHz} = 1.000\,\text{ms}$, or exactly $1000\,\text{Hz}$.
   - Setting $\text{CCR1} = 21250$ sets a $50\,\%$ duty cycle ($21250 / 42500 = 0.50$).
   - Channel 1 is placed in edge-aligned PWM mode 1 (`OC1M = 0110b`) with preload enabled (`OC1PE = 1`) and active-high output (`CC1P = 0`, `CC1E = 1`).
   - Software generates an update event via `TIM3->EGR = TIM_EGR_UG` to load preloaded registers into shadow registers before starting the counter with `TIM_CR1_CEN`.
