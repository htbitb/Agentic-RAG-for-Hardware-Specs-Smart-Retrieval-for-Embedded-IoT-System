### Assistant answer 0

### Configuration and Calculations

1. **Clock Frequencies**:
   - $\text{SYSCLK} = 170\text{ MHz}$, $\text{AHB PRESC} = 1 \implies \text{HCLK} = 170\text{ MHz}$.
   - $\text{APB1 PRESC} = 1 \implies \text{PCLK1} = 170\text{ MHz}$.
   - For STM32G4, when the APB prescaler is 1, the timer kernel clock equals PCLK1:
     $$\text{TIM3CLK} = 170\text{ MHz}$$

2. **PWM Frequency (20 kHz)**:
   - Using edge-aligned PWM Mode 1:
     $$f_{\text{PWM}} = \frac{\text{TIM3CLK}}{(\text{PSC} + 1) \cdot (\text{ARR} + 1)}$$
   - Choosing $\text{PSC} = 0$ gives the maximum duty cycle resolution (8,500 steps, ~13.05 bits):
     $$\text{ARR} = \frac{170{,}000{,}000}{20{,}000} - 1 = 8500 - 1 = 8499$$

3. **Duty Cycle (40 %)**:
   - In up-counting PWM Mode 1 with active-high polarity, output is active when $\text{CNT} < \text{CCR1}$:
     $$\text{CCR1} = 40\% \times (\text{ARR} + 1) = 0.40 \times 8500 = 3400$$

4. **GPIO Configuration**:
   - Pin: **PA6**
   - Alternate function: **AF2** corresponds to `TIM3_CH1` (configured via `AFR[0]`, bits [27:24]).
   - Mode: Alternate function mode (`MODER[13:12] = 10b`).

5. **Timer Specifics**:
   - `TIM3` is a general-purpose timer on APB1 (`RCC->APB1ENR1 |= RCC_APB1ENR1_TIM3EN`).
   - Does not have a break/dead-time register (`BDTR`) requiring `MOE` (unlike advanced timers TIM1/TIM8/TIM20).
   - Preload enabled on CCR1 (`OC1PE`) and ARR (`ARPE`).
   - Software update event triggered (`TIM_EGR_UG`) to transfer initial prescaler and ARR values to shadow registers before counter start (`TIM_CR1_CEN`).

### Bare-Metal C Code

```c
#include "stm32g4xx.h"

/**
 * @brief Initialize TIM3 Channel 1 on PA6 for 20 kHz PWM with 40% duty cycle.
 *        SYSCLK = PCLK1 = 170 MHz.
 */
void tim3_ch1_pwm_init(void)
{
    /* 1. Enable GPIOA peripheral clock */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;

    /* 2. Configure PA6 as Alternate Function mode (MODER6 = 10b) */
    GPIOA->MODER &= ~GPIO_MODER_MODE6_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE6_Pos);

    /* 3. Assign PA6 to AF2 (TIM3_CH1) in GPIOA alternate function low register (AFRL) */
    GPIOA->AFR[0] &= ~GPIO_AFRL_AFSEL6_Msk;
    GPIOA->AFR[0] |= (2U << GPIO_AFRL_AFSEL6_Pos);

    /* 4. Enable TIM3 peripheral clock */
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM3EN;

    /* 5. Configure time base:
     *    TIM3CLK = 170 MHz
     *    PSC = 0 -> timer counter clock = 170 MHz
     *    ARR = 8499 -> PWM frequency = 170 MHz / (1 * 8500) = 20,000 Hz (20 kHz)
     */
    TIM3->PSC = 0U;
    TIM3->ARR = 8499U;

    /* 6. Configure duty cycle:
     *    CCR1 = 3400 -> Duty cycle = 3400 / 8500 = 40.0%
     */
    TIM3->CCR1 = 3400U;

    /* 7. Configure Channel 1:
     *    - CC1S = 00 (Channel configured as output)
     *    - OC1M = 110 (PWM mode 1: active while CNT < CCR1)
     *    - OC1PE = 1 (Output compare 1 preload enable)
     */
    TIM3->CCMR1 &= ~(TIM_CCMR1_CC1S_Msk | TIM_CCMR1_OC1M_Msk);
    TIM3->CCMR1 |= (0x6U << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE;

    /* 8. Enable output on Channel 1 with active-high polarity (CC1P = 0) */
    TIM3->CCER &= ~TIM_CCER_CC1P;
    TIM3->CCER |= TIM_CCER_CC1E;

    /* 9. Generate an update event to transfer PSC, ARR, and CCR1 to active registers */
    TIM3->EGR = TIM_EGR_UG;

    /* 10. Enable Auto-Reload Preload (ARPE) and start counter (CEN) */
    TIM3->CR1 |= TIM_CR1_ARPE | TIM_CR1_CEN;
}
```

### Assistant answer 1

### Architectural Limitation: Shared Timer Time Base

In the STM32 architecture (RM0440 Section 30), all channels of a general-purpose timer such as **TIM3** share a single counter (`CNT`), prescaler (`PSC`), and auto-reload register (`ARR`):

$$f_{\text{PWM}} = \frac{f_{\text{TIMCLK}}}{(\text{PSC} + 1) \cdot (\text{ARR} + 1)}$$

- In Message 1, TIM3 was configured to run **TIM3_CH1 (PA6)** at **20 kHz** ($\text{PSC} = 0, \text{ARR} = 8499$) with a 40% duty cycle ($\text{CCR1} = 3400$).
- Because TIM3 Channel 1 and Channel 2 share the exact same `PSC` and `ARR`, **TIM3 cannot simultaneously generate 20 kHz on Channel 1 and 1 kHz on Channel 2**. 

To use **PA7 (TIM3_CH2)** on the same timer, Channel 2 must operate at the timer's established frequency of **20 kHz** (with a 50% duty cycle, $\text{CCR2} = 4250$). 

*(Note: If an independent 1 kHz frequency is strictly required on pin PA7 without changing PA6, PA7 can instead be mapped to **TIM17_CH1 (AF1)**, which is an independent timer on APB2).*

### Bare-Metal C Implementation

The function below enables the clocks, initializes the GPIO alternate functions (AF2) for both PA6 and PA7, and sets up **TIM3 Channel 1** (20 kHz, 40% duty cycle) and **TIM3 Channel 2** (20 kHz, 50% duty cycle):

```c
#include "stm32g4xx.h"

/**
 * @brief Configure PA6 (TIM3_CH1) and PA7 (TIM3_CH2) on TIM3.
 *        SYSCLK = PCLK1 = 170 MHz.
 *        Shared frequency: 20 kHz (PSC = 0, ARR = 8499).
 *        - PA6 (CH1): 40% duty cycle (CCR1 = 3400)
 *        - PA7 (CH2): 50% duty cycle (CCR2 = 4250)
 */
void tim3_ch1_ch2_init(void)
{
    /* 1. Enable GPIOA peripheral clock */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;

    /* 2. Configure PA6 and PA7 as Alternate Function mode (MODER = 10b) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE6_Msk | GPIO_MODER_MODE7_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE6_Pos) | (2U << GPIO_MODER_MODE7_Pos);

    /* 3. Assign PA6 and PA7 to AF2 (TIM3_CH1 and TIM3_CH2) in AFRL (AFR[0]) */
    GPIOA->AFR[0] &= ~(GPIO_AFRL_AFSEL6_Msk | GPIO_AFRL_AFSEL7_Msk);
    GPIOA->AFR[0] |= (2U << GPIO_AFRL_AFSEL6_Pos) | (2U << GPIO_AFRL_AFSEL7_Pos);

    /* 4. Enable TIM3 peripheral clock on APB1 */
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM3EN;

    /* 5. Configure time base for 20 kHz:
     *    TIM3CLK = 170 MHz
     *    PSC = 0 -> timer tick = 170 MHz
     *    ARR = 8499 -> f_PWM = 170 MHz / (1 * 8500) = 20,000 Hz (20 kHz)
     */
    TIM3->PSC = 0U;
    TIM3->ARR = 8499U;

    /* 6. Configure Channel 1 duty cycle (PA6, LED): 40% (3400 / 8500) */
    TIM3->CCR1 = 3400U;

    /* 7. Configure Channel 2 duty cycle (PA7, Buzzer): 50% (4250 / 8500) */
    TIM3->CCR2 = 4250U;

    /* 8. Configure CCMR1 for Channel 1 and Channel 2:
     *    - CC1S = 00, CC2S = 00 (Output compare)
     *    - OC1M = 110b, OC2M = 110b (PWM Mode 1)
     *    - OC1PE = 1, OC2PE = 1 (Preload enable)
     */
    TIM3->CCMR1 &= ~(TIM_CCMR1_CC1S_Msk | TIM_CCMR1_OC1M_Msk |
                     TIM_CCMR1_CC2S_Msk | TIM_CCMR1_OC2M_Msk);
    TIM3->CCMR1 |= (0x6U << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE |
                   (0x6U << TIM_CCMR1_OC2M_Pos) | TIM_CCMR1_OC2PE;

    /* 9. Enable Channel 1 and Channel 2 outputs (active-high polarity) */
    TIM3->CCER &= ~(TIM_CCER_CC1P | TIM_CCER_CC2P);
    TIM3->CCER |= TIM_CCER_CC1E | TIM_CCER_CC2E;

    /* 10. Generate an update event (UG) to transfer PSC, ARR, and CCRx */
    TIM3->EGR = TIM_EGR_UG;

    /* 11. Enable Auto-Reload Preload (ARPE) and start counter (CEN) */
    TIM3->CR1 |= TIM_CR1_ARPE | TIM_CR1_CEN;
}
```

Message 3: add a debug serial port on USART3 at 115200 baud with TX on pin PB10 and RX on pin PB11: 8 data bits, no parity, 1 stop bit, oversampling by 16, both directions enabled, and the baud-rate register written before the USART is enabled.

### Assistant answer 2

### Configuration and Calculations

1. **Clock Source & Frequency**:
   - `USART3` is on the APB1 domain.
   - At reset (`RCC_CCIPR[5:4] = 00b`), the `USART3` clock source is **PCLK1**.
   - Given $\text{PCLK1} = 170\text{ MHz}$, the input clock frequency is $f_{\text{CK}} = 170{,}000{,}000\text{ Hz}$.

2. **Baud Rate Calculation (115200 baud, Oversampling by 16)**:
   - For oversampling by 16 ($\text{OVER8} = 0$ in `USART_CR1`):
     $$\text{USARTDIV} = \frac{f_{\text{CK}}}{\text{Baud Rate}} = \frac{170{,}000{,}000}{115{,}200} = \frac{10625}{7.2} \approx 1475.6944$$
   - Rounding to the nearest integer gives $\text{BRR} = 1476$.
   - Resulting baud rate:
     $$\text{Actual Baud} = \frac{170{,}000{,}000}{1476} \approx 115{,}176.15\text{ Baud}$$

3. **Frame Format**:
   - **Data bits**: 8 data bits $\implies \text{M1:M0} = 00\text{b}$ (`M0 = 0`, `M1 = 0`).
   - **Parity**: None $\implies \text{PCE} = 0$.
   - **Stop bits**: 1 stop bit $\implies \text{STOP}[1:0] = 00\text{b}$ in `USART_CR2`.
   - **Oversampling**: 16 $\implies \text{OVER8} = 0$ in `USART_CR1`.
   - **Transmitter & Receiver**: $\text{TE} = 1$, $\text{RE} = 1$.

4. **Pin Multiplexing**:
   - **PB10** $\rightarrow$ `USART3_TX` via **AF7** (`AFRH` / `AFR[1]`, bits [11:8]).
   - **PB11** $\rightarrow$ `USART3_RX` via **AF7** (`AFRH` / `AFR[1]`, bits [15:12]).
   - Both pins configured in Alternate Function mode (`MODER[21:20] = 10b`, `MODER[23:22] = 10b`).

### Bare-Metal C Code

```c
#include "stm32g4xx.h"

/**
 * @brief Initialize USART3 on PB10 (TX) and PB11 (RX) at 115200 baud.
 *        SYSCLK = PCLK1 = 170 MHz.
 *        8 data bits, no parity, 1 stop bit, oversampling by 16.
 */
void usart3_init(void)
{
    /* 1. Enable GPIOB peripheral clock */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;

    /* 2. Configure PB10 (TX) and PB11 (RX) as Alternate Function mode (MODER = 10b) */
    GPIOB->MODER &= ~(GPIO_MODER_MODE10_Msk | GPIO_MODER_MODE11_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE10_Pos) | (2U << GPIO_MODER_MODE11_Pos);

    /* 3. Assign AF7 (USART3_TX / USART3_RX) to PB10 and PB11 in AFRH (AFR[1]) */
    GPIOB->AFR[1] &= ~(GPIO_AFRH_AFSEL10_Msk | GPIO_AFRH_AFSEL11_Msk);
    GPIOB->AFR[1] |= (7U << GPIO_AFRH_AFSEL10_Pos) | (7U << GPIO_AFRH_AFSEL11_Pos);

    /* 4. Enable USART3 peripheral clock on APB1 */
    RCC->APB1ENR1 |= RCC_APB1ENR1_USART3EN;

    /* 5. Set baud rate register (BRR) BEFORE enabling USART:
     *    f_CK = PCLK1 = 170 MHz
     *    Oversampling by 16: BRR = round(170000000 / 115200) = 1476
     */
    USART3->BRR = 1476U;

    /* 6. Configure CR2: 1 stop bit (STOP[1:0] = 00b) */
    USART3->CR2 &= ~USART_CR2_STOP_Msk;

    /* 7. Configure CR1:
     *    - 8 data bits: M1 = 0, M0 = 0
     *    - No parity: PCE = 0
     *    - Oversampling by 16: OVER8 = 0
     *    - Enable Transmitter (TE) and Receiver (RE)
     */
    USART3->CR1 &= ~(USART_CR1_M1 | USART_CR1_M0 | USART_CR1_PCE | USART_CR1_OVER8);
    USART3->CR1 |= USART_CR1_TE | USART_CR1_RE;

    /* 8. Enable USART3 (UE = 1) */
    USART3->CR1 |= USART_CR1_UE;
}

/**
 * @brief Transmit a single byte over USART3 (busy-wait polling).
 */
void usart3_write_byte(uint8_t data)
{
    /* Wait until the transmit data register is empty (TXE / TXFNF) */
    while (!(USART3->ISR & USART_ISR_TXE_TXFNF))
    {
    }
    USART3->TDR = data;
}

/**
 * @brief Receive a single byte over USART3 (busy-wait polling).
 */
uint8_t usart3_read_byte(void)
{
    /* Wait until received data is ready to be read (RXNE / RXFNE) */
    while (!(USART3->ISR & USART_ISR_RXNE_RXFNE))
    {
    }
    return (uint8_t)(USART3->RDR & 0xFFU);
}
```

### Explanation

1. **Clocks and GPIO Multiplexing**:
   - `RCC->AHB2ENR` enables the GPIOA and GPIOB peripheral clocks.
   - `RCC->APB1ENR1` enables the clocks for `TIM3` and `USART3`.
   - **PA6** and **PA7** are configured in alternate function mode (`MODER = 10b`) with **AF2** in `AFR[0]` (`AFRL`), routing them to `TIM3_CH1` and `TIM3_CH2`.
   - **PB10** and **PB11** are configured in alternate function mode (`MODER = 10b`) with **AF7** in `AFR[1]` (`AFRH`), routing them to `USART3_TX` and `USART3_RX`.

2. **PWM Generation (`TIM3`)**:
   - Because `TIM3` channels share a single time base (`PSC` and `ARR`), both channels operate at the common timer frequency of **20 kHz** ($\text{PSC} = 0$, $\text{ARR} = 8499$).
   - `CCR1 = 3400` sets the Channel 1 (PA6, LED) duty cycle to $3400 / 8500 = 40.0\%$.
   - `CCR2 = 4250` sets the Channel 2 (PA7, Buzzer) duty cycle to $4250 / 8500 = 50.0\%$.
   - Preload is enabled on both channels (`OC1PE`, `OC2PE`) and auto-reload (`ARPE`). An update event is generated via `TIM3->EGR = TIM_EGR_UG` to immediately load shadow registers before setting `TIM_CR1_CEN`.

3. **Serial Port (`USART3`)**:
   - Using $f_{\text{PCLK1}} = 170\text{ MHz}$ and oversampling by 16, the divider is $\text{BRR} = \text{round}(170{,}000{,}000 / 115{,}200) = 1476$, yielding an actual baud rate of $115{,}176\text{ Baud}$ ($-0.02\%$ error).
   - `BRR` is written before enabling the peripheral (`UE`), satisfying the hardware sequence requirement.
   - The peripheral is configured for 8 data bits, 1 stop bit, no parity, and both transmitter (`TE`) and receiver (`RE`) are enabled.
