### Configuration Summary

This implementation configures **USART1** on an **STM32G474** MCU running with $f_{\text{SYSCLK}} = f_{\text{PCLK2}} = 170\text{ MHz}$ for asynchronous communication at **230,400 baud**, 8 data bits, no parity, 1 stop bit, oversampling by 16, with both TX and RX enabled:

1. **Clocks and GPIO Multiplexing:**
   - **GPIOC**: Clock enabled via `RCC->AHB2ENR |= RCC_AHB2ENR_GPIOCEN;`
   - **USART1**: Clock enabled via `RCC->APB2ENR |= RCC_APB2ENR_USART1EN;`
   - **PC4** (USART1_TX): Configured as Alternate Function mode (`MODER[9:8] = 0b10`) with AF7 (`AFRL[19:16] = 0b0111`).
   - **PC5** (USART1_RX): Configured as Alternate Function mode (`MODER[11:10] = 0b10`) with AF7 (`AFRL[23:20] = 0b0111`).

2. **Baud Rate Calculation:**
   - With `RCC->CCIPR` in its reset state, USART1 kernel clock source is `PCLK2 = 170,000,000 Hz`.
   - In oversampling-by-16 mode (`OVER8 = 0` in `USART1_CR1`), the baud-rate divider is:
     $$\text{USARTDIV} = \frac{f_{\text{CK}}}{\text{Baud}} = \frac{170\,000\,000}{230\,400} \approx 737.847$$
   - Rounding to the nearest integer yields $\text{BRR} = 738$ (`0x02E2`), producing an actual baud rate of:
     $$\text{Actual Baud} = \frac{170\,000\,000}{738} \approx 230\,352.3\text{ baud} \quad (\approx -0.02\%\text{ error})$$
   - Per requirement, `USART1->BRR` is written while the USART is disabled (`UE = 0`).

3. **Frame Format & Direction Configuration:**
   - `CR1`: 8 data bits (`M1=0, M0=0`), parity disabled (`PCE=0`), oversampling by 16 (`OVER8=0`).
   - `CR2`: 1 stop bit (`STOP[1:0] = 00b`).
   - Transmitter (`TE`) and receiver (`RE`) along with the peripheral enable (`UE`) are asserted in `USART1->CR1`.

### Bare-Metal C Code

```c
#include "stm32g4xx.h"

void usart1_init(void) {
    /* 1. Enable peripheral clocks for GPIOC and USART1 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOCEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PC4 (TX) and PC5 (RX) for Alternate Function 7 (AF7) */
    /* Set PC4 and PC5 mode to Alternate Function (MODER = 0b10) */
    GPIOC->MODER &= ~(GPIO_MODER_MODE4_Msk | GPIO_MODER_MODE5_Msk);
    GPIOC->MODER |= (2U << GPIO_MODER_MODE4_Pos) | (2U << GPIO_MODER_MODE5_Pos);

    /* Map PC4 and PC5 to AF7 in AFRL */
    GPIOC->AFR[0] &= ~((0xFU << GPIO_AFRL_AFSEL4_Pos) | (0xFU << GPIO_AFRL_AFSEL5_Pos));
    GPIOC->AFR[0] |= (7U << GPIO_AFRL_AFSEL4_Pos) | (7U << GPIO_AFRL_AFSEL5_Pos);

    /* 3. Configure USART1 frame format while USART is disabled */
    USART1->CR1 &= ~USART_CR1_UE;

    /* CR2: 1 Stop bit (STOP[1:0] = 00b) */
    USART1->CR2 &= ~USART_CR2_STOP_Msk;

    /* CR1: 8 data bits (M0=0, M1=0), no parity (PCE=0), oversampling by 16 (OVER8=0) */
    USART1->CR1 &= ~(USART_CR1_M0 | USART_CR1_M1 | USART_CR1_PCE | USART_CR1_OVER8);

    /* 4. Configure baud rate: 230400 baud with PCLK2 = 170 MHz and OVER8 = 0
     * USARTDIV = 170000000 / 230400 = 737.847 -> rounded to 738 (0x02E2)
     * BRR is written before USART is enabled.
     */
    USART1->BRR = 738U;

    /* 5. Enable Transmitter, Receiver, and USART peripheral */
    USART1->CR1 |= USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
```
