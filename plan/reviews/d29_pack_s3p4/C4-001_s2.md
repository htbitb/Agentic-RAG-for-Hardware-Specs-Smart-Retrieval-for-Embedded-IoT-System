### Implementation: 20 kHz, 25% Duty Cycle PWM on PA8 (TIM1_CH1)

#### 1. Clock & Register Calculations
- **Timer Clock ($f_{\text{TIM1CLK}}$)**: With `SYSCLK = HCLK = PCLK2 = 170 MHz` and APB2 prescaler $= 1$, the timer kernel clock is:
  $$f_{\text{TIM1CLK}} = 170\text{ MHz}$$
- **Target PWM Frequency ($f_{\text{PWM}}$)**: $20\text{ kHz}$
- **Prescaler ($PSC$) & Auto-Reload ($ARR$)**:
  $$\text{Period Counts} = \frac{f_{\text{TIM1CLK}}}{f_{\text{PWM}}} = \frac{170\,000\,000}{20\,000} = 8500$$
  Selecting $PSC = 0$ provides the maximum counter resolution:
  $$ARR = 8500 - 1 = 8499$$
- **Duty Cycle ($CCR1$)**: For edge-aligned up-counting PWM Mode 1 with 25% duty:
  $$CCR1 = (ARR + 1) \times 25\% = 8500 \times 0.25 = 2125$$
- **Pin Multiplexing**: PA8 routes `TIM1_CH1` on **AF6** (`AFRH` register, bits [3:0]).
- **Advanced Timer Output**: TIM1 is an advanced control timer; setting `BDTR.MOE = 1` (Main Output Enable) is required to connect the output compare signal to the external pin.

#### 2. Bare-Metal C Code

```c
#include "stm32g4xx.h"

void tim1_pa8_pwm_init(void)
{
    /* 1. Enable peripheral clocks for GPIOA and TIM1 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_TIM1EN;

    /* 2. Configure PA8 as Alternate Function (AF6 = TIM1_CH1) */
    /* Set MODER8 to 10 (Alternate Function mode) */
    GPIOA->MODER &= ~GPIO_MODER_MODE8_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE8_Pos);

    /* Push-pull output (OTYPER8 = 0) */
    GPIOA->OTYPER &= ~GPIO_OTYPER_OT8;

    /* High speed output */
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED8_Pos);

    /* No pull-up / pull-down */
    GPIOA->PUPDR &= ~GPIO_PUPDR_PUPD8_Msk;

    /* AF6 on PA8 (AFSEL8 in AFR[1]) */
    GPIOA->AFR[1] &= ~GPIO_AFRH_AFSEL8_Msk;
    GPIOA->AFR[1] |= (6U << GPIO_AFRH_AFSEL8_Pos);

    /* 3. Configure TIM1 time-base for 20 kHz */
    TIM1->PSC = 0;       /* Prescaler = 0 -> timer counter runs at 170 MHz */
    TIM1->ARR = 8499;    /* Period = (8499 + 1) / 170 MHz = 50 us -> 20 kHz */

    /* 4. Configure Channel 1 for PWM Mode 1 (active while CNT < CCR1) */
    TIM1->CCMR1 &= ~(TIM_CCMR1_OC1M_Msk | TIM_CCMR1_CC1S_Msk);
    TIM1->CCMR1 |= (TIM_CCMR1_OC1M_1 | TIM_CCMR1_OC1M_2); /* OC1M = 0110: PWM mode 1 */
    TIM1->CCMR1 |= TIM_CCMR1_OC1PE;                        /* Output compare 1 preload enable */

    /* 5. Set 25% duty cycle */
    TIM1->CCR1 = 2125;   /* 2125 / 8500 = 25.0% */

    /* 6. Configure output polarity and enable Channel 1 output */
    TIM1->CCER &= ~TIM_CCER_CC1P;  /* Active high polarity */
    TIM1->CCER |= TIM_CCER_CC1E;   /* OC1 signal enabled to output */

    /* 7. Enable auto-reload preload */
    TIM1->CR1 |= TIM_CR1_ARPE;

    /* 8. Enable TIM1 Main Output (MOE) - mandatory for advanced timers */
    TIM1->BDTR |= TIM_BDTR_MOE;

    /* 9. Generate an update event to preload registers into active shadow registers */
    TIM1->EGR |= TIM_EGR_UG;

    /* 10. Start TIM1 counter */
    TIM1->CR1 |= TIM_CR1_CEN;
}
```

### Message 2: BME280 Initialization on I2C3 (Standard Mode, 100 kHz)

#### 1. Pin Selection & Electrical Considerations
- **Pin Assignment**:
  - `PA8` is already dedicated to `TIM1_CH1` (PWM from Message 1).
  - For the LQFP64 package, the unconflicted pin pair for `I2C3` is **PC8 (I2C3_SCL, AF8)** and **PC9 (I2C3_SDA, AF8)** [STM32G474_Datasheet p.75].
- **Voltage Domain Compatibility**:
  - The STM32G474 operates at $V_{\text{DD}} = 3.3\text{ V}$. Its minimum input high threshold is $V_{\text{IH,min}} = 0.7 \times 3.3\text{ V} = 2.31\text{ V}$ [STM32G474_Datasheet p.128].
  - The BME280 operates with a $1.8\text{ V}$ I/O supply ($V_{\text{DDIO}} = 1.8\text{ V}$), so a $1.8\text{ V}$ logic high cannot reliably satisfy the STM32 $V_{\text{IH,min}}$ of $2.31\text{ V}$, and a direct $3.3\text{ V}$ pull-up would exceed the sensor's maximum input rating.
  - **Level Shifter Required**: An external bidirectional level shifter (e.g., TXS0102) is placed between the MCU ($3.3\text{ V}$ on PC8/PC9) and the BME280 ($1.8\text{ V}$ on SCL/SDA).

---

#### 2. Clock Selection and Timing Calculation
- **Kernel Clock**: HSI16 ($16\text{ MHz}$) is selected as the independent clock source for I2C3 via `RCC->CCIPR` (`I2C3SEL[1:0] = 0b10`) [STM32G474_RM0440 p.322].
- **TIMINGR Settings for Standard Mode (100 kHz)** [STM32G474_RM0440 p.1657]:
  With $f_{\text{I2CCLK}} = 16\text{ MHz}$ ($t_{\text{I2CCLK}} = 62.5\text{ ns}$):
  - $\text{PRESC} = 3 \implies t_{\text{PRESC}} = (3 + 1) \times 62.5\text{ ns} = 250\text{ ns}$
  - $\text{SCLDEL} = 4 \implies t_{\text{SCLDEL}} = (4 + 1) \times 250\text{ ns} = 1250\text{ ns}$
  - $\text{SDADEL} = 2 \implies t_{\text{SDADEL}} = 2 \times 250\text{ ns} = 500\text{ ns}$
  - $\text{SCLH} = 0\text{x}0\text{F} \ (15) \implies t_{\text{SCLH}} = (15 + 1) \times 250\text{ ns} = 4.0\text{ }\mu\text{s}$
  - $\text{SCLL} = 0\text{x}13 \ (19) \implies t_{\text{SCLL}} = (19 + 1) \times 250\text{ ns} = 5.0\text{ }\mu\text{s}$
  - Nominal period: $t_{\text{SCL}} \approx 10\text{ }\mu\text{s} \implies 100\text{ kHz}$.

```c
#include "stm32g4xx.h"

void i2c3_bme280_init(void)
{
    /* 1. Ensure HSI16 is enabled and ready */
    RCC->CR |= RCC_CR_HSION;
    while (!(RCC->CR & RCC_CR_HSIRDY)) {
        /* Wait until HSI16 is stable */
    }

    /* 2. Select HSI16 as independent clock source for I2C3 */
    /* CCIPR bits [17:16] I2C3SEL: 00=PCLK1, 01=SYSCLK, 10=HSI16 */
    RCC->CCIPR &= ~RCC_CCIPR_I2C3SEL_Msk;
    RCC->CCIPR |= (2U << RCC_CCIPR_I2C3SEL_Pos);

    /* 3. Enable peripheral clock gates for GPIOC and I2C3 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOCEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_I2C3EN;

    /* 4. Configure PC8 (I2C3_SCL) and PC9 (I2C3_SDA) */
    /* Set MODER to Alternate Function mode (10b) */
    GPIOC->MODER &= ~(GPIO_MODER_MODE8_Msk | GPIO_MODER_MODE9_Msk);
    GPIOC->MODER |= (2U << GPIO_MODER_MODE8_Pos) | (2U << GPIO_MODER_MODE9_Pos);

    /* Open-drain output configuration (mandatory for I2C lines) */
    GPIOC->OTYPER |= (GPIO_OTYPER_OT8 | GPIO_OTYPER_OT9);

    /* High speed output */
    GPIOC->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED8_Pos) | (3U << GPIO_OSPEEDR_OSPEED9_Pos);

    /* Floating / No internal pull-up or pull-down (using external pull-ups to 3.3 V) */
    GPIOC->PUPDR &= ~(GPIO_PUPDR_PUPD8_Msk | GPIO_PUPDR_PUPD9_Msk);

    /* Configure Alternate Function 8 (AF8 = I2C3) in AFRH */
    GPIOC->AFR[1] &= ~(GPIO_AFRH_AFSEL8_Msk | GPIO_AFRH_AFSEL9_Msk);
    GPIOC->AFR[1] |= (8U << GPIO_AFRH_AFSEL8_Pos) | (8U << GPIO_AFRH_AFSEL9_Pos);

    /* 5. Configure I2C3 Controller */
    /* Ensure I2C3 is disabled before programming TIMINGR */
    I2C3->CR1 &= ~I2C_CR1_PE;

    /* Program timing for Standard Mode (100 kHz) with f_I2CCLK = 16 MHz */
    I2C3->TIMINGR = (3U << I2C_TIMINGR_PRESC_Pos) |
                    (4U << I2C_TIMINGR_SCLDEL_Pos) |
                    (2U << I2C_TIMINGR_SDADEL_Pos) |
                    (0x0FU << I2C_TIMINGR_SCLH_Pos) |
                    (0x13U << I2C_TIMINGR_SCLL_Pos);

    /* 6. Enable I2C3 peripheral */
    I2C3->CR1 |= I2C_CR1_PE;
}
```

### Complete Initialization Program

```c
#include "stm32g4xx.h"

int main(void)
{
    /* =========================================================================
     * 1. Clock Configuration: I2C3 Kernel Clock
     * ========================================================================= */
    /* Ensure HSI16 is enabled and ready (used as kernel clock for I2C3) */
    RCC->CR |= RCC_CR_HSION;
    while (!(RCC->CR & RCC_CR_HSIRDY)) {
        /* Wait until HSI16 is stable */
    }

    /* Select HSI16 as independent clock source for I2C3 (CCIPR[17:16] = 10b) */
    RCC->CCIPR &= ~RCC_CCIPR_I2C3SEL_Msk;
    RCC->CCIPR |= (2U << RCC_CCIPR_I2C3SEL_Pos);

    /* =========================================================================
     * 2. Peripheral Clock Gates
     * ========================================================================= */
    /* Enable GPIOA (for PA8 / TIM1_CH1) and GPIOC (for PC8, PC9 / I2C3) */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN | RCC_AHB2ENR_GPIOCEN;

    /* Enable TIM1 (APB2) and I2C3 (APB1ENR1) */
    RCC->APB2ENR |= RCC_APB2ENR_TIM1EN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_I2C3EN;

    /* =========================================================================
     * 3. GPIO Pin Multiplexing & Electrical Configuration
     * ========================================================================= */
    /* --- PA8: TIM1_CH1 (Alternate Function AF6) --- */
    GPIOA->MODER &= ~GPIO_MODER_MODE8_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE8_Pos);          /* AF mode */
    GPIOA->OTYPER &= ~GPIO_OTYPER_OT8;                     /* Push-pull */
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED8_Pos);    /* High speed */
    GPIOA->PUPDR &= ~GPIO_PUPDR_PUPD8_Msk;                 /* No pull */
    GPIOA->AFR[1] &= ~GPIO_AFRH_AFSEL8_Msk;
    GPIOA->AFR[1] |= (6U << GPIO_AFRH_AFSEL8_Pos);         /* AF6 = TIM1_CH1 */

    /* --- PC8 (I2C3_SCL), PC9 (I2C3_SDA): Alternate Function AF8 --- */
    GPIOC->MODER &= ~(GPIO_MODER_MODE8_Msk | GPIO_MODER_MODE9_Msk);
    GPIOC->MODER |= (2U << GPIO_MODER_MODE8_Pos) | (2U << GPIO_MODER_MODE9_Pos); /* AF mode */
    GPIOC->OTYPER |= (GPIO_OTYPER_OT8 | GPIO_OTYPER_OT9);  /* Open-drain (mandatory for I2C) */
    GPIOC->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED8_Pos) | (3U << GPIO_OSPEEDR_OSPEED9_Pos);
    GPIOC->PUPDR &= ~(GPIO_PUPDR_PUPD8_Msk | GPIO_PUPDR_PUPD9_Msk); /* External pull-ups */
    GPIOC->AFR[1] &= ~(GPIO_AFRH_AFSEL8_Msk | GPIO_AFRH_AFSEL9_Msk);
    GPIOC->AFR[1] |= (8U << GPIO_AFRH_AFSEL8_Pos) | (8U << GPIO_AFRH_AFSEL9_Pos); /* AF8 = I2C3 */

    /* =========================================================================
     * 4. TIM1 Configuration: 20 kHz, 25.0% Duty Cycle PWM
     * ========================================================================= */
    /* Prescaler = 0 -> timer counter clock = 170 MHz */
    TIM1->PSC = 0;
    /* Period = (8499 + 1) / 170 MHz = 50 us -> 20.000 kHz */
    TIM1->ARR = 8499;

    /* Channel 1 PWM Mode 1 with preload enable */
    TIM1->CCMR1 &= ~(TIM_CCMR1_OC1M_Msk | TIM_CCMR1_CC1S_Msk);
    TIM1->CCMR1 |= (TIM_CCMR1_OC1M_1 | TIM_CCMR1_OC1M_2); /* OC1M = 0110: PWM Mode 1 */
    TIM1->CCMR1 |= TIM_CCMR1_OC1PE;                        /* Preload enable */

    /* Duty cycle = 2125 / 8500 = 25.0% */
    TIM1->CCR1 = 2125;

    /* Active-high polarity, enable OC1 output */
    TIM1->CCER &= ~TIM_CCER_CC1P;
    TIM1->CCER |= TIM_CCER_CC1E;

    /* Enable ARR preload */
    TIM1->CR1 |= TIM_CR1_ARPE;

    /* Enable Main Output (MOE) - required for advanced timer TIM1 */
    TIM1->BDTR |= TIM_BDTR_MOE;

    /* Generate update event to load shadow registers from preload registers */
    TIM1->EGR |= TIM_EGR_UG;

    /* Start TIM1 counter */
    TIM1->CR1 |= TIM_CR1_CEN;

    /* =========================================================================
     * 5. I2C3 Configuration: Standard Mode (100 kHz)
     * ========================================================================= */
    /* Disable I2C3 peripheral prior to programming TIMINGR */
    I2C3->CR1 &= ~I2C_CR1_PE;

    /* Standard Mode (100 kHz) timing for f_I2CCLK = 16 MHz (HSI16):
     * PRESC = 3  -> t_presc  = (3 + 1) * 62.5 ns = 250 ns
     * SCLDEL = 4 -> t_SCLDEL = (4 + 1) * 250 ns  = 1250 ns (data setup)
     * SDADEL = 2 -> t_SDADEL = 2 * 250 ns        = 500 ns  (data hold)
     * SCLH = 15  -> t_SCLH   = (15 + 1) * 250 ns = 4.0 us
     * SCLL = 19  -> t_SCLL   = (19 + 1) * 250 ns = 5.0 us
     */
    I2C3->TIMINGR = (3U << I2C_TIMINGR_PRESC_Pos) |
                    (4U << I2C_TIMINGR_SCLDEL_Pos) |
                    (2U << I2C_TIMINGR_SDADEL_Pos) |
                    (0x0FU << I2C_TIMINGR_SCLH_Pos) |
                    (0x13U << I2C_TIMINGR_SCLL_Pos);

    /* Enable I2C3 peripheral */
    I2C3->CR1 |= I2C_CR1_PE;

    /* Infinite loop */
    while (1) {
    }
}
```

### Key Technical Aspects

1. **Clocks and Peripheral Gates**:
   - `HSI16` ($16\text{ MHz}$) is explicitly activated and routed through `RCC->CCIPR` as the kernel clock for `I2C3`.
   - Clocks for `GPIOA`, `GPIOC`, `TIM1`, and `I2C3` are un-gated via their respective AHB2 and APB bus enable registers before accessing peripheral registers.

2. **Pin Allocation**:
   - `PA8` is configured as **AF6** (`TIM1_CH1`) in push-pull mode at high speed.
   - `PC8` and `PC9` are configured as **AF8** (`I2C3_SCL` and `I2C3_SDA`) in open-drain mode. Because the BME280 operates at $1.8\text{ V}$ and the MCU at $3.3\text{ V}$, these pins connect through an external bidirectional level shifter (e.g., TXS0102).

3. **TIM1 PWM Parameters**:
   - $f_{\text{TIM1CLK}} = 170\text{ MHz}$. With $PSC = 0$ and $ARR = 8499$, the PWM frequency is exactly $20.000\text{ kHz}$ ($8500$ discrete counts per period).
   - $CCR1 = 2125$ achieves an exact $25.000\%$ duty cycle in PWM Mode 1.
   - `TIM1->BDTR |= TIM_BDTR_MOE` enables the main output stage required by advanced Cortex-M timers.

4. **I2C3 Timing**:
   - Programmed while $PE = 0$ as required by STM32 reference manuals.
   - Using $f_{\text{I2CCLK}} = 16\text{ MHz}$, a prescaled clock of $250\text{ ns}$ ($PRESC = 3$) delivers $t_{\text{SCLL}} = 5.0\text{ }\mu\text{s}$ and $t_{\text{SCLH}} = 4.0\text{ }\mu\text{s}$, meeting I2C Standard Mode specifications ($100\text{ kHz}$).
