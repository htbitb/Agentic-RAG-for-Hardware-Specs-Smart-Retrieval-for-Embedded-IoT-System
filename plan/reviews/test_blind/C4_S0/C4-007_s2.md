### Assistant answer 0

```c
#include "stm32g4xx.h"

void SystemClock_Config(void)
{
    /* 1. Enable HSE oscillator and wait for it to stabilize */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY));

    /* 2. Enable Power Controller clock and configure Range 1 Boost mode
          (Required to operate SYSCLK up to 170 MHz; normal Range 1 caps at 150 MHz) */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;
    PWR->CR5 &= ~PWR_CR5_R1MODE;  /* Clear R1MODE to enable Range 1 Boost mode */

    /* 3. Configure Flash latency for 168 MHz in Range 1 Boost Mode:
          4 Wait States (WS) are required for 136 MHz < HCLK <= 170 MHz */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY) != FLASH_ACR_LATENCY_4WS);

    /* 4. Configure PLL:
          - Source: HSE (24 MHz)
          - PLLM = 1 -> value 0 in bitfield (division by PLLM + 1)
          - PLLN = 14 -> VCO = (24 MHz / 1) * 14 = 336 MHz
          - PLLR = /2 -> value 00 in bitfield (SYSCLK = 336 MHz / 2 = 168 MHz)
          - Enable PLLR output (PLLREN) */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE
                 | (0U << RCC_PLLCFGR_PLLM_Pos)        /* PLLM = 1 */
                 | (14U << RCC_PLLCFGR_PLLN_Pos)       /* PLLN = 14 */
                 | (0U << RCC_PLLCFGR_PLLR_Pos)        /* PLLR division factor = 2 */
                 | RCC_PLLCFGR_PLLREN;                 /* Enable PLL "R" clock output */

    /* Enable PLL and wait for PLLRDY */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY));

    /* 5. Set prescalers (AHB = 1, APB1 = 1, APB2 = 1) and select PLL as SYSCLK
          Note: HPRE, PPRE1, and PPRE2 reset to 0 (division factor 1) */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL);
}
```

### Explanation

1. **HSE Activation**: The external 24 MHz oscillator is enabled by setting `RCC_CR_HSEON` and polling `RCC_CR_HSERDY`.
2. **Voltage Scaling (Boost Mode)**: Operating the STM32G474 beyond 150 MHz (up to 170 MHz) requires Voltage Scaling Range 1 Boost mode. We enable the `PWR` peripheral clock and clear `PWR_CR5_R1MODE`.
3. **Flash Latency**: In Range 1 Boost mode, operating at 168 MHz requires 4 wait states (`FLASH_ACR_LATENCY_4WS`). Latency must be configured before switching SYSCLK to avoid fetch stalls/crashes.
4. **PLL Setup**:
   * $\text{VCO\_IN} = \frac{\text{HSE}}{\text{PLLM}} = \frac{24\text{ MHz}}{1} = 24\text{ MHz}$
   * $\text{VCO} = \text{VCO\_IN} \times \text{PLLN} = 24\text{ MHz} \times 14 = 336\text{ MHz}$
   * $\text{SYSCLK} = \frac{\text{VCO}}{\text{PLLR}} = \frac{336\text{ MHz}}{2} = 168\text{ MHz}$
   * `PLLREN` enables the main PLLR output feeding the system clock multiplexer.
5. **Clock Switch**: The system clock switch (`RCC_CFGR_SW`) is set to `RCC_CFGR_SW_PLL`, and the code waits for the status bits (`RCC_CFGR_SWS`) to confirm that the PLL is actively driving SYSCLK. Prescalers remain at 1 ($168\text{ MHz}$).

```c
void USART1_Init(void)
{
    /* 1. Enable clocks for GPIOA and USART1 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PA9 (TX) and PA10 (RX) as Alternate Function AF7
          - MODER: 10 (Alternate function mode)
          - AFR: AF7 (USART1_TX on PA9, USART1_RX on PA10)
          - OSPEEDR: 11 (Very high speed for clean transitions)
          - PUPDR: 01 (Pull-up on RX line for idle high stability) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= (7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos);

    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED9_Pos) | (3U << GPIO_OSPEEDR_OSPEED10_Pos);
    GPIOA->PUPDR   |= (1U << GPIO_PUPDR_PUPD10_Pos);

    /* 3. Configure Baud Rate:
          - Default clock source (RCC_CCIPR_USART1SEL = 00) is PCLK2 = 168 MHz
          - OVER8 = 0 (Oversampling by 16)
          - USARTDIV = fCK / Baud = 168,000,000 / 115200 ≈ 1458.333 -> BRR = 1458
          - Actual Baud = 168,000,000 / 1458 ≈ 115226.3 baud (+0.023% error) */
    USART1->BRR = 1458U;

    /* 4. Configure frame format: 8 data bits, no parity (reset defaults in CR1), 
          1 stop bit (reset default in CR2), and enable TX, RX, and USART1 */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
```

### Explanation

1. **Clock Configuration**: 
   * USART1 clock selection resets to `00` in `RCC->CCIPR`, which routes `PCLK2` (168 MHz) directly to USART1.
   * `RCC_AHB2ENR_GPIOAEN` and `RCC_APB2ENR_USART1EN` are enabled.
2. **GPIO Configuration**: 
   * PA9 and PA10 are set to Alternate Function mode (`MODER = 10b`).
   * Multiplexer register `AFRH` maps PA9 and PA10 to `AF7` (USART1).
   * A pull-up is set on PA10 to prevent floating RX line state changes before transmission begins.
3. **Baud Rate Calculation**: 
   * With 16x oversampling (`OVER8 = 0` by default):
     $$\text{BRR} = \frac{f_{\text{CK}}}{\text{Baud}} = \frac{168\,000\,000}{115\,200} \approx 1458.33 \longrightarrow \text{round to } 1458$$
   * Resulting baud rate is $\frac{168\,000\,000}{1458} \approx 115\,226.34\text{ baud}$ (an error of only $+0.023\%$, well within the $\pm 2\%$ budget).
4. **USART Activation**: 
   * Default frame format specifies 8 data bits (bit $M1:M0 = 00b$), parity disabled (`PCE = 0`), and 1 stop bit (`STOP = 00b` in `CR2`).
   * Writing `BRR` before setting `USART_CR1_UE` conforms to the STM32 USART programming sequence. Enabling `TE` and `RE` activates both transmitter and receiver.

#include "stm32g4xx.h"

int main(void)
{
    /* =========================================================================
     * 1. CLOCK CONFIGURATION (SYSCLK = HCLK = PCLK1 = PCLK2 = 168 MHz)
     * ========================================================================= */

    /* Enable HSE (24 MHz) and wait for it to be ready */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY));

    /* Enable Power Controller clock and select Range 1 Boost Mode (needed for > 150 MHz) */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* Set Flash latency to 4 wait states (required for 168 MHz in Boost Mode) */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY) != FLASH_ACR_LATENCY_4WS);

    /* Configure PLL: Source = HSE, PLLM = /1, PLLN = *14, PLLR = /2 (VCO = 336 MHz) */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE
                 | (0U << RCC_PLLCFGR_PLLM_Pos)        /* PLLM = 1 (bits: 0000) */
                 | (14U << RCC_PLLCFGR_PLLN_Pos)       /* PLLN = 14 */
                 | (0U << RCC_PLLCFGR_PLLR_Pos)        /* PLLR = /2 (bits: 00) */
                 | RCC_PLLCFGR_PLLREN;                 /* Enable PLLR output */

    /* Enable PLL and wait for lock */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY));

    /* Switch SYSCLK to PLL and wait for confirmation (AHB, APB1, APB2 prescalers = 1) */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL);

    /* =========================================================================
     * 2. USART1 CONFIGURATION (115200 8N1, TX = PA9, RX = PA10)
     * ========================================================================= */

    /* Enable GPIOA and USART1 peripheral clocks */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* Configure PA9 (TX) and PA10 (RX) to AF7 (USART1) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= (7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos);

    /* Configure high speed on TX and RX, pull-up on RX line */
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED9_Pos) | (3U << GPIO_OSPEEDR_OSPEED10_Pos);
    GPIOA->PUPDR   |= (1U << GPIO_PUPDR_PUPD10_Pos);

    /* USART1 clock defaults to PCLK2 = 168 MHz (RCC_CCIPR_USART1SEL = 00).
     * With OVER8 = 0 (16x oversampling): BRR = 168,000,000 / 115200 = 1458 (115226 baud, +0.02% error) */
    USART1->BRR = 1458U;

    /* Set 8 data bits, no parity (CR1 reset default), 1 stop bit (CR2 reset default),
     * and enable transmitter (TE), receiver (RE), and USART (UE) */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;

    /* =========================================================================
     * 3. MAIN LOOP
     * ========================================================================= */
    while (1)
    {
    }
}

### Explanation

1. **Clock Setup**:
   * Starts the 24 MHz HSE crystal oscillator and polls `HSERDY`.
   * Puts the core in **Range 1 Boost Mode** via `PWR->CR5` (clearing `R1MODE`) to permit frequencies above 150 MHz up to 170 MHz.
   * Adjusts Flash latency to 4 wait states (`LATENCY_4WS`) to accommodate the 168 MHz core clock.
   * Configures the PLL with $M=1$, $N=14$, and $R=2$, producing $\text{SYSCLK} = 168\text{ MHz}$ ($\text{VCO} = 336\text{ MHz}$), locks the PLL, and switches `SYSCLK` to `PLL`.
2. **USART1 Setup**:

   * Configures PA9 and PA10 into Alternate Function mode mapped to AF7 (`USART1_TX` / `USART1_RX`).
   * Writes `BRR = 1458` calculated against the $168\text{ MHz}$ PCLK2 clock to achieve 115200 baud (+0.02% error) before enabling the peripheral.
   * Enables the receiver, transmitter, and peripheral via `USART1->CR1` keeping default 8-N-1 formatting.
