Write bare-metal C that accesses registers the CMSIS way (e.g. `TIM1->PSC = ...;`, `RCC->APB2ENR |= RCC_APB2ENR_TIM1EN;`) using the register and bit names of ST's `stm32g4xx.h` device header. Initial state: SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz (PLL fed by HSI16, AHB/APB1/APB2 prescalers = 1, voltage Range 1 boost mode, Flash wait states already set); the board is powered at VDD = 3.3 V. Every peripheral clock that is off at reset is still off, and all GPIO pins are in their reset state. Answer every message with the relevant C code (in fenced C code blocks that follow these conventions) and a short explanation. Message 1: configure USART3 for 115200 baud with TX on pin PB10 and RX on pin PB11: 8 data bits, no parity, 1 stop bit, oversampling by 16, both directions enabled, and the baud-rate register written before the USART is enabled.

### Assistant answer 0

```c
#include "stm32g4xx.h"

void usart3_init(void)
{
    /* 1. Enable peripheral clocks for GPIOB and USART3 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_USART3EN;

    /* 2. Configure PB10 (TX) and PB11 (RX) as Alternate Function 7 (AF7 = USART3) */
    /* Clear and set MODER for pins 10 and 11 to Alternate Function mode (10b) */
    GPIOB->MODER &= ~(GPIO_MODER_MODE10_Msk | GPIO_MODER_MODE11_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE10_Pos) | (2U << GPIO_MODER_MODE11_Pos);

    /* Set output speed to High Speed for PB10 */
    GPIOB->OSPEEDR |= (2U << GPIO_OSPEEDR_OSPEED10_Pos);

    /* Set alternate function AF7 (0111b) in AFR[1] (AFRH) for pins 10 and 11 */
    GPIOB->AFR[1] &= ~(GPIO_AFRH_AFSEL10_Msk | GPIO_AFRH_AFSEL11_Msk);
    GPIOB->AFR[1] |= (7U << GPIO_AFRH_AFSEL10_Pos) | (7U << GPIO_AFRH_AFSEL11_Pos);

    /* 3. Configure USART3 frame format */
    /* Reset state of CR1 and CR2 already provides:
     * - M[1:0] = 00b (8 data bits)
     * - PCE = 0 (parity disabled)
     * - OVER8 = 0 (oversampling by 16)
     * - STOP[1:0] = 00b in CR2 (1 stop bit)
     */
    USART3->CR1 = 0U;
    USART3->CR2 = 0U;
    USART3->CR3 = 0U;

    /* 4. Configure baud rate:
     * At reset, USART3 clock source in RCC->CCIPR is PCLK1 (170 MHz).
     * With OVER8 = 0, BRR = f_CK / baud = 170000000 / 115200 ≈ 1475.694 -> 1476.
     * Written prior to enabling UE.
     */
    USART3->BRR = (170000000U + (115200U / 2U)) / 115200U;

    /* 5. Enable Transmitter, Receiver, and USART peripheral */
    USART3->CR1 |= USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
```

### Explanation

1. **Clock Gating:** The GPIOB clock is enabled via `RCC->AHB2ENR`, and USART3 is enabled via `RCC->APB1ENR1`. At reset, `RCC->CCIPR` selects PCLK1 (170 MHz) as the USART3 clock source.
2. **Pin Multiplexing:** PB10 and PB11 are set to alternate function mode (`MODER = 10b`) and mapped to AF7 (`USART3_TX` and `USART3_RX`) in `AFR[1]` (the high alternate function register `AFRH`).
3. **USART Framing & Baud Rate:** With `OVER8 = 0`, the baud-rate divider is evaluated as $\text{USARTDIV} = \frac{170\,000\,000}{115\,200} \approx 1476$ (`0x05C4`). `USART3->BRR` is programmed before setting `USART_CR1_UE`.
4. **Peripheral Activation:** Enabling `TE`, `RE`, and `UE` simultaneously in `USART3->CR1` initializes transmitter and receiver operations [RM0440 p.1388].

### User message 1

Message 2: now add a 5 kHz PWM signal with an 80 % duty cycle on pin PB10 using TIM2 channel 3 to drive a heater; edge-aligned PWM mode 1, active-high output, no dead time.

### Assistant answer 1

```c
#include "stm32g4xx.h"

void tim2_ch3_pwm_init(void)
{
    /* 1. Enable peripheral clocks for GPIOB and TIM2 */
    RCC->AHB2ENR  |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN;

    /* 2. Reconfigure PB10 to Alternate Function 1 (AF1 = TIM2_CH3) */
    GPIOB->MODER &= ~GPIO_MODER_MODE10_Msk;
    GPIOB->MODER |= (2U << GPIO_MODER_MODE10_Pos);  /* Alternate function mode */

    GPIOB->AFR[1] &= ~GPIO_AFRH_AFSEL10_Msk;
    GPIOB->AFR[1] |= (1U << GPIO_AFRH_AFSEL10_Pos); /* AF1 for PB10 */

    /* 3. Configure TIM2 time base for 5 kHz PWM:
     * TIM2 clock = PCLK1 = 170 MHz (APB1 prescaler = 1).
     * Target frequency = f_CK / ((PSC + 1) * (ARR + 1))
     * 170 MHz / 5 kHz = 34,000 counts.
     * PSC = 0, ARR = 34,000 - 1 = 33,999.
     */
    TIM2->PSC = 0U;
    TIM2->ARR = 33999U;

    /* 4. Configure 80 % duty cycle:
     * CCR3 = (ARR + 1) * 80% = 34,000 * 0.8 = 27,200.
     */
    TIM2->CCR3 = 27200U;

    /* 5. Configure Channel 3 for PWM Mode 1 with preload enabled:
     * OC3M = 0110b (PWM mode 1: active while CNT < CCR3)
     */
    TIM2->CCMR2 &= ~(TIM_CCMR2_OC3M_Msk | TIM_CCMR2_CC3S_Msk);
    TIM2->CCMR2 |= (6U << TIM_CCMR2_OC3M_Pos) | TIM_CCMR2_OC3PE;

    /* 6. Enable Channel 3 output, active high (CC3P = 0) */
    TIM2->CCER &= ~TIM_CCER_CC3P;
    TIM2->CCER |= TIM_CCER_CC3E;

    /* 7. Enable Auto-reload preload and start the counter */
    TIM2->CR1 |= TIM_CR1_ARPE;
    TIM2->EGR  = TIM_EGR_UG;    /* Generate update event to transfer preload registers */
    TIM2->CR1 |= TIM_CR1_CEN;
}
```

### Explanation

1. **Pin Reassignment:** PB10 is switched from AF7 (USART3_TX) to AF1 (`TIM2_CH3`) by modifying `GPIOB->AFR[1]`.
2. **Frequency & Timing:** TIM2 runs at the timer clock frequency of 170 MHz (APB1 prescaler is 1). An ARR of 33,999 with PSC of 0 produces exactly $\frac{170\,\text{MHz}}{34\,000} = 5\,\text{kHz}$.
3. **Duty Cycle:** In PWM Mode 1 (`OC3M = 0110b`), the output is active high when $\text{CNT} < \text{CCR3}$. Setting $\text{CCR3} = 27\,200$ yields $\frac{27\,200}{34\,000} = 80\%$ duty cycle.
4. **Preload & Update:** Preload registers on ARR and CCR3 avoid glitches; setting `TIM_EGR_UG` loads the shadow registers before starting the timer via `TIM_CR1_CEN` [RM0440 p.1158].

### Assistant answer 2

```c
#include "stm32g4xx.h"

int main(void)
{
    /* ------------------------------------------------------------------------
     * 1. Enable peripheral clocks (GPIOB, USART3, TIM2)
     * ------------------------------------------------------------------------ */
    RCC->AHB2ENR  |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_USART3EN | RCC_APB1ENR1_TIM2EN;

    /* ------------------------------------------------------------------------
     * 2. Configure GPIO pins PB10 and PB11
     *    - PB10: AF1 (TIM2_CH3, heater PWM output)
     *    - PB11: AF7 (USART3_RX)
     * ------------------------------------------------------------------------ */
    /* Set PB10 and PB11 to Alternate Function mode (10b) */
    GPIOB->MODER &= ~(GPIO_MODER_MODE10_Msk | GPIO_MODER_MODE11_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE10_Pos) | (2U << GPIO_MODER_MODE11_Pos);

    /* Set High Speed for PB10 output */
    GPIOB->OSPEEDR |= (2U << GPIO_OSPEEDR_OSPEED10_Pos);

    /* Map PB10 to AF1 (TIM2_CH3) and PB11 to AF7 (USART3_RX) */
    GPIOB->AFR[1] &= ~(GPIO_AFRH_AFSEL10_Msk | GPIO_AFRH_AFSEL11_Msk);
    GPIOB->AFR[1] |= (1U << GPIO_AFRH_AFSEL10_Pos) | (7U << GPIO_AFRH_AFSEL11_Pos);

    /* ------------------------------------------------------------------------
     * 3. Configure USART3
     *    - 115200 baud, 8 data bits, no parity, 1 stop bit, oversampling by 16
     *    - BRR written before UE is set
     * ------------------------------------------------------------------------ */
    USART3->CR1 = 0U;
    USART3->CR2 = 0U;
    USART3->CR3 = 0U;

    /* BRR = 170 MHz / 115200 ≈ 1476 (0x05C4) */
    USART3->BRR = (170000000U + (115200U / 2U)) / 115200U;

    /* Enable Transmitter, Receiver, and the USART peripheral */
    USART3->CR1 |= USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;

    /* ------------------------------------------------------------------------
     * 4. Configure TIM2 Channel 3 for Heater PWM
     *    - 5 kHz, 80 % duty cycle, PWM mode 1, active high
     * ------------------------------------------------------------------------ */
    /* f_PWM = 170 MHz / (33999 + 1) = 5 kHz */
    TIM2->PSC = 0U;
    TIM2->ARR = 33999U;

    /* 80 % duty cycle: 34000 * 0.8 = 27200 */
    TIM2->CCR3 = 27200U;

    /* Channel 3: PWM mode 1 (OC3M = 0110b), enable preload (OC3PE) */
    TIM2->CCMR2 &= ~(TIM_CCMR2_OC3M_Msk | TIM_CCMR2_CC3S_Msk);
    TIM2->CCMR2 |= (6U << TIM_CCMR2_OC3M_Pos) | TIM_CCMR2_OC3PE;

    /* Active-high output polarity (CC3P = 0), enable output (CC3E = 1) */
    TIM2->CCER &= ~TIM_CCER_CC3P;
    TIM2->CCER |= TIM_CCER_CC3E;

    /* Enable ARR preload, trigger update to latch registers, and enable counter */
    TIM2->CR1 |= TIM_CR1_ARPE;
    TIM2->EGR  = TIM_EGR_UG;
    TIM2->CR1 |= TIM_CR1_CEN;

    /* Main loop */
    while (1)
    {
    }
}
```

### Explanation

1. **Pin Assignment Note:** PB10 was specified for USART3_TX in Message 1 and subsequently for TIM2_CH3 in Message 2. As configured above, PB10 routes to AF1 (`TIM2_CH3`) to generate the heater PWM signal, while PB11 routes to AF7 (`USART3_RX`) for UART reception.
2. **USART3 Configuration:** USART3 is clocked at 170 MHz from PCLK1, configured for standard 8N1 framing, and `BRR` is initialized to 1476 before enabling `TE`, `RE`, and `UE`.
3. **Timer 2 Configuration:** TIM2 runs prescaled by 1 at 170 MHz. An ARR of 33,999 gives a period of $200\ \mu\text{s}$ (5 kHz), and CCR3 of 27,200 sets the active-high pulse duration to $160\ \mu\text{s}$ (80% duty cycle). Preload registers are latched with `TIM_EGR_UG` before `TIM_CR1_CEN` starts the PWM output.
