### Assistant answer 0

```c
#include "stm32g4xx.h"

void usart1_init(void)
{
    /* 1. Enable GPIOA and USART1 peripheral clocks */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PA9 (TX) and PA10 (RX) for Alternate Function 7 (USART1) */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |=  ((7U   << GPIO_AFRH_AFSEL9_Pos) | (7U   << GPIO_AFRH_AFSEL10_Pos));

    GPIOA->MODER &= ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk);
    GPIOA->MODER |=  (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

    /* 3. Configure framing: 8 data bits, no parity (M1=0, M0=0, PCE=0 in CR1), 
          1 stop bit (STOP[1:0]=00 in CR2), and oversampling by 16 (OVER8=0 in CR1).
          These are the default reset values in CR1 and CR2. */
    USART1->CR1 = 0;
    USART1->CR2 = 0;
    USART1->CR3 = 0;

    /* 4. Set Baud Rate: USART1 is clocked by PCLK2 = 170 MHz by default (RCC_CCIPR).
          With OVER8 = 0: BRR = fCK / Baud = 170000000 / 115200 ≈ 1475.694 -> 1476.
          Actual baud rate: 170000000 / 1476 ≈ 115176 baud (-0.02% error). */
    USART1->BRR = (170000000UL + (115200UL / 2U)) / 115200UL;

    /* 5. Enable Transmitter, Receiver, and the USART peripheral */
    USART1->CR1 |= (USART_CR1_TE | USART_CR1_RE);
    USART1->CR1 |= USART_CR1_UE;
}
```

### Explanation

1. **Clocks**: The peripheral clocks for `GPIOA` (on AHB2) and `USART1` (on APB2) are enabled. By default, `USART1` derives its clock from `PCLK2` (170 MHz).
2. **GPIO Configuration**: PA9 and PA10 are assigned to Alternate Function 7 (AF7: USART1_TX and USART1_RX) and set to alternate function mode (`MODER` = `10b`).
3. **Format & Oversampling**: Clearing `CR1`, `CR2`, and `CR3` sets the standard default frame format (1 Start bit, 8 data bits, 1 Stop bit, no parity) with 16x oversampling (`OVER8 = 0`).
4. **Baud Rate**: Setting `BRR = 1476` divides the 170 MHz clock to yield approximately 115,176 baud (an error of -0.02%, well within the ±2% requirement). `BRR` is written while `UE = 0`.
5. **Enable**: Transmitter (`TE`), Receiver (`RE`), and the peripheral enable (`UE`) are activated.

```c
#include "stm32g4xx.h"

void i2c2_init(void)
{
    /* 1. Enable GPIOA and I2C2 peripheral clocks */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_I2C2EN;

    /* 2. Configure PA8 (SDA) and PA9 (SCL) for AF4 (I2C2), open-drain, high speed */
    /* Alternate function AF4 */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL8_Pos) | (0xFU << GPIO_AFRH_AFSEL9_Pos));
    GPIOA->AFR[1] |=  ((4U   << GPIO_AFRH_AFSEL8_Pos) | (4U   << GPIO_AFRH_AFSEL9_Pos));

    /* Mode: Alternate Function (10b) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE8_Msk | GPIO_MODER_MODE9_Msk);
    GPIOA->MODER |=  (2U << GPIO_MODER_MODE8_Pos) | (2U << GPIO_MODER_MODE9_Pos);

    /* Output type: Open-Drain (1b) */
    GPIOA->OTYPER |= (GPIO_OTYPER_OT8 | GPIO_OTYPER_OT9);

    /* Output speed: Very high speed (11b) */
    GPIOA->OSPEEDR |= (GPIO_OSPEEDR_OSPEED8_Msk | GPIO_OSPEEDR_OSPEED9_Msk);

    /* Pull-up: enable internal pull-ups (01b) */
    GPIOA->PUPDR &= ~(GPIO_PUPDR_PUPD8_Msk | GPIO_PUPDR_PUPD9_Msk);
    GPIOA->PUPDR |=  (1U << GPIO_PUPDR_PUPD8_Pos) | (1U << GPIO_PUPDR_PUPD9_Pos);

    /* 3. Ensure I2C2 is disabled before writing TIMINGR */
    I2C2->CR1 &= ~I2C_CR1_PE;

    /* 4. Configure timing register (I2C_TIMINGR):
          Source clock = PCLK1 = 170 MHz (reset default in RCC_CCIPR: I2C2SEL = 00 -> PCLK1).
          t_I2CCLK = 1 / 170 MHz ≈ 5.882 ns.
          
          Prescaler: PRESC = 16 (div 17) -> t_PRESC = 17 * 5.882 ns = 100 ns (10 MHz).
          Analog filter: ON (default, suppresses spikes up to 50 ns -> t_AFmin = 50 ns, DNF = 0).
          Assuming tr = 100 ns, tf = 10 ns:
          
          - SCLL = 13:
            tLOW = (SCLL + 1) * t_PRESC = 14 * 100 ns = 1.4 µs (>= 1.3 µs required)
          - SCLH = 8:
            tHIGH = (SCLH + 1) * t_PRESC = 9 * 100 ns = 0.9 µs (>= 0.6 µs required)
          - Period = tLOW + tHIGH + tr + tf = 1.4 µs + 0.9 µs + 0.1 µs + 0.01 µs ≈ 2.41 µs (≈ 415 kHz max nominal, ~400 kHz with standard rise/fall)
          - SDADEL = 2:
            tHD;DAT = SDADEL * t_PRESC - t_AFmin = 200 ns - 50 ns = 150 ns (>= 0)
          - SCLDEL = 3:
            tSU;DAT = (SCLDEL + 1) * t_PRESC - tr = 400 ns - 100 ns = 300 ns (>= 100 ns)
          
          TIMINGR = (PRESC << 28) | (SCLDEL << 20) | (SDADEL << 16) | (SCLH << 8) | SCLL
                  = (16 << 28) | (3 << 20) | (2 << 16) | (8 << 8) | 13
                  = 0x1032080D
    */
    I2C2->TIMINGR = (16U << I2C_TIMINGR_PRESC_Pos)
                  | (3U  << I2C_TIMINGR_SCLDEL_Pos)
                  | (2U  << I2C_TIMINGR_SDADEL_Pos)
                  | (8U  << I2C_TIMINGR_SCLH_Pos)
                  | (13U << I2C_TIMINGR_SCLL_Pos);

    /* 5. Enable the I2C2 peripheral */
    I2C2->CR1 |= I2C_CR1_PE;
}
```

### Explanation

1. **Clocks**: Enabled `GPIOA` (AHB2) and `I2C2` (APB1). By default in `RCC->CCIPR`, bits `I2C2SEL[1:0] = 00`, selecting `PCLK1` (170 MHz) as the kernel clock.
2. **GPIO Configuration**: Pins PA8 (SDA) and PA9 (SCL) are configured to Alternate Function 4 (AF4: I2C2_SDA / I2C2_SCL) in Open-Drain mode (`OTYPER = 1`) with optional internal pull-ups enabled. Note that this reassigns PA9 from its previous AF7 USART1 TX mapping.
3. **Timing (I2C_TIMINGR)**:
   - With $t_{\text{I2CCLK}} = \frac{1}{170\text{ MHz}} \approx 5.882\text{ ns}$ and `PRESC = 16`, the prescaled clock period $t_{\text{PRESC}} = (16 + 1) \times 5.882\text{ ns} = 100\text{ ns}$.
   - `SCLL = 13` yields $t_{\text{LOW}} = (13 + 1) \times 100\text{ ns} = 1.4\text{ }\mu\text{s}$, which satisfies $t_{\text{LOW}} \ge 1.3\text{ }\mu\text{s}$.
   - `SCLH = 8` yields $t_{\text{HIGH}} = (8 + 1) \times 100\text{ ns} = 0.9\text{ }\mu\text{s}$, which satisfies $t_{\text{HIGH}} \ge 0.6\text{ }\mu\text{s}$.
   - `SDADEL = 2` and `SCLDEL = 3` satisfy data hold and setup timing requirements for Fast-mode.
4. **Enable**: Peripheral enable bit `PE` in `I2C2->CR1` is set after `TIMINGR` configuration. [RM0440 p.1017, p.1044]

```c
#include "stm32g4xx.h"

int main(void)
{
    /* -------------------------------------------------------------------------
     * 1. Enable peripheral clocks on AHB2, APB1, and APB2
     * ------------------------------------------------------------------------- */
    RCC->AHB2ENR  |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_I2C2EN;
    RCC->APB2ENR  |= RCC_APB2ENR_USART1EN;

    /* -------------------------------------------------------------------------
     * 2. GPIO Configuration
     *    PA8:  AF4 (I2C2_SDA), Open-Drain, Pull-Up, Very High Speed
     *    PA9:  AF4 (I2C2_SCL), Open-Drain, Pull-Up, Very High Speed
     *          (Note: PA9 is reassigned here from AF7 USART1_TX to AF4 I2C2_SCL)
     *    PA10: AF7 (USART1_RX), Push-Pull, Floating, Default Speed
     * ------------------------------------------------------------------------- */
    /* Alternate Functions: PA8 = AF4, PA9 = AF4, PA10 = AF7 */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL8_Pos)  |
                       (0xFU << GPIO_AFRH_AFSEL9_Pos)  |
                       (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |=  ((4U   << GPIO_AFRH_AFSEL8_Pos)  |
                       (4U   << GPIO_AFRH_AFSEL9_Pos)  |
                       (7U   << GPIO_AFRH_AFSEL10_Pos));

    /* Output type: PA8, PA9 = Open-Drain (1b); PA10 = Push-Pull (0b) */
    GPIOA->OTYPER |= (GPIO_OTYPER_OT8 | GPIO_OTYPER_OT9);

    /* Output speed: PA8, PA9 = Very High Speed (11b) */
    GPIOA->OSPEEDR |= (GPIO_OSPEEDR_OSPEED8_Msk | GPIO_OSPEEDR_OSPEED9_Msk);

    /* Pull-up/pull-down: PA8, PA9 = Pull-up (01b); PA10 = No pull (00b) */
    GPIOA->PUPDR &= ~(GPIO_PUPDR_PUPD8_Msk | GPIO_PUPDR_PUPD9_Msk | GPIO_PUPDR_PUPD10_Msk);
    GPIOA->PUPDR |=  (1U << GPIO_PUPDR_PUPD8_Pos) | (1U << GPIO_PUPDR_PUPD9_Pos);

    /* Mode: PA8, PA9, PA10 = Alternate Function mode (10b) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE8_Msk | GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk);
    GPIOA->MODER |=  (2U << GPIO_MODER_MODE8_Pos)  |
                     (2U << GPIO_MODER_MODE9_Pos)  |
                     (2U << GPIO_MODER_MODE10_Pos);

    /* -------------------------------------------------------------------------
     * 3. USART1 Configuration (115200 baud, 8N1, 16x oversampling)
     *    Clock = PCLK2 = 170 MHz
     * ------------------------------------------------------------------------- */
    USART1->CR1 = 0;
    USART1->CR2 = 0;
    USART1->CR3 = 0;

    /* BRR = 170 MHz / 115200 ≈ 1476 (error = -0.02%) */
    USART1->BRR = (170000000UL + (115200UL / 2U)) / 115200UL;

    /* Enable transmitter, receiver, and peripheral */
    USART1->CR1 |= (USART_CR1_TE | USART_CR1_RE);
    USART1->CR1 |= USART_CR1_UE;

    /* -------------------------------------------------------------------------
     * 4. I2C2 Configuration (Fast-mode 400 kHz)
     *    Clock = PCLK1 = 170 MHz
     * ------------------------------------------------------------------------- */
    I2C2->CR1 &= ~I2C_CR1_PE;

    /* PRESC=16 (t_presc=100ns), SCLDEL=3, SDADEL=2, SCLH=8 (0.9µs), SCLL=13 (1.4µs) */
    I2C2->TIMINGR = (16U << I2C_TIMINGR_PRESC_Pos)
                  | (3U  << I2C_TIMINGR_SCLDEL_Pos)
                  | (2U  << I2C_TIMINGR_SDADEL_Pos)
                  | (8U  << I2C_TIMINGR_SCLH_Pos)
                  | (13U << I2C_TIMINGR_SCLL_Pos);

    /* Enable I2C2 */
    I2C2->CR1 |= I2C_CR1_PE;

    /* -------------------------------------------------------------------------
     * Main loop
     * ------------------------------------------------------------------------- */
    while (1)
    {
    }
}
```

### Explanation

1. **Clock Activation**: Clocks for `GPIOA`, `USART1`, and `I2C2` are enabled via `RCC->AHB2ENR`, `RCC->APB2ENR`, and `RCC->APB1ENR1`.
2. **Pin Allocation & Conflict**: Both peripherals are initialized per the specifications. Pins PA8 and PA9 are configured for I2C2 Fast-mode (AF4, open-drain, pull-ups), and PA10 for USART1 RX (AF7). *Note: Because PA9 was specified for both USART1 TX (Message 1) and I2C2 SCL (Message 2), the final configuration assigns PA9 to I2C2 SCL.*

4. **I2C2**: `I2C2->CR1` PE is held low while writing `TIMINGR` to ensure valid timing parameters ($t_{\mathrm{LOW}} \ge 1.3\ \mu\mathrm{s}$, $t_{\mathrm{HIGH}} \ge 0.6\ \mu\mathrm{s}$), then enabled.
