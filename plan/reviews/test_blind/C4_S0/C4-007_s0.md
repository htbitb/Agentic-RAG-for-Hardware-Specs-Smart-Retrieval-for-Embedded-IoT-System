```c
#include "stm32g4xx.h"

void Clock_Config_168MHz(void)
{
    /* 1. Enable HSE oscillator and wait for it to stabilize */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY)) {
        /* Busy-wait */
    }

    /* 2. Configure Flash latency: 4 wait states required for 168 MHz in Range 1 */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY) != FLASH_ACR_LATENCY_4WS) {
        /* Busy-wait until latency is set */
    }

    /* 3. Configure PLL:
     *    Source = HSE (24 MHz)
     *    PLLM = 1 (value 0: /1) -> 24 MHz
     *    PLLN = 14               -> VCO = 336 MHz
     *    PLLR = 2 (value 0: /2) -> PLLCLK = 168 MHz
     *    Enable PLLR output (PLLREN)
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE
                 | (0 << RCC_PLLCFGR_PLLM_Pos)
                 | (14 << RCC_PLLCFGR_PLLN_Pos)
                 | (0 << RCC_PLLCFGR_PLLR_Pos)
                 | RCC_PLLCFGR_PLLREN;

    /* 4. Enable the main PLL and wait until locked */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY)) {
        /* Busy-wait */
    }

    /* 5. Ensure AHB, APB1, and APB2 prescalers are /1 (reset default = 0) */
    RCC->CFGR &= ~(RCC_CFGR_HPRE | RCC_CFGR_PPRE1 | RCC_CFGR_PPRE2);

    /* 6. Switch SYSCLK to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
        /* Busy-wait until PLL is selected as SYSCLK */
    }
}
```

### Explanation

1. **HSE Enable**: Starts the 24 MHz external oscillator and waits for `HSERDY`.
2. **Flash Latency**: In Range 1 Boost mode (the default reset state for $V_{CORE}$ on STM32G4), running at $168\text{ MHz}$ requires 4 wait states (`FLASH_ACR_LATENCY_4WS`) [RM0440 p.96]. This is programmed before increasing the clock speed to prevent CPU fetch faults.
3. **PLL Configuration**:
   - `PLLSRC` is set to HSE.
   - `PLLM = 0` encodes a division factor of 1 ($24\text{ MHz} / 1 = 24\text{ MHz}$).
   - `PLLN = 14` multiplies the input frequency to yield a VCO frequency of $336\text{ MHz}$.
   - `PLLR = 0` encodes a division factor of 2 ($336\text{ MHz} / 2 = 168\text{ MHz}$).
   - `PLLREN` enables the main `PLLCLK` output line.
4. **PLL Ready & Switch**: The PLL is powered on (`PLLON`) and awaited (`PLLRDY`). The system clock multiplexer is switched to `PLL` (`SW_PLL`), and the loop waits for the hardware confirmation in `SWS` (`SWS_PLL`). Prescalers remain at $\div 1$, giving $\text{SYSCLK} = \text{HCLK} = \text{PCLK1} = \text{PCLK2} = 168\text{ MHz}$.

### Assistant answer 1

```c
#include "stm32g4xx.h"

void USART1_Init_115200(void)
{
    /* 1. Enable peripheral clocks for GPIOA and USART1 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PA9 (TX) and PA10 (RX) as Alternate Function 7 (AF7) */
    /* Set Moder to Alternate Function (10b) for PA9 and PA10 */
    GPIOA->MODER &= ~(GPIO_MODER_MODE9 | GPIO_MODER_MODE10);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

    /* Set AF7 (USART1) in AFRH for pin 9 (bits 7:4) and pin 10 (bits 11:8) */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= (7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos);

    /* 3. Configure USART1:
     *    Reset defaults give:
     *      - 8 data bits (M[1:0] = 00 in CR1)
     *      - No parity (PCE = 0 in CR1)
     *      - 1 stop bit (STOP[1:0] = 00 in CR2)
     *      - Oversampling by 16 (OVER8 = 0 in CR1)
     *      - Clock source = PCLK2 = 168 MHz (USART1SEL = 00 in RCC->CCIPR)
     */
    USART1->CR1 = 0;
    USART1->CR2 = 0;
    USART1->CR3 = 0;

    /* 4. Set baud rate register (BRR) before enabling USART:
     *    BRR = f_CK / baud = 168000000 / 115200 = 1458.333 -> 1458
     *    Actual baud: 168000000 / 1458 = 115226.3 baud (+0.023% error)
     */
    USART1->BRR = 1458;

    /* 5. Enable Transmitter, Receiver, and the USART module */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;

    /* 6. Wait for TE and RE acknowledge flags to confirm readiness */
    while (!(USART1->ISR & USART_ISR_TEACK) || !(USART1->ISR & USART_ISR_REACK)) {
        /* Busy-wait */
    }
}
```

### Explanation

1. **Clocks**: `GPIOA` clock on AHB2 and `USART1` clock on APB2 are enabled. At reset, `RCC->CCIPR` selects PCLK2 ($168\text{ MHz}$) as the USART1 clock source [RM0440 p.253].
2. **GPIO Configuration**: Pins PA9 and PA10 are placed into Alternate Function mode (`MODER = 10b`) and mapped to AF7 (USART1_TX / USART1_RX) via `AFR[1]` [STM32G474 datasheet p.76].
3. **Frame Format**: Registers `CR1`, `CR2`, and `CR3` are cleared to set the default 8 data bits, no parity, 1 stop bit, and $16\times$ oversampling (`OVER8 = 0`).
4. **Baud Rate**: For $16\times$ oversampling, $\text{BRR} = f_{CK} / \text{Baud} = 168{,}000{,}000 / 115{,}200 \approx 1458$ [RM0440 p.1218]. The resulting error is $+0.023\%$, well within $\pm 2\%$.
5. **Enable**: `BRR` is written prior to setting `UE` along with `TE` and `RE`. The loop waits for `TEACK` and `REACK` status flags to confirm both directions are active.

{

     * PLLM   = 1  (bits 0000b) -> 24 MHz / 1 = 24 MHz

     * PLLR   = 2  (bits 00b)   -> 336 MHz / 2 = 168 MHz

                 | RCC_PLLCFGR_PLLREN;

    RCC->CR |= RCC_CR_PLLON;

        /* Busy-wait until PLL is locked */

     * ==================================================================== */

    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;

    USART1->CR1 = 0;
    USART1->CR2 = 0;

### Explanation

- **Clock Tree**: Enables the 24 MHz HSE crystal and sets Flash read latency to 4 wait states to support 168 MHz operation. Configures the PLL with $M=1$, $N=14$, and $R=2$ ($24 \times 14 / 2 = 168\text{ MHz}$), then locks it and selects it as `SYSCLK` with all bus prescalers set to 1.

- **Main Loop**: The initialization finishes into a standard infinite `while (1)` loop.
