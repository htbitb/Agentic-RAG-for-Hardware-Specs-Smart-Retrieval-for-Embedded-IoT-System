void SystemClock_Config(void)
{
    /* 1. Enable power interface clock to configure voltage scaling */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* 2. Switch to Range 1 Boost Mode to allow operation up to 170 MHz.
     * Clearing R1MODE in PWR_CR5 enables Boost Mode (reset value is 1). */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 3. Configure Flash latency to 4 wait states (required for 170 MHz in Range 1 Boost mode)
     * and enable instruction cache, data cache, and prefetch buffer. */
    FLASH->ACR = FLASH_ACR_LATENCY_4WS | FLASH_ACR_ICEN | FLASH_ACR_DCEN | FLASH_ACR_PRFTEN;
    while ((FLASH->ACR & FLASH_ACR_LATENCY_Msk) != FLASH_ACR_LATENCY_4WS)
    {
        /* Wait until the new Flash latency is active */
    }

    /* 4. Enable HSE oscillator (8 MHz) */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY))
    {
        /* Wait until HSE is ready */
    }

    /* 5. Configure Main PLL:
     * PLL source = HSE (8 MHz)
     * PLLM = 2 -> PLL input = 8 MHz / 2 = 4 MHz
     * PLLN = 85 -> VCO output = 4 MHz * 85 = 340 MHz
     * PLLR = 2 (00b) -> PLLCLK = 340 MHz / 2 = 170 MHz
     * Enable PLL "R" output (SYSCLK) */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE
                 | ((2UL - 1UL) << RCC_PLLCFGR_PLLM_Pos)
                 | (85UL << RCC_PLLCFGR_PLLN_Pos)
                 | (0UL << RCC_PLLCFGR_PLLR_Pos) /* PLLR div by 2 is 00b */
                 | RCC_PLLCFGR_PLLREN;

    /* 6. Enable PLL and wait for lock */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY))
    {
        /* Wait until PLL is ready */
    }

    /* 7. Ensure AHB, APB1, and APB2 prescalers are set to /1 (reset values are 0) */
    RCC->CFGR &= ~(RCC_CFGR_HPRE | RCC_CFGR_PPRE1 | RCC_CFGR_PPRE2);

    /* 8. Select PLL as system clock source */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL)
    {
        /* Wait until PLL is used as SYSCLK */
    }
}

### Explanation
1. **Range 1 Boost Mode**: The STM32G474 requires Range 1 Boost Mode to run beyond 150 MHz up to 170 MHz [RM0440 p.232]. This is enabled by clearing `PWR_CR5_R1MODE` while the system clock is $\le 150\text{ MHz}$.

3. **PLL Calculation**: 
   $$\text{SYSCLK} = \frac{f_{\text{HSE}}}{\text{PLLM}} \times \frac{\text{PLLN}}{\text{PLLR}} = \frac{8\text{ MHz}}{2} \times \frac{85}{2} = 170.0\text{ MHz}$$

void PWM_TIM1_PA8_Init(void)
{
    /* 1. Enable GPIOA and TIM1 peripheral clocks */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_TIM1EN;

    /* 2. Configure PA8 as Alternate Function AF6 (TIM1_CH1), Very High Speed */
    GPIOA->MODER &= ~GPIO_MODER_MODE8_Msk;
    GPIOA->MODER |= (2UL << GPIO_MODER_MODE8_Pos); /* Alternate function mode (10b) */

    GPIOA->AFR[1] &= ~GPIO_AFRH_AFSEL8_Msk;
    GPIOA->AFR[1] |= (6UL << GPIO_AFRH_AFSEL8_Pos); /* AF6 = TIM1_CH1 */

    GPIOA->OSPEEDR |= (3UL << GPIO_OSPEEDR_OSPEED8_Pos); /* Very high speed (11b) */
    GPIOA->PUPDR   &= ~GPIO_PUPDR_PUPD8_Msk;             /* No pull-up / pull-down */

    /* 3. Configure TIM1 time-base for 100 kHz with SYSCLK = 200 MHz:
     * Timer clock = 200 MHz (APB2 prescaler is 1)
     * Prescaler = 0 -> timer ticks at 200 MHz
     * Period = (ARR + 1) = 200 MHz / 100 kHz = 2000 counts -> ARR = 1999
     * Duty cycle 50 %: CCR1 = 2000 / 2 = 1000 */
    TIM1->PSC = 0;
    TIM1->ARR = 2000UL - 1UL;
    TIM1->CCR1 = 1000UL;

    /* 4. Configure Channel 1:
     * - CC1S = 00 (Output)
     * - OC1M = 0110 (PWM Mode 1: active while CNT < CCR1)
     * - OC1PE = 1 (Output compare preload enable) */
    TIM1->CCMR1 &= ~(TIM_CCMR1_CC1S | TIM_CCMR1_OC1M);
    TIM1->CCMR1 |= (TIM_CCMR1_OC1M_1 | TIM_CCMR1_OC1M_2) | TIM_CCMR1_OC1PE;

    /* 5. Configure Channel 1 Output:
     * - CC1P = 0 (Active high)
     * - CC1E = 1 (Enable output on pin) */
    TIM1->CCER &= ~TIM_CCER_CC1P;
    TIM1->CCER |= TIM_CCER_CC1E;

    /* 6. Enable Main Output (MOE) - mandatory for advanced timers (TIM1/TIM8) */
    TIM1->BDTR |= TIM_BDTR_MOE;

    /* 7. Generate an update event to preload registers into active shadow registers */
    TIM1->EGR |= TIM_EGR_UG;

    /* 8. Enable auto-reload preload and start timer */
    TIM1->CR1 |= TIM_CR1_ARPE | TIM_CR1_CEN;
}

### Explanation
1. **200 MHz Operating Frequency**: The STM32G474 maximum operating specification is 170 MHz in Range 1 Boost mode with a max VCO frequency of 344 MHz [DS12288 p.76, p.108]; 200 MHz ($\text{VCO} = 400\text{ MHz}$) runs the silicon beyond datasheet ratings (overclock). To accommodate 200 MHz, Flash latency is increased to 5 wait states (`LATENCY_5WS`).
2. **Pin Assignment**: PA8 alternate function 6 (`AF6`) is mapped to `TIM1_CH1` [DS12288 p.60].
3. **PWM Frequency & Resolution**: With a 200 MHz counter clock and no prescaler (`PSC = 0`), an `ARR` value of `1999` yields:
   $$f_{\text{PWM}} = \frac{200\text{ MHz}}{(0 + 1) \times (1999 + 1)} = 100.0\text{ kHz}$$
   This configuration gives a resolution of 2000 discrete duty steps (0.05% per step).
4. **Advanced-Timer Main Output Enable (`MOE`)**: Advanced timers (TIM1/TIM8) do not drive outputs unless `BDTR_MOE` is set [RM0440 p.1044].

### Explanation
1. **Clock Setup**: The core is set to Range 1 Boost Mode (`PWR_CR5_R1MODE = 0`) with 5 Flash wait states. The HSE oscillator (8 MHz) feeds the PLL (`/2 * 100 / 2 = 200 MHz`). All bus prescalers remain at `/1`, yielding `SYSCLK = HCLK = PCLK1 = PCLK2 = 200 MHz`.
2. **GPIO Mapping**: Pin PA8 is configured in Alternate Function 6 (`AF6`), which connects it internally to `TIM1_CH1`.
3. **PWM Generation**: With TIM1 clocked at 200 MHz and prescaler `PSC = 0`, an auto-reload value of `ARR = 1999` yields a 100 kHz period ($200\text{ MHz} / 2000$). Setting `CCR1 = 1000` with PWM Mode 1 produces an active-high 50% duty cycle. Setting `TIM1->BDTR |= TIM_BDTR_MOE` enables the outputs on the external pins.
