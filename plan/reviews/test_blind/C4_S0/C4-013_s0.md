### Assistant answer 0

```c
#include "stm32g4xx.h"

void usart3_init(void)
{
    /* 1. Enable peripheral clocks for GPIOB and USART3 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_USART3EN;

    /* 2. Configure PB10 (TX) and PB11 (RX) as Alternate Function 7 (AF7) */
    // Pins are in analog mode (0b11) at reset; clear to alternate function mode (0b10)
    GPIOB->MODER &= ~((GPIO_MODER_MODE10_Msk) | (GPIO_MODER_MODE11_Msk));
    GPIOB->MODER |=  ((2U << GPIO_MODER_MODE10_Pos) | (2U << GPIO_MODER_MODE11_Pos));

    // Optional: High speed for TX pin
    GPIOB->OSPEEDR |= (2U << GPIO_OSPEEDR_OSPEED10_Pos);

    // Set AF7 (USART3_TX on PB10, USART3_RX on PB11) in AFR[1] (AFRH)
    GPIOB->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL10_Pos) | (0xFU << GPIO_AFRH_AFSEL11_Pos));
    GPIOB->AFR[1] |=  ((7U << GPIO_AFRH_AFSEL10_Pos)   | (7U << GPIO_AFRH_AFSEL11_Pos));

    /* 3. Configure USART3 frame and baud rate */
    // Ensure USART3 is disabled before configuration
    USART3->CR1 = 0;

    // Default clock source for USART3 is PCLK1 (170 MHz)
    // Oversampling by 16 (OVER8 = 0): BRR = round(170000000 / 115200) = 1476
    USART3->BRR = (170000000UL + (115200UL / 2UL)) / 115200UL;

    // 1 stop bit (STOP[1:0] = 00b in CR2)
    USART3->CR2 &= ~USART_CR2_STOP;

    // 8 data bits (M0=0, M1=0), parity disabled (PCE=0), enable TX and RX
    USART3->CR1 = USART_CR1_TE | USART_CR1_RE;

    /* 4. Enable USART */
    USART3->CR1 |= USART_CR1_UE;
}
```

### Explanation
1. **Clock Gating:** Clock access is enabled for `GPIOB` via `RCC->AHB2ENR` and `USART3` via `RCC->APB1ENR1`. By default, `RCC_CCIPR.USART3SEL` routes `PCLK1` (170 MHz) to USART3.
2. **GPIO Configuration:** Pins PB10 and PB11 default to analog mode (`0b11`) after reset. They are configured to Alternate Function mode (`0b10`), and multiplexed to `AF7` in `AFR[1]` (AFR High).
3. **Baud Rate & Frame Setup:**
   * With oversampling set to 16 (`OVER8 = 0`), the baud-rate divider is directly written to `USART3->BRR`:
     $$\text{BRR} = \frac{170\,000\,000}{115\,200} \approx 1475.69 \rightarrow 1476 \text{ (0x05C4)}$$
   * `CR1` defines 8-bit word length and no parity by leaving `M[1:0]` and `PCE` cleared to zero while enabling `TE` and `RE`.
   * `CR2` default stop bit setting (`STOP = 00b`) selects 1 stop bit.
4. **USART Enable:** `USART3->CR1` sets `UE` as the final step after the baud rate and transmission parameters are fully established.

### Assistant answer 1

```c
#include "stm32g4xx.h"

void tim2_ch3_pwm_init(void)
{
    /* 1. Enable peripheral clocks for GPIOB and TIM2 */
    RCC->AHB2ENR  |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN;

    /* 2. Configure PB10 as Alternate Function 1 (TIM2_CH3) */
    // Set PB10 mode to Alternate Function (0b10)
    GPIOB->MODER &= ~GPIO_MODER_MODE10_Msk;
    GPIOB->MODER |=  (2U << GPIO_MODER_MODE10_Pos);

    // High speed output for crisp edges
    GPIOB->OSPEEDR |= (2U << GPIO_OSPEEDR_OSPEED10_Pos);

    // Map PB10 to AF1 (TIM2_CH3) in AFR[1] (AFRH)
    GPIOB->AFR[1] &= ~GPIO_AFRH_AFSEL10_Msk;
    GPIOB->AFR[1] |=  (1U << GPIO_AFRH_AFSEL10_Pos);

    /* 3. Configure TIM2 time base for 5 kHz */
    // Timer clock = PCLK1 = 170 MHz (APB1 prescaler is 1)
    // Counter frequency = 170 MHz / (PSC + 1) = 170 MHz (with PSC = 0)
    // Period = 170 MHz / 5 kHz = 34,000 counts -> ARR = 34000 - 1 = 33999
    TIM2->PSC = 0;
    TIM2->ARR = 34000U - 1U;

    /* 4. Configure Channel 3 for PWM Mode 1 with 80% duty cycle */
    // Duty cycle = 80% of 34,000 = 27,200
    TIM2->CCR3 = 27200U;

    // CCMR2: Channel 3 as output (CC3S = 00b), PWM Mode 1 (OC3M = 0110b), Preload enable (OC3PE = 1)
    TIM2->CCMR2 &= ~(TIM_CCMR2_CC3S | TIM_CCMR2_OC3M);
    TIM2->CCMR2 |=  (TIM_CCMR2_OC3M_1 | TIM_CCMR2_OC3M_2 | TIM_CCMR2_OC3PE);

    // CCER: Enable output (CC3E = 1), active-high polarity (CC3P = 0)
    TIM2->CCER &= ~TIM_CCER_CC3P;
    TIM2->CCER |=  TIM_CCER_CC3E;

    /* 5. Enable auto-reload preload and start timer */
    TIM2->CR1 |= TIM_CR1_ARPE;
    TIM2->EGR  = TIM_EGR_UG;   // Generate update event to load preloaded registers
    TIM2->CR1 |= TIM_CR1_CEN;  // Enable counter
}
```

### Explanation
1. **Pin Mapping:** PB10 alternate function is switched to `AF1` (`TIM2_CH3`).
2. **Frequency & Duty Cycle Calculations:**
   * Since the APB1 prescaler is 1, TIM2 clock is equal to $PCLK1 = 170\text{ MHz}$.
   * At $\text{PSC} = 0$, counter step is $\frac{1}{170\text{ MHz}}$.
   * For $f_{\text{PWM}} = 5\text{ kHz}$:
     $$\text{ARR} = \frac{170\,000\,000}{5\,000} - 1 = 33\,999$$
   * For an $80\%$ duty cycle in PWM mode 1 (active while $\text{CNT} < \text{CCR3}$):
     $$\text{CCR3} = 34\,000 \times 0.80 = 27\,200$$
3. **Timer Output Setup:**
   * `TIM2->CCMR2`: Bits `OC3M[3:0] = 0110b` configure edge-aligned PWM Mode 1; `OC3PE` enables register preloading.
   * `TIM2->CCER`: Setting `CC3E = 1` and `CC3P = 0` sets channel 3 as an active-high output. TIM2 is a general-purpose timer without complementary outputs or dead time, so no break/main output enable (`BDTR`/`MOE`) is required.
   * `UG` bit generates an update to transfer the shadow values into active registers, and `CR1.CEN` turns on the counter.

```c
int main(void)
{
    /* -------------------------------------------------------------------------
     * 1. Enable Peripheral Clocks
     * ------------------------------------------------------------------------- */
    RCC->AHB2ENR  |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_USART3EN | RCC_APB1ENR1_TIM2EN;

    /* -------------------------------------------------------------------------
     * 2. GPIO Configuration
     *    PB10: TIM2_CH3   (AF1) - Heater PWM
     *    PB11: USART3_RX  (AF7)
     * ------------------------------------------------------------------------- */
    // Set PB10 and PB11 to Alternate Function mode (0b10)
    GPIOB->MODER &= ~((GPIO_MODER_MODE10_Msk) | (GPIO_MODER_MODE11_Msk));
    GPIOB->MODER |=  ((2U << GPIO_MODER_MODE10_Pos) | (2U << GPIO_MODER_MODE11_Pos));

    // High speed on PB10 for PWM output edges
    GPIOB->OSPEEDR |= (2U << GPIO_OSPEEDR_OSPEED10_Pos);

    // PB10 -> AF1 (TIM2_CH3), PB11 -> AF7 (USART3_RX)
    GPIOB->AFR[1] &= ~((GPIO_AFRH_AFSEL10_Msk) | (GPIO_AFRH_AFSEL11_Msk));
    GPIOB->AFR[1] |=  ((1U << GPIO_AFRH_AFSEL10_Pos) | (7U << GPIO_AFRH_AFSEL11_Pos));

    /* -------------------------------------------------------------------------
     * 3. USART3 Configuration (115200 baud, 8N1, PCLK1 = 170 MHz)
     * ------------------------------------------------------------------------- */
    USART3->CR1 = 0;

    // BRR = 170,000,000 / 115,200 ≈ 1476
    USART3->BRR = (170000000UL + (115200UL / 2UL)) / 115200UL;

    // 1 stop bit
    USART3->CR2 &= ~USART_CR2_STOP;

    // Enable TX and RX, 8 data bits, no parity
    USART3->CR1 = USART_CR1_TE | USART_CR1_RE;

    // Enable USART3
    USART3->CR1 |= USART_CR1_UE;

    /* -------------------------------------------------------------------------
     * 4. TIM2 Configuration (5 kHz PWM, 80% duty cycle on Channel 3)
     * ------------------------------------------------------------------------- */
    // ARR = (170 MHz / 5 kHz) - 1 = 33999
    TIM2->PSC = 0;
    TIM2->ARR = 34000U - 1U;

    // 80% duty cycle: CCR3 = 34000 * 0.80 = 27200
    TIM2->CCR3 = 27200U;

    // PWM mode 1 (OC3M = 0110b), preload enable (OC3PE = 1)
    TIM2->CCMR2 &= ~(TIM_CCMR2_CC3S | TIM_CCMR2_OC3M);
    TIM2->CCMR2 |=  (TIM_CCMR2_OC3M_1 | TIM_CCMR2_OC3M_2 | TIM_CCMR2_OC3PE);

    // Active-high output enable (CC3E = 1, CC3P = 0)
    TIM2->CCER &= ~TIM_CCER_CC3P;
    TIM2->CCER |=  TIM_CCER_CC3E;

    // Auto-reload preload enable, update registers, and start counter
    TIM2->CR1 |= TIM_CR1_ARPE;
    TIM2->EGR  = TIM_EGR_UG;
    TIM2->CR1 |= TIM_CR1_CEN;

    /* -------------------------------------------------------------------------
     * Main loop
     * ------------------------------------------------------------------------- */
    while (1)
    {
    }
}
```

### Explanation
* **Pin Allocation Conflict Note:** Both `USART3_TX` and `TIM2_CH3` are multiplexed on pin `PB10`. A GPIO pin can only serve one peripheral function at a time. In this consolidated program, `PB10` is assigned to `AF1` (`TIM2_CH3`) to output the 5 kHz PWM heater drive, while `PB11` remains mapped to `AF7` (`USART3_RX`). If USART3 transmission is also required simultaneously, `USART3_TX` must be mapped to another available pin (such as `PC10` on AF7).
* **Peripherals:** Clocks for `GPIOB`, `USART3`, and `TIM2` are enabled simultaneously. `USART3` is configured at 115200 baud with `BRR` calculated from the 170 MHz `PCLK1`. `TIM2` is configured with $PSC = 0$, $ARR = 33999$, and $CCR3 = 27200$ to output the 5 kHz, 80% duty cycle PWM on channel 3.
