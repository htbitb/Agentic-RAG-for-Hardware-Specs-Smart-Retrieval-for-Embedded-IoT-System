```c
#include "stm32g4xx.h"

void tim4_pwm_init(void)
{
    /* 1. Enable peripheral clocks for GPIOB and TIM4 */
    RCC->AHB2ENR  |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM4EN;

    /* 2. Configure PB6 and PB7 as Alternate Function 2 (TIM4_CH1, TIM4_CH2) */
    /* Set PB6 and PB7 to Alternate Function mode (0b10) */
    GPIOB->MODER &= ~(GPIO_MODER_MODE6_Msk | GPIO_MODER_MODE7_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE6_Pos) | (2U << GPIO_MODER_MODE7_Pos);

    /* Set AF2 (0b0010) in AFR[0] (AFRL) for pins 6 and 7 */
    GPIOB->AFR[0] &= ~(GPIO_AFRL_AFSEL6_Msk | GPIO_AFRL_AFSEL7_Msk);
    GPIOB->AFR[0] |= (2U << GPIO_AFRL_AFSEL6_Pos) | (2U << GPIO_AFRL_AFSEL7_Pos);

    /* Configure high output speed */
    GPIOB->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED6_Pos) | (3U << GPIO_OSPEEDR_OSPEED7_Pos);

    /* 3. Configure TIM4 time base 
     * With APB1 prescaler = 1, TIM4 clock = PCLK1 = 170 MHz.
     * f_PWM = 10 kHz -> ARR = (170,000,000 / (PSC + 1) / 10,000) - 1
     * With PSC = 0: ARR = 17,000 - 1 = 16,999.
     */
    TIM4->PSC = 0U;
    TIM4->ARR = 16999U;

    /* 4. Set Duty Cycles 
     * CH1: 30% of 17,000 = 5,100
     * CH2: 60% of 17,000 = 10,200
     */
    TIM4->CCR1 = 5100U;
    TIM4->CCR2 = 10200U;

    /* 5. Configure Channel 1 and Channel 2 in PWM mode 1 with preload enabled 
     * OC1M = 0110b (PWM mode 1), OC1PE = 1
     * OC2M = 0110b (PWM mode 1), OC2PE = 1
     */
    TIM4->CCMR1 &= ~(TIM_CCMR1_OC1M_Msk | TIM_CCMR1_OC2M_Msk);
    TIM4->CCMR1 |= (6U << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE
                |  (6U << TIM_CCMR1_OC2M_Pos) | TIM_CCMR1_OC2PE;

    /* 6. Enable outputs; polarity active-high by default (CC1P = 0, CC2P = 0) */
    TIM4->CCER |= TIM_CCER_CC1E | TIM_CCER_CC2E;

    /* 7. Enable Auto-reload preload, generate update event to latch shadow registers, start counter */
    TIM4->CR1 |= TIM_CR1_ARPE;
    TIM4->EGR |= TIM_EGR_UG;
    TIM4->CR1 |= TIM_CR1_CEN;
}
```

### Explanation

1. **Clocks**: Enabled `GPIOB` via `AHB2ENR` and `TIM4` via `APB1ENR1`. Because the APB1 prescaler is set to 1, the timer clock is not multiplied and receives the full 170 MHz PCLK1.
2. **GPIO Routing**: Configured PB6 and PB7 to Alternate Function mode with `AF2` mapping (`AFRL[6]` and `AFRL[7]` set to `0x2`), connecting them to `TIM4_CH1` and `TIM4_CH2`.
3. **Time Base**: With $f_{\text{timer}} = 170\text{ MHz}$ and $PSC = 0$, an $ARR$ value of $16999$ gives a period of 17,000 counts, yielding precisely $10\text{ kHz}$.
4. **Duty Cycle**: Edge-aligned PWM mode 1 outputs high while the counter is less than the compare register value ($CNT < CCRx$). For 30% duty cycle, $CCR1 = 17000 \times 0.30 = 5100$. For 60%, $CCR2 = 17000 \times 0.60 = 10200$.
5. **Output & Start**: Enabled channels 1 and 2 in `CCER` (default polarity is active-high). Because TIM4 is a standard general-purpose timer, the main output enable (`BDTR_MOE`) register is not present and counter enable (`CR1_CEN`) starts output generation immediately.

```c
#include "stm32g4xx.h"

void usart1_init(void)
{
    /* 1. Enable peripheral clocks for GPIOB and USART1 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PB6 (TX) and PB7 (RX) as Alternate Function 7 (USART1) */
    /* Set PB6 and PB7 to Alternate Function mode (0b10) */
    GPIOB->MODER &= ~(GPIO_MODER_MODE6_Msk | GPIO_MODER_MODE7_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE6_Pos) | (2U << GPIO_MODER_MODE7_Pos);

    /* Assign AF7 to both PB6 and PB7 */
    GPIOB->AFR[0] &= ~(GPIO_AFRL_AFSEL6_Msk | GPIO_AFRL_AFSEL7_Msk);
    GPIOB->AFR[0] |= (7U << GPIO_AFRL_AFSEL6_Pos) | (7U << GPIO_AFRL_AFSEL7_Pos);

    /* Configure high speed and enable pull-up on RX pin (PB7) */
    GPIOB->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED6_Pos) | (3U << GPIO_OSPEEDR_OSPEED7_Pos);
    GPIOB->PUPDR   &= ~GPIO_PUPDR_PUPD7_Msk;
    GPIOB->PUPDR   |= (1U << GPIO_PUPDR_PUPD7_Pos);

    /* 3. Configure USART1 Frame Format:
     * Reset state of CR1, CR2, and CR3 has:
     * - M1=0, M0=0 (8 data bits)
     * - PCE=0 (no parity)
     * - OVER8=0 (oversampling by 16)
     * - STOP[1:0]=00 (1 stop bit)
     */
    USART1->CR1 = 0U;
    USART1->CR2 = 0U;
    USART1->CR3 = 0U;

    /* 4. Set Baud Rate Register BEFORE enabling USART
     * Clock source is PCLK2 = 170 MHz (default USART1SEL in RCC_CCIPR = 00).
     * With OVER8 = 0: BRR = fCK / Baud = 170,000,000 / 115,200 = 1475.694 -> 1476.
     * Actual baud rate: 170,000,000 / 1476 = 115,176.15 baud (error: -0.021%).
     */
    USART1->BRR = 1476U;

    /* 5. Enable Transmitter, Receiver, and the USART peripheral */
    USART1->CR1 |= USART_CR1_TE | USART_CR1_RE;
    USART1->CR1 |= USART_CR1_UE;
}

void usart1_write_char(char c)
{
    /* Wait until transmit data register is empty (TXE / TXFNF) */
    while (!(USART1->ISR & USART_ISR_TXE_TXFNF))
        ;
    USART1->TDR = (uint8_t)c;
}

char usart1_read_char(void)
{
    /* Wait until data is received (RXNE / RXFNE) */
    while (!(USART1->ISR & USART_ISR_RXNE_RXFNE))
        ;
    return (char)(USART1->RDR & 0xFFU);
}
```

### Explanation

1. **Clock & Routing**: Enabled `GPIOB` via `AHB2ENR` and `USART1` via `APB2ENR`. Reassigned PB6 and PB7 from the previous timer function to Alternate Function 7 (`AF7`), connecting them to `USART1_TX` and `USART1_RX`. A pull-up is enabled on PB7 (RX) to prevent floating line states.
2. **Clock Source & Baud Rate**: By default, `RCC_CCIPR` selects PCLK2 (170 MHz) as the clock source for `USART1`. With 16× oversampling (`OVER8 = 0`), the baud-rate divisor is directly written to `USART1->BRR`:
   $$\text{BRR} = \left\lfloor\frac{170\,000\,000}{115\,200} + 0.5\right\rfloor = 1476$$
   This yields an actual baud rate of $115\,176.15\text{ baud}$ (an error of $-0.02\%$, well within $\pm 2\%$).
3. **Sequence**: `USART1->BRR` is written while the USART is disabled (`UE = 0`), after which transmitter (`TE`), receiver (`RE`), and the peripheral enable (`UE`) bits are asserted. Non-interrupt polled I/O is handled via status flags `TXE_TXFNF` and `RXNE_RXFNE` in `USART1->ISR`.

```c
#include "stm32g4xx.h"

int main(void)
{
    /* 1. Enable peripheral clocks */
    RCC->AHB2ENR  |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM4EN;
    RCC->APB2ENR  |= RCC_APB2ENR_USART1EN;

    /* 2. Configure TIM4 time base and PWM channels (10 kHz) */
    TIM4->PSC  = 0U;
    TIM4->ARR  = 16999U;         /* 170 MHz / 17000 = 10 kHz */
    TIM4->CCR1 = 5100U;          /* 30% duty cycle */
    TIM4->CCR2 = 10200U;         /* 60% duty cycle */

    /* PWM mode 1 with preload enabled on CH1 and CH2 */
    TIM4->CCMR1 &= ~(TIM_CCMR1_OC1M_Msk | TIM_CCMR1_OC2M_Msk);
    TIM4->CCMR1 |= (6U << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE
                |  (6U << TIM_CCMR1_OC2M_Pos) | TIM_CCMR1_OC2PE;

    /* Enable channel outputs (active high) */
    TIM4->CCER |= TIM_CCER_CC1E | TIM_CCER_CC2E;

    /* Auto-reload preload enable, force update event, enable counter */
    TIM4->CR1 |= TIM_CR1_ARPE;
    TIM4->EGR |= TIM_EGR_UG;
    TIM4->CR1 |= TIM_CR1_CEN;

    /* 3. Configure USART1 (8 data bits, no parity, 1 stop bit, 16x oversampling) */
    USART1->CR1 = 0U;
    USART1->CR2 = 0U;
    USART1->CR3 = 0U;

    /* BRR = 170 MHz / 115200 = 1476 (-0.02% error) */
    USART1->BRR = 1476U;

    /* Enable transmitter, receiver, and USART1 */
    USART1->CR1 |= USART_CR1_TE | USART_CR1_RE;
    USART1->CR1 |= USART_CR1_UE;

    /* 4. Configure GPIO Pins PB6 & PB7 */
    GPIOB->MODER &= ~(GPIO_MODER_MODE6_Msk | GPIO_MODER_MODE7_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE6_Pos) | (2U << GPIO_MODER_MODE7_Pos); /* AF mode */

    GPIOB->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED6_Pos) | (3U << GPIO_OSPEEDR_OSPEED7_Pos);
    GPIOB->PUPDR   &= ~GPIO_PUPDR_PUPD7_Msk;
    GPIOB->PUPDR   |= (1U << GPIO_PUPDR_PUPD7_Pos); /* Pull-up on RX */

    /* NOTE: Hardware Pin Conflict:
     * PB6 and PB7 cannot be simultaneously mapped to AF2 (TIM4) and AF7 (USART1).
     * Selecting AF7 assigns PB6 to USART1_TX and PB7 to USART1_RX.
     * To route TIM4 PWM to the pins instead, set AFSEL6 and AFSEL7 to 2U (AF2).
     */
    GPIOB->AFR[0] &= ~(GPIO_AFRL_AFSEL6_Msk | GPIO_AFRL_AFSEL7_Msk);
    GPIOB->AFR[0] |= (7U << GPIO_AFRL_AFSEL6_Pos) | (7U << GPIO_AFRL_AFSEL7_Pos); /* AF7: USART1 */

    while (1)
    {
    }
}
```

### Explanation

1. **Peripheral Clock Gating**: Bitmasks in `RCC->AHB2ENR`, `RCC->APB1ENR1`, and `RCC->APB2ENR` enable `GPIOB`, `TIM4`, and `USART1` respectively.
2. **TIM4 Setup**: $ARR = 16999$ with $PSC = 0$ configures a $10\text{ kHz}$ frequency from the $170\text{ MHz}$ timer clock. Compare values $CCR1 = 5100$ and $CCR2 = 10200$ define the 30% and 60% PWM duty cycles.
3. **USART1 Setup**: $BRR = 1476$ sets $115\,176.15\text{ baud}$ from $PCLK2 = 170\text{ MHz}$ prior to asserting $UE$.
4. **Pin Multiplexing Conflict**: Both peripherals were requested on pins `PB6` and `PB7`. An STM32 GPIO pin connects to only one alternate function multiplexer line at a time. The code configures `AF7` (USART1) in `GPIOB->AFR[0]`, leaving TIM4 running internally; switching `AFSEL6`/`AFSEL7` to `2U` connects the TIM4 PWM outputs instead.
