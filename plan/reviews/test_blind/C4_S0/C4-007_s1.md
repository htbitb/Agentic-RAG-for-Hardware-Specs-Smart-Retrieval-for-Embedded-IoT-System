RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;

### Explanation

1. **Boost Mode & Flash Latency**: Frequencies between 150 MHz and 170 MHz require switching the voltage regulator to Range 1 Boost mode by clearing `R1MODE` in `PWR_CR5` [RM0440 p.184]. At 168 MHz in Boost mode, the Flash access latency must be set to 4 wait states (`FLASH_ACR_LATENCY_4WS`) before raising the clock speed [RM0440 p.149].
2. **HSE & PLL Setup**: HSE is enabled and polled until `HSERDY` is set. The PLL is configured with HSE as input, $f_{\text{VCO}} = 24\text{ MHz} \times \frac{14}{1} = 336\text{ MHz}$, and $f_{\text{PLLCLK}} = \frac{336\text{ MHz}}{2} = 168\text{ MHz}$. `PLLREN` enables the main system output.
3. **Clock Switch**: After the PLL locks (`PLLRDY`), `RCC->CFGR` switches the system clock (`SW`) to PLL, and the code polls `SWS` until the switch completes. Prescalers (`HPRE`, `PPRE1`, `PPRE2`) remain at their reset value of divide-by-1, yielding 168 MHz for SYSCLK, HCLK, PCLK1, and PCLK2.

### Assistant answer 1

```c
/* 1. Enable peripheral clocks for GPIOA and USART1 */
RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

/* 2. Configure PA9 (TX) and PA10 (RX) as Alternate Function 7 (AF7 = USART1) */
GPIOA->MODER &= ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk);
GPIOA->MODER |= (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

GPIOA->AFR[1] &= ~(GPIO_AFRH_AFSEL9_Msk | GPIO_AFRH_AFSEL10_Msk);
GPIOA->AFR[1] |= (7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos);

/* 3. Configure baud rate:
 *    USART1 reset clock source is PCLK2 = 168 MHz (RCC_CCIPR.USART1SEL = 00b).
 *    Oversampling by 16 (OVER8 = 0):
 *    BRR = f_CK / Baud = 168,000,000 / 115,200 ≈ 1458 (0x05B2).
 *    Actual baud = 168,000,000 / 1458 ≈ 115226.3 baud (+0.023% error).
 */
USART1->BRR = 1458U;

/* 4. Configure frame format: 8 data bits, no parity, 1 stop bit (reset defaults)
 *    and enable Transmitter and Receiver
 */
USART1->CR1 = USART_CR1_TE | USART_CR1_RE;

/* 5. Enable USART1 */
USART1->CR1 |= USART_CR1_UE;
```

### Explanation

1. **Clock Source**: By default, `RCC->CCIPR.USART1SEL` selects `PCLK2` (168 MHz) [RM0440 p.253]. 
2. **Baud Rate Calculation**: With oversampling by 16 (`OVER8 = 0`), $\text{BRR} = \frac{f_{\text{CK}}}{\text{baud}} = \frac{168000000}{115200} \approx 1458$. The resulting error is $+0.023\%$, well within the $\pm 2\%$ limit.
3. **GPIO & AF**: PA9 and PA10 are routed to USART1 via AF7 [DS12288 p.74].
4. **Sequencing**: As required, `BRR` is programmed prior to asserting the `UE` bit in `USART1->CR1`. Default 8-bit word length (`M[1:0] = 00b`), no parity (`PCE = 0`), and 1 stop bit (`STOP[1:0] = 00b`) are retained.
