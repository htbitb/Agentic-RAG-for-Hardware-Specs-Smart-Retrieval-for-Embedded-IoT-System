### Assistant answer 0

Here is the configuration code for USART3 on the STM32G474.

```c
#include "stm32g4xx.h"

void usart3_init(void)
{
    /* 1. Enable peripheral clocks for GPIOB and USART3 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_USART3EN;

    /* 2. Configure PB10 (TX) and PB11 (RX) as Alternate Function 7 (USART3) */
    /* Set Alternate Function mode (10b) */
    GPIOB->MODER &= ~(GPIO_MODER_MODE10_Msk | GPIO_MODER_MODE11_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE10_Pos) | (2U << GPIO_MODER_MODE11_Pos);

    /* Set AF7 (0111b) for PB10 and PB11 in AFR[1] (AFRH) */
    GPIOB->AFR[1] &= ~(GPIO_AFRH_AFSEL10_Msk | GPIO_AFRH_AFSEL11_Msk);
    GPIOB->AFR[1] |= (7U << GPIO_AFRH_AFSEL10_Pos) | (7U << GPIO_AFRH_AFSEL11_Pos);

    /* Optional: high output speed on TX pin */
    GPIOB->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED10_Pos);

    /* Optional: pull-up on RX pin */
    GPIOB->PUPDR |= (1U << GPIO_PUPDR_PUPD11_Pos);

    /* 3. Configure USART3 Baud Rate
     * Default RCC->CCIPR USART3SEL is 00b (PCLK1 = 170 MHz).
     * With OVER8 = 0 (oversampling by 16):
     * USARTDIV = 170,000,000 / 115,200 ≈ 1475.694
     * Rounded: 1476 (0x05C4) -> actual baud = 115176.15 (~0.02% error)
     * BRR must be programmed while USART is disabled.
     */
    USART3->BRR = 1476U;

    /* 4. Configure frame format and enable directions:
     * - Word length: 8 data bits (M1:M0 = 00b, default)
     * - Parity: Disabled (PCE = 0, default)
     * - Stop bits: 1 stop bit (STOP[1:0] = 00b in CR2, default)
     * - Oversampling by 16: OVER8 = 0 (default)
     * - Transmitter Enable (TE) & Receiver Enable (RE)
     */
    USART3->CR1 = USART_CR1_TE | USART_CR1_RE;

    /* 5. Enable USART3 */
    USART3->CR1 |= USART_CR1_UE;
}
```

### Explanation

1. **Clock Gating**: Clocks to GPIOB (AHB2) and USART3 (APB1) are enabled via `RCC->AHB2ENR` and `RCC->APB1ENR1`. At reset, `RCC->CCIPR` routes PCLK1 (170 MHz) as the USART3 clock source.
2. **GPIO Pin Multiplexing**: PB10 and PB11 are set to Alternate Function mode (`MODER = 10b`) and mapped to AF7 (`USART3_TX` and `USART3_RX`) in `AFR[1]`.
3. **Baud Rate Calculation**: With oversampling by 16 (`OVER8 = 0`), `BRR` holds the full prescaler divisor $\text{USARTDIV} = \frac{f_{CK}}{\text{Baud}} = \frac{170\,000\,000}{115\,200} \approx 1476$.
4. **Frame Format & Enable Sequence**: Frame format bits in `CR1` and `CR2` default to 8 data bits, no parity, and 1 stop bit. Writing `USART3->BRR` is performed before enabling the USART via `USART_CR1_UE`.

Message 2: now add a 5 kHz PWM signal with an 80 % duty cycle on pin PB10 using TIM2 channel 3 to drive a heater; edge-aligned PWM mode 1, active-high output, no dead time.

### Assistant answer 1

```c
#include "stm32g4xx.h"

void tim2_ch3_pwm_init(void)
{
    /* 1. Enable peripheral clocks for GPIOB and TIM2 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN;

    /* 2. Configure PB10 as Alternate Function 1 (TIM2_CH3) */
    GPIOB->MODER &= ~GPIO_MODER_MODE10_Msk;
    GPIOB->MODER |= (2U << GPIO_MODER_MODE10_Pos); /* AF mode */

    GPIOB->AFR[1] &= ~GPIO_AFRH_AFSEL10_Msk;
    GPIOB->AFR[1] |= (1U << GPIO_AFRH_AFSEL10_Pos); /* AF1 = TIM2_CH3 */

    GPIOB->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED10_Pos); /* Very high speed */

    /* 3. Configure TIM2 time base for 5 kHz:
     * TIM2 clock = PCLK1 = 170 MHz (APB1 prescaler = 1).
     * Target frequency = 5 kHz -> Counter ticks = 170 MHz / 5 kHz = 34000.
     * PSC = 0 (divide by 1)
     * ARR = 34000 - 1 = 33999
     */
    TIM2->PSC = 0U;
    TIM2->ARR = 33999U;

    /* 4. Set duty cycle to 80%:
     * In PWM mode 1 (upcounting), output is active while CNT < CCR3.
     * CCR3 = 34000 * 80% = 27200
     */
    TIM2->CCR3 = 27200U;

    /* 5. Configure Channel 3 for PWM Mode 1:
     * - CC3S = 00b (Channel configured as output, default)
     * - OC3M = 0110b (PWM mode 1: active while CNT < CCR3)
     * - OC3PE = 1 (Preload register enable)
     */
    TIM2->CCMR2 &= ~TIM_CCMR2_OC3M_Msk;
    TIM2->CCMR2 |= (6U << TIM_CCMR2_OC3M_Pos) | TIM_CCMR2_OC3PE;

    /* 6. Enable Output and configure polarity:
     * - CC3P = 0 (Active high, default)
     * - CC3E = 1 (Channel 3 output enabled)
     */
    TIM2->CCER &= ~TIM_CCER_CC3P;
    TIM2->CCER |= TIM_CCER_CC3E;

    /* 7. Enable Auto-Reload Preload and start counter */
    TIM2->CR1 |= TIM_CR1_ARPE | TIM_CR1_CEN;
}
```

### Explanation

1. **Pin Reassignment**: PB10 is reassigned to Alternate Function 1 (`TIM2_CH3`) via `AFR[1]`, taking over from USART3_TX configured previously.
2. **Timing Calculation**: With the APB1 prescaler set to 1, the timer input clock is $f_{\text{CK\_INT}} = 170\text{ MHz}$. For a $5\text{ kHz}$ PWM frequency, $\text{ARR} = \frac{170\text{ MHz}}{5\text{ kHz}} - 1 = 33999$.
3. **Duty Cycle**: For an $80\%$ active-high duty cycle in PWM mode 1, $\text{CCR3} = 34000 \times 0.80 = 27200$.
4. **Output Control**: Channel 3 is set to PWM Mode 1 (`OC3M = 0110b`), active-high polarity (`CC3P = 0`), and enabled via `CC3E`. TIM2 is a general-purpose timer, so no main output enable (`BDTR.MOE`) is required.

```c
#include "stm32g4xx.h"

int main(void)
{
    /* 1. Enable peripheral clocks on AHB2 and APB1 */
    RCC->AHB2ENR  |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_USART3EN | RCC_APB1ENR1_TIM2EN;

    /* 2. Configure GPIO pins PB10 and PB11:
     * - PB10: TIM2_CH3 (AF1), high speed
     * - PB11: USART3_RX (AF7), pull-up enabled
     */
    GPIOB->MODER &= ~(GPIO_MODER_MODE10_Msk | GPIO_MODER_MODE11_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE10_Pos) | (2U << GPIO_MODER_MODE11_Pos);

    GPIOB->AFR[1] &= ~(GPIO_AFRH_AFSEL10_Msk | GPIO_AFRH_AFSEL11_Msk);
    GPIOB->AFR[1] |= (1U << GPIO_AFRH_AFSEL10_Pos)   /* AF1 for PB10 (TIM2_CH3)  */
                  |  (7U << GPIO_AFRH_AFSEL11_Pos);  /* AF7 for PB11 (USART3_RX) */

    GPIOB->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED10_Pos); /* High speed on PB10 */
    GPIOB->PUPDR   |= (1U << GPIO_PUPDR_PUPD11_Pos);    /* Pull-up on PB11    */

    /* 3. Configure USART3 (115200 baud, 8N1, oversampling by 16)
     * Clock = PCLK1 = 170 MHz. USARTDIV = 170,000,000 / 115,200 ≈ 1476.
     * BRR must be written before UE is set.
     */
    USART3->BRR = 1476U;
    USART3->CR1 = USART_CR1_TE | USART_CR1_RE;
    USART3->CR1 |= USART_CR1_UE;

    /* 4. Configure TIM2 Channel 3 for 5 kHz PWM at 80% duty cycle
     * Clock = 170 MHz.
     * Period = 170 MHz / 5 kHz = 34000 ticks -> PSC = 0, ARR = 33999.
     * Duty cycle = 34000 * 80% = 27200 ticks -> CCR3 = 27200.
     */
    TIM2->PSC   = 0U;
    TIM2->ARR   = 33999U;
    TIM2->CCR3  = 27200U;

    /* Output Compare mode: PWM mode 1 (0110b), preload enable */
    TIM2->CCMR2 &= ~TIM_CCMR2_OC3M_Msk;
    TIM2->CCMR2 |= (6U << TIM_CCMR2_OC3M_Pos) | TIM_CCMR2_OC3PE;

    /* Enable Channel 3 output, active-high polarity */
    TIM2->CCER &= ~TIM_CCER_CC3P;
    TIM2->CCER |= TIM_CCER_CC3E;

    /* Enable ARR preload and start TIM2 counter */
    TIM2->CR1 |= TIM_CR1_ARPE | TIM_CR1_CEN;

    /* Main loop */
    while (1)
    {
    }
}
```

### Explanation

1. **Pin Multiplexing**: PB10 was specified for USART3_TX in Message 1 and for TIM2_CH3 in Message 2. It is configured here as AF1 (`TIM2_CH3`) to output the PWM signal to the heater. PB11 is configured as AF7 (`USART3_RX`).
2. **USART3**: Peripheral clock is routed from PCLK1 (170 MHz). Baud rate is configured to 115200 (`BRR = 1476`) before the transmitter, receiver, and USART are enabled.
3. **TIM2 PWM**: Configured for 5 kHz edge-aligned PWM Mode 1 with $\text{ARR} = 33999$ and an 80% duty cycle ($\text{CCR3} = 27200$). Output on channel 3 is active-high and immediately driven upon enabling the counter (`TIM_CR1_CEN`).
