### Configuration Summary for USART2 on STM32G474

1. **Clocks and Power**:
   - Initial state: SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz [STM32G474_RM0440 p.309].
   - GPIOA clock enabled via bit `GPIOAEN` (bit 0) in `RCC->AHB2ENR` [STM32G474_RM0440 p.306].
   - USART2 peripheral clock enabled via bit `USART2EN` (bit 17) in `RCC->APB1ENR1` [STM32G474_RM0440 p.309].
   - By default in `RCC->CCIPR`, `USART2SEL[1:0] = 00b`, which routes PCLK1 (170 MHz) as the USART2 kernel clock [STM32G474_RM0440 p.322].

2. **Pin Multiplexing**:
   - `PA2` (USART2_TX): Alternate Function AF7 [STM32G474_Datasheet p.73].
   - `PA3` (USART2_RX): Alternate Function AF7 [STM32G474_Datasheet p.73].
   - Configured in `GPIOA->MODER` as Alternate Function mode (`10b`) on pins 2 and 3 [STM32G474_RM0440 p.355].
   - Configured in `GPIOA->AFR[0]` (`AFRL`) with AF7 (`0111b`) for positions 2 and 3 [STM32G474_RM0440 p.359].

3. **USART2 Parameters and Baud Rate**:
   - Data length: 8 data bits (reset state: `M[1:0] = 00` in `USART2->CR1`) [STM32G474_RM0440 p.1740].
   - Stop bits: 1 stop bit (reset state: `STOP[1:0] = 00` in `USART2->CR2`) [STM32G474_RM0440 p.1747].
   - Parity: None (reset state: `PCE = 0` in `USART2->CR1`).
   - Oversampling: by 16 (`OVER8 = 0` in `USART2->CR1`).

     $$\text{USARTDIV} = \frac{f_{\text{CK}}}{\text{baud}} = \frac{170\,000\,000}{115\,200} \approx 1475.694$$
     Rounding to the nearest integer for `USART_BRR` gives $1476$ (`0x5C4`) [STM32G474_RM0440 p.1707, 1755].
     Actual baud rate: $\frac{170\,000\,000}{1476} \approx 115\,176.15\text{ baud}$ (error $\approx 0.02\%$).

### Bare-Metal CMSIS C Code

```c
#include "stm32g4xx.h"

void usart2_init(void)
{
    /* 1. Enable peripheral clock for GPIOA and USART2 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_USART2EN;

    /* 2. Configure PA2 (TX) and PA3 (RX) for Alternate Function (AF7) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE2_Msk | GPIO_MODER_MODE3_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE2_Pos) | (2U << GPIO_MODER_MODE3_Pos);

    GPIOA->AFR[0] &= ~(GPIO_AFRL_AFSEL2_Msk | GPIO_AFRL_AFSEL3_Msk);
    GPIOA->AFR[0] |= (7U << GPIO_AFRL_AFSEL2_Pos) | (7U << GPIO_AFRL_AFSEL3_Pos);

    /* 3. Program baud rate register (170 MHz / 115200 = 1476) */
    USART2->BRR = 1476U;

    /* 4. Enable Transmitter (TE) and Receiver (RE) */
    USART2->CR1 |= USART_CR1_TE | USART_CR1_RE;

    /* 5. Enable USART peripheral (UE) */
    USART2->CR1 |= USART_CR1_UE;
}
```

### Pin Allocation Conflict and Resolution

When configuring I2C1, assigning **SCL to pin PB6** was rejected with `NO_SUCH_AF` [STM32G474_Datasheet p.74].
On STM32G474:
- Pin `PB6` does not have an alternate function for `I2C1_SCL` [STM32G474_Datasheet p.74].
- The available alternate-function pins for `I2C1_SCL` are:
  - **`PB8`** (AF4) [STM32G474_Datasheet p.74]
  - `PA13` (AF4 - conflicts with SWDIO) [STM32G474_Datasheet p.73]
  - `PA15` (AF4 - conflicts with JTDI) [STM32G474_Datasheet p.73]

**Decision (D1)**: We selected **`PB8`** (AF4) for `I2C1_SCL`. This routes both `I2C1_SDA` (PB7) and `I2C1_SCL` (PB8) on Port B without interfering with SWD/JTAG debug pins.

### Clock and Timing Calculations (RM0440 §39.4.9 & Table 358)

1. **Clock Source**:
   - `RCC_CCIPR` bits `I2C1SEL[1:0]` remain at `00b` (reset value), selecting **PCLK1 = 170 MHz** (170000000 Hz) as the I2C1 kernel clock ($t_{\text{I2CCLK}} = 1 / 170000000\text{ s} \approx 5.8824\text{ ns}$) [STM32G474_RM0440 p.323].

2. **Timing Constraints**:
   - Fast-mode (Fm) Table 358 minimums:
     - $t_{\text{LOW}} \ge 1.3\ \mu\text{s}$ (1300 ns)
     - $t_{\text{HIGH}} \ge 0.6\ \mu\text{s}$ (600 ns)
   - Controller timing formulas per RM0440 §39.4.9:
     - $t_{\text{SCLL}} = (SCLL + 1) \times (PRESC + 1) \times t_{\text{I2CCLK}}$
     - $t_{\text{SCLH}} = (SCLH + 1) \times (PRESC + 1) \times t_{\text{I2CCLK}}$
     - $t_{\text{LOW}} = t_{\text{SCLL}} + t_{\text{SYNC1}}$ with $t_{\text{SYNC1}} = 2 \times t_{\text{I2CCLK}} \approx 11.76\text{ ns}$
     - $t_{\text{HIGH}} = t_{\text{SCLH}} + t_{\text{SYNC2}}$ with $t_{\text{SYNC2}} = 2 \times t_{\text{I2CCLK}} \approx 11.76\text{ ns}$

3. **Selected Register Parameters**:
   - **`PRESC = 3`**: prescaled clock step is $(3 + 1) \times t_{\text{I2CCLK}} = 4 / 170000000\text{ s} \approx 23.5294\text{ ns}$.
   - **`SCLL = 56` (`0x38`)**:
     - $t_{\text{SCLL}} = (56 + 1) \times (4 / 170000000\text{ s}) \approx 1341.18\text{ ns}$
     - $t_{\text{LOW}} = 1341.18\text{ ns} + 11.76\text{ ns} = 1352.94\text{ ns} \ge 1300\text{ ns}$ (satisfies $t_{\text{LOW}} \ge 1.3\ \mu\text{s}$).
   - **`SCLH = 30` (`0x1E`)**:
     - $t_{\text{SCLH}} = (30 + 1) \times (4 / 170000000\text{ s}) \approx 729.41\text{ ns}$
     - $t_{\text{HIGH}} = 729.41\text{ ns} + 11.76\text{ ns} = 741.18\text{ ns} \ge 600\text{ ns}$ (satisfies $t_{\text{HIGH}} \ge 0.6\ \mu\text{s}$).
   - **Target Reachability**:
     - The counter duration is $[(30 + 1) + (56 + 1)] \times (4 / 170000000\text{ s}) = 88 \times (4 / 170000000\text{ s}) \approx 2070.59\text{ ns}$.
     - With $t_{\text{SYNC1}} + t_{\text{SYNC2}}$ varying between $4 \times t_{\text{I2CCLK}} \approx 23.53\text{ ns}$ and $1000\text{ ns}$, the total SCL period $t_{\text{SCL}}$ ranges from $2094.12\text{ ns}$ to $3070.59\text{ ns}$.
     - The target $400000\text{ Hz}$ period is $1 / 400000\text{ s} = 2500\text{ ns}$, which lies directly inside this reachable range (achieved when $t_{\text{SYNC1}} + t_{\text{SYNC2}} = 2500\text{ ns} - 2070.59\text{ ns} = 429.41\text{ ns}$).
   - **Data Delays**:
     - `SDADEL = 2` ($2 \times 23.53\text{ ns} = 47.06\text{ ns}$)
     - `SCLDEL = 4` ($5 \times 23.53\text{ ns} = 117.65\text{ ns}$)

### Bare-Metal CMSIS C Code

```c
#include "stm32g4xx.h"

void i2c1_init(void)
{
    /* 1. Enable GPIOB and I2C1 peripheral clocks */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_I2C1EN;

    /* 2. Configure PB7 (SDA) and PB8 (SCL) as Alternate Function (AF4), Open-Drain */
    GPIOB->MODER &= ~(GPIO_MODER_MODE7_Msk | GPIO_MODER_MODE8_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE7_Pos) | (2U << GPIO_MODER_MODE8_Pos);

    GPIOB->OTYPER |= (GPIO_OTYPER_OT7 | GPIO_OTYPER_OT8);

    /* Alternate function AF4 for PB7 (AFRL) and PB8 (AFRH) */
    GPIOB->AFR[0] &= ~GPIO_AFRL_AFSEL7_Msk;
    GPIOB->AFR[0] |= (4U << GPIO_AFRL_AFSEL7_Pos);

    GPIOB->AFR[1] &= ~GPIO_AFRH_AFSEL8_Msk;
    GPIOB->AFR[1] |= (4U << GPIO_AFRH_AFSEL8_Pos);

    /* 3. Configure I2C1_TIMINGR while peripheral is disabled (PE = 0):
     *    PRESC  = 3
     *    SCLDEL = 4
     *    SDADEL = 2
     *    SCLH   = 0x1E (30)
     *    SCLL   = 0x38 (56)
     */
    I2C1->TIMINGR = (3U << I2C_TIMINGR_PRESC_Pos)   |
                    (4U << I2C_TIMINGR_SCLDEL_Pos)  |
                    (2U << I2C_TIMINGR_SDADEL_Pos)  |
                    (0x1EU << I2C_TIMINGR_SCLH_Pos) |
                    (0x38U << I2C_TIMINGR_SCLL_Pos);

    /* 4. Enable I2C1 peripheral */
    I2C1->CR1 |= I2C_CR1_PE;
}
```

### Explanation of Initialization and Pin Choices

1. **Clock Enabling**:
   - `RCC->AHB2ENR`: Enables GPIOA and GPIOB clock gates [STM32G474_RM0440 p.306].
   - `RCC->APB1ENR1`: Enables USART2 (`USART2EN`) and I2C1 (`I2C1EN`) clock gates [STM32G474_RM0440 p.309].
   - `RCC->APB2ENR`: Enables USART1 (`USART1EN`) clock gate [STM32G474_RM0440 p.312].
   - All peripherals run off their default reset kernel clock sources (`RCC_CCIPR` reset to `0x00000000`): USART2 and I2C1 on PCLK1 (170 MHz), USART1 on PCLK2 (170 MHz) [STM32G474_RM0440 p.322].

2. **GPIO Routing & Resolved Conflicts**:
   - **USART2**:
     - `PA2` (TX) and `PA3` (RX) configured in Alternate Function AF7 [STM32G474_Datasheet p.73].
   - **I2C1**:
     - `PB7` (SDA) configured in Alternate Function AF4 with open-drain mode [STM32G474_Datasheet p.74].
     - `PB8` (SCL) was chosen because `PB6` does not carry an AF for `I2C1_SCL` on STM32G474 [STM32G474_Datasheet p.74]. `PB8` is configured in Alternate Function AF4 with open-drain mode [STM32G474_Datasheet p.74].
   - **USART1**:
     - `PB6` (TX) configured in Alternate Function AF7 [STM32G474_Datasheet p.74].
     - `PA10` (RX) was chosen because `PB7` is already used by `I2C1_SDA`. `PA10` is an available pin with AF7 in LQFP64 [STM32G474_Datasheet p.73].

3. **Peripheral Parameter Settings**:
   - **USART2**:
     - 170000000 Hz / 115200 baud = 1475.69, so `BRR = 1476` [STM32G474_RM0440 p.1755].
     - `TE` and `RE` enabled, followed by peripheral enable `UE` [STM32G474_RM0440 p.1740].
   - **USART1**:
     - 170000000 Hz / 921600 baud = 184.46, so `BRR = 184` [STM32G474_RM0440 p.1755].
     - Resulting baud rate is 170000000 Hz / 184 = 923913.04 baud, which has a 0.25% error (within the required $\pm 2\%$).
     - `TE` and `RE` enabled, followed by peripheral enable `UE` [STM32G474_RM0440 p.1740].
