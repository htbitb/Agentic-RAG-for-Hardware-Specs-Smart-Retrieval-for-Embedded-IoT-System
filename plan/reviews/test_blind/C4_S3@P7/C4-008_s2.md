### USART1 Configuration (115200 Baud, 8N1, PA9/PA10)

#### 1. Clock Source and Baud Rate Calculation
- **USART1 Kernel Clock**: Under the reset configuration of `RCC_CCIPR.USART1SEL = 00b`, USART1 is clocked by **PCLK2** [STM32G474_RM0440 p.322]. With the clock tree at $170\text{ MHz}$ (AHB div 1, APB2 div 1), $f_{\text{CK}} = 170\text{ MHz}$.
- **Oversampling**: Oversampling by 16 (`OVER8 = 0` in `USART1_CR1`) [STM32G474_RM0440 p.1743].
- **Baud Rate Equation**: When oversampling by 16, the baud rate is given by [STM32G474_RM0440 p.1707]:
  $$\text{USARTDIV} = \frac{f_{\text{CK}}}{\text{Baud Rate}} = \frac{170\,000\,000}{115\,200} \approx 1475.6944$$
  In oversampling by 16 mode, `USART_BRR` directly holds `USARTDIV` [STM32G474_RM0440 p.1708]:
  $$\text{BRR} = \text{round}(1475.6944) = 1476 = \text{0x05C4}$$
- **Achieved Baud Rate & Error**:
  $$\text{Actual Baud} = \frac{170\,000\,000}{1476} \approx 115\,176.15\text{ Baud}$$
  $$\text{Error} = \frac{115\,176.15 - 115\,200}{115\,200} \approx -0.0207\%$$
  This easily meets the requirement of being within $\pm 2\%$.

#### 2. Pin Multiplexing
- **PA9**: Alternate Function 7 (`AF7`) corresponds to `USART1_TX` [STM32G474_Datasheet p.73].
- **PA10**: Alternate Function 7 (`AF7`) corresponds to `USART1_RX` [STM32G474_Datasheet p.73].
- Both pins are configured to Alternate Function mode (`MODER = 0b10`) [STM32G474_RM0440 p.355].

#### 3. Initialization Sequence
1. Enable `GPIOA` clock on `RCC->AHB2ENR` [STM32G474_RM0440 p.306] and `USART1` clock on `RCC->APB2ENR` [STM32G474_RM0440 p.312].
2. Configure PA9 and PA10 alternate function to AF7 in `GPIOA->AFR[1]` (AFRH) and mode to AF in `GPIOA->MODER`.
3. Disable USART1 (`UE = 0`) to configure framing parameters.
4. Set 8 data bits (`M1=0, M0=0`), no parity (`PCE=0`), oversampling by 16 (`OVER8=0`) in `CR1` [STM32G474_RM0440 p.1743].
5. Set 1 stop bit (`STOP[1:0] = 00b`) in `CR2` [STM32G474_RM0440 p.1747].
6. Write the baud rate value ($1476$) into `USART1->BRR` [STM32G474_RM0440 p.1755] **before** enabling the peripheral.
7. Enable transmitter (`TE`), receiver (`RE`), and the USART module (`UE`) in `USART1->CR1`.

```c
#include "stm32g4xx.h"

void usart1_init(void)
{
    /* 1. Enable peripheral clocks for GPIOA and USART1 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PA9 (USART1_TX) and PA10 (USART1_RX) as AF7 */
    GPIOA->AFR[1] = (GPIOA->AFR[1] & ~(GPIO_AFRH_AFSEL9_Msk | GPIO_AFRH_AFSEL10_Msk))
                  | (7U << GPIO_AFRH_AFSEL9_Pos)
                  | (7U << GPIO_AFRH_AFSEL10_Pos);

    GPIOA->MODER = (GPIOA->MODER & ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk))
                 | (2U << GPIO_MODER_MODE9_Pos)
                 | (2U << GPIO_MODER_MODE10_Pos);

    /* 3. Configure framing: 8 data bits, no parity, oversampling by 16 */
    USART1->CR1 = 0; /* Clears UE, M0, M1, PCE, OVER8 */
    USART1->CR2 = 0; /* 1 stop bit (STOP[1:0] = 00b) */
    USART1->CR3 = 0;

    /* 4. Write baud rate register before enabling USART
     * PCLK2 = 170 MHz, Target = 115200 baud, OVER8 = 0
     * BRR = 170000000 / 115200 = 1476 (0x05C4) -> 115176 baud (-0.02% error)
     */
    USART1->BRR = 1476U;

    /* 5. Enable transmitter, receiver, and USART peripheral */
    USART1->CR1 |= USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
```

#### 1. Pin Conflict Notice

#### 2. Clock and Timing Calculation
- **Kernel Clock**: At reset, `RCC->CCIPR.I2C2SEL = 00b`, meaning I2C2 is clocked by **PCLK1** [STM32G474_RM0440 p.322]. With the initial clock tree running at $170\text{ MHz}$ (AHB = 1, APB1 = 1), $f_{\text{I2CCLK}} = 170\text{ MHz}$ ($t_{\text{I2CCLK}} \approx 5.882\text{ ns}$).
- **Target Mode**: Fast-mode ($400\text{ kHz}$, nominal period $t_{\text{SCL}} = 2.5\,\mu\text{s}$).
- **Timing Constraints** (from RM0440 Table 356 / Table 358) [STM32G474_RM0440 p.1633]:
  - $t_{\text{LOW}} \ge 1.3\,\mu\text{s}$
  - $t_{\text{HIGH}} \ge 0.6\,\mu\text{s}$
  - Data setup time $t_{\text{SU;DAT}} \ge 100\text{ ns}$
  - Data hold time $t_{\text{HD;DAT}} \ge 0\text{ ns}$
- **TIMINGR Prescaler & Parameters**:
  - Setting `PRESC = 16` gives a prescaled clock divider of $16 + 1 = 17$ [STM32G474_RM0440 p.1681]:
    $$t_{\text{PRESC}} = (16 + 1) \times \frac{1}{170\,\text{MHz}} = 100\text{ ns}$$
  - **SCLL** ($t_{\text{SCLL}} = (\text{SCLL} + 1) \times t_{\text{PRESC}}$):
    Choosing $\text{SCLL} = 14$ gives:
    $$t_{\text{SCLL}} = (14 + 1) \times 100\text{ ns} = 1.50\,\mu\text{s} \ge 1.3\,\mu\text{s}$$
  - **SCLH** ($t_{\text{SCLH}} = (\text{SCLH} + 1) \times t_{\text{PRESC}}$):
    Choosing $\text{SCLH} = 8$ gives:
    $$t_{\text{SCLH}} = (8 + 1) \times 100\text{ ns} = 0.90\,\mu\text{s} \ge 0.6\,\mu\text{s}$$
  - **Total Nominal Period**:
    $$t_{\text{SCLL}} + t_{\text{SCLH}} = 1.50\,\mu\text{s} + 0.90\,\mu\text{s} = 2.40\,\mu\text{s}$$
    Adding analog filter and synchronization delays ($t_{\text{SYNC1}} + t_{\text{SYNC2}} \approx 100\text{ ns}$), the resulting bus cycle is $2.50\,\mu\text{s}$ ($400\text{ kHz}$).
  - **SCLDEL and SDADEL**:
    - $\text{SCLDEL} = 4 \implies t_{\text{SCLDEL}} = (4 + 1) \times 100\text{ ns} = 500\text{ ns} \ge 100\text{ ns}$
    - $\text{SDADEL} = 2 \implies t_{\text{SDADEL}} = 2 \times 100\text{ ns} = 200\text{ ns} \ge 0\text{ ns}$

#### 3. Bare-Metal C Code

```c
#include "stm32g4xx.h"

void i2c2_init(void)
{
    /* 1. Enable peripheral clocks for GPIOA and I2C2 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_I2C2EN;

    /* 2. Configure PA8 (I2C2_SDA) and PA9 (I2C2_SCL)
     * Note: Configuring PA9 for I2C2 overrides its earlier USART1_TX allocation.
     */
    /* Set pins to open-drain */
    GPIOA->OTYPER |= GPIO_OTYPER_OT8 | GPIO_OTYPER_OT9;

    /* Enable internal pull-ups (PUPDR = 01b) */
    GPIOA->PUPDR = (GPIOA->PUPDR & ~(GPIO_PUPDR_PUPD8_Msk | GPIO_PUPDR_PUPD9_Msk))
                 | (1U << GPIO_PUPDR_PUPD8_Pos)
                 | (1U << GPIO_PUPDR_PUPD9_Pos);

    /* Alternate function AF4 for PA8 and PA9 */
    GPIOA->AFR[1] = (GPIOA->AFR[1] & ~(GPIO_AFRH_AFSEL8_Msk | GPIO_AFRH_AFSEL9_Msk))
                  | (4U << GPIO_AFRH_AFSEL8_Pos)
                  | (4U << GPIO_AFRH_AFSEL9_Pos);

    /* Alternate function mode (MODER = 10b) */
    GPIOA->MODER = (GPIOA->MODER & ~(GPIO_MODER_MODE8_Msk | GPIO_MODER_MODE9_Msk))
                 | (2U << GPIO_MODER_MODE8_Pos)
                 | (2U << GPIO_MODER_MODE9_Pos);

    /* 3. Ensure I2C2 is disabled before programming I2C_TIMINGR */
    I2C2->CR1 &= ~I2C_CR1_PE;

    /* 4. Configure TIMINGR for 400 kHz Fast Mode (f_I2CCLK = PCLK1 = 170 MHz)
     * PRESC  = 16 -> tPRESC = 100 ns
     * SCLDEL = 4  -> tSCLDEL = 500 ns (> 100 ns)
     * SDADEL = 2  -> tSDADEL = 200 ns
     * SCLH   = 8  -> tSCLH = 0.9 us (>= 0.6 us)
     * SCLL   = 14 -> tSCLL = 1.5 us (>= 1.3 us)
     */
    I2C2->TIMINGR = (16U << I2C_TIMINGR_PRESC_Pos)
                  | (4U  << I2C_TIMINGR_SCLDEL_Pos)
                  | (2U  << I2C_TIMINGR_SDADEL_Pos)
                  | (8U  << I2C_TIMINGR_SCLH_Pos)
                  | (14U << I2C_TIMINGR_SCLL_Pos);

    /* 5. Enable the I2C2 peripheral */
    I2C2->CR1 |= I2C_CR1_PE;
}
```

### STM32G474 Complete Peripheral Initialization (USART1 & I2C2)

#### 1. Pin Conflict & Resolution
- **Conflict on PA9**:
  - In Message 1, **PA9** was configured as `USART1_TX` (AF7) [STM32G474_Datasheet p.73].
  - In Message 2, **PA9** was requested for `I2C2_SCL` (AF4) [STM32G474_Datasheet p.73].
  - A single physical pin cannot drive two distinct peripheral signals simultaneously.
- **Resolution**:
  - In the STM32G474 LQFP64 package, `I2C2_SCL` is available on **PC4** with Alternate Function 4 (`AF4`) [STM32G474_Datasheet p.75].
  - To allow both USART1 and I2C2 to operate simultaneously:
    - **USART1**: `TX` on **PA9** (AF7) [STM32G474_Datasheet p.73], `RX` on **PA10** (AF7) [STM32G474_Datasheet p.73].
    - **I2C2**: `SCL` on **PC4** (AF4) [STM32G474_Datasheet p.75], `SDA` on **PA8** (AF4) [STM32G474_Datasheet p.73].

---

#### 2. Baud Rate & Timing Calculations
- **System Clocks**: Initialized at $170\text{ MHz}$ (SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz).
- **USART1 (115200 Baud, 8N1)**:
  - Kernel clock: Under reset state of `RCC_CCIPR.USART1SEL = 00b`, USART1 is clocked by **PCLK2** ($170\text{ MHz}$) [STM32G474_RM0440 p.324].
  - Oversampling: 16 (`OVER8 = 0`).
  - Baud calculation:
    $$\text{USARTDIV} = \frac{170\,000\,000}{115\,200} \approx 1475.694 \implies \text{BRR} = 1476 \text{ (0x05C4)}$$ [STM32G474_RM0440 p.1755].
  - Achieved baud rate: $115\,176.15\text{ Baud}$ (error: $-0.02\%$, within $\pm 2\%$).
- **I2C2 (Fast Mode, 400 kHz)**:
  - Kernel clock: Under reset state of `RCC_CCIPR.I2C2SEL = 00b`, I2C2 is clocked by **PCLK1** ($170\text{ MHz}$) [STM32G474_RM0440 p.323].
  - Timing constraints for Fast Mode from RM0440 Table 356 [STM32G474_RM0440 p.1633]:
    - $t_{\text{LOW}} \ge 1.3\,\mu\text{s}$
    - $t_{\text{HIGH}} \ge 0.6\,\mu\text{s}$
  - `TIMINGR` configuration:
    - $\text{PRESC} = 3 \implies t_{\text{PRESC}} = (3 + 1) \times t_{\text{I2CCLK}} = 4 \times 5.882\text{ ns} \approx 23.53\text{ ns}$ [STM32G474_RM0440 p.1681].
    - $\text{SCLL} = 54 \implies t_{\text{SCLL}} = (54 + 1) \times 23.53\text{ ns} \approx 1.294\,\mu\text{s} \implies t_{\text{LOW}} \approx 1.306\,\mu\text{s} \ge 1.3\,\mu\text{s}$.
    - $\text{SCLH} = 24 \implies t_{\text{SCLH}} = (24 + 1) \times 23.53\text{ ns} \approx 0.588\,\mu\text{s} \implies t_{\text{HIGH}} \approx 0.600\,\mu\text{s} \ge 0.6\,\mu\text{s}$.
    - $\text{SCLDEL} = 4 \implies t_{\text{SCLDEL}} = (4 + 1) \times 23.53\text{ ns} \approx 117.65\text{ ns} \ge 100\text{ ns}$.
    - $\text{SDADEL} = 8 \implies t_{\text{SDADEL}} = 8 \times 23.53\text{ ns} \approx 188.24\text{ ns} \ge 0\text{ ns}$.

#### 3. Complete Initialization Program

```c
#include "stm32g4xx.h"

int main(void)
{
    /* 1. Enable peripheral clocks for GPIOA, GPIOC, USART1, and I2C2 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN | RCC_AHB2ENR_GPIOCEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_I2C2EN;

    /* 2. Configure USART1 pins: PA9 (TX, AF7) and PA10 (RX, AF7) */
    GPIOA->AFR[1] = (GPIOA->AFR[1] & ~(GPIO_AFRH_AFSEL9_Msk | GPIO_AFRH_AFSEL10_Msk))
                  | (7U << GPIO_AFRH_AFSEL9_Pos)
                  | (7U << GPIO_AFRH_AFSEL10_Pos);

    GPIOA->MODER = (GPIOA->MODER & ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk))
                 | (2U << GPIO_MODER_MODE9_Pos)
                 | (2U << GPIO_MODER_MODE10_Pos);

    /* 3. Configure USART1: 115200 baud, 8 data bits, no parity, 1 stop bit */
    USART1->CR1 = 0; /* Clear UE, M0, M1, PCE, OVER8 (oversampling by 16) */
    USART1->CR2 = 0; /* 1 stop bit */
    USART1->CR3 = 0;

    /* Program BRR before enabling USART1: 170 MHz / 115200 = 1476 */
    USART1->BRR = 1476U;

    /* Enable transmitter, receiver, and USART peripheral */
    USART1->CR1 |= USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;

    /* 4. Configure I2C2 pins: PC4 (SCL, AF4) and PA8 (SDA, AF4)
     * Configured as open-drain output with pull-up enabled
     */
    /* PA8 -> SDA */
    GPIOA->OTYPER |= GPIO_OTYPER_OT8;
    GPIOA->PUPDR = (GPIOA->PUPDR & ~GPIO_PUPDR_PUPD8_Msk) | (1U << GPIO_PUPDR_PUPD8_Pos);
    GPIOA->AFR[1] = (GPIOA->AFR[1] & ~GPIO_AFRH_AFSEL8_Msk) | (4U << GPIO_AFRH_AFSEL8_Pos);
    GPIOA->MODER = (GPIOA->MODER & ~GPIO_MODER_MODE8_Msk) | (2U << GPIO_MODER_MODE8_Pos);

    /* PC4 -> SCL */
    GPIOC->OTYPER |= GPIO_OTYPER_OT4;
    GPIOC->PUPDR = (GPIOC->PUPDR & ~GPIO_PUPDR_PUPD4_Msk) | (1U << GPIO_PUPDR_PUPD4_Pos);
    GPIOC->AFR[0] = (GPIOC->AFR[0] & ~GPIO_AFRL_AFSEL4_Msk) | (4U << GPIO_AFRL_AFSEL4_Pos);
    GPIOC->MODER = (GPIOC->MODER & ~GPIO_MODER_MODE4_Msk) | (2U << GPIO_MODER_MODE4_Pos);

    /* 5. Configure I2C2 peripheral: Fast Mode (400 kHz)
     * The peripheral must be disabled (PE = 0) before writing TIMINGR
     */
    I2C2->CR1 &= ~I2C_CR1_PE;

    /* Program TIMINGR: PRESC=3, SCLDEL=4, SDADEL=8, SCLH=24, SCLL=54
     * Satisfies RM0440 Table 356 minimums: tLOW >= 1.3 us and tHIGH >= 0.6 us
     */
    I2C2->TIMINGR = (3U  << I2C_TIMINGR_PRESC_Pos)
                  | (4U  << I2C_TIMINGR_SCLDEL_Pos)
                  | (8U  << I2C_TIMINGR_SDADEL_Pos)
                  | (24U << I2C_TIMINGR_SCLH_Pos)
                  | (54U << I2C_TIMINGR_SCLL_Pos);

    /* Enable I2C2 peripheral */
    I2C2->CR1 |= I2C_CR1_PE;

    /* 6. Infinite loop */
    while (1)
    {
    }
}
```
