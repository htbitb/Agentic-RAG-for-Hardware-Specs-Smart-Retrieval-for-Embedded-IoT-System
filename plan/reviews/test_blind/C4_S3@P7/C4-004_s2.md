### PWM Configuration on PA0 (TIM2 Channel 1)

#### 1. Clock and Register Derivations
- **Timer Kernel Clock**: Since APB1 prescaler = 1, TIM2 kernel clock equals PCLK1 = 170 MHz.
- **Timer Resolution & Counter**: TIM2 is a 32-bit general-purpose timer.
- **Frequency Target**: 1 kHz (Period $T = 1\text{ ms}$).
  $$\text{PWM Frequency} = \frac{f_{\text{TIMCLK}}}{(\text{PSC} + 1) \times (\text{ARR} + 1)}$$
  Setting $\text{PSC} = 0$:
  $$\text{ARR} + 1 = \frac{170\,000\,000}{1\,000} = 170\,000 \implies \text{ARR} = 169\,999$$
  This yields an exact frequency of $1\,000\text{ Hz}$ ($0\text{ \%}$ error).
- **Duty Cycle Target**: 50 % in edge-aligned PWM Mode 1 (upcounting, output active when $\text{TIM2\_CNT} < \text{TIM2\_CCR1}$):
  $$\text{CCR1} = 50\% \times (\text{ARR} + 1) = 0.50 \times 170\,000 = 85\,000$$
  This yields an exact duty cycle of $50.0\text{ \%}$ ($0\text{ \%}$ error).
- **Pin Mapping & Registers**:
  - `PA0` alternate function 1 (AF1) maps to `TIM2_CH1` [STM32G474_Datasheet p.73].
  - GPIOA mode register `GPIOA_MODER` [STM32G474_RM0440 p.355] and alternate function register `GPIOA_AFRL` [STM32G474_RM0440 p.359].
  - Peripheral clocks enabled in `RCC_AHB2ENR` [STM32G474_RM0440 p.306] and `RCC_APB1ENR1` [STM32G474_RM0440 p.309].
  - Channel 1 PWM mode 1 configured via `TIM2_CCMR1` [STM32G474_RM0440 p.1379] and output enabled via `TIM2_CCER` [STM32G474_RM0440 p.1385].
  - Counter enabled and ARPE set via `TIM2_CR1` [STM32G474_RM0440 p.1366].

#### 2. Bare-metal C Implementation

```c
#include "stm32g4xx.h"

void tim2_pwm_init(void)
{
    /* 1. Enable peripheral clocks for GPIOA (AHB2) and TIM2 (APB1) */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN;

    /* 2. Configure PA0 to Alternate Function mode (MODER[1:0] = 10b) */
    GPIOA->MODER &= ~GPIO_MODER_MODE0_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE0_Pos);

    /* 3. Select AF1 (TIM2_CH1) for PA0 in AFRL (AFSEL0 = 0001b) */
    GPIOA->AFR[0] &= ~GPIO_AFRL_AFSEL0_Msk;
    GPIOA->AFR[0] |= (1U << GPIO_AFRL_AFSEL0_Pos);

    /* 4. Configure TIM2 timebase: 170 MHz / (0 + 1) / (169999 + 1) = 1 kHz */
    TIM2->PSC = 0;
    TIM2->ARR = 169999;

    /* 5. Set duty cycle to 50%: 85000 / 170000 */
    TIM2->CCR1 = 85000;

    /* 6. Configure Channel 1:
     *    - CC1S = 00 (Channel configured as output)
     *    - OC1M = 0110 (PWM mode 1)
     *    - OC1PE = 1 (Preload enable)
     */
    TIM2->CCMR1 &= ~TIM_CCMR1_OC1M_Msk;
    TIM2->CCMR1 |= (6U << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE;

    /* 7. Output polarity active high (CC1P = 0) and enable output (CC1E = 1) */
    TIM2->CCER &= ~TIM_CCER_CC1P;
    TIM2->CCER |= TIM_CCER_CC1E;

    /* 8. Enable auto-reload preload (ARPE) and enable counter (CEN) */
    TIM2->CR1 |= TIM_CR1_ARPE | TIM_CR1_CEN;

    /* 9. Generate an update event to transfer preloaded ARR and CCR1 values */
    TIM2->EGR |= TIM_EGR_UG;
}
```

### Hardware Conflict Analysis and Resolution

#### 1. Hardware Conflict on TIM2 Channels
The STM32 general-purpose timer architecture (TIM2/TIM3/TIM4/TIM5) uses a **single timebase counter** per timer instance [STM32G474_RM0440 p.1294, p.1318]:
- The PWM period and frequency are determined by the combination of the timer clock, the prescaler register (`PSC`), and the auto-reload register (`ARR`):
  $$f_{\text{PWM}} = \frac{f_{\text{TIMCLK}}}{(\text{PSC} + 1) \times (\text{ARR} + 1)}$$
- All capture/compare channels of `TIM2` share the exact same `PSC` and `ARR`.
- Therefore, `TIM2_CH1` (configured for $1\,000\text{ Hz}$ on `PA0`) and `TIM2_CH2` (requested for $50\text{ Hz}$ on `PA1`) **cannot run at different PWM frequencies simultaneously**. Attempting to configure `TIM2` for $50\text{ Hz}$ would alter the frequency of `PA0`.

#### 2. Selected Alternative: TIM5_CH2 on PA1 (AF2)
Pin `PA1` also multiplexes the channel output of an independent timer without changing board wiring:
- Looking up `PA1` alternate functions in the STM32G474 pin mapping table [STM32G474_Datasheet Table 13, p.73]:
  - `AF1`: `TIM2_CH2` (shares counter with TIM2_CH1 on PA0 — conflict)
  - `AF2`: `TIM5_CH2` (independent 32-bit general-purpose timer)
  - `AF9`: `TIM15_CH1N`
- By routing `PA1` to **`TIM5_CH2` (AF2)**, `TIM2` continues generating the $1\,000\text{ Hz}$, $50.0\text{ \%}$ PWM signal on `PA0`, while `TIM5` independently generates the $50\text{ Hz}$ servo signal on `PA1`.

#### 3. Parameter Derivations
- **TIM2 (PA0 - LED Driver)**:
  - Input Clock: $170\text{ MHz}$
  - Target Frequency: $1\,000\text{ Hz}$
  - Configuration: $\text{PSC} = 0$, $\text{ARR} = 169\,999 \implies f = 1\,000.0\text{ Hz}$ ($0\text{ \%}$ error).
  - Target Duty: $50.0\text{ \%} \implies \text{CCR1} = 85\,000$ ($0\text{ \%}$ error).
- **TIM5 (PA1 - Servo Control)**:
  - Input Clock: $170\text{ MHz}$ (APB1 prescaler = 1)
  - Target Frequency: $50\text{ Hz}$ (Period $T = 20\text{ ms}$)
    $$\text{ARR} + 1 = \frac{170\,000\,000\text{ Hz}}{50\text{ Hz}} = 3\,400\,000 \implies \text{ARR} = 3\,399\,999$$
    With $\text{PSC} = 0$, $\text{ARR} = 3\,399\,999$ (TIM5 is 32-bit), frequency is exactly $50.0\text{ Hz}$ ($0\text{ \%}$ error).
  - Target High Pulse: $1.5\text{ ms}$ (centre position)
    $$\text{Duty Cycle} = \frac{1.5\text{ ms}}{20\text{ ms}} = 7.5\text{ \%}$$
    $$\text{CCR2} = 7.5\text{ \%} \times (\text{ARR} + 1) = 0.075 \times 3\,400\,000 = 255\,000$$
    This yields an exact high pulse of $1.50\text{ ms}$ ($7.5\text{ \%}$ duty cycle, $0\text{ \%}$ error).

### Technical Explanation

1. **Peripheral Clock Enabling (`RCC`)**:
   - `GPIOA` is gated via AHB2 (`RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN`) [STM32G474_RM0440 p.306].
   - `TIM2` and `TIM5` are general-purpose 32-bit timers on APB1, enabled in `RCC->APB1ENR1` with bits `TIM2EN` and `TIM5EN` [STM32G474_RM0440 p.309].

2. **GPIO Alternate Function Routing**:
   - `PA0` is configured in alternate function mode (`MODER[1:0] = 10b`) [STM32G474_RM0440 p.355] and routed to AF1 (`TIM2_CH1`) via `AFR[0]` (`AFSEL0 = 0001b`) [STM32G474_Datasheet p.73] [STM32G474_RM0440 p.359].
   - `PA1` is configured in alternate function mode (`MODER[3:2] = 10b`) [STM32G474_RM0440 p.355] and routed to AF2 (`TIM5_CH2`) via `AFR[0]` (`AFSEL1 = 0010b`) [STM32G474_Datasheet p.73] [STM32G474_RM0440 p.359].
   - **Reason for selecting AF2 on PA1**: All channels belonging to a single timer instance share the identical counter, prescaler (`PSC`), and auto-reload register (`ARR`) [STM32G474_RM0440 p.1294] [STM32G474_RM0440 p.1388]. Therefore, `TIM2_CH1` (1 kHz) and `TIM2_CH2` (50 Hz) cannot run at different PWM frequencies simultaneously. Multiplexing `PA1` to `TIM5_CH2` (AF2) provides an independent 32-bit general-purpose timer timebase for the 50 Hz servo control signal on the exact requested pin without disrupting the 1 kHz PWM signal generated by `TIM2` on `PA0`.

3. **Timebase and Duty Cycle Derivations**:
   - With APB1 prescaler = 1, the timer kernel clock equals $f_{\text{TIMCLK}} = 170\text{ MHz}$.
   - **PA0 / TIM2 (LED Driver)**:
     $$f_{\text{PWM}} = \frac{170\,000\,000}{(0 + 1) \times (169\,999 + 1)} = 1\,000.0\text{ Hz}\quad (0\%\text{ error})$$
     $$\text{Duty Cycle} = \frac{85\,000}{170\,000} \times 100\% = 50.0\%\quad (0\%\text{ error})$$
   - **PA1 / TIM5 (Servo Control)**:
     $$f_{\text{PWM}} = \frac{170\,000\,000}{(0 + 1) \times (3\,399\,999 + 1)} = 50.0\text{ Hz}\quad (0\%\text{ error})$$
     $$\text{High Pulse} = \frac{255\,000}{3\,400\,000} \times 20\text{ ms} = 1.50\text{ ms}\quad (\text{Duty} = 7.5\%,\ 0\%\text{ error})$$

4. **PWM Mode 1 Operation**:
   - Output compare mode `OCxM = 0110b` in `CCMR1` selects edge-aligned PWM Mode 1 (active while $\text{CNT} < \text{CCRx}$, inactive otherwise) [STM32G474_RM0440 p.1379] [STM32G474_RM0440 p.1319].
   - Active-high polarity is set with `CCxP = 0`, and channel outputs are enabled with `CCxE = 1` in `CCER` [STM32G474_RM0440 p.1385].
   - Writing `TIM_EGR_UG` generates an update event, transferring preloaded `ARR` and `CCR` values into active shadow registers before counter operation.
