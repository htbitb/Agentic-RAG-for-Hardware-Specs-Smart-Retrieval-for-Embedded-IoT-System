### Assistant answer 0

### 1. Overview and Calculations

To generate a 1 kHz PWM waveform with a 50 % duty cycle on **PA0** using **TIM2 Channel 1**:

- **Clocks**: The APB1 prescaler is 1, so the timer clock feeding TIM2 is $f_{\text{TIM2CLK}} = 170\text{ MHz}$.
- **Timer Resolution & Reload**: TIM2 is a 32-bit general-purpose timer.
  - Setting prescaler $\text{PSC} = 0$ gives a timer counter frequency of:
    $$f_{\text{CNT}} = \frac{170\text{ MHz}}{0 + 1} = 170\text{ MHz}$$
  - For a target frequency $f_{\text{PWM}} = 1000\text{ Hz}$:
    $$\text{ARR} = \frac{f_{\text{CNT}}}{f_{\text{PWM}}} - 1 = \frac{170{,}000{,}000}{1000} - 1 = 169{,}999$$
  - For a $50\,\%$ duty cycle in PWM Mode 1 (active while $\text{CNT} < \text{CCR1}$):
    $$\text{CCR1} = \frac{\text{ARR} + 1}{2} = \frac{170{,}000}{2} = 85{,}000$$
  - Frequency error: $0.0\,\%$ (exact $1000\text{ Hz}$), duty cycle error: $0.0\,\%$ (exact $50.0\,\%$).

- **GPIO Configuration**:
  - Enable Port A clock in `RCC->AHB2ENR` bit `GPIOAEN` [STM32G474_RM0440 p.306].
  - Set PA0 mode to Alternate Function (`MODER0[1:0] = 0b10`) [STM32G474_RM0440 p.355].
  - Set PA0 alternate function to AF1 (`TIM2_CH1`) [STM32G474_Datasheet p.73].

- **Timer Configuration**:
  - Enable TIM2 clock in `RCC->APB1ENR1` bit `TIM2EN` [STM32G474_RM0440 p.309].
  - Set $\text{PSC} = 0$, $\text{ARR} = 169999$, $\text{CCR1} = 85000$.
  - Configure PWM Mode 1 on Channel 1 by setting `OC1M[3:0] = 0b0110` in `TIM2->CCMR1` [STM32G474_RM0440 p.1379].
  - Enable output compare preload via `OC1PE` bit in `TIM2->CCMR1` [STM32G474_RM0440 p.1379].
  - Configure active-high polarity (`CC1P = 0`) and enable channel 1 output (`CC1E = 1`) in `TIM2->CCER` [STM32G474_RM0440 p.1385].
  - Generate an update event via `UG` bit in `TIM2->EGR` to transfer preloaded values into the active registers [STM32G474_RM0440 p.1376].
  - Enable counter via `CEN` bit in `TIM2->CR1` [STM32G474_RM0440 p.1366].

### 2. Bare-Metal C Code

```c
#include "stm32g4xx.h"

void tim2_pwm_init(void) {
    /* 1. Enable peripheral clocks for GPIOA and TIM2 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN;

    /* 2. Configure PA0 as Alternate Function AF1 (TIM2_CH1) */
    GPIOA->MODER &= ~GPIO_MODER_MODE0_Msk;
    GPIOA->MODER |= GPIO_MODER_MODE0_1;                  /* Mode 10: Alternate Function */

    GPIOA->AFR[0] &= ~GPIO_AFRL_AFSEL0_Msk;
    GPIOA->AFR[0] |= (1U << GPIO_AFRL_AFSEL0_Pos);       /* AF1 selected */

    /* 3. Configure TIM2 timebase: 170 MHz / (169999 + 1) = 1 kHz */
    TIM2->PSC = 0;
    TIM2->ARR = 169999;
    TIM2->CCR1 = 85000;                                  /* 50% duty cycle */

    /* 4. Configure Channel 1 for PWM Mode 1 with preload enabled */
    TIM2->CCMR1 &= ~TIM_CCMR1_OC1M_Msk;
    TIM2->CCMR1 |= (TIM_CCMR1_OC1M_1 | TIM_CCMR1_OC1M_2); /* OC1M = 0110: PWM mode 1 */
    TIM2->CCMR1 |= TIM_CCMR1_OC1PE;                       /* Output compare 1 preload enable */

    /* 5. Set output polarity to active-high and enable Channel 1 output */
    TIM2->CCER &= ~TIM_CCER_CC1P;                        /* Active high */
    TIM2->CCER |= TIM_CCER_CC1E;                         /* Channel 1 output enable */

    /* 6. Generate an update event to load prescaler and ARR immediately */
    TIM2->EGR = TIM_EGR_UG;

    /* 7. Start the timer counter */
    TIM2->CR1 |= TIM_CR1_CEN;
}
```

### Assistant answer 1

### 1. Hardware Limitation & Conflict Explanation

In STM32 microcontrollers (such as STM32G474), timer channels belonging to the same timer instance share the exact same counter, clock prescaler, and auto-reload register:
- `TIMx->PSC` controls the counter step rate [STM32G474_RM0440 p.1387].
- `TIMx->ARR` defines the counter period and reload frequency [STM32G474_RM0440 p.1387].

Because **TIM2 Channel 1** on **PA0** is already generating a $1\text{ kHz}$ PWM signal ($\text{PSC} = 0$, $\text{ARR} = 169999$), any other channel of **TIM2** (including Channel 2) will also cycle at $1\text{ kHz}$. It is physically impossible for TIM2 Channel 2 to produce a $50\text{ Hz}$ waveform while Channel 1 produces a $1\text{ kHz}$ waveform.

---

### 2. Resolution: TIM5 Channel 2 (AF2) on Pin PA1

According to the alternate function mapping table [STM32G474_Datasheet p.73], pin **PA1** supports:
- **AF1**: `TIM2_CH2` (shares counter with TIM2_CH1)
- **AF2**: `TIM5_CH2` (independent 32-bit general-purpose timer on APB1)
- **AF9**: `TIM15_CH1N` (16-bit complementary output)

By selecting **AF2** (`TIM5_CH2`) on **PA1**, we use the dedicated 32-bit timer **TIM5**. This allows PA1 to produce the exact $50\text{ Hz}$ servo control signal with zero frequency error and sub-microsecond pulse-width precision, while **TIM2 Channel 1** continues to output the $1\text{ kHz}$ signal on **PA0** undisturbed.

#### Calculations for TIM5 (PA1, 50 Hz PWM, 1.5 ms High Pulse):
- Timer input clock: $f_{\text{TIM5CLK}} = 170\text{ MHz}$ (APB1 prescaler = 1).
- Target frequency: $50\text{ Hz}$ (period $T = 20\text{ ms}$).
  - With $\text{PSC} = 0$:
    $$\text{ARR} = \frac{170{,}000{,}000}{50} - 1 = 3{,}399{,}999$$
- High pulse: $1.5\text{ ms}$ (centre position):
  $$\text{Duty Cycle} = \frac{1.5\text{ ms}}{20\text{ ms}} = 7.5\,\%$$
  $$\text{CCR2} = 1.5\text{ ms} \times 170\text{ MHz} = 255{,}000$$

### Explanation of Configuration & Register Operations

1. **Clock Enabling (`RCC`)**:
   - `RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN` enables the clock for GPIO Port A [STM32G474_RM0440 p.306].
   - `RCC->APB1ENR1 |= (RCC_APB1ENR1_TIM2EN | RCC_APB1ENR1_TIM5EN)` enables the APB1 peripheral bus clocks for both TIM2 and TIM5 [STM32G474_RM0440 p.309].

2. **GPIO Alternate Functions (`GPIOA`)**:
   - **PA0**: Configured as Alternate Function mode (`MODER0 = 0b10`) [STM32G474_RM0440 p.355] and mapped to **AF1** (`TIM2_CH1`) in `AFR[0]` (AFRL) [STM32G474_Datasheet p.73].
   - **PA1**: Configured as Alternate Function mode (`MODER1 = 0b10`) [STM32G474_RM0440 p.355] and mapped to **AF2** (`TIM5_CH2`) in `AFR[0]` (AFRL) [STM32G474_Datasheet p.73]. Using TIM5 on PA1 resolves the hardware constraint where all channels of TIM2 must share the same prescaler and auto-reload registers.

3. **TIM2 (1 kHz PWM on PA0)**:
   - With $f_{\text{TIM2CLK}} = 170\text{ MHz}$ and $\text{PSC} = 0$, the counter operates at $170\text{ MHz}$ [STM32G474_RM0440 p.1387].
   - Auto-reload register $\text{ARR} = 169999$ produces an exact frequency of:
     $$f = \frac{170\text{ MHz}}{169999 + 1} = 1000\text{ Hz}$$
   - Compare register $\text{CCR1} = 85000$ yields an exact $50.0\,\%$ duty cycle.
   - Configured in edge-aligned PWM Mode 1 (`OC1M = 0110`), active-high (`CC1P = 0`), with channel output enabled (`CC1E = 1`) [STM32G474_RM0440 p.1379, p.1385].

4. **TIM5 (50 Hz Servo PWM on PA1)**:
   - TIM5 is an independent 32-bit counter timer on APB1 clocked at $170\text{ MHz}$. With $\text{PSC} = 0$, the counter ticks at $170\text{ MHz}$ [STM32G474_RM0440 p.1387].
   - Auto-reload register $\text{ARR} = 3399999$ produces an exact frequency of:
     $$f = \frac{170\text{ MHz}}{3399999 + 1} = 50\text{ Hz}\quad (T = 20\text{ ms})$$
   - Compare register $\text{CCR2} = 255000$ provides an exact high pulse duration of:
     $$t_{\text{high}} = \frac{255000}{170\text{ MHz}} = 1.5\text{ ms}\quad (7.5\,\%\text{ duty cycle})$$
   - Configured in edge-aligned PWM Mode 1 on Channel 2 (`OC2M = 0110`), active-high (`CC2P = 0`), with channel output enabled (`CC2E = 1`) [STM32G474_RM0440 p.1379, p.1385].

5. **Update Event & Counter Activation**:
   - Setting the `UG` bit in `TIMx->EGR` generates an update event to initialize the prescaler and transfer shadow register values (`PSC`, `ARR`, `CCRx`) immediately before starting the counter [STM32G474_RM0440 p.1376].
   - Setting the `CEN` bit in `TIMx->CR1` starts both timer counters running concurrently [STM32G474_RM0440 p.1366].
