### Clock Tree Configuration to 168 MHz (STM32G474)

#### Hardware Limit Conflict and Resolution
According to the **STM32G474 Datasheet Table 46 (p. 123)**:
- The PLL input clock frequency $f_{\text{PLL\_IN}}$ must be in the range **2.66 MHz to 16 MHz**.
- A direct prescaler of $\text{PLLM} = 1$ with an external HSE frequency of $24\text{ MHz}$ results in $f_{\text{PLL\_IN}} = 24\text{ MHz}$, which exceeds the absolute maximum specified PLL input frequency ($16\text{ MHz}$) and triggers `CLOCK_LIMIT:PLL_IN`.
- To comply with the hardware electrical limits while achieving the requested **SYSCLK = 168 MHz**, the division and multiplication factors are scaled:
  - $\text{PLLM} = 2 \implies f_{\text{PLL\_IN}} = \frac{24\text{ MHz}}{2} = 12\text{ MHz}$ (valid, within $[2.66, 16]\text{ MHz}$)
  - $\text{PLLN} = 28 \implies f_{\text{VCO}} = 12\text{ MHz} \times 28 = 336\text{ MHz}$ (valid, Range 1 VCO range is $96 - 344\text{ MHz}$) [STM32G474_Datasheet p.123]
  - $\text{PLLR} = 2 \implies f_{\text{PLL\_R}} = \frac{336\text{ MHz}}{2} = 168\text{ MHz}$ [STM32G474_Datasheet p.123]

#### Voltage Range and Flash Wait States
- **Range 1 Boost Mode**: According to **RM0440 p. 232–233, 267**, operation above $150\text{ MHz}$ (up to $170\text{ MHz}$) requires clearing the `R1MODE` bit (bit 8) in `PWR_CR5` to enter Range 1 Boost Mode.
- **Flash Latency**: In Range 1 Boost Mode, for $136 < \text{HCLK} \le 170\text{ MHz}$, the Flash latency must be set to **4 wait states** (`LATENCY = 4WS`) [STM32G474_RM0440 p. 98].
- **Frequency Switching Sequence**: According to **RM0440 p. 233, 279–280**, when increasing the system frequency beyond $150\text{ MHz}$, the AHB prescaler should be divided by 2 before switching `SYSCLK` to the PLL, then restored to 1 after switching.

### Implementation (CMSIS Bare-Metal C)

```c
#include "stm32g4xx.h"

void clock_init_168mhz(void)
{
    /* 1. Enable PWR peripheral clock and configure Range 1 Boost Mode for > 150 MHz */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;
    (void)RCC->APB1ENR1; /* Read back to ensure clock enable takes effect */

    /* Clear R1MODE to enable Range 1 Boost Mode (allows SYSCLK up to 170 MHz) */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 2. Configure Flash Latency to 4 wait states (for 168 MHz in Range 1 Boost Mode) */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY) != FLASH_ACR_LATENCY_4WS);

    /* 3. Enable HSE oscillator (24 MHz) and wait until ready */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY));

    /* 4. Configure PLL:
     * HSE = 24 MHz
     * PLLM = 2 (register field value = 1) -> f_PLL_IN = 24 MHz / 2 = 12 MHz (valid: 2.66 - 16 MHz)
     * PLLN = 28 (register field value = 28) -> f_VCO = 12 MHz * 28 = 336 MHz (valid: 96 - 344 MHz)
     * PLLR = 2 (register field value = 0) -> f_PLL_R = 336 MHz / 2 = 168 MHz
     * PLLSRC = HSE (0b11)
     * Enable main PLL output clock (PLLREN)
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1U << RCC_PLLCFGR_PLLM_Pos) |
                   (28U << RCC_PLLCFGR_PLLN_Pos) |
                   RCC_PLLCFGR_PLLREN;

    /* 5. Enable Main PLL and wait for PLLRDY */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY));

    /* 6. Switch system clock to PLL:
     * Set AHB prescaler to /2 before clock switch (recommended when switching > 150 MHz)
     */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    /* Switch SYSCLK source to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL);

    /* Short delay (>= 1 us) before restoring AHB prescaler */
    for (volatile int i = 0; i < 100; i++);

    /* Restore AHB prescaler to /1:
     * Resulting frequencies: SYSCLK = HCLK = PCLK1 = PCLK2 = 168 MHz
     */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;
}
```

### USART1 Configuration on PA9/PA10 at 115200 Baud

#### 1. Clock Source and Baud Rate Calculation
- **USART1 Kernel Clock**: With `RCC->CCIPR` kept at its reset default (`USART1SEL = 00b`), USART1 is clocked by **PCLK2** [STM32G474_RM0440 p. 324].
- Under the 168 MHz system clock configuration established previously (with APB2 prescaler = 1), **PCLK2 = 168 MHz**.
- **Oversampling by 16** (`OVER8 = 0` in `USART_CR1`):
  According to **RM0440 p. 1707–1708**, the baud rate equation is:
  $$\text{Baud} = \frac{f_{\text{CK}}}{\text{USARTDIV}}$$
  $$\text{USARTDIV} = \frac{168\,000\,000}{115\,200} \approx 1458.3333$$
  Rounding to the nearest integer gives $\text{BRR} = 1458$ (`0x05B2`).
- **Achieved Baud Rate & Error**:
  $$\text{Baud}_{\text{actual}} = \frac{168\,000\,000}{1458} \approx 115226.34\text{ baud}$$
  $$\text{Error} = \frac{115226.34 - 115200}{115200} \times 100\% = +0.023\%$$
  This easily satisfies the requested $\pm 2\%$ tolerance requirement.

#### 2. GPIO Alternate Function Mapping
- **PA9 (USART1_TX)**: Alternate Function **AF7** [STM32G474_Datasheet p. 73].
- **PA10 (USART1_RX)**: Alternate Function **AF7** [STM32G474_Datasheet p. 73].
- Both pins are configured in Alternate Function Mode (`MODER = 0b10`) with `AFRH9 = 7` and `AFRH10 = 7` [STM32G474_RM0440 p. 355, 360].

#### 3. Framing and Sequence
- **Word Length**: 8 data bits (`M[1:0] = 00b` in `USART_CR1`, default) [STM32G474_RM0440 p. 1740].
- **Parity**: Disabled (`PCE = 0` in `USART_CR1`, default) [STM32G474_RM0440 p. 1740].
- **Stop Bits**: 1 stop bit (`STOP[1:0] = 00b` in `USART_CR2`, default) [STM32G474_RM0440 p. 1747].
- **Enabling Sequence**: Per datasheet/RM requirements, `BRR` is written before setting `UE`, and `TE`, `RE`, and `UE` are enabled.

### Bare-Metal C Code

```c
#include "stm32g4xx.h"

void usart1_init(void)
{
    /* 1. Enable peripheral clocks for GPIOA and USART1 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    (void)RCC->AHB2ENR; /* Read-back delay for bus synchronization */

    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;
    (void)RCC->APB2ENR;

    /* 2. Configure PA9 (TX) and PA10 (RX) as Alternate Function AF7 (USART1) */
    /* Set MODER: 0b10 (Alternate Function) on PA9 and PA10 */
    GPIOA->MODER &= ~((3U << GPIO_MODER_MODE9_Pos) | (3U << GPIO_MODER_MODE10_Pos));
    GPIOA->MODER |= (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

    /* Set AF7 in AFRH (AFR[1]) for pins 9 and 10 */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= (7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos);

    /* 3. Configure Baud Rate:
     * USART1 kernel clock is PCLK2 = 168 MHz (RCC_CCIPR USART1SEL reset default = 00b).
     * With OVER8 = 0 (oversampling by 16):
     * USARTDIV = 168,000,000 / 115,200 = 1458.333 -> BRR = 1458 (0x05B2).
     * Actual baud rate = 115,226.34 baud (+0.023% error).
     * Note: BRR is written before USART enable (UE).
     */
    USART1->BRR = 1458U;

    /* 4. Configure Stop Bits:
     * 1 stop bit: STOP[1:0] = 00b in CR2
     */
    USART1->CR2 &= ~USART_CR2_STOP;

    /* 5. Configure Word length, parity, oversampling, and enable Transmitter, Receiver, USART:
     * 8 data bits: M[1:0] = 00b
     * No parity: PCE = 0
     * Oversampling by 16: OVER8 = 0
     * TE = 1, RE = 1, UE = 1
     */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
```

### Complete Initialization Program (Clock Tree & USART1)

int main(void)
{
    /* 1. Enable PWR clock and switch to Range 1 Boost Mode (> 150 MHz) */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;
    (void)RCC->APB1ENR1; /* Read back to ensure peripheral clock is active */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 2. Configure Flash Latency to 4 wait states (for 168 MHz in Boost Mode) */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY) != FLASH_ACR_LATENCY_4WS);

    /* 3. Enable HSE oscillator (24 MHz external crystal) and wait until ready */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY));

    /* 4. Configure PLL:
     * HSE = 24 MHz
     * PLLM = 2 (register field value = 1) -> f_PLL_IN = 24 / 2 = 12 MHz (valid: 2.66 - 16 MHz)
     * PLLN = 28 (register field value = 28) -> f_VCO = 12 * 28 = 336 MHz (valid: 96 - 344 MHz)
     * PLLR = 2 (register field value = 0) -> f_PLL_R = 336 / 2 = 168 MHz
     * Source = HSE, enable PLLR output (PLLREN)
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1U << RCC_PLLCFGR_PLLM_Pos) |
                   (28U << RCC_PLLCFGR_PLLN_Pos) |
                   RCC_PLLCFGR_PLLREN;

    /* 5. Enable Main PLL and wait until locked */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY));

    /* 6. Switch system clock to PLL:
     * Divide AHB prescaler by 2 before switching (> 150 MHz recommended sequence)
     */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    /* Switch SYSCLK source to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL);

    /* Short delay (>= 1 us) before restoring AHB prescaler */
    for (volatile int i = 0; i < 100; i++);

    /* Restore AHB prescaler to /1: SYSCLK = HCLK = PCLK1 = PCLK2 = 168 MHz */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;

    /* 7. Enable GPIOA and USART1 peripheral clocks */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    (void)RCC->AHB2ENR;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;
    (void)RCC->APB2ENR;

    /* 8. Configure PA9 (TX) and PA10 (RX) as Alternate Function AF7 (USART1) */
    GPIOA->MODER &= ~((3U << GPIO_MODER_MODE9_Pos) | (3U << GPIO_MODER_MODE10_Pos));
    GPIOA->MODER |= (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= (7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos);

    /* 9. Configure USART1:
     * Kernel clock is PCLK2 = 168 MHz.
     * With OVER8 = 0 (oversampling by 16):
     * USARTDIV = 168,000,000 / 115,200 = 1458.333 -> BRR = 1458 (0x05B2).
     * Baud rate = 115,226.34 baud (+0.023% error).
     * Written before UE.
     */
    USART1->BRR = 1458U;

    /* 1 stop bit (STOP[1:0] = 00b) */
    USART1->CR2 &= ~USART_CR2_STOP;

    /* 8 data bits, no parity, OVER8 = 0, TE = 1, RE = 1, UE = 1 */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;

    /* Infinite loop */
    while (1)
    {
    }
}

### Explanation of the Initialization Sequence

1. **Power and Range 1 Boost Mode**:
   - Clearing `R1MODE` in `PWR_CR5` sets the main regulator into **Range 1 Boost Mode** [STM32G474_RM0440 p.267], which allows the core and system frequency to run up to 170 MHz [STM32G474_RM0440 p.232].
2. **Flash Wait States**:
   - For Range 1 Boost Mode with $136 < \text{HCLK} \le 170\text{ MHz}$, the Flash latency must be configured to **4 wait states** (`LATENCY = 4`) [STM32G474_RM0440 p.98] before increasing the clock speed.
3. **PLL and HSE Setup**:
   - The PLL input frequency $f_{\text{PLL\_IN}}$ must remain within the datasheet operating range. Using $\text{PLLM} = 2$ scales down the 24 MHz HSE to $f_{\text{PLL\_IN}} = 12\text{ MHz}$. With $\text{PLLN} = 28$, the intermediate VCO frequency is $f_{\text{VCO}} = 336\text{ MHz}$, and division by $\text{PLLR} = 2$ gives $f_{\text{PLL\_R}} = 168\text{ MHz}$.
   - When switching SYSCLK above 150 MHz, the AHB prescaler is first divided by 2 before switching `SW` to PLL, followed by a short delay before restoring the prescaler to 1 [STM32G474_RM0440 p.233].
4. **GPIO Alternate Functions**:
   - Pin `PA9` (USART1_TX) and pin `PA10` (USART1_RX) are mapped to Alternate Function **AF7** [STM32G474_Datasheet p.73].
5. **USART1 Configuration**:
   - USART1 kernel clock is fed by `PCLK2` (168 MHz) by default (`RCC_CCIPR.USART1SEL = 00b`) [STM32G474_RM0440 p.324].
   - With oversampling by 16 (`OVER8 = 0`), $\text{BRR} = \text{USARTDIV} = 168\,000\,000 / 115\,200 \approx 1458$ (`0x05B2`) [STM32G474_RM0440 p.1707–1708], giving an actual baud rate of 115,226.34 baud (+0.023% error, well within the requested $\pm 2\%$).
   - `USART1->BRR` is written before enabling the peripheral (`UE = 1`) [STM32G474_RM0440 p.1755], and `TE`, `RE`, and `UE` are enabled with 8 data bits, no parity, and 1 stop bit.
