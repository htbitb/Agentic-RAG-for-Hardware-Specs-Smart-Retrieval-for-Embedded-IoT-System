### Configuration & Derivation Summary

1. **Clock Configuration and Timings**:
   - The system is running with $SYSCLK = HCLK = PCLK1 = PCLK2 = 170\text{ MHz}$ [STM32G474_RM0440 p.285].
   - Because the APB1 prescaler is 1, the timer clock frequency feeding TIM4 ($f_{\text{TIM4CLK}}$) is equal to $PCLK1 = 170\text{ MHz}$ [STM32G474_RM0440 p.285].
   - For a target PWM frequency $f_{\text{target}} = 10\text{ kHz}$:
     $$\text{Target period counts} = \frac{f_{\text{TIM4CLK}}}{f_{\text{target}}} = \frac{170\,000\,000}{10\,000} = 17\,000$$
   - Selecting prescaler $\text{PSC} = 0$, auto-reload register $\text{ARR} = 17000 - 1 = 16999$ [STM32G474_RM0440 p.1387].
   - Counter counts edge-aligned upcounting from 0 to 16999.
   - For Channel 1 (30 % duty cycle):
     $$\text{CCR1} = 17000 \times 0.30 = 5100$$
   - For Channel 2 (60 % duty cycle):
     $$\text{CCR2} = 17000 \times 0.60 = 10200$$

2. **GPIO Pin Mapping**:
   - **PB6**: Alternate Function 2 (`AF2`) maps to `TIM4_CH1` [STM32G474_Datasheet p.74].
   - **PB7**: Alternate Function 2 (`AF2`) maps to `TIM4_CH2` [STM32G474_Datasheet p.74].
   - In `GPIOB->MODER`, pins PB6 and PB7 are configured to Alternate Function mode (`10b`) [STM32G474_RM0440 p.355].
   - In `GPIOB->AFR[0]` (`AFRL`), bits `[27:24]` and `[31:28]` are set to `0010b` (AF2) [STM32G474_RM0440 p.359].

3. **Timer PWM Configuration**:
   - Peripheral clock for TIM4 is enabled via bit 2 (`TIM4EN`) in `RCC->APB1ENR1` [STM32G474_RM0440 p.309].
   - Peripheral clock for GPIOB is enabled via bit 1 (`GPIOBEN`) in `RCC->AHB2ENR` [STM32G474_RM0440 p.306].
   - PWM Mode 1 is set on Channel 1 and Channel 2 by setting `OC1M[2:0] = 110b` and `OC2M[2:0] = 110b` in `TIM4->CCMR1` [STM32G474_RM0440 p.1379].
   - Preload registers are enabled by setting `OC1PE` and `OC2PE` in `TIM4->CCMR1`, and `ARPE` in `TIM4->CR1` [STM32G474_RM0440 p.1366, 1379].
   - Channel outputs are enabled with active-high polarity by setting `CC1E = 1`, `CC1P = 0`, `CC2E = 1`, `CC2P = 0` in `TIM4->CCER` [STM32G474_RM0440 p.1385].
   - An update event is generated via `TIM4->EGR = TIM_EGR_UG` to load preloaded registers into shadow registers [STM32G474_RM0440 p.1376].
   - The counter is started with `TIM4->CR1 |= TIM_CR1_CEN` [STM32G474_RM0440 p.1366].

### Bare-Metal C Implementation

```c
#include "stm32g4xx.h"

void tim4_pwm_init(void)
{
    /* 1. Enable peripheral clock for GPIOB and TIM4 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM4EN;

    /* 2. Configure PB6 and PB7 to Alternate Function mode (AF2: TIM4_CH1, TIM4_CH2) */
    GPIOB->MODER &= ~(GPIO_MODER_MODE6_Msk | GPIO_MODER_MODE7_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE6_Pos) | (2U << GPIO_MODER_MODE7_Pos);

    GPIOB->AFR[0] &= ~((0xFU << GPIO_AFRL_AFSEL6_Pos) | (0xFU << GPIO_AFRL_AFSEL7_Pos));
    GPIOB->AFR[0] |= (2U << GPIO_AFRL_AFSEL6_Pos) | (2U << GPIO_AFRL_AFSEL7_Pos);

    /* 3. Configure TIM4 time base for 10 kHz PWM */
    /* TIM4CLK = 170 MHz. With PSC = 0 and ARR = 16999:
     * f_PWM = 170,000,000 / ((0 + 1) * (16999 + 1)) = 10,000 Hz = 10 kHz */
    TIM4->PSC = 0;
    TIM4->ARR = 16999;

    /* 4. Configure duty cycles: CH1 = 30%, CH2 = 60% */
    /* CCR1 = 17000 * 30% = 5100 */
    /* CCR2 = 17000 * 60% = 10200 */
    TIM4->CCR1 = 5100;
    TIM4->CCR2 = 10200;

    /* 5. Set PWM mode 1 (active while CNT < CCRx) and enable output preload */
    TIM4->CCMR1 = (TIM_CCMR1_OC1M_2 | TIM_CCMR1_OC1M_1 | TIM_CCMR1_OC1PE) |
                  (TIM_CCMR1_OC2M_2 | TIM_CCMR1_OC2M_1 | TIM_CCMR1_OC2PE);

    /* 6. Enable channel outputs with active-high polarity (CCxP = 0) */
    TIM4->CCER |= TIM_CCER_CC1E | TIM_CCER_CC2E;

    /* 7. Generate update event to load prescaler and reload values into shadow registers */
    TIM4->EGR = TIM_EGR_UG;

    /* 8. Enable auto-reload preload and start timer counter */
    TIM4->CR1 |= TIM_CR1_ARPE | TIM_CR1_CEN;
}
```

### Pin Conflict and Alternative Pin Selection

In Message 1, pins **PB6** and **PB7** were configured as `TIM4_CH1` and `TIM4_CH2` outputs for the 10 kHz PWM generators. Attempting to assign `USART1_TX` and `USART1_RX` to **PB6** and **PB7** caused a direct resource conflict (`DRC-PIN-01` / `CONFLICT:PB6`), as each physical pin on the STM32G474 can only serve one peripheral function at a time [STM32G474_Datasheet p.71].

To preserve the TIM4 PWM generators from Message 1 without conflict:
- **PA9** was selected for `USART1_TX` (AF7, pin 43 in LQFP64) [STM32G474_Datasheet p.73].
- **PA10** was selected for `USART1_RX` (AF7, pin 44 in LQFP64) [STM32G474_Datasheet p.73].

*(Note: If your hardware specifically connects PB6/PB7 to a serial header instead of the PWM outputs, the TIM4 PWM outputs must be relocated to other pins such as PA11/PA12 or PB8/PB9, freeing PB6/PB7 for USART1 AF7 [STM32G474_Datasheet p.74]).*

### USART1 Configuration and Baud-Rate Derivation

1. **Clock Source & Prescaler**:
   - By default in `RCC->CCIPR`, the `USART1SEL[1:0]` bits are `00b`, routing `PCLK2` (170 MHz) as the USART1 kernel clock $f_{\text{CK}}$ [STM32G474_RM0440 p.322].
   - Oversampling is configured for 16 (`OVER8 = 0` in `USART1->CR1`) [STM32G474_RM0440 p.1740].

2. **Baud Rate Calculation**:
   - Formula with 16x oversampling [STM32G474_RM0440 p.1708]:
     $$\text{USARTDIV} = \frac{f_{\text{CK}}}{\text{Baud Rate}} = \frac{170\,000\,000}{115\,200} \approx 1475.694$$
   - In 16x oversampling mode, $\text{BRR} = \text{round}(\text{USARTDIV}) = 1476$ (`0x05C4`) [STM32G474_RM0440 p.1708, 1755].
   - Actual baud rate achieved:
     $$\text{Baud}_{\text{actual}} = \frac{170\,000\,000}{1476} \approx 115\,176.15\text{ baud}$$
   - Error:
     $$\text{Error} = \frac{115\,176.15 - 115\,200}{115\,200} \times 100\% \approx -0.021\%$$
     This is well within the requested $\pm 2\%$ tolerance.

3. **Frame Format**:
   - 8 data bits: `M1 = 0`, `M0 = 0` in `USART1->CR1` (reset default) [STM32G474_RM0440 p.1740].
   - 1 stop bit: `STOP[1:0] = 00b` in `USART1->CR2` (reset default) [STM32G474_RM0440 p.1747].
   - No parity: `PCE = 0` in `USART1->CR1` (reset default) [STM32G474_RM0440 p.1740].
   - `BRR` is written before enabling the USART via `UE`, `TE`, and `RE` in `USART1->CR1` [STM32G474_RM0440 p.1740].

#include "stm32g4xx.h"

void usart1_init(void)
{
    /* 1. Enable peripheral clock for GPIOA (AHB2) and USART1 (APB2) */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PA9 (TX) and PA10 (RX) to Alternate Function mode (AF7: USART1)
     * (PA9/PA10 selected to avoid conflict with PB6/PB7 used by TIM4 PWM) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

    /* AF7 in GPIOA->AFR[1] (AFRH) for PA9 (bits 7:4) and PA10 (bits 11:8) */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= (7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos);

    /* 3. Configure Baud Rate to 115200:
     * Clock source = PCLK2 = 170 MHz (RCC_CCIPR USART1SEL = 0)
     * Oversampling by 16 (OVER8 = 0)
     * BRR = 170,000,000 / 115,200 = 1475.694 -> 1476 (0x5C4)
     * Actual baud rate = 115176.15 baud (-0.02% error)
     * Written before enabling USART1 */
    USART1->BRR = 1476U;

    /* 4. Configure frame: 8 data bits, 1 stop bit, no parity (CR1/CR2 reset values)
     * Enable Transmitter (TE), Receiver (RE), and USART (UE) */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}

### Complete Initialization Program

Below is the complete C program configuring the TIM4 PWM generators and the USART1 debug console using CMSIS-style direct register access on the STM32G474:

```c
#include "stm32g4xx.h"

int main(void)
{
    /* -------------------------------------------------------------------------
     * 1. Enable Peripheral Clocks
     * ------------------------------------------------------------------------- */
    /* Enable GPIOA and GPIOB clocks on AHB2 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN | RCC_AHB2ENR_GPIOBEN;

    /* Enable TIM4 clock on APB1 */
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM4EN;

    /* Enable USART1 clock on APB2 */
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* -------------------------------------------------------------------------
     * 2. Configure GPIO Pins for TIM4 PWM (PB6 and PB7)
     * ------------------------------------------------------------------------- */
    /* PB6 -> TIM4_CH1 (AF2), PB7 -> TIM4_CH2 (AF2) */
    GPIOB->MODER &= ~(GPIO_MODER_MODE6_Msk | GPIO_MODER_MODE7_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE6_Pos) | (2U << GPIO_MODER_MODE7_Pos);

    /* Alternate function AF2 for pins 6 and 7 in AFR[0] (AFRL) */
    GPIOB->AFR[0] &= ~((0xFU << GPIO_AFRL_AFSEL6_Pos) | (0xFU << GPIO_AFRL_AFSEL7_Pos));
    GPIOB->AFR[0] |= (2U << GPIO_AFRL_AFSEL6_Pos) | (2U << GPIO_AFRL_AFSEL7_Pos);

    /* -------------------------------------------------------------------------
     * 3. Configure TIM4 for 10 kHz PWM
     * ------------------------------------------------------------------------- */
    /* Clock: TIM4CLK = 170 MHz (APB1 prescaler = 1)
     * Target frequency = 10 kHz:
     *   ARR = (170,000,000 / ((0 + 1) * 10,000)) - 1 = 16999
     * Duty cycles:
     *   CH1 (PB6): 30% -> CCR1 = 17,000 * 0.30 = 5100
     *   CH2 (PB7): 60% -> CCR2 = 17,000 * 0.60 = 10200
     */
    TIM4->PSC = 0;
    TIM4->ARR = 16999;
    TIM4->CCR1 = 5100;
    TIM4->CCR2 = 10200;

    /* Edge-aligned PWM mode 1 (OCxM = 110b) with output preload enabled (OCxPE) */
    TIM4->CCMR1 = (TIM_CCMR1_OC1M_2 | TIM_CCMR1_OC1M_1 | TIM_CCMR1_OC1PE) |
                  (TIM_CCMR1_OC2M_2 | TIM_CCMR1_OC2M_1 | TIM_CCMR1_OC2PE);

    /* Enable channel outputs with active-high polarity (CCxE = 1, CCxP = 0) */
    TIM4->CCER |= TIM_CCER_CC1E | TIM_CCER_CC2E;

    /* Generate an update event to load preloaded registers into shadow registers */
    TIM4->EGR = TIM_EGR_UG;

    /* Enable auto-reload preload and start counter */
    TIM4->CR1 |= TIM_CR1_ARPE | TIM_CR1_CEN;

    /* -------------------------------------------------------------------------
     * 4. Configure GPIO Pins for USART1 (PA9 and PA10)
     * ------------------------------------------------------------------------- */
    /* Note on pin allocation: PB6 and PB7 were already assigned to TIM4_CH1/CH2.
     * To prevent a pin collision, PA9 (TX) and PA10 (RX) are used for USART1 (AF7). */
    GPIOA->MODER &= ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

    /* Alternate function AF7 for pins 9 and 10 in AFR[1] (AFRH) */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= (7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos);

    /* -------------------------------------------------------------------------
     * 5. Configure USART1 (115200 baud, 8N1, 16x oversampling)
     * ------------------------------------------------------------------------- */
    /* Clock: PCLK2 = 170 MHz (RCC_CCIPR default USART1SEL = 0)
     * Oversampling by 16 (OVER8 = 0 in CR1)
     * BRR = 170,000,000 / 115,200 = 1475.694 -> 1476 (0x5C4)
     * Actual baud rate = 115,176.15 baud (-0.02% error)
     * BRR is written before enabling the USART.
     */
    USART1->BRR = 1476U;

    /* 8 data bits (M0=0, M1=0), 1 stop bit (CR2 STOP=00b), no parity (PCE=0).
     * Enable Transmitter (TE), Receiver (RE), and USART peripheral (UE). */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;

    /* -------------------------------------------------------------------------
     * Main loop
     * ------------------------------------------------------------------------- */
    while (1)
    {
    }
}
```

### Explanation of the Initialization Sequence

1. **Clock Enabling (`RCC`)**:
   - `RCC->AHB2ENR` enables the clock gates for `GPIOA` (bit 0) and `GPIOB` (bit 1) [STM32G474_RM0440 p.306].
   - `RCC->APB1ENR1` enables `TIM4EN` (bit 2) [STM32G474_RM0440 p.309].
   - `RCC->APB2ENR` enables `USART1EN` (bit 14) [STM32G474_RM0440 p.312].

2. **Pin Assignment & Conflict Resolution (Decision D1)**:
   - Pins **PB6** and **PB7** are configured as Alternate Function `AF2` for `TIM4_CH1` and `TIM4_CH2` [STM32G474_Datasheet p.74].
   - Because PB6 and PB7 were already assigned to the PWM channels, USART1 was routed to **PA9** (`USART1_TX`, AF7) and **PA10** (`USART1_RX`, AF7) to avoid a pin collision [STM32G474_Datasheet p.73].

3. **TIM4 PWM Generation**:
   - Counter counts at $f_{\text{TIM4CLK}} = 170\text{ MHz}$ ($PSC = 0$) up to $ARR = 16999$, producing an exact $10.0\text{ kHz}$ repetition rate [STM32G474_RM0440 p.1388].
   - $CCR1 = 5100$ produces a $30\%$ duty cycle ($5100 / 17000 = 0.30$).
   - $CCR2 = 10200$ produces a $60\%$ duty cycle ($10200 / 17000 = 0.60$).
   - Output compare mode 1 (`OCxM = 110b`) keeps outputs high while `TIM4_CNT < CCRx` and low when `CNT >= CCRx` [STM32G474_RM0440 p.1379].
   - `EGR = TIM_EGR_UG` transfers the preloaded values to shadow registers [STM32G474_RM0440 p.1376], and `TIM_CR1_CEN` begins counting [STM32G474_RM0440 p.1366].

4. **USART1 Serial Port**:
   - Kernel clock source is $PCLK2 = 170\text{ MHz}$.
   - Oversampling by 16 with $BRR = 1476$ sets the baud rate to $115\,176.15\text{ baud}$ (error of $-0.02\%$, well within $\pm 2\%$) [STM32G474_RM0440 p.1755].
   - `BRR` is written prior to enabling `USART1->CR1` with `TE`, `RE`, and `UE` [STM32G474_RM0440 p.1740].
