  - By reset default in `RCC_CCIPR`, the USART3 clock source is `PCLK1` (170 MHz) [STM32G474_RM0440 p.324].
  - `USART3_PRESC` defaults to 0 (prescaler division by 1), so $f_{\text{CK}} = 170\text{ MHz}$ [STM32G474_RM0440 p.1772].

- **Pin Multiplexing**:
  - Pin PB10 carries `USART3_TX` on Alternate Function 7 (AF7) [STM32G474_Datasheet p.74].

- **Baud Rate Calculation**:
  - Oversampling by 16 (`OVER8 = 0` in `USART_CR1`) [STM32G474_RM0440 p.1707, p.1741].
  - $\text{BRR} = \frac{f_{\text{CK}}}{\text{Baud}} = \frac{170\,000\,000}{115\,200} \approx 1475.694$.

- **Frame Format**:
  - 8 data bits: bits `M1` (bit 28) and `M0` (bit 12) in `USART_CR1` are set to `00` [STM32G474_RM0440 p.1744].
  - Parity disabled: `PCE` (bit 10) in `USART_CR1` is `0` [STM32G474_RM0440 p.1745].
  - 1 stop bit: `STOP[1:0]` (bits 13:12) in `USART_CR2` is set to `00` [STM32G474_RM0440 p.1747].
  - Transmitter (`TE`), Receiver (`RE`), and USART enable (`UE`) are set after writing `USART_BRR`, adhering to the requirement [STM32G474_RM0440 p.1702, p.1743].

#include "stm32g4xx.h"

void usart3_init(void)
{
    /* 1. Enable peripheral clocks for GPIOB and USART3 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_USART3EN;

    /* 2. Configure PB10 (TX) and PB11 (RX) as Alternate Function (AF7) */
    /* Clear and set PB10 and PB11 mode to alternate function (0b10) */
    GPIOB->MODER &= ~((3U << GPIO_MODER_MODE10_Pos) | (3U << GPIO_MODER_MODE11_Pos));
    GPIOB->MODER |=  ((2U << GPIO_MODER_MODE10_Pos) | (2U << GPIO_MODER_MODE11_Pos));

    /* Set AF7 (0x07) in AFRH for PB10 and PB11 */
    GPIOB->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL10_Pos) | (0xFU << GPIO_AFRH_AFSEL11_Pos));
    GPIOB->AFR[1] |=  ((7U << GPIO_AFRH_AFSEL10_Pos) | (7U << GPIO_AFRH_AFSEL11_Pos));

    /* 3. Ensure USART3 is disabled before configuring frame settings */
    USART3->CR1 = 0U;
    USART3->CR2 = 0U;
    USART3->CR3 = 0U;

    /* 4. Write Baud Rate Register (BRR) before enabling USART:
     *    BRR = (f_ck + Baud/2) / Baud = (170000000 + 57600) / 115200 = 1476 (0x05C4)
     */
    USART3->BRR = (170000000U + (115200U / 2U)) / 115200U;

    /* 5. Enable Transmitter (TE), Receiver (RE), and USART (UE)
     *    8 data bits (M[1:0] = 00), parity disabled (PCE = 0), OVER16 (OVER8 = 0)
     */
    USART3->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}

1. **Clocks**:
   - `GPIOB` is on the AHB2 bus: clock enabled via `RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN` [STM32G474_RM0440 p.306].
   - `TIM2` is on the APB1 bus: clock enabled via `RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN` [STM32G474_RM0440 p.309].

2. **Pin Multiplexing**:

   - `GPIOB->MODER` sets PB10 to Alternate Function mode (`0b10`) [STM32G474_RM0440 p.355].
   - `GPIOB->AFR[1]` (`AFRH`) sets AF1 (`0x1`) for pin 10 [STM32G474_RM0440 p.360].

3. **Timer Frequency & Duty Cycle Calculations**:
   - Counter clock: $f_{\text{CNT}} = \frac{f_{\text{TIM}}}{PSC + 1} = \frac{170\text{ MHz}}{0 + 1} = 170\text{ MHz}$.
   - For a target PWM frequency $f_{\text{PWM}} = 5\text{ kHz}$:
     $$\text{ARR} + 1 = \frac{f_{\text{CNT}}}{f_{\text{PWM}}} = \frac{170\,000\,000}{5\,000} = 34\,000 \implies \text{ARR} = 33\,999 \quad (0\text{ Hz error})$$
   - For an 80% duty cycle in edge-aligned PWM mode 1:
     $$\text{CCR3} = 34\,000 \times 0.80 = 27\,200 \quad (0\%\text{ error})$$
   - Resolution: 34,000 steps ($\approx 15.05\text{ bits}$).

4. **PWM Output Settings**:
   - PWM Mode 1 on Channel 3: `OC3M[3:0] = 0110b` (`OC3M = 0b110` in bits [6:4], `OC3M_3 = 0` in bit 16 of `TIM2_CCMR2`) [STM32G474_RM0440 p.1382].
   - Output compare preload enabled: `OC3PE = 1` in `TIM2_CCMR2` [STM32G474_RM0440 p.1382].
   - Auto-reload preload enabled: `ARPE = 1` in `TIM2_CR1` [STM32G474_RM0440 p.1373].
   - Channel 3 active-high output enabled: `CC3P = 0`, `CC3E = 1` in `TIM2_CCER` [STM32G474_RM0440 p.1385].
   - Update generation: `TIM2->EGR = TIM_EGR_UG` loads shadow registers [STM32G474_RM0440 p.1380].
   - Counter start: `CEN = 1` in `TIM2_CR1` [STM32G474_RM0440 p.1374].
   - Note: TIM2 is a general-purpose timer without complementary dead-time registers (no BDTR/MOE register required).

void tim2_ch3_heater_pwm_init(void)
{
    /* 1. Enable peripheral clocks for GPIOB and TIM2 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN;

    /* 2. Configure PB10 as AF1 (TIM2_CH3) */
    GPIOB->MODER &= ~(3U << GPIO_MODER_MODE10_Pos);
    GPIOB->MODER |=  (2U << GPIO_MODER_MODE10_Pos);

    GPIOB->AFR[1] &= ~(0xFU << GPIO_AFRH_AFSEL10_Pos);
    GPIOB->AFR[1] |=  (1U << GPIO_AFRH_AFSEL10_Pos);

    /* 3. Configure TIM2 time base:
     *    f_tim = 170 MHz, PSC = 0 -> timer counter clock = 170 MHz
     *    ARR = 33999 -> f_pwm = 170000000 / (0 + 1) / (33999 + 1) = 5000 Hz
     */
    TIM2->PSC = 0U;
    TIM2->ARR = 33999U;

    /* 4. Set duty cycle to 80%:
     *    CCR3 = (ARR + 1) * 80% = 34000 * 0.80 = 27200
     */
    TIM2->CCR3 = 27200U;

    /* 5. Configure Channel 3 in PWM mode 1 (OC3M = 0110b) with preload enabled (OC3PE) */
    TIM2->CCMR2 &= ~(TIM_CCMR2_CC3S | TIM_CCMR2_OC3M | TIM_CCMR2_OC3M_3);
    TIM2->CCMR2 |= (6U << TIM_CCMR2_OC3M_Pos) | TIM_CCMR2_OC3PE;

    /* 6. Enable Channel 3 output with active-high polarity (CC3P = 0, CC3E = 1) */
    TIM2->CCER &= ~TIM_CCER_CC3P;
    TIM2->CCER |= TIM_CCER_CC3E;

    /* 7. Enable Auto-Reload Preload (ARPE) and trigger an update event */
    TIM2->CR1 |= TIM_CR1_ARPE;
    TIM2->EGR = TIM_EGR_UG;

    /* 8. Enable counter (CEN) */
    TIM2->CR1 |= TIM_CR1_CEN;
}

{

    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN | RCC_APB1ENR1_USART3EN;

     *    PB9:  USART3_TX -> AF7
     *    PB10: TIM2_CH3  -> AF1 (PWM output)
     *    PB11: USART3_RX -> AF7

    GPIOB->MODER &= ~((3U << GPIO_MODER_MODE9_Pos) |
                      (3U << GPIO_MODER_MODE10_Pos) |
                      (3U << GPIO_MODER_MODE11_Pos));
    GPIOB->MODER |=  ((2U << GPIO_MODER_MODE9_Pos) |
                      (2U << GPIO_MODER_MODE10_Pos) |
                      (2U << GPIO_MODER_MODE11_Pos));

    /* Configure Alternate Functions in AFRH (AFR[1]):
     * PB9  -> AF7 (0x7)
     * PB10 -> AF1 (0x1)
     * PB11 -> AF7 (0x7)
     */
    GPIOB->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) |
                       (0xFU << GPIO_AFRH_AFSEL10_Pos) |
                       (0xFU << GPIO_AFRH_AFSEL11_Pos));
    GPIOB->AFR[1] |=  ((7U << GPIO_AFRH_AFSEL9_Pos) |
