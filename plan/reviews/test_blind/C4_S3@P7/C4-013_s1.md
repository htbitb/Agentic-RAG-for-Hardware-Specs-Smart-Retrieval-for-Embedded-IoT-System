### USART3 Configuration for STM32G474 (PB10 TX, PB11 RX, 115200 Baud)

#### 1. Pin Multiplexing & Alternate Functions
- **PB10**: USART3_TX via **AF7** [STM32G474_Datasheet p.74].
- **PB11**: USART3_RX via **AF7** [STM32G474_Datasheet p.74].
- Both pins are configured in Alternate Function mode (`MODER[1:0] = 0b10`) with `AFRH10 = 7` and `AFRH11 = 7` [STM32G474_RM0440 p.355, p.360].

#### 2. Clocking and Baud Rate Calculation
- By default at reset, `RCC->CCIPR` bits `USART3SEL[1:0] = 0b00`, selecting **PCLK1** as the USART3 kernel clock (`f_CK = 170 MHz`) [STM32G474_RM0440 p.322].
- Clock gating:
  - GPIOB clock is enabled via bit `GPIOBEN` in `RCC->AHB2ENR` [STM32G474_RM0440 p.306].
  - USART3 clock is enabled via bit `USART3EN` in `RCC->APB1ENR1` [STM32G474_RM0440 p.309].
- With oversampling by 16 (`OVER8 = 0` in `USART_CR1`), the baud rate formula is [STM32G474_RM0440 p.1707]:
  $$\text{USARTDIV} = \frac{f_{\text{CK}}}{\text{Baud}} = \frac{170\,000\,000}{115\,200} \approx 1475.694$$
  Rounding to the nearest integer gives $\text{BRR} = 1476$ (`0x05C4`), yielding an actual baud rate of $115\,176.15\text{ Baud}$ (relative error $\approx -0.021\%$).

#### 3. Framing & Control Configuration
- Word length: 8 data bits (`M0 = 0`, `M1 = 0` in `USART_CR1`, default `0`) [STM32G474_RM0440 p.1740].
- Parity: disabled (`PCE = 0` in `USART_CR1`, default `0`) [STM32G474_RM0440 p.1740].
- Stop bits: 1 stop bit (`STOP[1:0] = 00` in `USART_CR2`, default `0`) [STM32G474_RM0440 p.1747].
- As required, `USART3->BRR` is written before enabling the peripheral (`UE`).
- `USART3->CR1` is written with `TE = 1`, `RE = 1`, and `UE = 1` (`USART_CR1_TE | USART_CR1_RE | USART_CR1_UE`).

### Bare-Metal C Implementation

```c
#include "stm32g4xx.h"

void usart3_init(void)
{
    /* 1. Enable GPIOB clock */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;

    /* 2. Configure PB10 and PB11 to Alternate Function mode (AF7) */
    GPIOB->MODER &= ~(GPIO_MODER_MODE10_Msk | GPIO_MODER_MODE11_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE10_Pos) | (2U << GPIO_MODER_MODE11_Pos);

    /* AF7 on PB10 and PB11 (AFR[1] is AFRH for pins 8 through 15) */
    GPIOB->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL10_Pos) | (0xFU << GPIO_AFRH_AFSEL11_Pos));
    GPIOB->AFR[1] |= (7U << GPIO_AFRH_AFSEL10_Pos) | (7U << GPIO_AFRH_AFSEL11_Pos);

    /* 3. Enable USART3 clock in APB1 */
    RCC->APB1ENR1 |= RCC_APB1ENR1_USART3EN;

    /* 4. Configure baud rate:
     * Clock source = PCLK1 = 170 MHz, OVER8 = 0 (oversampling by 16)
     * BRR = 170,000,000 / 115,200 = 1475.694 -> 1476 (0x5C4)
     * Written before USART is enabled.
     */
    USART3->BRR = 1476U;

    /* 5. Enable Transmitter, Receiver, and USART (8 data bits, no parity, 1 stop bit) */
    USART3->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
```

### Pin Conflict Resolution & PWM Configuration on STM32G474

#### 1. Pin Conflict & Alternative Selection
In Message 1, pin **PB10** was allocated and configured as `USART3_TX` [STM32G474_Datasheet p.74].
A single microcontroller pin can only map to one alternate function at a time. Assigning **TIM2_CH3** (which on PB10 requires **AF1**) [STM32G474_Datasheet p.74] to PB10 creates a pin conflict with `USART3_TX`.

To preserve USART3 on PB10 while generating the heater PWM with TIM2 Channel 3:
- **PA2** (LQFP64 pin 14) also provides `TIM2_CH3` via **AF1** [STM32G474_Datasheet p.73].
- TIM2 Channel 3 is assigned to **PA2** with Alternate Function 1.

#### 2. Timer 2 Calculations (5 kHz, 80 % Duty Cycle)
- With APB1 prescaler = 1, `TIM2CLK` equals `PCLK1 = 170 MHz`.
- For edge-aligned up-counting PWM mode 1:
  $$f_{\text{PWM}} = \frac{f_{\text{TIM2CLK}}}{(\text{PSC} + 1) \times (\text{ARR} + 1)}$$
  Selecting $\text{PSC} = 0$:
  $$\text{ARR} + 1 = \frac{170\,000\,000}{5\,000} = 34\,000 \implies \text{ARR} = 33999$$
- For an 80 % duty cycle:
  $$\text{CCR3} = 80\% \times (\text{ARR} + 1) = 0.80 \times 34000 = 27200$$
  - Frequency error: $0\%$
  - Duty cycle error: $0\%$ (resolution: 34,000 steps).

#### 3. Register Configuration
- **GPIOA**: Clock enabled via `RCC_AHB2ENR_GPIOAEN`. PA2 configured in Alternate Function mode (`MODER2[1:0] = 0b10`) and `AFRL2 = 1` (AF1) [STM32G474_Datasheet p.73].
- **TIM2**: Clock enabled via `RCC_APB1ENR1_TIM2EN`.
- Channel 3 configured in PWM mode 1 with preload enabled:
  - `CC3S = 00` (output) in `TIM2->CCMR2` [STM32G474_RM0440 p.1382].
  - `OC3M = 0110` (PWM mode 1) in `TIM2->CCMR2` [STM32G474_RM0440 p.1382].
  - `OC3PE = 1` (preload enable) in `TIM2->CCMR2` [STM32G474_RM0440 p.1382].
- Channel 3 output enabled with active-high polarity:
  - `CC3P = 0` (active high) and `CC3E = 1` in `TIM2->CCER` [STM32G474_RM0440 p.1385].
- Auto-reload preload enabled (`ARPE` in `TIM2->CR1`), software update event triggered via `TIM2->EGR = TIM_EGR_UG` to load shadow registers, and counter started with `TIM_CR1_CEN`.

### Bare-Metal C Implementation

```c
#include "stm32g4xx.h"

void tim2_ch3_pwm_init(void)
{
    /* 1. Enable GPIOA clock */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;

    /* 2. Configure PA2 as Alternate Function 1 (TIM2_CH3)
     * Routed to PA2 to preserve USART3_TX on PB10.
     */
    GPIOA->MODER &= ~GPIO_MODER_MODE2_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE2_Pos);

    GPIOA->AFR[0] &= ~GPIO_AFRL_AFSEL2_Msk;
    GPIOA->AFR[0] |= (1U << GPIO_AFRL_AFSEL2_Pos);

    /* 3. Enable TIM2 peripheral clock in APB1 */
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN;

    /* 4. Configure Prescaler, Period, and Duty Cycle:
     * TIM2CLK = 170 MHz
     * Target frequency = 5,000 Hz: ARR = (170,000,000 / (1 * 5,000)) - 1 = 33,999
     * Target duty = 80 %: CCR3 = 0.80 * 34,000 = 27,200
     */
    TIM2->PSC = 0U;
    TIM2->ARR = 33999U;
    TIM2->CCR3 = 27200U;

    /* 5. Set Channel 3 to PWM mode 1 (OC3M = 0b0110) with preload enabled (OC3PE = 1) */
    TIM2->CCMR2 &= ~(TIM_CCMR2_CC3S_Msk | TIM_CCMR2_OC3M_Msk);
    TIM2->CCMR2 |= (6U << TIM_CCMR2_OC3M_Pos) | TIM_CCMR2_OC3PE;

    /* 6. Configure Channel 3 as active-high output and enable output */
    TIM2->CCER &= ~(TIM_CCER_CC3P | TIM_CCER_CC3NP);
    TIM2->CCER |= TIM_CCER_CC3E;

    /* 7. Enable Auto-reload preload (ARPE), generate update to load registers, and start counter */
    TIM2->CR1 |= TIM_CR1_ARPE;
    TIM2->EGR = TIM_EGR_UG;
    TIM2->CR1 |= TIM_CR1_CEN;
}
```

{

     * 1. GPIO Clock & Pin Configuration

    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN | RCC_AHB2ENR_GPIOBEN;

    GPIOB->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL10_Pos) | (0xFU << GPIO_AFRH_AFSEL11_Pos));
    GPIOB->AFR[1] |= (7U << GPIO_AFRH_AFSEL10_Pos) | (7U << GPIO_AFRH_AFSEL11_Pos);

    /* PA2 (TIM2_CH3) -> Alternate Function AF1
     * Note: Reassigned to PA2 to avoid pin conflict with USART3_TX on PB10.
     */
    GPIOA->MODER &= ~GPIO_MODER_MODE2_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE2_Pos);

    GPIOA->AFR[0] &= ~GPIO_AFRL_AFSEL2_Msk;

     * ========================================================================= */

     * 3. USART3 Configuration (115200 baud, 8N1, TX & RX enabled)

     * ========================================================================= */

     * PSC = 0

     * ========================================================================= */

### Explanation

1. **GPIO Setup & Pin Conflict Resolution**:
   - The clocks for ports A and B are enabled through `RCC->AHB2ENR` [STM32G474_RM0440 p.306].
   - **PB10** and **PB11** are set to Alternate Function mode (`MODER = 0b10`) [STM32G474_RM0440 p.355] and mapped to **AF7** in `GPIOB->AFRH` [STM32G474_Datasheet p.74, STM32G474_RM0440 p.360] for `USART3_TX` and `USART3_RX`.
   - Because PB10 was already assigned to `USART3_TX`, assigning `TIM2_CH3` to PB10 creates a pin conflict. To preserve `USART3_TX`, `TIM2_CH3` is routed to **PA2** via **AF1** (`MODER2 = 0b10`, `AFRL2 = 1`) [STM32G474_Datasheet p.73].

2. **USART3 Configuration**:
   - The USART3 clock is enabled in `RCC->APB1ENR1` via `USART3EN` [STM32G474_RM0440 p.309].
   - Operating at `PCLK1 = 170 MHz` with 16x oversampling (`OVER8 = 0` in `USART_CR1` [STM32G474_RM0440 p.1740]), the divisor is $\text{USARTDIV} = 170\,000\,000 / 115\,200 \approx 1475.694$.
   - Writing `USART3->BRR = 1476` yields an actual baud rate of $115\,176.15\text{ Baud}$ ($-0.021\%$ error).
   - `USART3->CR1` is subsequently written to enable transmitter (`TE`), receiver (`RE`), and the peripheral (`UE`) [STM32G474_RM0440 p.1740].

3. **TIM2 Channel 3 PWM Configuration**:
   - The TIM2 clock is enabled in `RCC->APB1ENR1` via `TIM2EN` [STM32G474_RM0440 p.309].
   - Running at `TIM2CLK = 170 MHz` with `PSC = 0`:
     $$\text{ARR} = \frac{170\,000\,000}{5\,000} - 1 = 33\,999$$
     $$\text{CCR3} = 0.80 \times (\text{ARR} + 1) = 0.80 \times 34\,000 = 27\,200$$
   - `TIM2->CCMR2` sets Channel 3 to PWM mode 1 (`OC3M = 0b0110`) and enables the output compare preload (`OC3PE = 1`) [STM32G474_RM0440 p.1382].
   - `TIM2->CCER` sets active-high polarity (`CC3P = 0`) and enables the channel 3 output (`CC3E = 1`) [STM32G474_RM0440 p.1385].
   - Auto-reload preload is enabled via `ARPE` in `TIM2->CR1` [STM32G474_RM0440 p.1366], shadow registers are updated immediately using `TIM2->EGR = TIM_EGR_UG` [STM32G474_RM0440 p.1376], and the counter is started with `CEN` [STM32G474_RM0440 p.1366].
