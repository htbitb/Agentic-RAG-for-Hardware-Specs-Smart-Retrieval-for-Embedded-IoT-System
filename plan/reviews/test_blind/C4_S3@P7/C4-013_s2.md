### USART3 Configuration for STM32G474 (PB10 TX / PB11 RX at 115200 Baud)

#### Hardware & Clock Analysis
1. **Clock Source & Prescalers:**
   - The system is running at $f_{\text{SYSCLK}} = f_{\text{HCLK}} = f_{\text{PCLK1}} = 170\text{ MHz}$.
   - In `RCC_CCIPR`, bits `USART3SEL[1:0]` reset to `00b`, selecting `PCLK1` ($170\text{ MHz}$) as the USART3 kernel clock (`usart_ker_ck`) [STM32G474_RM0440 p.322].
   - The USART prescaler `USART3->PRESC` resets to `0` (prescaler division factor = 1) [STM32G474_RM0440 p.1772].

2. **Baud Rate Calculation:**
   - With oversampling by 16 (`OVER8 = 0` in `USART_CR1`):
     $$\text{USARTDIV} = \frac{f_{\text{ker\_ck}}}{\text{Baud}} = \frac{170\,000\,000}{115\,200} \approx 1475.694$$
   - Rounding to the nearest integer gives `USART3->BRR = 1476` (`0x05C4`) [STM32G474_RM0440 p.1755].
   - Resulting baud rate:
     $$\text{Actual Baud} = \frac{170\,000\,000}{1476} \approx 115\,176\text{ Baud}$$
     which gives a baud rate error of about $-0.02\%$.

3. **GPIO Pin Multiplexing:**
   - `PB10`: Alternate Function 7 (`AF7` $\rightarrow$ `USART3_TX`) [STM32G474_Datasheet p.74].
   - `PB11`: Alternate Function 7 (`AF7` $\rightarrow$ `USART3_RX`) [STM32G474_Datasheet p.74].
   - Pins PB10 and PB11 are configured in Alternate Function mode (`MODER` = `10b`) in `GPIOB->MODER` and mapped using `GPIOB->AFR[1]` (bits `AFRH10` and `AFRH11` set to `0111b`).

4. **Frame Format & Sequence:**
   - 8 data bits: `M1 = 0`, `M0 = 0` in `USART3->CR1` [STM32G474_RM0440 p.1740].
   - Parity control disabled: `PCE = 0` in `USART3->CR1` [STM32G474_RM0440 p.1740].
   - 1 stop bit: `STOP[1:0] = 00b` in `USART3->CR2` [STM32G474_RM0440 p.1697, p.1747].
   - `USART3->BRR` is written before enabling the peripheral (`UE = 1`).
   - Transmitter enable (`TE = 1`) and Receiver enable (`RE = 1`) are set together with `UE = 1` in `USART3->CR1` [STM32G474_RM0440 p.1740].

### Bare-Metal C Implementation

```c
#include "stm32g4xx.h"

/**
 * @brief Configure USART3 on PB10 (TX) and PB11 (RX) at 115200 baud, 8N1.
 *        Assumes SYSCLK = PCLK1 = 170 MHz.
 */
void usart3_init(void)
{
    /* 1. Enable GPIOB peripheral clock */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;

    /* 2. Configure PB10 and PB11 to Alternate Function mode (10b) */
    GPIOB->MODER &= ~(GPIO_MODER_MODE10_Msk | GPIO_MODER_MODE11_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE10_Pos) | (2U << GPIO_MODER_MODE11_Pos);

    /* 3. Assign AF7 (USART3_TX and USART3_RX) to PB10 and PB11 */
    GPIOB->AFR[1] &= ~(GPIO_AFRH_AFSEL10_Msk | GPIO_AFRH_AFSEL11_Msk);
    GPIOB->AFR[1] |= (7U << GPIO_AFRH_AFSEL10_Pos) | (7U << GPIO_AFRH_AFSEL11_Pos);

    /* 4. Configure high output speed for PB10 (TX) and PB11 (RX) */
    GPIOB->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED10_Pos) | (3U << GPIO_OSPEEDR_OSPEED11_Pos);

    /* 5. Enable USART3 peripheral clock on APB1 */
    RCC->APB1ENR1 |= RCC_APB1ENR1_USART3EN;

    /* 6. Program the Baud Rate Register (BRR) before enabling UE
     *    BRR = 170,000,000 / 115,200 = 1475.694 -> 1476 (0x05C4)
     */
    USART3->BRR = 1476U;

    /* 7. Configure frame format: 8 data bits (M0=0, M1=0), no parity (PCE=0), oversampling by 16 (OVER8=0) */
    USART3->CR1 &= ~(USART_CR1_M1 | USART_CR1_M0 | USART_CR1_PCE | USART_CR1_OVER8);

    /* 8. Configure stop bits: 1 stop bit (STOP[1:0] = 00b) */
    USART3->CR2 &= ~USART_CR2_STOP_Msk;

    /* 9. Enable Transmitter (TE), Receiver (RE), and USART peripheral (UE) */
    USART3->CR1 |= (USART_CR1_TE | USART_CR1_RE | USART_CR1_UE);
}
```

### Resource Conflict Analysis & Pin Selection

1. **Pin Conflict on PB10:**
   - In Message 1, pin `PB10` was configured as `USART3_TX` (`AF7`) [STM32G474_Datasheet p.74].
   - Assigning `TIM2_CH3` to `PB10` causes a direct pin conflict (`DRC-PIN-01`: one owner per pin).
   - Alternate pins available for `TIM2_CH3` on the STM32G474 in the LQFP64 package are:
     - `PA2` (`AF1`) [STM32G474_Datasheet p.73]
     - `PA9` (`AF10`) [STM32G474_Datasheet p.73]
   - To preserve USART3 functionality on PB10, `PA2` was chosen for `TIM2_CH3` (`AF1`).

### Timer Calculations (TIM2 Channel 3)

- **Timer Clock ($f_{\text{TIMCLK}}$):**
  - With APB1 prescaler = 1 (`apb1_div = 1`), $f_{\text{PCLK1}} = 170\text{ MHz}$, so $f_{\text{TIM2CLK}} = 170\text{ MHz}$.
- **Frequency ($f_{\text{target}} = 5\text{ kHz}$):**
  - Up-counting PWM mode 1:
    $$f_{\text{PWM}} = \frac{f_{\text{TIM2CLK}}}{(\text{PSC} + 1) \times (\text{ARR} + 1)}$$
  - With $\text{PSC} = 0$:
    $$\text{ARR} = \frac{170\,000\,000}{5\,000} - 1 = 33999$$
    (Frequency error: $0\%$).
- **Duty Cycle ($80\%$):**
  - For active-high PWM mode 1:
    $$\text{CCR3} = 80\% \times (\text{ARR} + 1) = 0.80 \times 34000 = 27200$$
    (Duty cycle error: $0\%$, resolution = 34000 steps $\approx 15.05$ bits).

- **`TIM2->ARR`:** Set to `33999`.

### Bare-Metal C Implementation

```c
#include "stm32g4xx.h"

/**
 * @brief Configure TIM2 Channel 3 for 5 kHz PWM, 80% duty cycle on PA2.
 *        Assumes SYSCLK = PCLK1 = 170 MHz.
 *        Note: PA2 (AF1) is used because PB10 is occupied by USART3_TX.
 */
void tim2_pwm_init(void)
{
    /* 1. Enable GPIOA peripheral clock */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;

    /* 2. Configure PA2 to Alternate Function mode (10b) */
    GPIOA->MODER &= ~GPIO_MODER_MODE2_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE2_Pos);

    /* 3. Assign AF1 (TIM2_CH3) to PA2 */
    GPIOA->AFR[0] &= ~GPIO_AFRL_AFSEL2_Msk;
    GPIOA->AFR[0] |= (1U << GPIO_AFRL_AFSEL2_Pos);

    /* 4. Configure High Speed for PA2 */
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED2_Pos);

    /* 5. Enable TIM2 peripheral clock on APB1 */
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN;

    /* 6. Configure prescaler and auto-reload for 5 kHz PWM
     *    f_PWM = 170 MHz / ((0 + 1) * (33999 + 1)) = 5000 Hz
     */
    TIM2->PSC = 0U;
    TIM2->ARR = 33999U;

    /* 7. Configure compare register for 80% duty cycle
     *    CCR3 = 80% * (33999 + 1) = 27200
     */
    TIM2->CCR3 = 27200U;

    /* 8. Configure Channel 3 in PWM mode 1 (OC3M = 0110b) with preload enabled (OC3PE = 1) */
    TIM2->CCMR2 &= ~(TIM_CCMR2_CC3S_Msk | TIM_CCMR2_OC3M_Msk | TIM_CCMR2_OC3M_3);
    TIM2->CCMR2 |= (TIM_CCMR2_OC3M_1 | TIM_CCMR2_OC3M_2) | TIM_CCMR2_OC3PE;

    /* 9. Configure output polarity active-high (CC3P = 0) and enable output (CC3E = 1) */
    TIM2->CCER &= ~TIM_CCER_CC3P;
    TIM2->CCER |= TIM_CCER_CC3E;

    /* 10. Enable Auto-reload preload (ARPE = 1) */
    TIM2->CR1 |= TIM_CR1_ARPE;

    /* 11. Trigger update event to load preloaded registers into shadow registers */
    TIM2->EGR |= TIM_EGR_UG;

    /* 12. Enable the counter */
    TIM2->CR1 |= TIM_CR1_CEN;
}
```

int main(void)
{
    /* -------------------------------------------------------------
     * 1. GPIO Clock & Pin Configuration
     * ------------------------------------------------------------- */

    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN | RCC_AHB2ENR_GPIOBEN;

    /* PB10 (USART3_TX) and PB11 (USART3_RX) -> Alternate Function AF7 */
    GPIOB->MODER &= ~(GPIO_MODER_MODE10_Msk | GPIO_MODER_MODE11_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE10_Pos) | (2U << GPIO_MODER_MODE11_Pos);
    GPIOB->AFR[1] &= ~(GPIO_AFRH_AFSEL10_Msk | GPIO_AFRH_AFSEL11_Msk);
    GPIOB->AFR[1] |= (7U << GPIO_AFRH_AFSEL10_Pos) | (7U << GPIO_AFRH_AFSEL11_Pos);
    GPIOB->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED10_Pos) | (3U << GPIO_OSPEEDR_OSPEED11_Pos);

    /* PA2 (TIM2_CH3 - Heater PWM) -> Alternate Function AF1
     * Note: PB10 is occupied by USART3_TX, so TIM2_CH3 is mapped to PA2.
     */
    GPIOA->MODER &= ~GPIO_MODER_MODE2_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE2_Pos);
    GPIOA->AFR[0] &= ~GPIO_AFRL_AFSEL2_Msk;
    GPIOA->AFR[0] |= (1U << GPIO_AFRL_AFSEL2_Pos);
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED2_Pos);

    /* -------------------------------------------------------------
     * 2. USART3 Configuration (115200 baud, 8N1)
     * ------------------------------------------------------------- */
    /* Enable USART3 peripheral clock on APB1 */
    RCC->APB1ENR1 |= RCC_APB1ENR1_USART3EN;

     * Kernel clock = PCLK1 = 170 MHz, oversampling by 16:
     * USARTDIV = 170,000,000 / 115,200 = 1475.694 -> BRR = 1476 (0x05C4)
     * Actual baud rate = 115,176.15 baud (-0.02% error).

     * 3. TIM2 Channel 3 Configuration (5 kHz PWM, 80% Duty Cycle)

    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN;

    /* Prescaler = 0, ARR = 33999:
     * f_PWM = 170 MHz / ((0 + 1) * (33999 + 1)) = 5000 Hz (0% error)

    TIM2->PSC = 0U;
    TIM2->ARR = 33999U;

    /* Duty cycle = 80%:
     * CCR3 = 0.80 * (33999 + 1) = 27200 (0% error)

    TIM2->CCR3 = 27200U;

    /* Configure Channel 3 in PWM mode 1 (OC3M = 0110b) with preload enabled (OC3PE = 1) */
    TIM2->CCMR2 &= ~(TIM_CCMR2_CC3S_Msk | TIM_CCMR2_OC3M_Msk | TIM_CCMR2_OC3M_3);
    TIM2->CCMR2 |= (TIM_CCMR2_OC3M_1 | TIM_CCMR2_OC3M_2) | TIM_CCMR2_OC3PE;

    /* Output polarity active-high (CC3P = 0) and enable output (CC3E = 1) */
    TIM2->CCER &= ~TIM_CCER_CC3P;
    TIM2->CCER |= TIM_CCER_CC3E;

    TIM2->CR1 |= TIM_CR1_ARPE;

    TIM2->EGR |= TIM_EGR_UG;

    TIM2->CR1 |= TIM_CR1_CEN;

### Hardware & Configuration Explanation

1. **Pin Allocation & Conflict Resolution:**
   - **`PB10` / `PB11`**: Configured as Alternate Function 7 (`AF7`) to route `USART3_TX` on `PB10` and `USART3_RX` on `PB11` [STM32G474_Datasheet p.74].
   - **Conflict Resolution on PB10**: Because `PB10` is used by `USART3_TX`, assigning `TIM2_CH3` to `PB10` would cause a pin conflict (`DRC-PIN-01`). The timer channel was therefore routed to `PA2`, which carries `TIM2_CH3` on Alternate Function 1 (`AF1`) [STM32G474_Datasheet p.73].

2. **USART3 Timing & Settings:**
   - Powered from $f_{\text{PCLK1}} = 170\text{ MHz}$ via `RCC_APB1ENR1`.
   - With oversampling by 16 (`OVER8 = 0`), the divisor is $\text{USARTDIV} = 170\,000\,000 / 115\,200 \approx 1475.694$.
   - Writing `BRR = 1476` (`0x05C4`) sets the baud rate to $115\,176.15\text{ Baud}$ ($-0.02\%$ error) [STM32G474_RM0440 p.1755].
   - `BRR` is written prior to enabling `UE`, `TE`, and `RE` in `USART3->CR1` [STM32G474_RM0440 p.1740].

3. **TIM2 PWM Timing & Settings:**
   - Powered from APB1 timer clock $f_{\text{TIMCLK}} = 170\text{ MHz}$ via `RCC_APB1ENR1`.
   - Using $\text{PSC} = 0$ and $\text{ARR} = 33999$ yields exactly $f_{\text{PWM}} = 170\text{ MHz} / (1 \times 34000) = 5\text{ kHz}$.
   - Setting $\text{CCR3} = 27200$ sets the duty cycle to $27200 / 34000 = 80.0\%$.
   - Output compare 3 is configured in PWM mode 1 (`OC3M = 0110b`) with preload enabled (`OC3PE = 1`) [STM32G474_RM0440 p.1382] and active-high polarity (`CC3P = 0`, `CC3E = 1`) [STM32G474_RM0440 p.1385]. Preload transfers are triggered by `UG = 1` in `TIM2->EGR` before counter start (`CEN = 1`) [STM32G474_RM0440 p.1376].
