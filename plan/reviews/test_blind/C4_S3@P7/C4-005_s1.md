### STM32G474 Clock Configuration to 170 MHz (HSE PLL)

To configure the STM32G474 clock system to operate at $\text{SYSCLK} = \text{HCLK} = \text{PCLK1} = \text{PCLK2} = 170\text{ MHz}$ using an 8 MHz HSE crystal:

#### 1. Clock and Voltage Calculations
- **VCORE Voltage Scaling**: Operation at frequencies above 150 MHz up to 170 MHz requires Range 1 **Boost Mode** [STM32G474_RM0440 p.232]. Range 1 boost mode is selected by clearing the `R1MODE` bit in `PWR_CR5` (bit 8 = 0) [STM32G474_RM0440 p.267]. Clock gating for the power interface is first enabled via `RCC_APB1ENR1_PWREN` [STM32G474_RM0440 p.309].
- **Flash Latency**: In Range 1 Boost Mode, for $136\text{ MHz} < \text{HCLK} \le 170\text{ MHz}$, 4 wait states (5 CPU cycles access time, `FLASH_ACR_LATENCY_4WS`) are required [STM32G474_RM0440 p.98].
- **PLL Configuration**:
  - $f_{\text{IN}} = 8\text{ MHz}$ (HSE)
  - Division factor $M = 2 \implies f_{\text{VCO\_IN}} = 8\text{ MHz} / 2 = 4\text{ MHz}$ (allowed range: $2.66\text{ to }16\text{ MHz}$ [STM32G474_Datasheet p.123]). In `RCC_PLLCFGR`, value `0b0001` programs $M = 2$.
  - Multiplication factor $N = 85 \implies f_{\text{VCO}} = 4\text{ MHz} \times 85 = 340\text{ MHz}$ (allowed Range 1 VCO range: $96\text{ to }344\text{ MHz}$ [STM32G474_Datasheet p.123]).
  - Output division factor $R = 2 \implies f_{\text{PLL\_R}} = 340\text{ MHz} / 2 = 170\text{ MHz}$ (0.0% error against the target 170 MHz).
  - Main PLL output clock enable bit `PLLREN` is asserted.
- **Clock Switching Sequence (Transition State)**:
  - Per the reference manual [STM32G474_RM0440 p.233, p.279–280], when switching from HSE/HSI16 to the PLL with $\text{HCLK} > 80\text{ MHz}$ (and for $> 150\text{ MHz}$ boost mode entry):
    1. The AHB prescaler (`HPRE[3:0]`) is first set to divide SYSCLK by 2 (`HPRE_DIV2`, $170\text{ MHz} / 2 = 85\text{ MHz}$ intermediate HCLK).
    2. Switch SYSCLK to PLL (`SW = 0b11`) and poll `SWS` until locked.
    3. Wait at least $1\ \mu\text{s}$.
    4. Reconfigure `HPRE` to divide by 1 (`HPRE_DIV1`) to achieve $\text{HCLK} = 170\text{ MHz}$.
  - APB1 and APB2 prescalers remain at their reset value of 1 (`PPRE1 = 0b000`, `PPRE2 = 0b000`), yielding $\text{PCLK1} = 170\text{ MHz}$ and $\text{PCLK2} = 170\text{ MHz}$.

```c
#include "stm32g4xx.h"

void SystemClock_Config_170MHz(void)
{
    // 1. Enable power interface clock to configure voltage regulator
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    // 2. Select Range 1 Boost Mode (required for SYSCLK > 150 MHz, up to 170 MHz)
    // R1MODE = 0: Range 1 boost mode enabled
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    // 3. Configure Flash latency: 4 wait states required for 170 MHz in Range 1 boost mode
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;

    // 4. Enable HSE oscillator (8 MHz external crystal) and wait for stability
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY)) {
        // Wait until HSE is stable
    }

    // 5. Configure Main PLL:
    // Source: HSE (8 MHz)
    // M = 2  -> f_IN = 8 MHz / 2 = 4 MHz (PLLM = 0b0001)
    // N = 85 -> f_VCO = 4 MHz * 85 = 340 MHz
    // R = 2  -> f_PLL_R = 340 MHz / 2 = 170 MHz (PLLR = 0b00)
    // Enable PLLR clock output (PLLREN)
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1U << RCC_PLLCFGR_PLLM_Pos) |
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   RCC_PLLCFGR_PLLREN;

    // 6. Enable PLL and wait until it locks
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY)) {
        // Wait until PLL is locked
    }

    // 7. Transition state: Set AHB prescaler to /2 before switching to PLL (RM0440 p.233, p.279)
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    // 8. Select PLL as system clock source and wait for switch status
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
        // Wait until PLL is selected as SYSCLK
    }

    // 9. Wait at least 1 us in intermediate state (at 170 MHz / 2 = 85 MHz, 1 us is ~85 cycles)
    for (volatile int i = 0; i < 100; i++) {
        __NOP();
    }

    // 10. Reconfigure AHB prescaler to /1 to achieve full 170 MHz HCLK
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;
}
```

### Design Conflict & Resolution: Maximum Operating Frequency (170 MHz vs. 200 MHz)

1. **AHB and APB Clock Limits**: In the general operating conditions table [STM32G474_Datasheet p.84, Table 17], the maximum allowable frequencies for $f_{\text{HCLK}}$, $f_{\text{PCLK1}}$, and $f_{\text{PCLK2}}$ are all **170 MHz**. Operating at 200 MHz exceeds this maximum rating.

3. **Dynamic Voltage Scaling**: In the STM32G4 series reference manual [STM32G474_RM0440 p.232], Range 1 Boost mode specifies operation up to a maximum frequency of **170 MHz**.

**Resolution**: SYSCLK, HCLK, PCLK1, and PCLK2 are maintained at the maximum guaranteed operating frequency of **170 MHz**. At $f_{\text{TIM1CLK}} = 170\text{ MHz}$ and a target PWM frequency of $100\text{ kHz}$, a prescaler of $\text{PSC} = 0$ yields 1700 discrete duty cycle steps ($\approx 10.73\text{ bits}$ of resolution) with exactly **0.0% frequency error** and **0.0% duty cycle error**.

     * 3. HSE Oscillator Enable
     * ------------------------------------------------------------------------ */
    /* Enable HSE (8 MHz external crystal) and busy-wait until stable */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY)) {
        /* Wait for HSERDY flag */
    }

    /* ------------------------------------------------------------------------
     * 4. Main PLL Configuration & Activation
     * ------------------------------------------------------------------------
     * HSE = 8 MHz
     * PLLM = 2  -> f_IN = 8 MHz / 2 = 4 MHz (PLLM = 0b0001)
     * PLLN = 85 -> f_VCO = 4 MHz * 85 = 340 MHz (Range 1 VCO max = 344 MHz)
     * PLLR = 2  -> f_PLL_R = 340 MHz / 2 = 170 MHz (PLLR = 0b00)
     * PLLREN = 1: enable main PLL clock output

                   (1U << RCC_PLLCFGR_PLLM_Pos) |
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   RCC_PLLCFGR_PLLREN;

    /* Enable PLL and wait until locked */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY)) {
        /* Wait for PLLRDY flag */
    }

     * 5. System Clock Transition
     * ------------------------------------------------------------------------
     * Intermediate transition rule: set AHB prescaler to /2 before switching
     * to PLL, wait >= 1 us, then restore prescaler to /1.

### Explanation of Program Stages

1. **Voltage Range & Flash Latency**:
   - Operating at 170 MHz requires Range 1 **Boost Mode**, which is entered by clearing `R1MODE` in `PWR_CR5` [STM32G474_RM0440 p.267].
   - `FLASH_ACR_LATENCY_4WS` sets the Flash access wait states to 4 (5 CPU clock cycles access time), as required for frequencies above 136 MHz up to 170 MHz in Range 1 boost mode [STM32G474_RM0440 p.98].

2. **Clock Tree & 200 MHz Limitation**:
   - The STM32G474 absolute maximum frequency for $f_{\text{HCLK}}$, $f_{\text{PCLK1}}$, and $f_{\text{PCLK2}}$ is **170 MHz** [STM32G474_Datasheet p.84], and the maximum Range 1 PLL VCO frequency is **344 MHz** [STM32G474_Datasheet p.123]. Exceeding 170 MHz violates these physical hardware limits.
   - Using $M = 2$, $N = 85$, and $R = 2$ produces $f_{\text{VCO}} = 340\text{ MHz}$ and $f_{\text{PLL\_R}} = 170\text{ MHz}$ ($0.0\%$ error).
   - In accordance with the hardware transition sequence [STM32G474_RM0440 p.233, p.279], `HPRE` is temporarily configured to divide by 2 while switching system clocks before returning to divide by 1.

3. **Pin Multiplexing**:
   - `PA8` is multiplexed to Alternate Function 6 (`AF6`), which connects it to `TIM1_CH1` [STM32G474_Datasheet p.73].
   - Output speed is configured to Very High Speed (`OSPEEDR8 = 0b11`) for crisp switching edges.

4. **TIM1 PWM Generation**:
   - Since the APB2 prescaler is 1, the timer kernel clock equals the APB domain frequency: $\text{TIM1CLK} = \text{PCLK2} = 170\text{ MHz}$ [STM32G474_RM0440 p.281].
   - With prescaler $\text{PSC} = 0$, the auto-reload value is $\text{ARR} = 1699$, setting the period to exactly $10\ \mu\text{s}$ ($100\text{ kHz}$).
   - Setting $\text{CCR1} = 850$ establishes an exact $50.0\%$ duty cycle ($0.0\%$ frequency and duty cycle error), yielding 1700 discrete resolution steps ($\approx 10.73$ bits).
   - `TIM1` is an advanced control timer; setting `TIM1_BDTR_MOE` (Main Output Enable) is mandatory to connect the timer output logic to the physical package pin [STM32G474_RM0440 p.1267].
   - `TIM1_EGR_UG` transfers the preload registers immediately, and `TIM1_CR1_CEN` enables the counter.
