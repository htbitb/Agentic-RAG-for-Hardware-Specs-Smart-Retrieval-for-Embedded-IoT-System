### STM32G474 170 MHz Clock Configuration (HSE PLL)

#### 1. Clock Derivation and Operating Parameters
- **Crystal input**: HSE = 8.000000 MHz.
- **Voltage Range 1 Boost Mode**: The STM32G474 requires Voltage Scaling Range 1 Boost Mode (`PWR_CR5.R1MODE = 0`) to operate SYSCLK up to 170 MHz [STM32G474_RM0440 p.233, p.267]. In Range 1 normal mode, the maximum SYSCLK is 150 MHz [STM32G474_Datasheet p.123].
- **Flash Latency**: In Range 1 Boost Mode at 170 MHz, Table 9 specifies 4 wait states (`LATENCY = 4WS`, 5 CPU cycles) [STM32G474_RM0440 p.98].
- **PLL Configuration**:
  - Input clock: HSE = 8 MHz.
  - Division factor $M = 2$ (`PLLM[3:0] = 0001b` in `RCC_PLLCFGR`):
    $$f_{\text{VCO\_IN}} = \frac{8\text{ MHz}}{2} = 4\text{ MHz}$$
    Valid range is 2.66 MHz to 16 MHz [STM32G474_Datasheet p.123].
  - Multiplication factor $N = 85$ (`PLLN[6:0] = 85`):
    $$f_{\text{VCO}} = 4\text{ MHz} \times 85 = 340\text{ MHz}$$
    Valid range for Range 1 is 96 MHz to 344 MHz [STM32G474_Datasheet p.123].
  - Output division factor $R = 2$ (`PLLR[1:0] = 00b`, enabled with `PLLREN = 1`):
    $$f_{\text{PLL\_R}} = \frac{340\text{ MHz}}{2} = 170.000\text{ MHz}$$
    Exact frequency with 0.0% error.
  - Prescalers: AHB (HPRE = DIV1), APB1 (PPRE1 = DIV1), APB2 (PPRE2 = DIV1):
    $$\text{SYSCLK} = \text{HCLK} = \text{PCLK1} = \text{PCLK2} = 170\text{ MHz}$$
- **Intermediate Clock Switching Sequence**: RM0440 specifies that when switching from HSE/HSI16 to the PLL with HCLK > 80 MHz, an intermediate step dividing HCLK by 2 (`HPRE = DIV2`) must be used before switching SYSCLK, followed by at least 1 µs delay before setting HPRE back to DIV1 [STM32G474_RM0440 p.233, p.279].

#include "stm32g4xx.h"

void system_clock_config(void)
{
    /* 1. Enable power interface clock in RCC_APB1ENR1 to access PWR registers */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* 2. Switch to Range 1 Boost mode by clearing R1MODE bit in PWR_CR5 */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 3. Configure Flash latency: 4 wait states for 170 MHz in Range 1 Boost mode */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;

    /* 4. Enable HSE oscillator and wait for it to become ready */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY)) {
        /* Busy wait */
    }

    /* 5. Configure PLL:
     *    Source: HSE
     *    PLLM = 2  (0001b, /2 -> 4 MHz)
     *    PLLN = 85 (*85 -> 340 MHz VCO)
     *    PLLR = 2  (00b, /2 -> 170 MHz)
     *    Enable PLL "R" output (PLLREN)
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1U << RCC_PLLCFGR_PLLM_Pos) |
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   RCC_PLLCFGR_PLLREN;

    /* 6. Enable PLL and wait for PLLRDY */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY)) {
        /* Busy wait */
    }

    /* 7. Transition state: divide HCLK by 2 before switching to PLL > 80 MHz */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    /* 8. Select PLL as system clock source */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;

    /* 9. Wait until PLL is indicated as system clock */
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
        /* Busy wait */
    }

    /* 10. Wait >= 1 us transition delay, then restore AHB prescaler to DIV1 (170 MHz) */
    for (__IO uint32_t i = 0; i < 50; i++) {
        __NOP();
    }
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;
}

#### 1. Hardware, Pin Conflict, and Electrical Compatibility Analysis

1. **Pin Collision on PA9 (CONFLICT: PA9)**:
   - In **Message 2**, pin `PA9` was allocated to `USART1_TX` (AF7) [STM32G474_Datasheet p.73].
   - Assigning `PA9` to `I2C2_SCL` (AF4) creates a pin collision on `PA9`.
   - **Alternatives**:
     - *If USART1 is retained on the board*: `USART1_TX` can be remapped to `PB6` (AF7) or `PC4` (AF7) [STM32G474_Datasheet p.74, p.75], or `I2C2_SCL` can be routed to `PC4` (AF4) [STM32G474_Datasheet p.75] while keeping `PA9` for `USART1_TX`.
     - *If PA9 is dedicated to I2C2*: PA9 is configured as `I2C2_SCL` (AF4) in open-drain mode, superseding the previous USART1_TX allocation on PA9.

2. **Electrical Incompatibility (1.8 V sensor vs. 3.3 V STM32 I/O)**:
   - The pressure sensor I/O rail is 1.8 V.
   - The STM32G474 I/O pins are supplied at VDD = 3.3 V.
   - According to the STM32G474 DC characteristics, the minimum input high-level voltage is:
     $$V_{\text{IH, min}} = 0.7 \times V_{\text{DD}} = 0.7 \times 3.3\text{ V} = 2.31\text{ V}$$
     [STM32G474_Datasheet p.128].
   - The sensor powered at 1.8 V cannot generate a logic high reaching 2.31 V, violating the minimum high-level input threshold. In addition, connecting a 1.8 V device to pull-ups on a 3.3 V rail exceeds the sensor's maximum supply voltage rating.
   - **Resolution**: An open-drain bidirectional level translator (such as PCA9306) must be placed between the STM32 (3.3 V domain on pins PA8/PA9) and the sensor (1.8 V domain on SDA/SCL).

void i2c2_pressure_sensor_init(void)
{
    /* 1. Enable peripheral clock for GPIOA and I2C2 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_I2C2EN;

    /* 2. Configure PA8 (I2C2_SDA) and PA9 (I2C2_SCL) as Alternate Function (MODER = 10b) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE8_Msk | GPIO_MODER_MODE9_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE8_Pos) | (2U << GPIO_MODER_MODE9_Pos);

    /* 3. Configure PA8 and PA9 as Open-Drain (OTYPER bit = 1) */
    GPIOA->OTYPER |= (GPIO_OTYPER_OT8 | GPIO_OTYPER_OT9);

    /* 4. Enable internal pull-ups (external pull-ups on the level shifter lines are also required) */
    GPIOA->PUPDR &= ~(GPIO_PUPDR_PUPD8_Msk | GPIO_PUPDR_PUPD9_Msk);
    GPIOA->PUPDR |= (1U << GPIO_PUPDR_PUPD8_Pos) | (1U << GPIO_PUPDR_PUPD9_Pos);

    /* 5. Assign AF4 (I2C2) to PA8 and PA9 in GPIOA_AFRH */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL8_Pos) | (0xFU << GPIO_AFRH_AFSEL9_Pos));
    GPIOA->AFR[1] |= (4U << GPIO_AFRH_AFSEL8_Pos) | (4U << GPIO_AFRH_AFSEL9_Pos);

    /* 6. Ensure I2C2 peripheral is disabled before programming TIMINGR */
    I2C2->CR1 &= ~I2C_CR1_PE;

    /* 7. Configure I2C2_TIMINGR for Standard Mode 100 kHz with PCLK1 = 170 MHz:
     *    PRESC  = 16 (0x10) -> tPRESC = (16 + 1) * (1 / 170 MHz) = 100 ns
     *    SCLDEL = 4         -> tSCLDEL = 5 * 100 ns = 500 ns
     *    SDADEL = 2         -> tSDADEL = 2 * 100 ns = 200 ns
     *    SCLH   = 39 (0x27) -> tSCLH = 40 * 100 ns = 4.0 us
     *    SCLL   = 48 (0x30) -> tSCLL = 49 * 100 ns = 4.9 us
     */
    I2C2->TIMINGR = (0x10U << I2C_TIMINGR_PRESC_Pos) |
                    (4U << I2C_TIMINGR_SCLDEL_Pos) |
                    (2U << I2C_TIMINGR_SDADEL_Pos) |
                    (0x27U << I2C_TIMINGR_SCLH_Pos) |
                    (0x30U << I2C_TIMINGR_SCLL_Pos);

    /* 8. Enable I2C2 peripheral in controller mode */
    I2C2->CR1 |= I2C_CR1_PE;
}

    /* 4. Enable HSE oscillator and wait for it to become ready */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY)) {
        /* Busy wait */
    }

    /* 5. Configure PLL:
     *    Source: HSE (8 MHz)
     *    PLLM = 2  (/2 -> 4 MHz)
     *    PLLN = 85 (*85 -> 340 MHz VCO)
     *    PLLR = 2  (/2 -> 170 MHz)
     *    Enable PLL "R" output (PLLREN)
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1U << RCC_PLLCFGR_PLLM_Pos) |
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   RCC_PLLCFGR_PLLREN;

    /* 6. Enable PLL and wait for PLLRDY */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY)) {
        /* Busy wait */
    }

    /* 7. Transition state: divide HCLK by 2 before switching to PLL > 80 MHz */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    /* 8. Select PLL as system clock source */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;

    /* 9. Wait until PLL is indicated as system clock */
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
        /* Busy wait */
    }

    /* 10. Wait >= 1 us transition delay, then restore AHB prescaler to DIV1 (170 MHz) */
    for (volatile uint32_t i = 0; i < 50; i++) {
        __NOP();
    }
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;
}

void tim3_ch1_pwm_init(void)
{

    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM3EN;

     *    TIM3CLK = 170000000 Hz
     *    PSC = 3      -> f_CNT = 170000000 / (3 + 1) = 42500000 Hz
     *    ARR = 42499  -> f_PWM = 42500000 / (42499 + 1) = 1000 Hz
     *    CCR1 = 21250 -> Duty  = 21250 / 42500 = 50.0%

    TIM3->PSC = 3;

### Analysis of 180 MHz Request on STM32G474

#### 1. Hardware Limit Violations
The requested frequency of **180 MHz** for SYSCLK and HCLK cannot be configured because it exceeds multiple absolute hardware and operating limits specified by the manufacturer for the STM32G474:

1. **Maximum CPU / AHB / APB Clock Frequency ($f_{\text{HCLK}}$, $f_{\text{PCLK1}}$, $f_{\text{PCLK2}}$)**:
   - According to the STM32G474 general operating conditions, the maximum allowable internal AHB and APB bus clock frequency in Voltage Scaling Range 1 Boost Mode is **170 MHz** [STM32G474_Datasheet p.84, Table 17]:
     $$f_{\text{HCLK, max}} = 170\text{ MHz}, \quad f_{\text{PCLK1, max}} = 170\text{ MHz}, \quad f_{\text{PCLK2, max}} = 170\text{ MHz}$$
   - Section 7.2 of the Reference Manual similarly specifies: *"The maximum frequency of the AHB, APB1, and APB2 domains is 170 MHz"* [STM32G474_RM0440 p.272].
   - Running at 180 MHz exceeds this maximum rating.

2. **Maximum PLL VCO Frequency ($f_{\text{VCO\_OUT}}$)**:
   - With an 8 MHz HSE crystal and $M = 2$ ($f_{\text{IN}} = 4\text{ MHz}$), achieving 180 MHz at the PLL "R" output ($R = 2$) requires an $N$ multiplier of 90:
     $$f_{\text{VCO}} = 4\text{ MHz} \times 90 = 360\text{ MHz}$$
   - In Voltage Scaling Range 1, the maximum PLL VCO output frequency is **344 MHz** [STM32G474_Datasheet p.123, Table 46]:
     $$f_{\text{VCO\_OUT, max}} = 344\text{ MHz}$$
   - A VCO frequency of 360 MHz violates this parameter.

3. **Maximum PLL "R" Output Frequency ($f_{\text{PLL\_R\_OUT}}$)**:
   - The maximum rated frequency for $f_{\text{PLL\_R\_OUT}}$ in Range 1 Boost Mode is **170 MHz** [STM32G474_Datasheet p.123, Table 46].
