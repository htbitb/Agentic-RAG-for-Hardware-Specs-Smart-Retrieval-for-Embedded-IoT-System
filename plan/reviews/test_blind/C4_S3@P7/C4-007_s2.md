### Clock Tree Configuration to 168 MHz (HSE 24 MHz)

#### 1. Hardware Limits & Parameter Selection Conflict Resolution
- **PLL Input Clock Limit**:
  According to STM32G474 datasheet Table 46 [STM32G474_Datasheet p.123], the PLL input frequency $f_{\text{PLL\_IN}}$ must strictly be between **2.66 MHz and 16 MHz**.
  - The requested $PLLM = 1$ with a 24 MHz HSE input gives $f_{\text{PLL\_IN}} = \frac{24\text{ MHz}}{1} = 24\text{ MHz}$, which violates the maximum rating of 16 MHz (`CLOCK_LIMIT:PLL_IN`).
  - To resolve this while achieving the exact target $SYSCLK = 168\text{ MHz}$ and $VCO = 336\text{ MHz}$, $PLLM$ is set to **2** and $PLLN$ is set to **28** ($PLLR = 2$):
    $$f_{\text{PLL\_IN}} = \frac{24\text{ MHz}}{2} = 12\text{ MHz} \quad (2.66 \le 12 \le 16\text{ MHz})$$
    $$f_{\text{VCO}} = 12\text{ MHz} \times 28 = 336\text{ MHz} \quad (96 \le 336 \le 344\text{ MHz})$$
    $$f_{\text{PLL\_R}} = \frac{336\text{ MHz}}{2} = 168\text{ MHz}$$
  This decision was recorded in the Board State under decision **D1**.

- **Voltage Scaling & Boost Mode**:
  For $SYSCLK > 150\text{ MHz}$ (up to 170 MHz), the internal regulator must operate in **Range 1 Boost Mode** [STM32G474_RM0440 p.233].
  - The power controller clock is enabled (`RCC_APB1ENR1_PWREN`).
  - Bit `R1MODE` in `PWR_CR5` is cleared to 0 (`PWR_CR5_R1MODE = 0`) to activate Range 1 Boost Mode [STM32G474_RM0440 p.267].

- **Flash Read Access Latency**:
  According to RM0440 Table 9 [STM32G474_RM0440 p.98], for $V_{\text{CORE}}$ Range 1 boost mode and $136\text{ MHz} < HCLK \le 170\text{ MHz}$, Flash latency must be set to **4 wait states** (5 CPU cycles): `FLASH_ACR_LATENCY_4WS` (value `0x4`).

- **Prescalers**:
  - AHB Prescaler = 1 (`HPRE = 0000`, $HCLK = 168\text{ MHz}$)
  - APB1 Prescaler = 1 (`PPRE1 = 000`, $PCLK1 = 168\text{ MHz}$)
  - APB2 Prescaler = 1 (`PPRE2 = 000`, $PCLK2 = 168\text{ MHz}$)

#### 2. Bare-Metal C Implementation

```c
#include "stm32g4xx.h"

void SystemClock_Config(void)
{
    /* 1. Enable Power interface clock and configure Voltage Range 1 Boost Mode */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;
    PWR->CR5 &= ~PWR_CR5_R1MODE;  /* Clear R1MODE to enable Range 1 Boost mode for > 150 MHz */

    /* 2. Configure Flash latency: 4 WS (5 CPU cycles) for 168 MHz in Range 1 Boost mode */
    FLASH->ACR &= ~FLASH_ACR_LATENCY;
    FLASH->ACR |= FLASH_ACR_LATENCY_4WS;

    /* 3. Enable HSE oscillator (24 MHz) and wait for it to be ready */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY)) {
        /* Busy-wait until HSE is stable */
    }

    /* 4. Configure PLL:
     *    Source: HSE (24 MHz)
     *    PLLM = 2  -> f_PLL_IN = 12 MHz (within 2.66 to 16 MHz limit)
     *    PLLN = 28 -> f_VCO = 336 MHz (within 96 to 344 MHz Range 1 limit)
     *    PLLR = 2  -> f_PLL_R = 168 MHz
     *    Enable PLLR output
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1U << RCC_PLLCFGR_PLLM_Pos) |   /* PLLM = 2 (register field value = M - 1 = 1) */
                   (28U << RCC_PLLCFGR_PLLN_Pos) |  /* PLLN = 28 */
                   (0U << RCC_PLLCFGR_PLLR_Pos) |   /* PLLR = 2 (encoded as 00b) */
                   RCC_PLLCFGR_PLLREN;              /* Enable PLLCLK output */

    /* 5. Enable Main PLL and wait for PLLRDY flag */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY)) {
        /* Busy-wait until PLL is locked */
    }

    /* 6. Switch system clock to PLL and wait for switch status */
    RCC->CFGR &= ~RCC_CFGR_SW;
    RCC->CFGR |= RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
        /* Busy-wait until PLL is used as SYSCLK */
    }
}
```

### USART1 Configuration at 115200 Baud on PA9 / PA10

#### 1. Clock Source & Baud Rate Calculation
- **Clock Source**:
  At reset, bits `USART1SEL[1:0]` in `RCC_CCIPR` are `00b`, selecting **PCLK2** as the USART1 kernel clock [STM32G474_RM0440 p.324].
  With the configured clock tree ($SYSCLK = HCLK = PCLK2 = 168\text{ MHz}$), the USART1 kernel clock is $f_{\text{CK}} = 168\text{ MHz}$.

- **Oversampling & BRR Value**:
  The request specifies oversampling by 16 (`OVER8 = 0` in `USART_CR1`, which is the reset default) [STM32G474_RM0440 p.1740].
  According to RM0440 Section 40.5.7 [STM32G474_RM0440 p.1707]:
  $$\text{USARTDIV} = \frac{f_{\text{CK}}}{\text{Baud}} = \frac{168\,000\,000}{115\,200} \approx 1458.3333$$
  For `OVER8 = 0`, the baud rate register directly takes $\text{USARTDIV}$ rounded to the nearest integer [STM32G474_RM0440 p.1708]:
  $$\text{BRR} = 1458 \quad (\text{0x05B2})$$
  Resulting actual baud rate:
  $$\text{Baud}_{\text{actual}} = \frac{168\,000\,000}{1458} \approx 115\,226.34\text{ baud}$$
  $$\text{Error} = \frac{115\,226.34 - 115\,200}{115\,200} \times 100\% = +0.0229\%$$
  This error is well within the required $\pm 2\%$ tolerance.

#### 2. Pin Multiplexing & Alternate Functions
According to STM32G474 Datasheet Table 13 [STM32G474_Datasheet p.73]:
- **PA9**: Alternate Function **AF7** maps to `USART1_TX`.
- **PA10**: Alternate Function **AF7** maps to `USART1_RX`.

To configure:
- `RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN`: Enable GPIOA clock [STM32G474_RM0440 p.306].
- `RCC->APB2ENR |= RCC_APB2ENR_USART1EN`: Enable USART1 clock [STM32G474_RM0440 p.312].
- `GPIOA->MODER`: Set pins 9 and 10 to Alternate Function mode (`10b`).
- `GPIOA->AFR[1]` (`AFRH`): Set `AFSEL9[3:0] = 7` (bits 7:4) and `AFSEL10[3:0] = 7` (bits 11:8).

#### 3. Framing Configuration & Enable Order
- **Word Length & Parity**: 8 data bits and no parity (`M[1:0] = 00b`, `PCE = 0` in `USART_CR1`, reset defaults).
- **Stop Bits**: 1 stop bit (`STOP[1:0] = 00b` in `USART_CR2`, reset default).
- **Register Write Order**:
  As required, `USART1->BRR` is written first before enabling `USART1->CR1`.
  Writing `USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE` enables transmitter, receiver, and peripheral simultaneously [STM32G474_RM0440 p.1740].

### Bare-Metal C Implementation

```c
#include "stm32g4xx.h"

void USART1_Init(void)
{
    /* 1. Enable peripheral clock for GPIOA (AHB2) and USART1 (APB2) */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PA9 (TX) and PA10 (RX) to Alternate Function mode (MODER = 10b) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE9 | GPIO_MODER_MODE10);
    GPIOA->MODER |= (GPIO_MODER_MODE9_1 | GPIO_MODER_MODE10_1);

    /* 3. Route AF7 (USART1) to PA9 and PA10 in AFRH (AFR[1]) */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= ((7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos));

    /* 4. Configure Baud Rate:
     *    USART1 kernel clock = PCLK2 = 168 MHz (RCC_CCIPR.USART1SEL = 00b reset default)
     *    Oversampling by 16 (USART_CR1.OVER8 = 0 reset default)
     *    USARTDIV = 168,000,000 / 115,200 = 1458.3333 -> BRR = 1458 (0x05B2)
     *    Actual baud = 115,226.34 (+0.023 % error, well within +/- 2 %)
     *    BRR is programmed before enabling the USART (UE).
     */
    USART1->BRR = 1458U;

    /* 5. Enable Transmitter (TE), Receiver (RE), and USART (UE):
     *    - 8 data bits: M[1:0] = 00b (reset default)
     *    - No parity: PCE = 0 (reset default)
     *    - 1 stop bit: STOP[1:0] = 00b in USART1->CR2 (reset default)
     *    - Oversampling by 16: OVER8 = 0 (reset default)
     */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
```

### Explanation of the Implementation

1. **Voltage Scaling & Flash Latency**:
   - For operation above 150 MHz up to 170 MHz, the core regulator must be in **Range 1 Boost Mode** [STM32G474_RM0440 p.233]. We enable the `PWR` peripheral clock in `RCC->APB1ENR1` and clear `R1MODE` in `PWR->CR5` [STM32G474_RM0440 p.267].
   - At 168 MHz in Range 1 Boost Mode, Flash memory access requires **4 wait states** (5 CPU cycles) [STM32G474_RM0440 p.98], configured via `FLASH->ACR |= FLASH_ACR_LATENCY_4WS`.

2. **HSE & PLL Configuration**:
   - The HSE oscillator (24 MHz) is started by setting `RCC_CR_HSEON` and waited on until `RCC_CR_HSERDY` is asserted.
   - To adhere to the hardware specification $2.66\text{ MHz} \le f_{\text{PLL\_IN}} \le 16\text{ MHz}$ [STM32G474_Datasheet p.123], PLLM is set to 2 ($f_{\text{PLL\_IN}} = 12\text{ MHz}$) and PLLN to 28, keeping $VCO = 336\text{ MHz}$ within the Range 1 VCO limits (96 to 344 MHz) and generating $SYSCLK = \frac{336}{2} = 168\text{ MHz}$ with $PLLR = 2$ (recorded in decision **D1**).
   - Once PLL locks (`RCC_CR_PLLRDY`), SYSCLK is switched to PLL (`SW = 11b`) and confirmed via `SWS`.

3. **GPIO Pin Multiplexing**:
   - Clocks for GPIOA and USART1 are enabled via `RCC->AHB2ENR` and `RCC->APB2ENR`.
   - PA9 and PA10 are configured to Alternate Function mode (`MODER = 10b`) and mapped to **AF7** (`USART1_TX` and `USART1_RX`) in `GPIOA->AFR[1]` (`AFRH`) [STM32G474_Datasheet p.73].

4. **USART1 Baud Rate & Activation**:
   - USART1 kernel clock is PCLK2 = 168 MHz by default (`RCC_CCIPR.USART1SEL = 00b`) [STM32G474_RM0440 p.324].
   - With oversampling by 16 (`OVER8 = 0`), $\text{USARTDIV} = \frac{168\,000\,000}{115\,200} \approx 1458.3333$, giving $\text{BRR} = 1458$ (`0x05B2`), yielding an actual baud rate of 115,226.34 baud (+0.023% error).
   - `USART1->BRR` is written prior to writing `USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE`, activating the receiver, transmitter, and peripheral.
