### TIM4 PWM Configuration (PB6 / PB7) on STM32G474

To generate the two edge-aligned PWM signals at 10 kHz with active-high polarity:
- **TIM4_CH1 on PB6**: 30% duty cycle
- **TIM4_CH2 on PB7**: 60% duty cycle

#### 1. Pin Multiplexing & Alternate Functions
According to the alternate function mapping [STM32G474_Datasheet p.74]:
- **PB6**: Alternate Function 2 (`AF2`) connects to `TIM4_CH1`.
- **PB7**: Alternate Function 2 (`AF2`) connects to `TIM4_CH2`.

Both pins are configured in alternate function mode (`MODER = 10b`) via `GPIOB->MODER` [STM32G474_RM0440 p.355] and mapped to AF2 in `GPIOB->AFR[0]` (`AFRL`) [STM32G474_RM0440 p.359].

#### 2. Timer Clock and Frequency Calculations
- The timer clock for APB1 timers (including TIM4) is $f_{\text{TIM}} = 170\text{ MHz}$ (since APB1 prescaler = 1, $f_{\text{TIMCLK}} = f_{\text{PCLK1}} = 170\text{ MHz}$).
- For edge-aligned upcounting PWM mode 1:
  $$f_{\text{PWM}} = \frac{f_{\text{TIM}}}{(\text{PSC} + 1) \times (\text{ARR} + 1)}$$
  Selecting $\text{PSC} = 0$:
  $$\text{ARR} + 1 = \frac{170\,000\,000}{10\,000} = 17\,000 \implies \text{ARR} = 16999$$
- Duty cycle formula:
  $$\text{Duty} = \frac{\text{CCR}}{\text{ARR} + 1}$$
  - For Channel 1 (30% duty): $\text{CCR1} = 0.30 \times 17000 = 5100$
  - For Channel 2 (60% duty): $\text{CCR2} = 0.60 \times 17000 = 10200$

#### 3. PWM Mode Configuration
- In `TIM4->CCMR1` [STM32G474_RM0440 p.1379]:
  - `OC1M = 0110b` (PWM mode 1: active while `CNT < CCR1`, inactive otherwise).
  - `OC1PE = 1` (Output Compare 1 preload enabled).
  - `OC2M = 0110b` (PWM mode 1: active while `CNT < CCR2`, inactive otherwise).
  - `OC2PE = 1` (Output Compare 2 preload enabled).
- In `TIM4->CCER` [STM32G474_RM0440 p.1385]:
  - `CC1E = 1`, `CC1P = 0` (Active high output enabled on CH1).
  - `CC2E = 1`, `CC2P = 0` (Active high output enabled on CH2).
- In `TIM4->CR1` [STM32G474_RM0440 p.1366]:
  - `ARPE = 1` (Auto-reload preload enabled).
  - `CEN = 1` (Counter enable).
- An update event is generated via `TIM4->EGR = TIM_EGR_UG` [STM32G474_RM0440 p.1376] to pre-load the register values before starting the counter. TIM4 is a general-purpose timer without complementary dead-time control (no `BDTR` / `MOE` register required).

### Bare-Metal C Code

```c
#include "stm32g4xx.h"

void tim4_pwm_init(void) {
    /* 1. Enable peripheral clocks for GPIOB and TIM4 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM4EN;

    /* 2. Configure PB6 and PB7 as Alternate Function mode (AF2) */
    GPIOB->MODER &= ~(GPIO_MODER_MODE6_Msk | GPIO_MODER_MODE7_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE6_Pos) | (2U << GPIO_MODER_MODE7_Pos);

    /* Assign AF2 (TIM4_CH1 on PB6, TIM4_CH2 on PB7) in AFRL */
    GPIOB->AFR[0] &= ~((0xFU << GPIO_AFRL_AFSEL6_Pos) | (0xFU << GPIO_AFRL_AFSEL7_Pos));
    GPIOB->AFR[0] |= (2U << GPIO_AFRL_AFSEL6_Pos) | (2U << GPIO_AFRL_AFSEL7_Pos);

    /* 3. Configure TIM4 time base for 10 kHz PWM with 170 MHz timer clock */
    TIM4->PSC = 0;
    TIM4->ARR = 16999;

    /* 4. Set duty cycles: 30% on CH1, 60% on CH2 */
    TIM4->CCR1 = 5100;
    TIM4->CCR2 = 10200;

    /* 5. Set PWM mode 1 (OCxM = 6) and enable preload for both channels */
    TIM4->CCMR1 &= ~(TIM_CCMR1_CC1S | TIM_CCMR1_OC1M | TIM_CCMR1_CC2S | TIM_CCMR1_OC2M);
    TIM4->CCMR1 |= (6U << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE
                | (6U << TIM_CCMR1_OC2M_Pos) | TIM_CCMR1_OC2PE;

    /* 6. Enable channel outputs with active-high polarity */
    TIM4->CCER &= ~(TIM_CCER_CC1P | TIM_CCER_CC2P);
    TIM4->CCER |= TIM_CCER_CC1E | TIM_CCER_CC2E;

    /* 7. Enable Auto-reload preload and generate an update event to latch settings */
    TIM4->CR1 |= TIM_CR1_ARPE;
    TIM4->EGR = TIM_EGR_UG;

    /* 8. Enable TIM4 counter */
    TIM4->CR1 |= TIM_CR1_CEN;
}
```

The configuration has been verified through Clang syntax/semantic compilation checks and hardware register simulation, confirming PB6 and PB7 active PWM output generation at exactly 10,000 Hz, with 30.0% and 60.0% duty cycle respectively.

### Pin Allocation Conflict and Resolution

#### 1. Detected Conflict
In Message 1, pins **PB6** and **PB7** were assigned to **TIM4_CH1** (PWM 10 kHz, 30% duty) and **TIM4_CH2** (PWM 10 kHz, 60% duty).
Assigning `USART1_TX` to PB6 and `USART1_RX` to PB7 creates a pin collision (`CONFLICT: PB6, PB7`), as a microcontroller pin cannot simultaneously output a timer PWM signal and serve as a USART transceiver line.

#### 2. Selected Alternative (Decision D1)
- On the STM32G474 (LQFP64 package), the primary alternate function pins for USART1 are:
  - **PA9**: Alternate Function 7 (`AF7` = `USART1_TX`), Pin 43 [STM32G474_Datasheet p.73].
  - **PA10**: Alternate Function 7 (`AF7` = `USART1_RX`), Pin 44 [STM32G474_Datasheet p.73].
- Both PA9 and PA10 are free, 5V-tolerant (`FT_fda`), and preserve the ongoing TIM4 PWM operation on PB6 and PB7.

### USART1 Configuration & Baud Rate Derivation

- **Clock Source**: USART1 is on APB2 (`RCC_APB2ENR_USART1EN`). By default in `RCC_CCIPR`, `USART1SEL = 00b`, selecting `PCLK2` ($f_{\text{PCLK2}} = 170\text{ MHz}$) as the kernel clock [STM32G474_RM0440 p.322].
- **Oversampling**: Oversampling by 16 (`OVER8 = 0` in `USART_CR1`).
- **Baud Rate Calculation** [STM32G474_RM0440 p.1708]:
  $$\text{USARTDIV} = \frac{f_{\text{CK}}}{\text{Baud}} = \frac{170\,000\,000}{115\,200} \approx 1475.6944$$
  Rounding to the nearest integer for `USART_BRR`:
  $$\text{BRR} = 1476 \quad (0\text{x}05\text{C}4)$$
  Resulting actual baud rate:
  $$\text{Baud}_{\text{actual}} = \frac{170\,000\,000}{1476} \approx 115\,176.15\text{ baud}$$
  Error:
  $$\text{Error} = \frac{115\,176.15 - 115\,200}{115\,200} \approx -0.021\%$$
  This is well within the required $\pm 2\%$ tolerance.
- **Frame Format**:
  - 8 data bits: `M[1:0] = 00b` (`M0 = 0`, `M1 = 0` in `USART_CR1`) [STM32G474_RM0440 p.1744].
  - Parity disabled: `PCE = 0` in `USART_CR1`.
  - 1 stop bit: `STOP[1:0] = 00b` in `USART_CR2` (reset value = `00b`) [STM32G474_RM0440 p.1747].
  - Enable Transmitter (`TE = 1`), Receiver (`RE = 1`), and USART (`UE = 1`) after setting `BRR` [STM32G474_RM0440 p.1740].

int main(void) {
    /* 1. Enable peripheral clocks in RCC */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN | RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM4EN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PB6 (TIM4_CH1) and PB7 (TIM4_CH2) as Alternate Function 2 (AF2) */
    GPIOB->MODER &= ~(GPIO_MODER_MODE6_Msk | GPIO_MODER_MODE7_Msk);
    GPIOB->MODER |= (2U << GPIO_MODER_MODE6_Pos) | (2U << GPIO_MODER_MODE7_Pos);

    GPIOB->AFR[0] &= ~((0xFU << GPIO_AFRL_AFSEL6_Pos) | (0xFU << GPIO_AFRL_AFSEL7_Pos));
    GPIOB->AFR[0] |= (2U << GPIO_AFRL_AFSEL6_Pos) | (2U << GPIO_AFRL_AFSEL7_Pos);

    /* 3. Configure PA9 (USART1_TX) and PA10 (USART1_RX) as Alternate Function 7 (AF7) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= (7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos);

    /* 4. Configure TIM4 for 10 kHz edge-aligned PWM mode 1
     *    f_TIM4CLK = 170 MHz (APB1 prescaler = 1)
     *    ARR = 170 MHz / 10 kHz - 1 = 16999
     *    CCR1 = 30% of 17000 = 5100
     *    CCR2 = 60% of 17000 = 10200

    TIM4->ARR = 16999;
    TIM4->CCR1 = 5100;
    TIM4->CCR2 = 10200;

    TIM4->CCER &= ~(TIM_CCER_CC1P | TIM_CCER_CC2P);
    TIM4->CCER |= TIM_CCER_CC1E | TIM_CCER_CC2E;

    TIM4->CR1 |= TIM_CR1_ARPE;
    TIM4->EGR = TIM_EGR_UG;
    TIM4->CR1 |= TIM_CR1_CEN;

    /* 5. Configure USART1 for 115200 baud, 8N1, oversampling by 16

     *    BRR = 170000000 / 115200 = 1476 (actual: 115176 baud, -0.02% error)

    /* Enable transmitter (TE), receiver (RE), and USART peripheral (UE) */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;

    /* 6. Main loop */
    while (1) {
    }

### Explanation of Operation

1. **Clock Enable**:
   - `RCC->AHB2ENR` enables the GPIO clocks for `GPIOA` and `GPIOB` [STM32G474_RM0440 p.306].
   - `RCC->APB1ENR1` enables the timer clock for `TIM4` [STM32G474_RM0440 p.309].
   - `RCC->APB2ENR` enables the clock for `USART1` [STM32G474_RM0440 p.312].

2. **GPIO Configuration**:
   - **PB6 & PB7**: Configured in alternate function mode (`MODER = 10b`) and mapped to `AF2` in `GPIOB->AFR[0]` (`AFRL`), connecting them to `TIM4_CH1` and `TIM4_CH2` [STM32G474_Datasheet p.74].
   - **PA9 & PA10**: Configured in alternate function mode (`MODER = 10b`) and mapped to `AF7` in `GPIOA->AFR[1]` (`AFRH`), connecting them to `USART1_TX` and `USART1_RX` [STM32G474_Datasheet p.73].

3. **TIM4 PWM Setup**:
   - With $f_{\text{TIM4CLK}} = 170\text{ MHz}$, $\text{PSC} = 0$, and $\text{ARR} = 16999$, the timer period is exactly $(16999 + 1) / 170\text{ MHz} = 100\ \mu\text{s}$ ($10\text{ kHz}$).
   - `CCR1 = 5100` gives $5100 / 17000 = 30.0\%$ duty cycle.
   - `CCR2 = 10200` gives $10200 / 17000 = 60.0\%$ duty cycle.
   - Setting `OC1M = 6` and `OC2M = 6` selects PWM mode 1 (output active when counter `< CCRx`).
   - `ARPE` and `OCxPE` preload registers ensure glitch-free updates, latched via `TIM4->EGR = TIM_EGR_UG` before enabling the timer via `CEN`.

4. **USART1 Configuration**:
   - With $f_{\text{PCLK2}} = 170\text{ MHz}$ and oversampling by 16 (`OVER8 = 0`), writing `BRR = 1476` sets the baud rate to $170\,000\,000 / 1476 \approx 115\,176.15\text{ baud}$ ($-0.02\%$ error, well within $\pm 2\%$) [STM32G474_RM0440 p.1708].
   - Writing `USART_CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE` keeps the frame format at 8 data bits, 1 stop bit, no parity, and activates both transmitter and receiver after `BRR` is configured [STM32G474_RM0440 p.1755].
