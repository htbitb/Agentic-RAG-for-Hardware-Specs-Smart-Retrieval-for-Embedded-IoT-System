### Clock Tree Configuration to 170 MHz (STM32G474)

To operate the STM32G474 at its maximum core frequency of $170\text{ MHz}$ [STM32G474_Datasheet p.84] from an $8\text{ MHz}$ HSE crystal, the system requires entering **Range 1 Boost Mode**, programming the required Flash read latency, and setting up the main PLL.

#### 1. Parameter Derivations & Constraints
- **VCORE Voltage Range 1 Boost Mode**: In default Range 1 normal mode, SYSCLK is limited to $150\text{ MHz}$ [STM32G474_Datasheet p.123]. To operate up to $170\text{ MHz}$, Range 1 Boost mode must be activated by clearing the `R1MODE` bit in `PWR_CR5` (bit 8 = 0) [STM32G474_RM0440 p.232, p.267]. The PWR peripheral clock must first be enabled via `RCC_APB1ENR1_PWREN` [STM32G474_RM0440 p.309].
- **Frequency Switching Sequence**: As specified in the reference manual [STM32G474_RM0440 p.233], before switching to a frequency $>150\text{ MHz}$, HCLK is prescaled (divided by 2 via `HPRE` in `RCC_CFGR`), boost mode is enabled, wait states adjusted, PLL selected as system clock, and then the prescaler is restored to 1.
- **Flash Latency**: In Range 1 Boost mode with $\text{HCLK} = 170\text{ MHz}$ ($136 < \text{HCLK} \le 170\text{ MHz}$), the required Flash read access latency is **4 wait states (5 CPU cycles)** (`FLASH_ACR_LATENCY_4WS`) [STM32G474_RM0440 p.98].
- **PLL Configuration**:
  - $f_{\text{IN}} = 8\text{ MHz}$ (HSE crystal) [STM32G474_Datasheet p.117].
  - $\text{PLLM} = 2 \implies f_{\text{PLL\_IN}} = 8\text{ MHz} / 2 = 4\text{ MHz}$ (within the allowable range $2.66\text{ MHz} \le f_{\text{PLL\_IN}} \le 16\text{ MHz}$) [STM32G474_Datasheet p.123]. In register `RCC_PLLCFGR`, value `1` corresponds to division by 2 (`PLLM[3:0] = 0001b`) [STM32G474_RM0440 p.291].
  - $\text{PLLN} = 85 \implies f_{\text{VCO}} = 4\text{ MHz} \times 85 = 340\text{ MHz}$ (within the allowable VCO range $96\text{ MHz} \le f_{\text{VCO}} \le 344\text{ MHz}$) [STM32G474_Datasheet p.123].
  - $\text{PLLR} = 2 \implies f_{\text{SYSCLK}} = 340\text{ MHz} / 2 = 170\text{ MHz}$ (exact $170.000\text{ MHz}$, error $0.0\% \le 0.1\%$). In `RCC_PLLCFGR`, `PLLR[1:0] = 00b` corresponds to division by 2, and `PLLREN` (bit 24) enables the PLL 'R' output [STM32G474_RM0440 p.291].
- **Bus Prescalers**: AHB, APB1, and APB2 prescalers are configured to division factor 1, resulting in:
  $$\text{SYSCLK} = \text{HCLK} = \text{PCLK1} = \text{PCLK2} = 170\text{ MHz}$$

### Bare-Metal CMSIS C Code

```c
#include "stm32g4xx.h"

void system_clock_config(void)
{
    /* 1. Enable PWR peripheral clock */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* 2. Divide HCLK by 2 temporarily before entering boost mode / switching above 150 MHz */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    /* 3. Enable Range 1 boost mode: clear R1MODE bit in PWR_CR5 */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 4. Configure Flash latency: 4 WS (5 CPU cycles) required for 170 MHz in Range 1 Boost */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY) != FLASH_ACR_LATENCY_4WS);

    /* 5. Enable HSE oscillator and wait for it to stabilize */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY));

    /* 6. Configure PLL:
     * Source: HSE (8 MHz)
     * PLLM: /2 -> 4 MHz VCO input (valid: 2.66 - 16 MHz)
     * PLLN: x85 -> 340 MHz VCO output (valid: 96 - 344 MHz)
     * PLLR: /2 -> 170 MHz SYSCLK
     * Enable PLLR output
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1U << RCC_PLLCFGR_PLLM_Pos) | /* PLLM = 2 (register field value 1) */
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   (0U << RCC_PLLCFGR_PLLR_Pos) | /* PLLR = 2 (register field value 0) */
                   RCC_PLLCFGR_PLLREN;

    /* 7. Enable PLL and wait for lock */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY));

    /* 8. Switch system clock to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL);

    /* 9. Restore AHB prescaler to 1 to reach 170 MHz HCLK */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;

    /* Ensure APB1 and APB2 prescalers are 1 (division factor 1 / reset default) */
    RCC->CFGR &= ~(RCC_CFGR_PPRE1 | RCC_CFGR_PPRE2);
}
```

### USART1 Debug Serial Port Configuration (115200 Baud, PA9/PA10)

This configuration enables and configures **USART1** as a debug serial interface on STM32G474.

#### 1. Pin Multiplexing & Alternate Functions
- **PA9** carries **USART1_TX** mapped to **AF7** [STM32G474_Datasheet p.73].
- **PA10** carries **USART1_RX** mapped to **AF7** [STM32G474_Datasheet p.73].
- The GPIO port A clock is enabled via `RCC_AHB2ENR_GPIOAEN` [STM32G474_RM0440 p.306].
- PA9 and PA10 are configured in Alternate Function mode (`MODER[1:0] = 10b`) in `GPIOA_MODER` [STM32G474_RM0440 p.355] and assigned alternate function AF7 (`AFRH9 = 7`, `AFRH10 = 7`) in `GPIOA_AFRH` [STM32G474_RM0440 p.360].

#### 2. Clock Source & Baud Rate Calculation
- **USART1 Clock Source**: By default, in register `RCC_CCIPR`, field `USART1SEL[1:0] = 00b`, which selects **PCLK2** as the USART1 kernel clock [STM32G474_RM0440 p.322].
- With the system clock configuration from Message 1, $f_{\text{PCLK2}} = 170\text{ MHz}$.
- **Oversampling by 16**: Bit `OVER8 = 0` in `USART1_CR1` [STM32G474_RM0440 p.1740].
- **Baud Rate Formula**: As defined in the reference manual [STM32G474_RM0440 p.1707]:
  $$\text{USARTDIV} = \frac{f_{\text{CK}}}{\text{Baud}} = \frac{170{,}000{,}000}{115{,}200} \approx 1475.6944$$
  Rounding to the nearest integer gives:
  $$\text{BRR} = 1476 \quad (0\text{x}05\text{C}4)$$
  The resulting baud rate is:
  $$\text{Baud}_{\text{actual}} = \frac{170{,}000{,}000}{1476} \approx 115{,}176.15\text{ baud} \quad (\text{error} = -0.021\%)$$
  which is well within standard UART tolerance ($\pm 2\%$). The value is written to `USART1_BRR` [STM32G474_RM0440 p.1755].

#### 3. Framing & Sequence Requirements
- **Data Bits**: 8 data bits: bits `M1` and `M0` in `USART1_CR1` are cleared to 0 [STM32G474_RM0440 p.1740].
- **Parity**: Disabled (`PCE = 0` in `USART1_CR1`) [STM32G474_RM0440 p.1740].
- **Stop Bits**: 1 stop bit (`STOP[1:0] = 00b` in `USART1_CR2`) [STM32G474_RM0440 p.1747].
- **Writing BRR before enabling USART**:
  `USART1->BRR` is programmed while `USART1->CR1` has bit `UE = 0`. Both transmitter (`TE`) and receiver (`RE`) are enabled, followed by setting the USART enable bit (`UE`) [STM32G474_RM0440 p.1740].

```c
#include "stm32g4xx.h"

void usart1_debug_init(void)
{
    /* 1. Enable peripheral clocks for GPIOA and USART1 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PA9 (TX) and PA10 (RX) as Alternate Function AF7 (USART1) */
    GPIOA->MODER = (GPIOA->MODER & ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk))
                 | (2U << GPIO_MODER_MODE9_Pos)
                 | (2U << GPIO_MODER_MODE10_Pos);

    GPIOA->AFR[1] = (GPIOA->AFR[1] & ~(GPIO_AFRH_AFSEL9_Msk | GPIO_AFRH_AFSEL10_Msk))
                  | (7U << GPIO_AFRH_AFSEL9_Pos)
                  | (7U << GPIO_AFRH_AFSEL10_Pos);

    /* 3. Ensure USART1 is disabled before configuring parameters (UE = 0) */
    USART1->CR1 = 0;
    USART1->CR2 = 0;
    USART1->CR3 = 0;

    /* 4. Write baud rate register BEFORE enabling the USART:
     * Clock source = PCLK2 = 170 MHz (RCC_CCIPR default USART1SEL = 00)
     * OVER8 = 0 (oversampling by 16)
     * BRR = 170000000 / 115200 = 1475.694 -> 1476 (0x5C4)
     * Actual baud = 115176 baud (-0.02% error)
     */
    USART1->BRR = 1476U;

    /* 5. Enable transmitter (TE) and receiver (RE) */
    USART1->CR1 |= (USART_CR1_TE | USART_CR1_RE);

    /* 6. Enable USART1 (UE = 1) */
    USART1->CR1 |= USART_CR1_UE;
}
```

### Hardware Conflict & Level Incompatibility Analysis

#### 1. Pin Conflict on PA9
- In Message 2, pin `PA9` was allocated to **`USART1_TX` (AF7)** [STM32G474_Datasheet p.73].
- Message 3 requested `PA9` for `I2C2_SCL`. Reallocating `PA9` causes a pin conflict (`CONFLICT:PA9`) [STM32G474_Datasheet p.66] and would break the debug serial interface.
- **Alternative Chosen (Decision D1)**:
  - On the STM32G474 LQFP64 package (pin 22), **`PC4`** supports alternate function **AF4 (`I2C2_SCL`)** [STM32G474_Datasheet p.60, p.75].
  - Pin **`PA8`** supports alternate function **AF4 (`I2C2_SDA`)** [STM32G474_Datasheet p.73].
  - Allocating `PC4` for SCL and `PA8` for SDA keeps `USART1_TX` operational on `PA9`.

#### 2. Electrical Level Incompatibility (1.8 V Sensor vs 3.3 V MCU)
- The pressure sensor I/O rail is $1.8\text{ V}$, while the STM32G474 operates at $V_{\text{DD}} = 3.3\text{ V}$.
- On the STM32G474, the minimum high-level input voltage is:
  $$V_{\text{IH, min}} = 0.7 \times V_{\text{DD}} = 0.7 \times 3.3\text{ V} = 2.31\text{ V} \quad [\text{STM32G474_Datasheet p.128}]$$
- Because a $1.8\text{ V}$ signal cannot drive above $2.31\text{ V}$ ($V_{\text{OH, min}} = 1.4\text{ V} < V_{\text{IH, min}} = 2.31\text{ V}$), a direct connection fails logic-level margins.
- **Solution**: A bidirectional open-drain level shifter (e.g. PCA9306) is placed between the $1.8\text{ V}$ sensor bus and the $3.3\text{ V}$ STM32 bus. Both `PC4` and `PA8` are 5 V-tolerant (`FT`) I/Os [STM32G474_Datasheet p.60, p.73].

### I2C2 Timing Register Derivation (100 kHz Standard Mode)

- **Kernel Clock**: $f_{\text{I2CCLK}} = f_{\text{PCLK1}} = 170\text{ MHz}$ [STM32G474_RM0440 p.322].

  - `PRESC = 15` ($0\text{xF}$): prescales the clock by $(15 + 1) = 16$:
    $$t_{\text{PRESC}} = \frac{16}{170\text{ MHz}} \approx 94.118\text{ ns}$$
  - `SCLDEL = 4` ($0\text{x}4$): data setup delay:
    $$t_{\text{SCLDEL}} = (4 + 1) \times t_{\text{PRESC}} \approx 470.59\text{ ns}$$
  - `SDADEL = 3` ($0\text{x}3$): data hold delay:
    $$t_{\text{SDADEL}} = 3 \times t_{\text{PRESC}} \approx 282.35\text{ ns}$$
  - `SCLH = 51` ($0\text{x}33$): SCL high period:
    $$t_{\text{SCLH}} = (51 + 1) \times t_{\text{PRESC}} \approx 4894.12\text{ ns}$$
  - `SCLL = 53` ($0\text{x}35$): SCL low period:
    $$t_{\text{SCLL}} = (53 + 1) \times t_{\text{PRESC}} \approx 5082.35\text{ ns}$$
  - Total SCL period:
    $$t_{\text{SCL}} = t_{\text{SYNC}} + t_{\text{SCLH}} + t_{\text{SCLL}} = 10.0\text{ }\mu\text{s} \implies f_{\text{SCL}} = 100{,}000\text{ Hz} \quad (100\text{ kHz})$$

### Status LED PWM Configuration on PB4 (TIM3 Channel 1)

This configuration sets up **TIM3 Channel 1** to output a $1\text{ kHz}$ PWM signal with a $50\%$ duty cycle on pin **PB4** to drive a status LED.

---

### 1. Pin Multiplexing & Alternate Functions
- **Pin**: On the STM32G474 (LQFP64 package, pin 57), **PB4** supports alternate function **AF2 (`TIM3_CH1`)** [STM32G474_Datasheet p.74].
- **GPIO Clock**: Enabled via `RCC_AHB2ENR_GPIOBEN` in `RCC->AHB2ENR` [STM32G474_RM0440 p.306].
- **Pin Configuration**:
  - Mode: Alternate function mode (`MODER4[1:0] = 10b`) in `GPIOB->MODER` [STM32G474_RM0440 p.355].
  - Output type: Push-pull (`OT4 = 0`) in `GPIOB->OTYPER` [STM32G474_RM0440 p.355].
  - Alternate Function: AF2 programmed in `AFR[0]` (`AFSEL4[3:0] = 0010b`) in `GPIOB->AFR[0]` [STM32G474_RM0440 p.359].

---

### 2. Timer Kernel Clock & PWM Parameter Derivation
- **Timer Clock Source**: TIM3 clock is enabled via `RCC_APB1ENR1_TIM3EN` in `RCC->APB1ENR1` [STM32G474_RM0440 p.309]. With the system clock configured at $170\text{ MHz}$ ($\text{PCLK1} = 170\text{ MHz}$ and APB1 prescaler $= 1$), the timer clock is $f_{\text{TIM\_CLK}} = 170\text{ MHz}$.
- **Target Frequency**: $f_{\text{PWM}} = 1000\text{ Hz}$.
  $$\frac{f_{\text{TIM\_CLK}}}{(\text{PSC} + 1) \times (\text{ARR} + 1)} = 1000\text{ Hz}$$
- Setting $\text{PSC} = 3$:
  $$f_{\text{CNT}} = \frac{170\text{ MHz}}{3 + 1} = 42.5\text{ MHz}$$
  $$\text{ARR} + 1 = \frac{42.5\text{ MHz}}{1000\text{ Hz}} = 42500 \implies \text{ARR} = 42499$$
  The resulting PWM frequency is exactly $1000.0\text{ Hz}$ ($0.0\%$ error).
- **Duty Cycle**: $50\%$ in edge-aligned up-counting mode:
  $$\text{CCR1} = \frac{\text{ARR} + 1}{2} = \frac{42500}{2} = 21250$$
  $$\text{Duty Cycle} = \frac{21250}{42500} = 50.0\% \quad (0.0\%\text{ error})$$

---

### 3. Channel & Timer Modes
- **PWM Mode 1**: Configured by writing `OC1M[2:0] = 0110b` (6) in `TIM3->CCMR1` [STM32G474_RM0440 p.1379]. In up-counting mode, Channel 1 is active when $\text{CNT} < \text{CCR1}$, and inactive otherwise.
- **Preload Registers**: Output compare preload enabled via `OC1PE = 1` in `TIM3->CCMR1` [STM32G474_RM0440 p.1379], and auto-reload preload enabled via `ARPE = 1` in `TIM3->CR1` [STM32G474_RM0440 p.1366].
- **Output Enable & Polarity**: Active-high output enabled via `CC1E = 1` and `CC1P = 0` in `TIM3->CCER` [STM32G474_RM0440 p.1385].
- **Update Event**: Writing `UG = 1` in `TIM3->EGR` [STM32G474_RM0440 p.1376] transfers preloaded values to shadow registers, and setting `CEN = 1` in `TIM3->CR1` [STM32G474_RM0440 p.1366] starts the counter.

```c
{
    /* 1. Enable PWR peripheral clock */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* 2. Divide HCLK by 2 temporarily before entering boost mode */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    while ((FLASH->ACR & FLASH_ACR_LATENCY) != FLASH_ACR_LATENCY_4WS);

    /* 5. Enable HSE oscillator (8 MHz) */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY));

    /* 6. Configure PLL: HSE (8 MHz) / 2 * 85 / 2 = 170 MHz */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1U << RCC_PLLCFGR_PLLM_Pos) |
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   (0U << RCC_PLLCFGR_PLLR_Pos) |
                   RCC_PLLCFGR_PLLREN;

    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY));

    /* 8. Switch SYSCLK to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL);

    /* 9. Restore AHB prescaler to 1 to reach 170 MHz */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;
    RCC->CFGR &= ~(RCC_CFGR_PPRE1 | RCC_CFGR_PPRE2);
}

{

    system_clock_config();

    /* 1. Enable peripheral clocks for GPIOB and TIM3 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM3EN;

    /* 2. Configure PB4 as Alternate Function AF2 (TIM3_CH1, Push-Pull) */
    GPIOB->MODER = (GPIOB->MODER & ~GPIO_MODER_MODE4_Msk) | (2U << GPIO_MODER_MODE4_Pos);
    GPIOB->OTYPER &= ~GPIO_OTYPER_OT4;
    GPIOB->AFR[0] = (GPIOB->AFR[0] & ~GPIO_AFRL_AFSEL4_Msk) | (2U << GPIO_AFRL_AFSEL4_Pos);

    /* 3. Configure TIM3 time base for 1 kHz PWM from 170 MHz kernel clock:
     * PSC = 3   -> Timer counter clock = 170 MHz / (3 + 1) = 42.5 MHz
     * ARR = 42499 -> PWM frequency = 42.5 MHz / (42499 + 1) = 1000 Hz
     */
    TIM3->PSC = 3U;
    TIM3->ARR = 42499U;

    /* 4. Set CCR1 for 50 % duty cycle:
     * CCR1 = 21250 -> Duty cycle = 21250 / 42500 = 50.0 %
     */
    TIM3->CCR1 = 21250U;

    /* 5. Configure Channel 1:
     * Output compare mode: PWM mode 1 (OC1M = 0110b = 6)
     * Output compare preload enable: OC1PE = 1
     */
    TIM3->CCMR1 = (TIM3->CCMR1 & ~(TIM_CCMR1_OC1M_Msk | TIM_CCMR1_CC1S_Msk))
                | (6U << TIM_CCMR1_OC1M_Pos)
                | TIM_CCMR1_OC1PE;

    /* 6. Enable Channel 1 output: active-high (CC1E = 1, CC1P = 0) */
    TIM3->CCER = (TIM3->CCER & ~TIM_CCER_CC1P) | TIM_CCER_CC1E;

    /* 7. Enable auto-reload preload (ARPE) and start counter (CEN) */
    TIM3->CR1 |= TIM_CR1_ARPE | TIM_CR1_CEN;

    /* 8. Generate an update event to transfer preloaded values to shadow registers */
    TIM3->EGR |= TIM_EGR_UG;
}
```

### Assistant answer 4

### Clock Limit Analysis: Request to Raise SYSCLK to 180 MHz

The request to configure **SYSCLK = HCLK = 180 MHz** cannot be implemented because it directly violates the maximum operating limits of the STM32G474.

---

### Datasheet Limits & Technical Violations

1. **Maximum CPU / Core Frequency ($f_{\text{HCLK}}$)**:
   - In Table 17 (*General operating conditions*), the absolute maximum internal AHB clock frequency ($f_{\text{HCLK}}$) is **170 MHz** in Range 1 Boost mode [STM32G474_Datasheet p.84].
   - Section 6.1.5 (*Dynamic voltage scaling management*) of the reference manual also states that Range 1 Boost mode allows operation only up to **170 MHz** [STM32G474_RM0440 p.232].
   - Setting $f_{\text{HCLK}} = 180\text{ MHz}$ exceeds the maximum specified operating frequency.

2. **Peripheral Bus Clock Limits ($f_{\text{PCLK1}}$, $f_{\text{PCLK2}}$)**:
   - With APB1 and APB2 prescalers kept at 1, setting $\text{SYSCLK} = 180\text{ MHz}$ would result in $f_{\text{PCLK1}} = 180\text{ MHz}$ and $f_{\text{PCLK2}} = 180\text{ MHz}$.
   - Table 17 specifies the maximum APB1 frequency ($f_{\text{PCLK1}}$) is **170 MHz**, and the maximum APB2 frequency ($f_{\text{PCLK2}}$) is **170 MHz** [STM32G474_Datasheet p.84]. Both bus limits are exceeded.

3. **Main PLL VCO Frequency Limits ($f_{\text{VCO}}$)**:
   - In Table 46 (*PLL characteristics*), the PLL VCO operating output frequency range is:
     $$96\text{ MHz} \le f_{\text{VCO\_OUT}} \le 344\text{ MHz} \quad [\text{STM32G474_Datasheet p.123}]$$
   - To achieve $180\text{ MHz}$ via the main PLL with division factor $\text{PLLR} = 2$, the required VCO output frequency would be:
     $$f_{\text{VCO}} = 180\text{ MHz} \times 2 = 360\text{ MHz}$$
   - Because $360\text{ MHz} > 344\text{ MHz}$, this exceeds the maximum PLL VCO frequency specification, risking PLL instability or loss of lock.

---

### Design Decision & System State

- **Decision D2**: Retain the system clock configuration at the maximum rated frequency of **170 MHz** (Range 1 Boost Mode, $\text{PLLM}=2$, $\text{PLLN}=85$, $\text{PLLR}=2$, $\text{Flash Latency}=4\text{ WS}$).
- All peripherals remain fully functional at their existing settings:
  - **USART1**: 115200 baud on PA9/PA10 from 170 MHz PCLK2.
  - **I2C2**: 100 kHz standard mode on PC4/PA8 from 170 MHz PCLK1.
  - **TIM3**: 1 kHz, 50% duty PWM on PB4 from 170 MHz TIM3CLK.

### Assistant answer 5

### Consolidated Firmware Initialization (STM32G474)

This program initializes the STM32G474 from its power-on reset state with:
1. **Clock Tree**: Range 1 Boost mode, 170 MHz SYSCLK / HCLK / PCLK1 / PCLK2 generated from an 8 MHz HSE crystal via the main PLL.
2. **Debug Port (USART1)**: 115200 baud, 8 data bits, no parity, 1 stop bit on PA9 (TX) and PA10 (RX).
3. **Sensor Bus (I2C2)**: 100 kHz standard mode controller on PC4 (SCL) and PA8 (SDA), both configured in open-drain mode (accommodating the 1.8 V sensor bus via a level shifter and resolving the PA9 conflict with USART1_TX).
4. **Status LED PWM (TIM3 Channel 1)**: 1 kHz PWM, 50 % duty cycle, active-high edge-aligned PWM Mode 1 on PB4.

### Complete CMSIS C Initialization Program

```c
#include "stm32g4xx.h"

int main(void)
{
    /* =========================================================================
     * 1. CLOCK CONFIGURATION: 170 MHz from 8 MHz HSE crystal (Range 1 Boost)
     * ========================================================================= */
    /* Enable PWR peripheral clock */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* Divide HCLK by 2 temporarily before entering boost mode */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    /* Enable Range 1 Boost mode: clear R1MODE bit in PWR_CR5 */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* Configure Flash latency: 4 WS (5 CPU cycles) required for 170 MHz in Range 1 Boost */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY) != FLASH_ACR_LATENCY_4WS);

    /* Start HSE oscillator (8 MHz) and wait for it to stabilize */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY));

    /* Configure PLL:
     * Source: HSE (8 MHz)
     * PLLM: /2 -> 4 MHz VCO input (valid: 2.66 - 16 MHz)
     * PLLN: x85 -> 340 MHz VCO output (valid: 96 - 344 MHz)
     * PLLR: /2 -> 170 MHz SYSCLK
     * Enable PLLR output
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1U << RCC_PLLCFGR_PLLM_Pos) | /* PLLM = 2 (register field value 1) */
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   (0U << RCC_PLLCFGR_PLLR_Pos) | /* PLLR = 2 (register field value 0) */
                   RCC_PLLCFGR_PLLREN;

    /* Enable PLL and wait for lock */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY));

    /* Select PLL as system clock */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL);

    /* Restore AHB prescaler to 1 -> HCLK = 170 MHz */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;

    /* Ensure APB1 and APB2 prescalers are 1 -> PCLK1 = PCLK2 = 170 MHz */
    RCC->CFGR &= ~(RCC_CFGR_PPRE1 | RCC_CFGR_PPRE2);

    /* =========================================================================
     * 2. GPIO PORT CLOCKS
     * ========================================================================= */
    RCC->AHB2ENR |= (RCC_AHB2ENR_GPIOAEN | RCC_AHB2ENR_GPIOBEN | RCC_AHB2ENR_GPIOCEN);

    /* =========================================================================
     * 3. USART1 DEBUG PORT: 115200 baud, 8N1, PA9 (TX), PA10 (RX)
     * ========================================================================= */
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* Configure PA9 (TX) and PA10 (RX) as Alternate Function AF7 (USART1) */
    GPIOA->MODER = (GPIOA->MODER & ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk))
                 | (2U << GPIO_MODER_MODE9_Pos)
                 | (2U << GPIO_MODER_MODE10_Pos);
    GPIOA->AFR[1] = (GPIOA->AFR[1] & ~(GPIO_AFRH_AFSEL9_Msk | GPIO_AFRH_AFSEL10_Msk))
                  | (7U << GPIO_AFRH_AFSEL9_Pos)
                  | (7U << GPIO_AFRH_AFSEL10_Pos);

    /* Reset control registers before programming (UE = 0) */
    USART1->CR1 = 0;
    USART1->CR2 = 0;
    USART1->CR3 = 0;

    /* Write BRR before enabling USART:
     * Clock = PCLK2 = 170 MHz, OVER8 = 0
     * BRR = 170000000 / 115200 = 1475.694 -> 1476 (0x5C4) -> 115176 baud (-0.02% error)
     */
    USART1->BRR = 1476U;

    /* Enable transmitter (TE) and receiver (RE), then enable USART1 (UE) */
    USART1->CR1 |= (USART_CR1_TE | USART_CR1_RE);
    USART1->CR1 |= USART_CR1_UE;

    /* =========================================================================
     * 4. I2C2 CONTROLLER: 100 kHz Standard Mode, PC4 (SCL), PA8 (SDA)
     * ========================================================================= */
    RCC->APB1ENR1 |= RCC_APB1ENR1_I2C2EN;

    /* Configure PC4 as I2C2_SCL (AF4, Open-Drain) */
    GPIOC->MODER = (GPIOC->MODER & ~GPIO_MODER_MODE4_Msk) | (2U << GPIO_MODER_MODE4_Pos);
    GPIOC->OTYPER |= GPIO_OTYPER_OT4;
    GPIOC->AFR[0] = (GPIOC->AFR[0] & ~GPIO_AFRL_AFSEL4_Msk) | (4U << GPIO_AFRL_AFSEL4_Pos);

    /* Configure PA8 as I2C2_SDA (AF4, Open-Drain) */
    GPIOA->MODER = (GPIOA->MODER & ~GPIO_MODER_MODE8_Msk) | (2U << GPIO_MODER_MODE8_Pos);
    GPIOA->OTYPER |= GPIO_OTYPER_OT8;
    GPIOA->AFR[1] = (GPIOA->AFR[1] & ~GPIO_AFRH_AFSEL8_Msk) | (4U << GPIO_AFRH_AFSEL8_Pos);

    /* Ensure I2C2 is disabled before programming TIMINGR (PE = 0) */
    I2C2->CR1 &= ~I2C_CR1_PE;

    /* TIMINGR for 100 kHz Standard Mode from 170 MHz I2CCLK (PCLK1):
     * PRESC = 15 (0xF)
     * SCLDEL = 4  (0x4)
     * SDADEL = 3  (0x3)
     * SCLH   = 51 (0x33)
     * SCLL   = 53 (0x35)
     */
    I2C2->TIMINGR = (15U << I2C_TIMINGR_PRESC_Pos) |
                    (4U  << I2C_TIMINGR_SCLDEL_Pos) |
                    (3U  << I2C_TIMINGR_SDADEL_Pos) |
                    (51U << I2C_TIMINGR_SCLH_Pos)   |
                    (53U << I2C_TIMINGR_SCLL_Pos);

    /* Enable I2C2 peripheral (PE = 1) */
    I2C2->CR1 |= I2C_CR1_PE;

    /* =========================================================================
     * 5. TIM3 CH1 PWM: 1 kHz, 50% Duty Cycle, PB4 (AF2)
     * ========================================================================= */
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM3EN;

    /* Configure PB4 as Alternate Function AF2 (TIM3_CH1, Push-Pull) */
    GPIOB->MODER = (GPIOB->MODER & ~GPIO_MODER_MODE4_Msk) | (2U << GPIO_MODER_MODE4_Pos);
    GPIOB->OTYPER &= ~GPIO_OTYPER_OT4;
    GPIOB->AFR[0] = (GPIOB->AFR[0] & ~GPIO_AFRL_AFSEL4_Msk) | (2U << GPIO_AFRL_AFSEL4_Pos);

    /* Time base: 170 MHz / ((3 + 1) * (42499 + 1)) = 1000 Hz */
    TIM3->PSC = 3U;
    TIM3->ARR = 42499U;

    /* Duty cycle: 50% -> 21250 / 42500 */
    TIM3->CCR1 = 21250U;

    /* Configure PWM mode 1 (OC1M = 6) with output compare preload (OC1PE = 1) */
    TIM3->CCMR1 = (TIM3->CCMR1 & ~(TIM_CCMR1_OC1M_Msk | TIM_CCMR1_CC1S_Msk))
                | (6U << TIM_CCMR1_OC1M_Pos)
                | TIM_CCMR1_OC1PE;

    /* Enable Channel 1 output: active-high (CC1E = 1, CC1P = 0) */
    TIM3->CCER = (TIM3->CCER & ~TIM_CCER_CC1P) | TIM_CCER_CC1E;

    /* Enable auto-reload preload (ARPE) and start counter (CEN) */
    TIM3->CR1 |= TIM_CR1_ARPE | TIM_CR1_CEN;

    /* Generate update event to load preloaded registers into active registers */
    TIM3->EGR |= TIM_EGR_UG;

    /* =========================================================================
     * 6. MAIN LOOP
     * ========================================================================= */
    while (1)
    {
    }
}
```

### Summary of Design & Operational Details

1. **Clock Configuration (170 MHz Range 1 Boost)**:
   - Operating at 170 MHz requires Range 1 Boost Mode [STM32G474_Datasheet p.84], entered by clearing `R1MODE` in `PWR_CR5` [STM32G474_RM0440 p.233, p.267] with HCLK temporarily divided by 2 [STM32G474_RM0440 p.233].
   - Flash read latency is set to 4 wait states (`FLASH_ACR_LATENCY_4WS`) [STM32G474_RM0440 p.98].
   - The PLL derives 170 MHz from the 8 MHz HSE crystal ($8\text{ MHz} / 2 \times 85 / 2 = 170\text{ MHz}$) [STM32G474_Datasheet p.117, p.123].
   - *Note on 180 MHz*: As established in Message 5 (Decision D2), 180 MHz exceeds the maximum ratings for $f_{\text{HCLK}}$, $f_{\text{PCLK1}}$, and $f_{\text{PCLK2}}$ (all rated at 170 MHz max) [STM32G474_Datasheet p.84] and the PLL VCO limit ($f_{\text{VCO, max}} = 344\text{ MHz}$) [STM32G474_Datasheet p.123]. The design safely remains at 170 MHz.

2. **USART1 Debug Serial Port**:
   - `PA9` is configured as TX (AF7) and `PA10` as RX (AF7) [STM32G474_Datasheet p.73].
   - Kernel clock $f_{\text{PCLK2}} = 170\text{ MHz}$ with `OVER8 = 0` yields $\text{BRR} = 170{,}000{,}000 / 115{,}200 = 1476$ ($115176\text{ baud}$, error $-0.02\%$) [STM32G474_RM0440 p.1707, p.1708]. `BRR` is written prior to enabling `UE`.

3. **I2C2 Pressure Sensor Interface**:
   - `PC4` serves as `I2C2_SCL` (AF4) and `PA8` as `I2C2_SDA` (AF4), both configured in open-drain mode [STM32G474_Datasheet p.60, p.66, p.73, p.75]. This resolves the pin conflict on `PA9` with `USART1_TX` (Decision D1) and allows safe bidirectional level shifting between the 3.3 V MCU and 1.8 V sensor rails.
   - `TIMINGR = 0xF0433335` produces standard mode 100 kHz SCL ($t_{\text{SCL}} = 10.0\text{ }\mu\text{s}$) from the 170 MHz APB1 peripheral clock [STM32G474_RM0440 p.1681].

4. **Status LED PWM (TIM3 Channel 1)**:
   - `PB4` is configured in alternate function mode AF2 [STM32G474_Datasheet p.74].
   - With $f_{\text{TIM3CLK}} = 170\text{ MHz}$, prescaler $\text{PSC} = 3$ gives $f_{\text{CNT}} = 42.5\text{ MHz}$. An auto-reload value of $\text{ARR} = 42499$ produces exactly $1000\text{ Hz}$ PWM, and $\text{CCR1} = 21250$ gives a precise $50.0\%$ duty cycle in active-high PWM mode 1 [STM32G474_RM0440 p.1491].
