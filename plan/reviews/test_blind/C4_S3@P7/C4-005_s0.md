### Clock Configuration to 170 MHz on STM32G474

To configure the STM32G474 system and peripheral bus clocks to $170\text{ MHz}$ using an $8\text{ MHz}$ HSE crystal, several requirements and sequence steps from the datasheet and reference manual must be satisfied:

1. **Power Regulator Range 1 Boost Mode**:
   - The default regulator setting (Range 1 Normal mode) only supports frequencies up to $150\text{ MHz}$ [STM32G474_RM0440 p.232].
   - Operating at $170\text{ MHz}$ requires switching to **Range 1 Boost mode** by clearing the `R1MODE` bit (bit 8) in `PWR_CR5` [STM32G474_RM0440 p.267].
   - Access to `PWR_CR5` requires enabling the power interface clock by setting `PWREN` in `RCC_APB1ENR1` [STM32G474_RM0440 p.309].

2. **Flash Read Latency (Wait States)**:
   - According to Table 9 *Number of wait states according to CPU clock (HCLK) frequency* for category 3 devices in VCORE Range 1 Boost mode, operating at $170\text{ MHz}$ ($136 < \text{HCLK} \le 170\text{ MHz}$) requires **4 wait states** (`LATENCY = 4WS`, binary `0100`) [STM32G474_RM0440 p.98].
   - The latency must be programmed in `FLASH_ACR` before increasing the core frequency [STM32G474_RM0440 p.98].

3. **PLL Calculation**:
   - Input clock: $\text{HSE} = 8\text{ MHz}$.
   - PLL input divider: $M = 2$ (`PLLM = 0001b`), resulting in $f_{\text{PLL\_IN}} = \frac{8\text{ MHz}}{2} = 4\text{ MHz}$ (valid range: $2.66$ to $16\text{ MHz}$ [STM32G474_Datasheet p.123]).
   - PLL multiplier: $N = 85$ (`PLLN = 85`), resulting in $f_{\text{VCO}} = 4\text{ MHz} \times 85 = 340\text{ MHz}$ (valid Range 1 VCO range: $96$ to $344\text{ MHz}$ [STM32G474_Datasheet p.123]).
   - PLL "R" divider: $R = 2$ (`PLLR = 00b`, enabled via `PLLREN`), resulting in:
     $$\text{SYSCLK} = \frac{340\text{ MHz}}{2} = 170\text{ MHz} \quad (0.0\%\text{ error})$$
   - All prescalers (AHB `HPRE`, APB1 `PPRE1`, APB2 `PPRE2`) remain at division factor 1, giving:
     $$\text{HCLK} = \text{PCLK1} = \text{PCLK2} = 170\text{ MHz}$$

4. **Safe Switching Sequence**:
   - When switching to a system clock higher than $80\text{ MHz}$ (and specifically $> 150\text{ MHz}$ in Boost mode), the reference manual requires dividing the AHB clock by 2 (`HPRE = /2`) before switching to the PLL, waiting at least $1\,\mu\text{s}$, and then restoring the AHB prescaler to 1 (`HPRE = /1`) [STM32G474_RM0440 p.233, p.279–280].

#include "stm32g4xx.h"

void clock_init_170mhz(void)
{
    /* 1. Enable Power Control clock */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;

    /* 2. Enable Range 1 Boost Mode (clearing R1MODE in PWR_CR5) */
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 3. Configure Flash latency to 4 wait states for 170 MHz in Range 1 Boost mode */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY) != FLASH_ACR_LATENCY_4WS) {
        /* Busy-wait until the new Flash latency is applied */
    }

    /* 4. Enable HSE oscillator (8 MHz external crystal) and wait until ready */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY)) {
        /* Wait for HSERDY */
    }

    /* 5. Set AHB prescaler to /2 before transitioning to high frequency (>80 MHz) */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    /* 6. Configure PLL:
     *    Source = HSE
     *    PLLM   = 2 (div 2 -> 4 MHz PLL input)
     *    PLLN   = 85 (x85  -> 340 MHz VCO)
     *    PLLR   = 2 (div 2 -> 170 MHz PLLCLK)
     *    Enable PLL "R" output (PLLREN)
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1U << RCC_PLLCFGR_PLLM_Pos) |
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   RCC_PLLCFGR_PLLREN;

    /* 7. Enable Main PLL and wait until locked */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY)) {
        /* Wait for PLLRDY */
    }

    /* 8. Select PLL as system clock source and wait until switch completes */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
        /* Wait for SWS == PLL */
    }

    /* 9. Small delay (>1 us) in transition state */
    for (volatile int i = 0; i < 200; i++) {
        __NOP();
    }

    /* 10. Restore AHB prescaler to 1 -> HCLK = SYSCLK = 170 MHz */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;
    while ((RCC->CFGR & RCC_CFGR_HPRE) != RCC_CFGR_HPRE_DIV1) {
        /* Wait for HPRE update */
    }
}

### Clock Frequency Limitation Notice

The STM32G474 datasheet specifies an absolute maximum operating frequency of **170 MHz** for SYSCLK, HCLK, PCLK1, and PCLK2 in Range 1 Boost mode [STM32G474_Datasheet p.84, STM32G474_RM0440 p.232]. Furthermore, the maximum VCO frequency for the main PLL in Range 1 is **344 MHz** [STM32G474_Datasheet p.123]. Raising SYSCLK to 200 MHz would require operating the PLL VCO at 400 MHz (or higher) and clocking the AHB/APB buses beyond their specified maximum operating limits.

Therefore, the clock tree is kept at the maximum specified frequency of **170 MHz** (SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz). At 170 MHz, a 100 kHz PWM carrier achieves 1,700 discrete duty-cycle steps (~10.73 bits of resolution).

### PWM Configuration on PA8 (TIM1 Channel 1)

1. **Pin Allocation**:
   - PA8 alternate function 6 maps to `TIM1_CH1` [STM32G474_Datasheet p.73].
   - Configured in Alternate Function Mode (`MODER8 = 10b`), push-pull, very high speed.

2. **TIM1 Timing Parameters**:
   - Timer clock: $f_{\text{TIM1CLK}} = 170\text{ MHz}$ (APB2 prescaler = 1).
   - Prescaler: $\text{PSC} = 0$.
   - Auto-reload:
     $$\text{ARR} = \frac{f_{\text{TIM1CLK}}}{f_{\text{target}}} - 1 = \frac{170\text{ MHz}}{100\text{ kHz}} - 1 = 1699$$

     $$\text{CCR1} = \frac{\text{ARR} + 1}{2} = 850$$

3. **Timer Operating Modes**:

### Technical Explanation

1. **Clock Configuration and Limitations**:
   - The STM32G474 absolute maximum operating frequency for SYSCLK, HCLK, PCLK1, and PCLK2 in Range 1 Boost mode is **170 MHz** [STM32G474_Datasheet p.84].
   - Furthermore, the maximum PLL VCO frequency is **344 MHz** [STM32G474_Datasheet p.123]. Clocking at 200 MHz would violate both maximum operating frequencies and is out of specification. Thus, the system clock is maintained at the maximum rated 170 MHz.
   - Operating at 170 MHz requires Range 1 Boost mode by clearing `R1MODE` in `PWR_CR5` [STM32G474_RM0440 p.267].
   - Per the Flash access wait states table, running HCLK at 170 MHz in Range 1 Boost mode requires **4 wait states** (`LATENCY = 4WS`) [STM32G474_RM0440 p.98].
   - From an 8 MHz HSE crystal, `PLLM = 2` creates a 4 MHz PLL input ($f_{\text{PLL\_IN}}$ is within the 2.66 to 16 MHz limit [STM32G474_Datasheet p.123]), `PLLN = 85` generates $f_{\text{VCO}} = 340\text{ MHz}$ (within 96 to 344 MHz [STM32G474_Datasheet p.123]), and `PLLR = 2` yields `SYSCLK = 170 MHz` with 0.0% error.

2. **PA8 Alternate Function Mapping**:
   - PA8 is configured to Alternate Function 6 (`AF6`), which maps to `TIM1_CH1` [STM32G474_Datasheet p.73].

3. **PWM Generation**:
   - With APB2 prescaler = 1, `TIM1CLK` is 170 MHz.
   - Prescaler is set to 0 (`TIM1->PSC = 0`).
   - The auto-reload register `ARR = 1699` sets the period to $(1699 + 1) / 170\text{ MHz} = 10\,\mu\text{s}$ ($100\text{ kHz}$).
   - `CCR1 = 850` yields an exact 50.0% duty cycle ($850 / 1700$).
   - TIM1 is an advanced-control timer; setting the `MOE` (Main Output Enable) bit in `TIM1->BDTR` is required to enable output signals on the external pins [STM32G474_RM0440 p.1267].
