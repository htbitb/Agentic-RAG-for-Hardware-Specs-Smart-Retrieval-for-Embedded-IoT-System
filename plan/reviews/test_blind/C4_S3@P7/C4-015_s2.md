### Clock Configuration to 170 MHz on STM32G474

To configure the STM32G474 to run at **SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz** from an 8 MHz HSE crystal, the following hardware constraints and programming sequence must be respected:

#### 1. Voltage Scaling & Boost Mode
* Operating above 150 MHz up to the maximum 170 MHz requires **Range 1 Boost Mode** [STM32G474_RM0440 p.232].
* In Range 1 Boost Mode, the `R1MODE` bit in `PWR_CR5` must be cleared to `0` [STM32G474_RM0440 p.267].
* Enabling `PWR` register access requires setting `RCC_APB1ENR1_PWREN` [STM32G474_RM0440 p.309].

#### 2. Flash Read Latency
* At 170 MHz in Range 1 Boost Mode, the Flash memory read access requires **4 wait states** (`LATENCY = 4WS`, 5 CPU cycles) [STM32G474_RM0440 p.98, Table 9].

#### 3. Main PLL Parameters
* **Input source**: HSE = 8 MHz (`PLLSRC = 3` / `RCC_PLLCFGR_PLLSRC_HSE`) [STM32G474_RM0440 p.291].
* **Input prescaler $M$**: $M = 2$ (`PLLM = 1`, since encoded value is $M - 1$). The input frequency to the VCO is:
  $$\frac{8\text{ MHz}}{2} = 4\text{ MHz}$$
  This is strictly within the allowed range of 2.66 MHz to 16 MHz [STM32G474_Datasheet p.123, Table 46].
* **Multiplication factor $N$**: $N = 85$ (`PLLN = 85`).
  $$4\text{ MHz} \times 85 = 340\text{ MHz}$$
  This is within the allowed VCO range of 96 MHz to 344 MHz in Range 1 [STM32G474_Datasheet p.123, Table 46].
* **Output divider $R$**: $R = 2$ (`PLLR = 0`, representing division by 2).
  $$\frac{340\text{ MHz}}{2} = 170\text{ MHz}$$
  This matches the target 170 MHz exactly (0.0% error).
* **Enable PLL output**: Set `PLLREN` bit to allow the PLL R output to drive the system clock tree [STM32G474_RM0440 p.291].

#### 4. Switching Procedure & Intermediate Frequency Transition
* According to the reference manual [STM32G474_RM0440 p.279–280, p.233], switching from HSI16/HSE to a PLL frequency where HCLK is higher than 80 MHz requires an intermediate transition state to protect clock tree logic:
  1. Set AHB prescaler $HPRE = \text{DIV2}$ to divide the incoming clock by 2 during switchover.
  2. Switch SYSCLK to PLL (`SW = 3`) and poll `SWS` until PLL is active.
  3. Wait at least $1\,\mu\text{s}$.
  4. Restore AHB prescaler $HPRE = \text{DIV1}$ so $f_{\text{HCLK}} = 170\text{ MHz}$.
  5. Ensure APB1 and APB2 prescalers are configured to division by 1 (`PPRE1 = 0`, `PPRE2 = 0`), so $f_{\text{PCLK1}} = f_{\text{PCLK2}} = 170\text{ MHz}$ [STM32G474_Datasheet p.84, Table 17].

```c
#include "stm32g4xx.h"

/**
 * @brief  Configures the system clock to 170 MHz using the 8 MHz HSE crystal.
 *         SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz.
 *         Follows STM32G4 Range 1 Boost Mode and Flash latency requirements.
 */
void SystemClock_Config_170MHz(void)
{
    /* 1. Enable Power Controller clock and enter Range 1 Boost Mode */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 2. Configure Flash latency: 4 WS (5 CPU cycles) required for 170 MHz in Boost Mode */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY_Msk) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY_Msk) != FLASH_ACR_LATENCY_4WS) {
        /* Wait for Flash latency to take effect */
    }

    /* 3. Enable HSE oscillator and wait until stable */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY)) {
        /* Busy-wait on HSERDY */
    }

    /* 4. Configure PLL:
     *    Source = HSE (8 MHz)
     *    M = 2  -> f_IN = 8 MHz / 2 = 4 MHz
     *    N = 85 -> f_VCO = 4 MHz * 85 = 340 MHz
     *    R = 2  -> f_PLL_R = 340 MHz / 2 = 170 MHz
     *    Enable PLL R output (PLLREN)
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1UL << RCC_PLLCFGR_PLLM_Pos) | /* M = 2 (register field value = M - 1 = 1) */
                   (85UL << RCC_PLLCFGR_PLLN_Pos) |
                   (0UL << RCC_PLLCFGR_PLLR_Pos) | /* R = 2 (register field value = 0) */
                   RCC_PLLCFGR_PLLREN;

    /* 5. Enable PLL and wait for lock */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY)) {
        /* Busy-wait on PLLRDY */
    }

    /* 6. Switch system clock to PLL using transition intermediate AHB division (/2) */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE_Msk) | RCC_CFGR_HPRE_DIV2;

    /* Select PLL as SYSCLK */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW_Msk) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS_Msk) != RCC_CFGR_SWS_PLL) {
        /* Busy-wait on SWS until PLL is selected */
    }

    /* Wait at least 1 us before restoring full AHB speed */
    for (__IO uint32_t i = 0; i < 200; i++) {
        __NOP();
    }

    /* Set AHB prescaler to 1: HCLK = 170 MHz */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE_Msk) | RCC_CFGR_HPRE_DIV1;

    /* Ensure APB1 and APB2 prescalers are 1 (PCLK1 = PCLK2 = 170 MHz) */
    RCC->CFGR &= ~(RCC_CFGR_PPRE1_Msk | RCC_CFGR_PPRE2_Msk);
}
```

### Hardware Configuration Details

1. **Clock Routing and Enables**:
   * **GPIOA Clock**: Enabled via bit `GPIOAEN` in `RCC->AHB2ENR` [STM32G474_RM0440 p.306].
   * **USART1 Clock**: Enabled via bit `USART1EN` in `RCC->APB2ENR` [STM32G474_RM0440 p.312].
   * **Clock Source**: By default, `RCC_CCIPR.USART1SEL` reset value is `00b` (PCLK) [STM32G474_RM0440 p.322]. With $f_{\text{PCLK2}} = 170\text{ MHz}$ and prescaler `USART1->PRESC = 0` (divide by 1) [STM32G474_RM0440 p.1772], the USART kernel clock $f_{\text{CK}} = 170\text{ MHz}$.

2. **GPIO Pin Multiplexing**:
   * **PA9** (USART1_TX) and **PA10** (USART1_RX) map to alternate function **AF7** [STM32G474_Datasheet p.73].
   * Pins are configured to Alternate Function Mode (`MODER = 10b`) in `GPIOA->MODER` [STM32G474_RM0440 p.355].
   * Alternate function 7 is selected in `GPIOA->AFR[1]` (`AFRH9` and `AFRH10`) [STM32G474_RM0440 p.360].

3. **Baud Rate Calculation (Oversampling by 16)**:
   * With oversampling by 16 (`OVER8 = 0` in `USART_CR1`) [STM32G474_RM0440 p.1740], the baud rate formula is [STM32G474_RM0440 p.1708]:
     $$\text{USARTDIV} = \frac{f_{\text{CK}}}{\text{BaudRate}} = \frac{170\,000\,000}{115\,200} \approx 1475.6944$$
   * For oversampling by 16, `USART_BRR = USARTDIV` rounded to the nearest integer [STM32G474_RM0440 p.1708, p.1755]:
     $$\text{BRR} = \text{round}(1475.6944) = 1476 \quad (\text{0x05C4})$$
   * Actual achieved baud rate:
     $$\text{Baud}_{\text{actual}} = \frac{170\,000\,000}{1476} \approx 115\,176.15\text{ baud}$$
     Error: $\approx -0.021\%$, well within asynchronous serial communication tolerance limits.

4. **USART Frame & Enable Sequencing**:
   * **Data bits**: 8 data bits (`M[1:0] = 00b` in `USART_CR1`, default reset value) [STM32G474_RM0440 p.1740].
   * **Parity**: Disabled (`PCE = 0` in `USART_CR1`, default reset value).
   * **Stop bits**: 1 stop bit (`STOP[1:0] = 00b` in `USART_CR2`, default reset value) [STM32G474_RM0440 p.1747].
   * **Programming order** [STM32G474_RM0440 p.1702]:
     1. Clear `UE` in `USART_CR1`.
     2. Write word length, stop bits, and oversampling configuration.
     3. Write `USART_BRR = 1476` while `UE = 0`.
     4. Enable Transmitter (`TE = 1`) and Receiver (`RE = 1`).
     5. Enable USART peripheral (`UE = 1`).

### Bare-Metal CMSIS C Code

```c
#include "stm32g4xx.h"

/**
 * @brief  Initializes USART1 as a debug serial port at 115200 baud (8N1).
 *         Pins: PA9 -> USART1_TX, PA10 -> USART1_RX.
 *         Clock: PCLK2 = 170 MHz, oversampling by 16.
 */
void USART1_Init_115200(void)
{
    /* 1. Enable GPIOA and USART1 peripheral clocks */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PA9 (TX) and PA10 (RX) as Alternate Function AF7 */
    /* Set MODER to Alternate Function (10b = 2) for PA9 and PA10 */
    GPIOA->MODER &= ~((3UL << GPIO_MODER_MODE9_Pos) | (3UL << GPIO_MODER_MODE10_Pos));
    GPIOA->MODER |=  ((2UL << GPIO_MODER_MODE9_Pos) | (2UL << GPIO_MODER_MODE10_Pos));

    /* Set AF7 in AFRH (AFR[1]) for pins 9 and 10 */
    GPIOA->AFR[1] &= ~((0xFUL << GPIO_AFRH_AFSEL9_Pos) | (0xFUL << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |=  ((7UL << GPIO_AFRH_AFSEL9_Pos) | (7UL << GPIO_AFRH_AFSEL10_Pos));

    /* Set high output speed on TX pin (PA9) */
    GPIOA->OSPEEDR |= (3UL << GPIO_OSPEEDR_OSPEED9_Pos);

    /* 3. Configure USART1:
     *    - Ensure USART is disabled (UE = 0) during configuration
     *    - 8 data bits, parity control disabled, oversampling by 16 (OVER8 = 0)
     *    - 1 stop bit (STOP = 00b in CR2)
     */
    USART1->CR1 = 0;
    USART1->CR2 = 0;
    USART1->CR3 = 0;

    /* 4. Write Baud Rate Register before enabling USART:
     *    BRR = 170,000,000 / 115,200 = 1476 (0x05C4) -> 115176 baud (-0.02% error)
     */
    USART1->BRR = 1476UL;

    /* 5. Enable transmitter, receiver, and USART peripheral */
    USART1->CR1 |= USART_CR1_TE | USART_CR1_RE;
    USART1->CR1 |= USART_CR1_UE;
}
```

```c
 * @brief  Initializes I2C2 as Controller in Standard-Mode (100 kHz).
 *         Pins: PA9 -> SCL (AF4, Open-Drain), PA8 -> SDA (AF4, Open-Drain)
 *         Kernel clock: 16 MHz HSI16.
 *
 * @note   Because the pressure sensor is powered at 1.8 V and STM32G474 VIH_min
 *         is 2.31 V at 3.3 V VDD, a bidirectional level shifter (e.g. PCA9306)
 *         is required on the board between the MCU and the sensor.
 */
void I2C2_PressureSensor_Init(void)
{

    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_I2C2EN;

    /* 2. Configure I2C2 kernel clock source to HSI16 (16 MHz) in RCC_CCIPR */
    RCC->CCIPR = (RCC->CCIPR & ~RCC_CCIPR_I2C2SEL_Msk) | (2UL << RCC_CCIPR_I2C2SEL_Pos);

    /* 3. Configure PA8 (SDA) and PA9 (SCL) */
    /* Alternate function mode (MODER = 10b) */
    GPIOA->MODER &= ~((3UL << GPIO_MODER_MODE8_Pos) | (3UL << GPIO_MODER_MODE9_Pos));

    /* Open-drain output type (OTYPER = 1b) for I2C lines */
    GPIOA->OTYPER |= (GPIO_OTYPER_OT8 | GPIO_OTYPER_OT9);

    /* High speed output */
    GPIOA->OSPEEDR |= ((3UL << GPIO_OSPEEDR_OSPEED8_Pos) | (3UL << GPIO_OSPEEDR_OSPEED9_Pos));

    /* Pull-up enabled (optional internal pull-up, external pull-ups required on bus) */

    GPIOA->PUPDR |=  ((1UL << GPIO_PUPDR_PUPD8_Pos) | (1UL << GPIO_PUPDR_PUPD9_Pos));

    GPIOA->AFR[1] &= ~((0xFUL << GPIO_AFRH_AFSEL8_Pos) | (0xFUL << GPIO_AFRH_AFSEL9_Pos));

                    (0x13UL << I2C_TIMINGR_SCLL_Pos);
```

### Hardware Configuration Details

1. **Pin Multiplexing and GPIO Configuration**:
   * **PB4** carries `TIM3_CH1` via Alternate Function **AF2** [STM32G474_Datasheet p.74].
   * GPIO Port B peripheral clock is enabled via `RCC_AHB2ENR_GPIOBEN`.
   * PB4 is configured for Alternate Function mode (`MODER4 = 10b`) in `GPIOB->MODER` [STM32G474_RM0440 p.355].
   * AF2 is assigned to pin 4 via bitfield `AFSEL4` in `GPIOB->AFR[0]` (`AFRL`) [STM32G474_RM0440 p.359].
   * Output speed is set to high speed in `GPIOB->OSPEEDR` [STM32G474_RM0440 p.356].

2. **Timer Clock and Timebase Calculation**:
   * **Timer Clock**: TIM3 peripheral clock is enabled via bit `TIM3EN` in `RCC->APB1ENR1` [STM32G474_RM0440 p.309].
   * With the system clock configured to 170 MHz (Range 1 Boost mode, PLL fed by HSE) and APB1 prescaler set to 1 ($f_{\text{PCLK1}} = 170\text{ MHz}$), the timer kernel clock is:
     $$f_{\text{TIM\_CLK}} = 170\text{ MHz}$$
   * **Frequency Formulation**:
     $$f_{\text{PWM}} = \frac{f_{\text{TIM\_CLK}}}{(\text{PSC} + 1) \times (\text{ARR} + 1)} = 1000\text{ Hz}$$
     Choosing prescaler $\text{PSC} = 3$:
     $$f_{\text{CNT}} = \frac{170\text{ MHz}}{3 + 1} = 42.5\text{ MHz}$$
     The auto-reload register value is:
     $$\text{ARR} = \frac{42\,500\,000\text{ Hz}}{1000\text{ Hz}} - 1 = 42\,499 \quad (\text{0xA603})$$
     Since TIM3 is a 16-bit timer with maximum $\text{ARR} = 65\,535$ [STM32G474_RM0440 p.1388], $42\,499$ is fully within range and provides an exact 1.000 kHz frequency (0.0 % error).
   * **Duty Cycle**:
     In up-counting PWM Mode 1, the output is active while $\text{CNT} < \text{CCR1}$:
     $$\text{Duty} = \frac{\text{CCR1}}{\text{ARR} + 1} = 50\% \implies \text{CCR1} = \frac{42\,500}{2} = 21\,250 \quad (\text{0x5302})$$

3. **Output Compare Mode & Timer Activation**:
   * **PWM Mode 1**: Configured by setting $\text{OC1M} = \text{0110b}$ and enabling preload with $\text{OC1PE} = 1$ in `TIM3->CCMR1` [STM32G474_RM0440 p.1379, p.1380].
   * **Auto-Reload Preload**: Enabled by setting `ARPE` in `TIM3->CR1` [STM32G474_RM0440 p.1366].
   * **Polarity and Output Enable**: Active-high output polarity (`CC1P = 0`) and channel 1 output enable (`CC1E = 1`) are configured in `TIM3->CCER` [STM32G474_RM0440 p.1385]. As a general-purpose timer without complementary dead-time outputs, TIM3 does not require an active `MOE` bit.
   * **Update Generation and Start**: An update event is generated via `UG = 1` in `TIM3->EGR` [STM32G474_RM0440 p.1376] to latch the prescaler and preload registers, and the counter is started by setting `CEN = 1` in `TIM3->CR1` [STM32G474_RM0440 p.1366].

```c
    /* Intermediate switch with AHB /2 */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE_Msk) | RCC_CFGR_HPRE_DIV2;
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW_Msk) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS_Msk) != RCC_CFGR_SWS_PLL);

    /* Restore AHB = 1, APB1 = 1, APB2 = 1 */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE_Msk) | RCC_CFGR_HPRE_DIV1;
    RCC->CFGR &= ~(RCC_CFGR_PPRE1_Msk | RCC_CFGR_PPRE2_Msk);
}

/**
 * @brief  Initializes TIM3 Channel 1 on PB4 to output a 1 kHz, 50% duty cycle PWM signal.
 *         Mode: Edge-aligned PWM mode 1, active-high, no dead time.
 *         Clock: APB1 timer clock = 170 MHz.
 */
void StatusLED_PWM_Init(void)
{
    /* Ensure system clock is at 170 MHz */
    SystemClock_Config_170MHz();

    /* 1. Enable GPIOB and TIM3 peripheral clocks */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOBEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM3EN;

    /* 2. Configure PB4 as Alternate Function AF2 (TIM3_CH1) */
    /* Set MODER to AF (10b) for pin 4 */
    GPIOB->MODER &= ~GPIO_MODER_MODE4_Msk;
    GPIOB->MODER |=  (2UL << GPIO_MODER_MODE4_Pos);

    /* Set AF2 in AFRL (AFR[0]) for pin 4 */
    GPIOB->AFR[0] &= ~GPIO_AFRL_AFSEL4_Msk;
    GPIOB->AFR[0] |=  (2UL << GPIO_AFRL_AFSEL4_Pos);

    /* Configure High Output Speed */
    GPIOB->OSPEEDR |= (3UL << GPIO_OSPEEDR_OSPEED4_Pos);

    /* 3. Configure Timebase for 1 kHz PWM from 170 MHz:
     *    f_PWM = f_TIM / ((PSC + 1) * (ARR + 1))
     *    f_PWM = 170,000,000 / ((3 + 1) * (42499 + 1)) = 170,000,000 / (4 * 42500) = 1000 Hz
     *    CCR1 = 21250 gives exactly 50% duty cycle (21250 / 42500)
     */
    TIM3->PSC = 3;
    TIM3->ARR = 42499;
    TIM3->CCR1 = 21250;

    /* 4. Configure Channel 1:
     *    - Output compare mode: PWM mode 1 (OC1M = 0110b)
     *    - Enable output compare preload (OC1PE = 1)
     *    - Configure as output channel (CC1S = 00b)
     */
    TIM3->CCMR1 &= ~(TIM_CCMR1_OC1M_Msk | TIM_CCMR1_CC1S_Msk);
    TIM3->CCMR1 |= (6UL << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE;

    /* 5. Enable Auto-Reload Preload (ARPE) in CR1 */
    TIM3->CR1 |= TIM_CR1_ARPE;

    /* 6. Configure Channel 1 polarity to Active High (CC1P = 0) and enable output (CC1E = 1) */
    TIM3->CCER &= ~TIM_CCER_CC1P;
    TIM3->CCER |= TIM_CCER_CC1E;

    /* 7. Generate update event to load preloaded registers into active registers */
    TIM3->EGR = TIM_EGR_UG;

    /* 8. Enable counter */
    TIM3->CR1 |= TIM_CR1_CEN;
}
```

### Hardware Clock Limits Analysis on STM32G474

#### 1. Why SYSCLK and HCLK Cannot Be Raised to 180 MHz
Operating SYSCLK and HCLK at **180 MHz** violates the electrical and functional operating specifications of the STM32G474:

* **Maximum Operating Frequency ($f_{\text{HCLK}}$, $f_{\text{PCLK1}}$, $f_{\text{PCLK2}}$)**:
  According to Table 17 ("General operating conditions") in the STM32G474 datasheet [STM32G474_Datasheet p.84], the maximum internal clock frequency for AHB ($f_{\text{HCLK}}$), APB1 ($f_{\text{PCLK1}}$), and APB2 ($f_{\text{PCLK2}}$) in **Range 1 Boost Mode** is **170 MHz**:
  $$f_{\text{HCLK,max}} = 170\text{ MHz}$$
  $$f_{\text{PCLK1,max}} = 170\text{ MHz}$$
  $$f_{\text{PCLK2,max}} = 170\text{ MHz}$$
* **PLL VCO Operating Limits ($f_{\text{VCO}}$)**:
  According to Table 46 ("PLL characteristics") in the STM32G474 datasheet [STM32G474_Datasheet p.123], the PLL VCO output frequency in Range 1 has a maximum limit of **344 MHz**:
  $$f_{\text{VCO,max}} = 344\text{ MHz}$$
  To generate a 180 MHz system clock using the minimum integer PLL output divider $R = 2$, the VCO output frequency would be:
  $$f_{\text{VCO}} = 180\text{ MHz} \times 2 = 360\text{ MHz}$$
  This exceeds the rated maximum VCO frequency ($360\text{ MHz} > 344\text{ MHz}$), which can prevent the PLL from locking or cause clock instability.

Because operating beyond 170 MHz exceeds STMicroelectronics recommended operating limits, the microcontroller is maintained at its rated maximum frequency of **170 MHz**.

---

#### 2. Peripheral Frequency Invariance at Maximum 170 MHz
Because the clock remains at the maximum valid frequency of 170 MHz ($f_{\text{HCLK}} = f_{\text{PCLK1}} = f_{\text{PCLK2}} = 170\text{ MHz}$), all peripheral frequencies remain accurate and unperturbed:

1. **USART1 Baud Rate (115200 baud)**:
   * Clock source: $f_{\text{PCLK2}} = 170\text{ MHz}$.
   * Register: `USART1->BRR = 1476` [STM32G474_RM0440 p.1755].
   * Achieved baud rate: $115\,176.15\text{ baud}$ ($-0.02\%$ error).
2. **I2C2 SCL Frequency (100 kHz Standard Mode)**:
   * Clock source: Independent internal 16 MHz HSI16 clock via `RCC_CCIPR.I2C2SEL` [STM32G474_RM0440 p.322].
   * Timing settings: Standard-mode 100 kHz configured with prescaler 3, SCL high 15, SCL low 19, setup 4, hold 2 as given in Table 360 [STM32G474_RM0440 p.1657].
   * Register: `I2C2->TIMINGR` [STM32G474_RM0440 p.1681].
   * SCL frequency remains exactly 100 kHz, completely isolated from SYSCLK.
3. **TIM3 Status LED PWM (1 kHz, 50% Duty Cycle)**:
   * Timer clock: $f_{\text{TIM\_CLK}} = f_{\text{PCLK1}} = 170\text{ MHz}$.
   * Timebase: $\text{PSC} = 3$, $\text{ARR} = 42499$ in `TIM3->ARR` [STM32G474_RM0440 p.1388], $\text{CCR1} = 21250$.
   * Frequency: $f_{\text{PWM}} = \frac{170\,000\,000}{(3 + 1) \times (42499 + 1)} = 1000.0\text{ Hz}$ ($0.0\%$ error).

```c
 * @brief  Configures the system clock to the maximum allowable 170 MHz.
 *         SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz (Range 1 Boost Mode).
 *         Note: 180 MHz exceeds the STM32G474 max rated frequency of 170 MHz
 *         (DS12288 Table 17 p.84) and the PLL VCO limit of 344 MHz (Table 46 p.123).
 */
void SystemClock_Config_Max170MHz(void)
{
    /* 1. Enable Power Controller clock and enter Range 1 Boost Mode */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 2. Configure Flash read latency: 4 WS (5 CPU cycles) for 170 MHz in Boost Mode */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY_Msk) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY_Msk) != FLASH_ACR_LATENCY_4WS) {
        /* Wait for Flash latency to take effect */
    }

    /* 3. Enable HSE oscillator (8 MHz external crystal) and wait for ready */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY)) {
        /* Wait for HSERDY */
    }

    /* 4. Configure Main PLL:
     *    Source = HSE (8 MHz)
     *    M = 2  -> f_IN = 8 MHz / 2 = 4 MHz
     *    N = 85 -> f_VCO = 4 MHz * 85 = 340 MHz (within 96-344 MHz VCO limit)
     *    R = 2  -> f_PLL_R = 340 MHz / 2 = 170 MHz
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1UL << RCC_PLLCFGR_PLLM_Pos) | /* M = 2 */
                   (85UL << RCC_PLLCFGR_PLLN_Pos) |
                   (0UL << RCC_PLLCFGR_PLLR_Pos) | /* R = 2 */
                   RCC_PLLCFGR_PLLREN;

    /* 5. Enable PLL and wait for lock */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY)) {
        /* Wait for PLLRDY */
    }

    /* 6. Intermediate AHB prescaler (/2) during system clock switch */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE_Msk) | RCC_CFGR_HPRE_DIV2;

    /* Switch system clock source to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW_Msk) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS_Msk) != RCC_CFGR_SWS_PLL) {
        /* Wait for SWS == PLL */
    }

    /* Wait for clock stabilization */
    for (__IO uint32_t i = 0; i < 200; i++) {
        __NOP();
    }

    /* Restore AHB prescaler to /1 -> HCLK = 170 MHz */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE_Msk) | RCC_CFGR_HPRE_DIV1;

    /* APB1 and APB2 prescalers = 1 -> PCLK1 = PCLK2 = 170 MHz */
    RCC->CFGR &= ~(RCC_CFGR_PPRE1_Msk | RCC_CFGR_PPRE2_Msk);
}
```
