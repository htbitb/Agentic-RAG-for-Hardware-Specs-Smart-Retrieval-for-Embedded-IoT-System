### PWM Configuration for PA0 (TIM2 Channel 1)

#### 1. Pin and Peripheral Configuration
- **Pin**: `PA0` configured in Alternate Function mode (`MODER[1:0] = 10b`) with alternate function **AF1** (`AFR[0] = 1`) for signal `TIM2_CH1` [STM32G474_Datasheet p.73].
- **Clocks**: 
  - GPIOA peripheral clock enabled via `RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN` [STM32G474_RM0440 p.306].
  - TIM2 peripheral clock enabled via `RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN` [STM32G474_RM0440 p.309].

#### 2. Timer Frequency & Duty Cycle Derivations
Given:
- Timer input clock $f_{\text{TIM}} = 170\text{ MHz}$ ($PCLK1 = 170\text{ MHz}$, APB1 prescaler = 1, so timer multiplier is 1).
- Target PWM frequency: $f_{\text{PWM}} = 1\text{ kHz} = 1000\text{ Hz}$.
- Target duty cycle: $50\%$.

Calculations:
- $\text{Total timer periods} = \frac{170\text{ MHz}}{1000\text{ Hz}} = 170{,}000$.
- TIM2 is a 32-bit general-purpose timer [STM32G474_RM0440 p.1388]. With prescaler $\text{PSC} = 0$:
  $$\text{ARR} = \frac{f_{\text{TIM}}}{(\text{PSC} + 1) \cdot f_{\text{PWM}}} - 1 = \frac{170{,}000{,}000}{1 \cdot 1000} - 1 = 169{,}999$$
  - Frequency error: $0\%$.
- For 50% duty cycle in PWM mode 1:
  $$\text{CCR1} = (\text{ARR} + 1) \cdot 50\% = 170{,}000 \cdot 0.50 = 85{,}000$$
  - Duty cycle error: $0$ percentage points.

#### 3. PWM Mode Setup
- **PWM Mode 1**: Set `OC1M[3:0] = 0110b` in `TIM2->CCMR1` (`TIM_CCMR1_OC1M_2 | TIM_CCMR1_OC1M_1`) [STM32G474_RM0440 p.1379].
- **Preload**: Set `OC1PE` in `TIM2->CCMR1` and `ARPE` in `TIM2->CR1`.
- **Output Polarity**: Active-high by keeping `CC1P = 0` in `TIM2->CCER`, enabled via `CC1E = 1` [STM32G474_RM0440 p.1385].
- **Update Event & Start**: Trigger `UG` in `TIM2->EGR` to transfer preloaded settings, then start counter via `CEN` in `TIM2->CR1` [STM32G474_RM0440 p.1366, p.1376].

### Bare-Metal C Code

```c
#include "stm32g4xx.h"

void tim2_pa0_pwm_init(void)
{
    /* 1. Enable GPIOA peripheral clock */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;

    /* 2. Configure PA0 to Alternate Function mode (MODER0 = 10b) */
    GPIOA->MODER &= ~GPIO_MODER_MODE0_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE0_Pos);

    /* 3. Map PA0 to AF1 (TIM2_CH1) */
    GPIOA->AFR[0] &= ~GPIO_AFRL_AFSEL0_Msk;
    GPIOA->AFR[0] |= (1U << GPIO_AFRL_AFSEL0_Pos);

    /* 4. Enable TIM2 peripheral clock */
    RCC->APB1ENR1 |= RCC_APB1ENR1_TIM2EN;

    /* 5. Configure time base for 1 kHz PWM with 170 MHz clock:
     *    f_PWM = f_TIM / ((PSC + 1) * (ARR + 1))
     *    1000 Hz = 170,000,000 / (1 * 170,000)
     */
    TIM2->PSC = 0U;
    TIM2->ARR = 169999U;

    /* 6. Configure 50% duty cycle: CCR1 = (ARR + 1) * 50% = 85,000 */
    TIM2->CCR1 = 85000U;

    /* 7. Configure Channel 1 as PWM mode 1 with preload enabled */
    TIM2->CCMR1 &= ~(TIM_CCMR1_OC1M_Msk | TIM_CCMR1_CC1S_Msk);
    TIM2->CCMR1 |= (6U << TIM_CCMR1_OC1M_Pos) | TIM_CCMR1_OC1PE;

    /* 8. Enable Channel 1 output, active-high polarity (CC1P = 0) */
    TIM2->CCER &= ~TIM_CCER_CC1P;
    TIM2->CCER |= TIM_CCER_CC1E;

    /* 9. Enable Auto-Reload Preload (ARPE) */
    TIM2->CR1 |= TIM_CR1_ARPE;

    /* 10. Generate an update event to load registers into shadow buffers */
    TIM2->EGR |= TIM_EGR_UG;

    /* 11. Start TIM2 counter */
    TIM2->CR1 |= TIM_CR1_CEN;
}
```

### Assistant answer 1

### Hardware Conflict & Resolution

In STM32 microcontrollers, all channels of a given general-purpose timer share the same time base: the counter prescaler (`PSC`) and auto-reload register (`ARR`) [STM32G474_RM0440 p.1387, p.1388]. Consequently, all output channels of a timer must operate at the exact same PWM frequency in standard edge-aligned PWM mode 1. 

Channel 1 of TIM2 is already running at **1 kHz** on pin PA0. Therefore, TIM2 Channel 2 cannot simultaneously generate a **50 Hz** PWM signal.

To resolve this without changing the physical pin PA1:
- As documented in the STM32G474 pinout table, **PA1** also connects to **TIM5_CH2** via alternate function **AF2** [STM32G474_Datasheet p.73].
- TIM5 is an independent 32-bit general-purpose timer on the APB1 bus [STM32G474_RM0440 p.1388].
- Using TIM5_CH2 (AF2) allows PA1 to generate the 50 Hz servo PWM while leaving the 1 kHz LED PWM on PA0 (TIM2_CH1, AF1) completely intact and operating concurrently.

### Derivations for TIM5 (50 Hz Servo PWM with 1.5 ms pulse)

- **Timer Clock**: APB1 timer clock $f_{\text{TIM}} = 170\text{ MHz}$ ($PCLK1 = 170\text{ MHz}$, prescaler = 1).
- **Target Frequency**: $f_{\text{PWM}} = 50\text{ Hz}$ (Period $T = 20\text{ ms}$).
  - Total periods: $\frac{170{,}000{,}000\text{ Hz}}{50\text{ Hz}} = 3{,}400{,}000\text{ cycles}$.
  - Setting $\text{PSC} = 0$:
    $$\text{ARR} = 3{,}400{,}000 - 1 = 3{,}399{,}999$$
    - Resulting frequency: $50.00\text{ Hz}$ ($0\%$ error).
- **Target High Pulse**: $t_{\text{high}} = 1.5\text{ ms}$ (centre position).
  - Target duty cycle: $\frac{1.5\text{ ms}}{20\text{ ms}} = 7.5\%$.
  - In edge-aligned PWM mode 1, the output is high while $\text{CNT} < \text{CCR2}$:
    $$\text{CCR2} = 1.5\text{ ms} \times 170{,}000{,}000\text{ Hz} = 255{,}000$$
    - Resulting duty cycle: $\frac{255{,}000}{3{,}400{,}000} = 7.50\%$ ($0$ percentage point error).

### Hardware Architecture & Configuration Explanation

#### 1. Hardware Conflict & Alternative Choice
- In general-purpose timers, all channels share the same prescaler (`TIMx_PSC` [STM32G474_RM0440 p.1387]) and auto-reload register (`TIMx_ARR` [STM32G474_RM0440 p.1388]). Because the frequency of all channels is determined by $\frac{f_{\text{TIM}}}{(\text{PSC} + 1)(\text{ARR} + 1)}$, a single timer cannot simultaneously output two independent frequencies (1 kHz and 50 Hz).
- While pin **PA1** can serve as `TIM2_CH2` (AF1) [STM32G474_Datasheet p.73], it also connects to **TIM5_CH2** via alternate function **AF2** [STM32G474_Datasheet p.73].
- Using **TIM5** for the servo PWM preserves the exact physical pin assignment (`PA1`), avoids disrupting the 1 kHz LED PWM already active on `PA0` (`TIM2_CH1`, AF1) [STM32G474_Datasheet p.73], and takes advantage of TIM5's 32-bit counter on the APB1 bus [STM32G474_RM0440 p.1388].

#### 2. Clock Distribution & Derivations ($f_{\text{TIM}} = 170\text{ MHz}$)
- Both TIM2 and TIM5 reside on the APB1 bus. With $PCLK1 = 170\text{ MHz}$ and an APB1 prescaler of 1, the timer kernel clocks equal $170\text{ MHz}$.
- **TIM2 (LED Driver on PA0, AF1)**:
  - Desired frequency: $1000\text{ Hz}$.
  - Counter periods: $170{,}000{,}000 / 1000 = 170{,}000$.
  - Settings: $\text{PSC} = 0$, $\text{ARR} = 169{,}999$ ($0\%$ error).
  - Duty cycle: $50\% \implies \text{CCR1} = 170{,}000 \times 0.50 = 85{,}000$ ($0$ percentage point error).
- **TIM5 (Servo on PA1, AF2)**:
  - Desired frequency: $50\text{ Hz}$ ($20\text{ ms}$ period).
  - Counter periods: $170{,}000{,}000 / 50 = 3{,}400{,}000$.
  - Settings: $\text{PSC} = 0$, $\text{ARR} = 3{,}399{,}999$ ($0\%$ error).
  - Pulse width: $1.5\text{ ms} \implies \text{CCR2} = 1.5\text{ ms} \times 170{,}000{,}000\text{ Hz} = 255{,}000$ (exactly $7.5\%$ duty cycle, $0$ percentage point error).

#### 3. Output Control
- Both channels run in **PWM Mode 1** (`OCxM = 0110b` in `TIMx_CCMR1` [STM32G474_RM0440 p.1379]), where the output is asserted active-high while the counter $\text{CNT} < \text{CCRx}$, and low otherwise.
- Preload registers are enabled (`OCxPE` in `TIMx_CCMR1` [STM32G474_RM0440 p.1379] and `ARPE` in `TIMx_CR1` [STM32G474_RM0440 p.1366]), and an initial software update event (`UG` bit in `TIMx_EGR` [STM32G474_RM0440 p.1376]) transfers all configuration values into active shadow registers before counter start (`CEN` bit in `TIMx_CR1` [STM32G474_RM0440 p.1366]).
- Output pins are enabled with active-high polarity via `CC1E = 1` and `CC2E = 1` in `TIMx_CCER` [STM32G474_RM0440 p.1385].
