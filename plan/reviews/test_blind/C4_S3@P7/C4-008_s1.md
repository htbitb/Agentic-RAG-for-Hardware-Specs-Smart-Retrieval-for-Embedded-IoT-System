### Bare-Metal USART1 Configuration (STM32G474)

#### 1. Clock and Baud Rate Calculation
- **Clock Source**: By default (`RCC->CCIPR` reset value = `0x00000000`), USART1 clock source is selected as `PCLK` (APB2 clock) [STM32G474_RM0440 p.322].
- **APB2 Clock Frequency**: With SYSCLK = 170 MHz and APB2 prescaler = 1, `f_CK` = 170 MHz.
- **Oversampling**: Oversampling by 16 (`OVER8 = 0` in `USART1_CR1`, default reset value) [STM32G474_RM0440 p.1740].
- **Baud Rate Equation**:
  $$\text{USARTDIV} = \frac{f_{CK}}{\text{Baud Rate}} = \frac{170\,000\,000}{115\,200} \approx 1475.6944$$
  Rounding to the nearest integer gives:
  $$\text{USART1->BRR} = 1476 \quad (\text{0x05C4})$$
  [STM32G474_RM0440 p.1707, p.1755].
- **Achieved Baud Rate & Error**:
  $$\text{Actual Baud} = \frac{170\,000\,000}{1476} \approx 115\,176.15\text{ baud}$$
  $$\text{Error} = \frac{115\,176.15 - 115\,200}{115\,200} \times 100\% \approx -0.0207\%$$
  This easily satisfies the ±2 % tolerance requirement.

#### 2. Pin Configuration
- **PA9 (USART1_TX)**: Alternate Function AF7 [STM32G474_Datasheet p.73].
- **PA10 (USART1_RX)**: Alternate Function AF7 [STM32G474_Datasheet p.73].
- Configuration:
  - Enable `GPIOA` clock in `RCC->AHB2ENR` [STM32G474_RM0440 p.306].
  - Set `MODER[9]` and `MODER[10]` to `0b10` (Alternate function mode) [STM32G474_RM0440 p.355].
  - Set `AFRH[9]` (`AFSEL9`) and `AFRH[10]` (`AFSEL10`) to `7` (AF7) [STM32G474_RM0440 p.360].

#### 3. USART1 Peripheral Configuration Sequence
Per RM0440 sections 40.5.5, 40.5.6, and 40.5.7:
1. Enable `USART1` peripheral clock in `RCC->APB2ENR` [STM32G474_RM0440 p.312].
2. Set baud rate register `USART1->BRR = 1476` prior to enabling USART (`UE = 1`) [STM32G474_RM0440 p.1702, p.1755].
3. Frame format: 8 data bits (`M1=0`, `M0=0`), no parity (`PCE=0`), 1 stop bit (`STOP[1:0]=00` in `USART1_CR2`), and `OVER8=0` (oversampling by 16) are the reset default values [STM32G474_RM0440 p.1740, p.1747].
4. Enable transmitter (`TE`), receiver (`RE`), and the peripheral (`UE`) in `USART1_CR1` [STM32G474_RM0440 p.1740].

```c
#include "stm32g4xx.h"

void usart1_init(void)
{
    /* 1. Enable peripheral clocks for GPIOA and USART1 */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;
    RCC->APB2ENR |= RCC_APB2ENR_USART1EN;

    /* 2. Configure PA9 (TX) and PA10 (RX) for Alternate Function 7 (AF7) */
    /* Set PA9 and PA10 mode to Alternate Function (0b10) */
    GPIOA->MODER &= ~(GPIO_MODER_MODE9_Msk | GPIO_MODER_MODE10_Msk);
    GPIOA->MODER |= (2U << GPIO_MODER_MODE9_Pos) | (2U << GPIO_MODER_MODE10_Pos);

    /* Set AF7 for PA9 (AFSEL9) and PA10 (AFSEL10) in AFRH */
    GPIOA->AFR[1] &= ~((0xFU << GPIO_AFRH_AFSEL9_Pos) | (0xFU << GPIO_AFRH_AFSEL10_Pos));
    GPIOA->AFR[1] |= ((7U << GPIO_AFRH_AFSEL9_Pos) | (7U << GPIO_AFRH_AFSEL10_Pos));

    /* 3. Program the baud rate register before enabling USART1
     *    f_PCLK2 = 170 MHz, OVER8 = 0 (oversampling by 16)
     *    BRR = 170,000,000 / 115,200 = 1475.694 -> 1476 (0x05C4)
     *    Achieved baud rate = 115,176.15 baud (-0.02% error)
     */
    USART1->BRR = 1476U;

    /* 4. Configure frame format: 8 data bits, no parity, 1 stop bit.
     *    USART1->CR2 reset value has STOP[1:0] = 0b00 (1 stop bit).
     *    USART1->CR1 reset value has M0 = 0, M1 = 0 (8 data bits), PCE = 0 (parity disabled),
     *    and OVER8 = 0 (oversampling by 16).
     */
    USART1->CR2 &= ~USART_CR2_STOP_Msk;

    /* 5. Enable transmitter (TE), receiver (RE), and USART peripheral (UE) */
    USART1->CR1 = USART_CR1_TE | USART_CR1_RE | USART_CR1_UE;
}
```

#### 2. Clock Source and `I2C_TIMINGR` Derivation
- **Kernel Clock**: By default (`RCC->CCIPR` reset value = `0x00000000`), the I2C2 kernel clock `f_I2CCLK` is selected as `PCLK1` (APB1 clock) [STM32G474_RM0440 p.322].
- With SYSCLK = 170 MHz and APB1 prescaler = 1, `f_I2CCLK` = 170 MHz ($t_\text{I2CCLK} \approx 5.882\text{ ns}$).
- **Table 358 Fast-Mode Requirements** [STM32G474_RM0440 p.1648]:
  - $t_\text{LOW} \ge 1.3\ \mu\text{s}$
  - $t_\text{HIGH} \ge 0.6\ \mu\text{s}$
- **Timing Calculations**:
  - Setting $\text{PRESC} = 15$ ($0\text{xF}$):
    $$t_\text{PRESC} = (\text{PRESC} + 1) \times t_\text{I2CCLK} = 16 \times 5.8824\text{ ns} \approx 94.118\text{ ns}$$
  - Setting $\text{SCLL} = 14$ ($0\text{x0E}$):
    $$t_\text{SCLL} = (\text{SCLL} + 1) \times t_\text{PRESC} = 15 \times 94.118\text{ ns} \approx 1.412\ \mu\text{s} \ge 1.3\ \mu\text{s}$$
  - Setting $\text{SCLH} = 8$ ($0\text{x08}$):
    $$t_\text{SCLH} = (\text{SCLH} + 1) \times t_\text{PRESC} = 9 \times 94.118\text{ ns} \approx 0.847\ \mu\text{s} \ge 0.6\ \mu\text{s}$$
  - Setting $\text{SDADEL} = 2$ ($0\text{x2}$):
    $$t_\text{SDADEL} = \text{SDADEL} \times t_\text{PRESC} = 2 \times 94.118\text{ ns} \approx 188.2\text{ ns}$$
  - Setting $\text{SCLDEL} = 3$ ($0\text{x3}$):
    $$t_\text{SCLDEL} = (\text{SCLDEL} + 1) \times t_\text{PRESC} = 4 \times 94.118\text{ ns} \approx 376.5\text{ ns}$$
  - Resulting `I2C_TIMINGR` register value:
    $$\text{TIMINGR} = (15\ll 28) \mid (3\ll 20) \mid (2\ll 16) \mid (8\ll 8) \mid 14 = \mathtt{0xF032080E}$$

```c
void i2c2_init(void)
{
    /* 1. Enable peripheral clocks for GPIOA, GPIOC, and I2C2 */
    RCC->AHB2ENR  |= RCC_AHB2ENR_GPIOAEN | RCC_AHB2ENR_GPIOCEN;
    RCC->APB1ENR1 |= RCC_APB1ENR1_I2C2EN;

    /* 2. Configure PA8 as I2C2_SDA (AF4, Open-Drain, Pull-Up, High Speed) */
    GPIOA->MODER &= ~GPIO_MODER_MODE8_Msk;
    GPIOA->MODER |= (2U << GPIO_MODER_MODE8_Pos);          /* Alternate function mode */
    GPIOA->OTYPER |= GPIO_OTYPER_OT8;                      /* Open-drain */
    GPIOA->PUPDR &= ~GPIO_PUPDR_PUPD8_Msk;
    GPIOA->PUPDR |= (1U << GPIO_PUPDR_PUPD8_Pos);          /* Pull-up */
    GPIOA->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED8_Pos);    /* Very high speed */
    GPIOA->AFR[1] &= ~(0xFU << GPIO_AFRH_AFSEL8_Pos);
    GPIOA->AFR[1] |= (4U << GPIO_AFRH_AFSEL8_Pos);         /* AF4: I2C2_SDA */

    /* 3. Configure PC4 as I2C2_SCL (AF4, Open-Drain, Pull-Up, High Speed)
     *    Note: PA9 was requested for SCL, but PA9 is already in use by USART1_TX.
     *    PC4 is the alternative pin for I2C2_SCL on LQFP64.
     */
    GPIOC->MODER &= ~GPIO_MODER_MODE4_Msk;
    GPIOC->MODER |= (2U << GPIO_MODER_MODE4_Pos);          /* Alternate function mode */
    GPIOC->OTYPER |= GPIO_OTYPER_OT4;                      /* Open-drain */
    GPIOC->PUPDR &= ~GPIO_PUPDR_PUPD4_Msk;
    GPIOC->PUPDR |= (1U << GPIO_PUPDR_PUPD4_Pos);          /* Pull-up */
    GPIOC->OSPEEDR |= (3U << GPIO_OSPEEDR_OSPEED4_Pos);    /* Very high speed */
    GPIOC->AFR[0] &= ~(0xFU << GPIO_AFRL_AFSEL4_Pos);
    GPIOC->AFR[0] |= (4U << GPIO_AFRL_AFSEL4_Pos);         /* AF4: I2C2_SCL */

    /* 4. Disable I2C2 peripheral before writing TIMINGR (RM0440 p.1675) */
    I2C2->CR1 &= ~I2C_CR1_PE;

    /* 5. Program I2C_TIMINGR for Fast-mode (400 kHz) with f_I2CCLK = 170 MHz:
     *    PRESC  = 15 (0xF) -> tPRESC = (15 + 1) * 5.882 ns = 94.12 ns
     *    SCLDEL = 3  (0x3) -> tSCLDEL = (3 + 1) * 94.12 ns = 376.5 ns
     *    SDADEL = 2  (0x2) -> tSDADEL = 2 * 94.12 ns = 188.2 ns
     *    SCLH   = 8  (0x8) -> tSCLH = (8 + 1) * 94.12 ns = 847 ns (>= 0.6 us)
     *    SCLL   = 14 (0xE) -> tSCLL = (14 + 1) * 94.12 ns = 1412 ns (>= 1.3 us)
     *    TIMINGR = 0xF032080E
     */
    I2C2->TIMINGR = (15U << I2C_TIMINGR_PRESC_Pos)  |
                    (3U  << I2C_TIMINGR_SCLDEL_Pos) |
                    (2U  << I2C_TIMINGR_SDADEL_Pos) |
                    (8U  << I2C_TIMINGR_SCLH_Pos)   |
                    (14U << I2C_TIMINGR_SCLL_Pos);

    /* 6. Enable the I2C2 peripheral */
    I2C2->CR1 |= I2C_CR1_PE;
}
```

### Explanation of the Initialization Sequence

1. **Clock Enabling (`RCC`)**:
   - `RCC->AHB2ENR`: Enables GPIO ports A and C [STM32G474_RM0440 p.306].
   - `RCC->APB1ENR1`: Enables the `I2C2` peripheral clock [STM32G474_RM0440 p.309].
   - `RCC->APB2ENR`: Enables the `USART1` peripheral clock [STM32G474_RM0440 p.312].

2. **GPIO Configuration**:
   - **PA9 (`USART1_TX`) and PA10 (`USART1_RX`)**: Configured in Alternate Function mode (`MODER = 0b10`) and mapped to `AF7` in `GPIOA->AFR[1]` [STM32G474_Datasheet p.73].
   - **PA8 (`I2C2_SDA`) & PC4 (`I2C2_SCL`)**: Configured in Alternate Function mode (`MODER = 0b10`) mapped to `AF4` (`AFRH8 = 4`, `AFRL4 = 4`), set to open-drain output (`OTYPER = 1`) with internal pull-ups enabled (`PUPDR = 0b01`) and very high speed [STM32G474_Datasheet p.73, STM32G474_Datasheet p.75].
   - *Pin Allocation Decision*: Pin PA9 was requested for SCL in Message 2, but PA9 was already committed to `USART1_TX`. To prevent bus contention and retain full-duplex UART communication, `I2C2_SCL` was assigned to **PC4** (pin 22 on LQFP64), which provides `AF4` hardware multiplexing for `I2C2_SCL` [STM32G474_Datasheet p.75].

3. **USART1 Configuration**:
   - The baud rate generator uses APB2 clock $f_\text{CK} = 170\text{ MHz}$ with oversampling by 16 (`OVER8 = 0`).
   - Baud rate divisor calculation:
     $$\text{USARTDIV} = \frac{170\,000\,000}{115\,200} \approx 1475.694 \implies \text{BRR} = 1476 \quad (\mathtt{0x05C4})$$
     producing an actual baud rate of $115\,176.15\text{ baud}$ (error of $-0.02\%$, well within $\pm 2\%$) [STM32G474_RM0440 p.1708].
   - The baud rate register `BRR` and configuration registers are programmed prior to setting `UE = 1`, satisfying the reception/transmission initialization sequence [STM32G474_RM0440 p.1702].
   - `USART1_CR1` enables the transmitter (`TE`), receiver (`RE`), and the peripheral (`UE`).

4. **I2C2 Configuration**:
   - `I2C2` is held disabled (`PE = 0`) while programming `I2C2_TIMINGR` [STM32G474_RM0440 p.1681].
   - Driven by $f_\text{I2CCLK} = 170\text{ MHz}$ ($t_\text{I2CCLK} \approx 5.882\text{ ns}$), prescaler $\text{PRESC}=15$ scales the internal timer tick to $t_\text{PRESC} = 16 \times 5.882\text{ ns} = 94.12\text{ ns}$.
   - High time: $t_\text{SCLH} = (8 + 1) \times 94.12\text{ ns} = 847.1\text{ ns} \ge 0.6\ \mu\text{s}$ [STM32G474_RM0440 p.1648].
   - Low time: $t_\text{SCLL} = (14 + 1) \times 94.12\text{ ns} = 1411.8\text{ ns} \ge 1.3\ \mu\text{s}$ [STM32G474_RM0440 p.1648].
   - Data setup and hold delays ($\text{SCLDEL}=3 \implies 376.5\text{ ns}$, $\text{SDADEL}=2 \implies 188.2\text{ ns}$) meet the Table 358 Fast-mode specifications [STM32G474_RM0440 p.1648].
   - Finally, `PE = 1` activates the controller for bus operations.
