### Clock Configuration: STM32G474 SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz

To configure the STM32G474 from its default reset state (16 MHz HSI16) to 170 MHz using the 8 MHz HSE crystal oscillator:

1. **Power & Dynamic Voltage Scaling**:
   - To operate up to 170 MHz, the chip must be in **Range 1 Boost mode** [STM32G474_RM0440 p.232].
   - At reset, the voltage scaling is Range 1 normal mode (`VOS[1:0] = 01b` in `PWR_CR1`, `R1MODE = 1` in `PWR_CR5`) [STM32G474_RM0440 p.253, p.267].
   - First enable the power interface clock via `RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN` [STM32G474_RM0440 p.309].
   - Clear the `R1MODE` bit in `PWR->CR5` (`PWR->CR5 &= ~PWR_CR5_R1MODE`) to enter Boost mode [STM32G474_RM0440 p.267].

2. **Flash Wait States (Latency)**:
   - According to Table 9 (category 3 devices) / Table 19 in RM0440, for $136\text{ MHz} < HCLK \le 170\text{ MHz}$ in Range 1 Boost mode, Flash read access requires **4 wait states** (`LATENCY = 4WS` / 5 CPU cycles) [STM32G474_RM0440 p.98, p.151].
   - Configure `FLASH->ACR` latency to 4 wait states and wait until read back as 4 wait states.

3. **HSE Oscillator**:
   - Enable HSE via `RCC->CR |= RCC_CR_HSEON` [STM32G474_RM0440 p.287].
   - Busy-wait until `RCC_CR_HSERDY` is set.

4. **PLL Configuration**:
   - Input clock: $f_{\text{OSC\_IN}} = 8\text{ MHz}$.
   - Divisor $M = 2$ (`PLLM[3:0] = 0001b` in `RCC_PLLCFGR`), giving $f_{\text{PLL\_IN}} = 8 / 2 = 4\text{ MHz}$ (valid range: 2.66 MHz to 16 MHz) [STM32G474_Datasheet p.123].
   - Multiplier $N = 85$ (`PLLN[6:0] = 85`), giving $f_{\text{VCO}} = 4 \times 85 = 340\text{ MHz}$ (valid range in Range 1: 96 MHz to 344 MHz) [STM32G474_Datasheet p.123].
   - Main PLL 'R' divider $R = 2$ (`PLLR[1:0] = 00b`), giving $f_{\text{PLL\_R}} = 340 / 2 = 170\text{ MHz}$ [STM32G474_RM0440 p.291].
   - Enable PLL 'R' output clock (`PLLREN = 1`).
   - Accuracy: $8\text{ MHz} / 2 \times 85 / 2 = 170.000\text{ MHz}$ (exact, 0.0% error).

5. **PLL Enable & Clock Switching Transition**:
   - Enable the PLL via `RCC->CR |= RCC_CR_PLLON` and poll `RCC_CR_PLLRDY` [STM32G474_RM0440 p.287].
   - **Switching condition**: RM0440 Section 7.2.7 requires that when switching from HSE/HSI16 to PLL with HCLK > 80 MHz (and especially > 150 MHz), an intermediate transition state dividing HCLK by 2 (`HPRE = 1000b` / `/2`) should be used, followed by a wait of at least $1\,\mu\text{s}$ before switching HPRE back to 1 [STM32G474_RM0440 p.232, p.279].
   - Switch system clock `SW[1:0] = 11b` (PLL) and poll `SWS[1:0] == 11b` (`RCC_CFGR_SWS_PLL`) [STM32G474_RM0440 p.289].
   - Restore AHB prescaler `HPRE` to 1 (`RCC_CFGR_HPRE_DIV1`).
   - APB1 and APB2 prescalers remain at reset default of 1 (`PPRE1 = 000b`, `PPRE2 = 000b`), resulting in $HCLK = PCLK1 = PCLK2 = 170\text{ MHz}$.

### C Code Implementation

```c
#include "stm32g4xx.h"

/**
 * @brief Configure SYSCLK = HCLK = PCLK1 = PCLK2 = 170 MHz using HSE (8 MHz) and PLL.
 */
void SystemClock_Config(void)
{
    /* 1. Enable Power Control clock and switch regulator to Range 1 Boost mode */
    RCC->APB1ENR1 |= RCC_APB1ENR1_PWREN;
    PWR->CR5 &= ~PWR_CR5_R1MODE;

    /* 2. Configure Flash memory access latency to 4 wait states for 170 MHz (Range 1 Boost) */
    FLASH->ACR = (FLASH->ACR & ~FLASH_ACR_LATENCY) | FLASH_ACR_LATENCY_4WS;
    while ((FLASH->ACR & FLASH_ACR_LATENCY) != FLASH_ACR_LATENCY_4WS) {
        /* Wait for Flash latency update to take effect */
    }

    /* 3. Enable HSE oscillator (8 MHz crystal) */
    RCC->CR |= RCC_CR_HSEON;
    while (!(RCC->CR & RCC_CR_HSERDY)) {
        /* Wait for HSE to be ready */
    }

    /* 4. Configure PLL:
     *    Source = HSE (8 MHz)
     *    PLLM   = 2 (8 MHz / 2 = 4 MHz VCO input)
     *    PLLN   = 85 (4 MHz * 85 = 340 MHz VCO output)
     *    PLLR   = 2 (340 MHz / 2 = 170 MHz PLLCLK)
     *    PLLREN = 1 (Enable PLL 'R' output for SYSCLK)
     */
    RCC->PLLCFGR = RCC_PLLCFGR_PLLSRC_HSE |
                   (1U << RCC_PLLCFGR_PLLM_Pos) |
                   (85U << RCC_PLLCFGR_PLLN_Pos) |
                   RCC_PLLCFGR_PLLREN;

    /* 5. Enable PLL and wait until locked */
    RCC->CR |= RCC_CR_PLLON;
    while (!(RCC->CR & RCC_CR_PLLRDY)) {
        /* Wait for PLL to lock */
    }

    /* 6. Intermediate transition state: set AHB prescaler to /2 before switching to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV2;

    /* 7. Switch system clock source to PLL */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_SW) | RCC_CFGR_SW_PLL;
    while ((RCC->CFGR & RCC_CFGR_SWS) != RCC_CFGR_SWS_PLL) {
        /* Wait for system clock switch to PLL */
    }

    /* Wait at least 1 us in transition state */
    for (volatile int i = 0; i < 100; i++) {
        __NOP();
    }

    /* 8. Restore AHB prescaler to /1 -> HCLK = SYSCLK = 170 MHz */
    RCC->CFGR = (RCC->CFGR & ~RCC_CFGR_HPRE) | RCC_CFGR_HPRE_DIV1;
}
```

### Clock Frequency Constraint Note (200 MHz vs 170 MHz Limit)

The STM32G474 datasheet specifies the maximum allowable operating frequency for SYSCLK, HCLK, and PCLK as **170 MHz** in Range 1 Boost mode [STM32G474_Datasheet p.84]. Furthermore:
- The PLL VCO output frequency range in Range 1 is **96 MHz to 344 MHz** [STM32G474_Datasheet p.123]. Generating 200 MHz with the minimum divider ($R = 2$) would require a VCO frequency of $400\text{ MHz}$, exceeding the maximum VCO limit of $344\text{ MHz}$.
- Running the STM32G474 at 200 MHz violates the chip's Recommended Operating Conditions.

Consequently, SYSCLK is kept at the maximum rated **170 MHz** (Range 1 Boost mode). At 170 MHz, a 100 kHz PWM signal yields an ARR of 1699, providing **1,700 discrete duty-cycle steps** (10.73 bits of resolution), which is exceptionally fine for switching power converter control.

```c
/**
 * @brief Configure PA8 as TIM1_CH1 outputting 100 kHz PWM at 50% duty cycle.
 *        Edge-aligned PWM Mode 1, active high, no dead time.
 */
void PWM_PA8_TIM1_CH1_Init(void)
{
    /* 1. Enable GPIOA clock */
    RCC->AHB2ENR |= RCC_AHB2ENR_GPIOAEN;

    /* 2. Configure PA8 to Alternate Function 6 (TIM1_CH1) */
    GPIOA->MODER &= ~(3U << (8 * 2));
    GPIOA->MODER |= (2U << (8 * 2)); /* AF mode */

    GPIOA->AFR[1] &= ~(0xFU << ((8 - 8) * 4));
    GPIOA->AFR[1] |= (6U << ((8 - 8) * 4)); /* AF6 */

    GPIOA->OSPEEDR |= (3U << (8 * 2)); /* Very high speed */

    /* 3. Enable TIM1 peripheral clock */
    RCC->APB2ENR |= RCC_APB2ENR_TIM1EN;

    /* 4. Configure period and duty cycle:
     *    TIM1CLK = 170 MHz
     *    PSC = 0 -> timer ticks at 170 MHz
     *    ARR = 1699 -> period = (1699 + 1) / 170 MHz = 10 us (100 kHz)
     *    CCR1 = 850 -> duty = 850 / 1700 = 50.0%
     */
    TIM1->PSC = 0;
    TIM1->ARR = 1699;
    TIM1->CCR1 = 850;

    /* 5. Channel 1: PWM Mode 1 (OC1M = 0110b), preload enable (OC1PE = 1) */
    TIM1->CCMR1 &= ~TIM_CCMR1_OC1M;
    TIM1->CCMR1 |= (TIM_CCMR1_OC1M_1 | TIM_CCMR1_OC1M_2 | TIM_CCMR1_OC1PE);

    /* 6. Channel 1 output enable, active high (CC1P = 0) */
    TIM1->CCER &= ~TIM_CCER_CC1P;
    TIM1->CCER |= TIM_CCER_CC1E;

    /* 7. Auto-reload preload enable */
    TIM1->CR1 |= TIM_CR1_ARPE;

    /* 8. Main output enable (MOE) for advanced timer TIM1 */
    TIM1->BDTR |= TIM_BDTR_MOE;

    /* 9. Generate update event to transfer preloaded ARR and CCR1 values */
    TIM1->EGR |= TIM_EGR_UG;

    /* 10. Start counter */
    TIM1->CR1 |= TIM_CR1_CEN;
}
```

### Technical Explanation

1. **Clock Configuration & 170 MHz Maximum Limit**:
   - The STM32G474 datasheet specifies the maximum operating frequency for SYSCLK, HCLK, and PCLK as **170 MHz** in Range 1 Boost mode [STM32G474_Datasheet p.84]. Furthermore, the PLL VCO output frequency limit in Range 1 is **344 MHz** [STM32G474_Datasheet p.123]. Raising SYSCLK to 200 MHz would violate recommended operating conditions and exceed the VCO range ($400\text{ MHz}$ would be required for $R=2$). Therefore, SYSCLK is kept at the maximum rated 170 MHz.
   - Range 1 Boost mode is entered by clearing `R1MODE` in `PWR->CR5` (`PWR_CR5 &= ~PWR_CR5_R1MODE`) [STM32G474_RM0440 p.232, p.267].
   - Per RM0440 Table 38, transitioning to SYSCLK > 150 MHz requires setting the AHB prescaler to `/2`, switching `SW` to PLL, waiting at least $1\,\mu\text{s}$, and then restoring `HPRE` to `/1` [STM32G474_RM0440 p.233].
   - At 170 MHz in Range 1 Boost mode, Flash read accesses require 4 wait states (`FLASH_ACR_LATENCY_4WS`, 5 CPU cycles) [STM32G474_RM0440 p.98].
   - PLL settings with 8 MHz HSE crystal:
     $$f_{\text{VCO\_IN}} = \frac{8\text{ MHz}}{2} = 4\text{ MHz}, \quad f_{\text{VCO}} = 4\text{ MHz} \times 85 = 340\text{ MHz}, \quad f_{\text{PLL\_R}} = \frac{340\text{ MHz}}{2} = 170.000\text{ MHz}$$
     This satisfies all PLL limits ($f_{\text{PLL\_IN}} \in [2.66, 16]\text{ MHz}$, $f_{\text{VCO\_OUT}} \in [96, 344]\text{ MHz}$) [STM32G474_Datasheet p.123].

2. **PA8 Pin Multiplexing**:
   - Pin PA8 connects to `TIM1_CH1` via Alternate Function 6 (`AF6`) [STM32G474_Datasheet p.73].
   - `GPIOA->MODER` is set to `10b` (Alternate Function), and `AFRH` (pin 8) is set to `0110b` (`AF6`).

3. **TIM1 PWM Setup**:
   - With APB2 prescaler = 1, `TIM1CLK` is 170 MHz.
   - For a 100 kHz PWM frequency with `PSC = 0`:
     $$\text{ARR} = \frac{170{,}000{,}000\text{ Hz}}{100{,}000\text{ Hz} \times 1} - 1 = 1699$$
   - For 50.0% duty cycle:
     $$\text{CCR1} = \frac{50}{100} \times (\text{ARR} + 1) = \frac{1700}{2} = 850$$
     This provides 1,700 discrete duty steps (10.73 bits of resolution).
   - `TIM1->BDTR |= TIM_BDTR_MOE` sets the Main Output Enable bit, which is required on advanced timers (TIM1, TIM8, TIM20) to connect the output compare signal to the physical pin [STM32G474_RM0440 p.1270].
   - Generating an update event via `TIM1->EGR |= TIM_EGR_UG` transfers the preloaded ARR and CCR1 values to their active shadow registers immediately before starting the counter with `CEN = 1`.
